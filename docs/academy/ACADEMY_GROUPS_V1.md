# 동아리·학생회·학내 집단 운영 v1

2026-10-25. 정적 조직 도감의 정의와 회차별 집단 운영 상태를 구분한다. 기존 영향력·직급·세계 시간·이동·활동·성장·기억 엔진을 복제하지 않았다.

## 실제 구현

- 정식 동아리12종: 검술연구부, 전투마법연구회, 정령교류회, 연금술연구부, 마도공학제작부, 전술연구회, 역사탐구회, 문예부, 음악예술부, 요리연구회, 천문관측회, 탐험연구회. 목적/활동/관련 숙련도/시설/요일/시간/정원/심사 방식이 다르다.
- 기존 `academy-council` 학생회와 시험 대비 스터디·귀족 학생 사교 모임·자유 연구 모임. 초기에는 빈 운영 정의이며 실제 학생의 신청으로 채워진다. 고정 인물의 정식 설정에 가입/직책을 추가하지 않는다.
- NPC 관심 점수: 시드 개인차, 실제 숙련도, 성향/특성/전문 분야/문화 취향, 개인 목표, 이미 아는 회원에 대한 신뢰, 조직의 실제 활동 평판. 자율 가입은 부담 예산2개, 수동 가입은 개수 자체보다 시간/의무/정원 조건을 검사한다. 일부 학생은 미가입을 유지한다.
- 신청/정원 초과 선발/숙련도·추천·종합 조건/거절 사유, 탈퇴와 재가입 이력. 현재 회차의 실제 교수만 지도 교수로 배정한다.
- 회장·부회장·운영/행사/학생 의견 직책과 임기 이력. 같은 직책의 이전 임기는 종료하고 새 임기를 기록한다. 학적 상실은 캐릭터 변경을 관찰해 탈퇴/직책 종료하며, 임기 만료는 정확한 예약 시각에 처리한다.
- 일일 예약과 주간 운영 평가. 실제 NPC 임원의 안건, 실제 회의 참여자의 찬반, 공동 목표, 조직 간 협력/경쟁 의견, 학교에 제출한 건의는 승인 대기로 구분한다. 안건 반대만으로 관계를 깎지 않는다.
- 시설 예약 시간/초대 회원 충돌 검사. 실제 일과표에 우선순위60의 중단 가능한 임시 일정을 넣고 수업/시험/근무를 우선한다. 이동/출입은 기존 엔진이 담당한다. 장소에 실제 도착한 뒤 활동한 시간만 성과에 집계한다. 개별 XP/관계/욕구 효과는 기존 활동·상호작용 엔진이 한 번 적용한다.
- 공동 활동은 기존 수락/거절/같은 장소/현재 활동 검사를 사용한다. 거절되었다고 성공 처리하거나 사람을 순간이동시키지 않는다. 물건/돈/공연/전투 결과를 새로 만들어내지 않는다.
- 선거: 공고 → 등록 → 운동 → 투표 → 결과 고정. 일반 학생회 선거 공고는3월/8월5일이라는 조정 가능한 운영 기본값이다. 확정 세계관의 시험/축제 날짜로 취급하지 않는다. 투표는 유권자1명1표, 기간/후보 자격 검증, 시드 동점 처리. 후보의 공개 공약/활동과 본인의 관계만 사용한다. 개별 투표는 결과 발표 후에도 일반 조회에서 숨긴다.
- 플레이어는 직접 출마/투표한다. 당선 후에는 회장직 수락 팝업에서 결정할 때까지 공통 시간 진행을 중단한다. 정기 활동 참가를 제외한 중요한 결정을 자동 확정하지 않는다.
- 실제 같은 장소에 모인 신뢰 관계의 학생들이 비공식 모임을 제안할 수 있다. NPC의 자율 결성은 실제 완료한 협력 경험/공통 관심/최소 인원/쿨다운/조직 상한을 추가 검사한다. 활동 후 정식 등록 요청과 실제 교수의 승인/거절, 빈 집단의 자연 해산을 지원한다. 기존 기억/인간관계/집단 ID는 유지한다.
- 실제 상태 변경28종을 명시적인 `AcademyGroupChanged` 도메인 사건과 세계 이벤트 카탈로그에 연결한다. 직접 관련 인물만 개인 기억을 받으며 모든 NPC에게 조직 내부 정보를 방송하지 않는다. 전체28종이 자연 발생한 장기 통계라는 뜻은 아니다.
- 실제 플레이 상단의 ‘동아리·학생회’, 공통 캐릭터 상세의 가입 집단, 설정집 도감/테스트 진입, 기존 격리 시뮬레이터 관찰·개입과 공통 로그를 연결했다. 일반 플레이와 개발자 관찰을 구분한다.

## 저장·성능

`AiSandboxSave.groups`는 선택 필드다. 전체 세계/플레이 슬롯/JSON에 포함되며, 구형 저장에는 명시적 초기화만 허용한다. 중복 회원/잘못된 회원·활동·시설·선거/목표 범위 등을 검사한다. RNG는 세계 시드/안정 ID 기반 해시를 사용하며 UI 조회는 세계를 진행하지 않는다.

일일 관리와 정기 활동·이동·선거·임기 경계만 예약한다. 최근 로그600개, 종료 활동120개, 종료 선거12개, 종료 안건120개, 완료 목표12개를 보존하고 미종료 상태와 회원/임원 이력은 유지한다. 조직이 삽입한 종료 임시 일정은14일 뒤 정의만 정리하고 실제 활동 실행 이력은 기존 엔진에 남긴다.

100명 전체AI, Windows/Node22.18.0, 시드 `group-full-ai-100`, 생성 직후 제국력427년3월1일08:00~09:00: **2,861ms**. 생성·UI 렌더링은 제외한 엔진 측정이며1시간 목표300ms/경고1000ms를 초과했다. 활동 회원20건, 총16개 집단, AI 판단872회. 다른 기존 측정과 환경/시드가 달라 조직 기능의 순수 증가 비용으로 단정할 수 없다.1일/7일 응답 목표와 장기 안정성을 입증하지 않는다.30/360일 실행은 이번 작업에서 하지 않았다.

## 파일과 API

- `types/academyGroup.ts`, `data/academyGroups/{index,events}.ts`: 정의·회원/임원·목표·활동·신청/안건·선거/투표·당사자 수락·로그/저장 계약.
- `systems/academyGroups.ts`: `apply/selectMembers/withdraw`, `appoint/resign/assignAdvisor`, `planMeeting/attend`, `announceElection/registerCandidate/vote/acceptLeadership`, `form/requestRegistration/reviewRegistration`, `propose/opine/dissolve`, `save/diagnose`.
- `systems/{npcAi,aiSandbox,worldSimulation,npcSchedules,npcMemory}.ts`, `types/{actionEffects,worldSimulation}.ts`, `data/worldEvents/index.ts`: 선택적 어댑터·라이프사이클·중앙 명령·도메인 기록·저장/복원.
- `components/AcademyGroupsPanel.{tsx,css}`, `Gameplay.tsx`, `Simulation.tsx`, `CharacterStatusPanel.tsx`, `AcademySurvival.tsx`: 플레이/설정집/격리 관찰/공통 상세.
- `scripts/test-academy-groups{,-browser}.mjs`, `diagnose-academy-groups.mjs`, `academy-validation-registry.mjs`, `package.json`: 계약·UI·짧은 성능·검사 선택.
- `data/features/index.ts`, `PROJECT_CONTEXT.md`, `IMPLEMENTATION_STATUS.md`: 실제 범위와 검증 상태.

## 검증과 제한

새 계약: 중복 가입/임원, 시설 충돌, 의무 일정 우선, 기존 위치 보존, 같은 장소/신뢰 기반 결성, 교수 자격, 해산 후 관계 보존, 실제 공동 훈련/기억, 선거 단계/비밀 투표/중복 방지/결과 고정, 플레이어 수락 시각 중단, 저장 복원/구형 저장,120분 일괄 대 분할 동등성을 검사한다. UI 스모크는 가입/목록/고정 뷰포트/모바일/런타임 오류를 검사한다.

검사 원본은 `test-results/academy-groups/`에 보존한다. 중앙 저장/도메인 계약을 만져 자동 선택은 Extended로 승격되었다. 이미 통과한 검사는 반복하지 않고 실패한 항목과 미실행 꼬리만 재개한다. 기존 생활 기능의 누적 변경으로 발견한 검사 가정은 실제 계약에 맞춰 보완했다: 도메인 정의 수103, 생활 전용 상호작용의 거주 엔진 없는 요청 거절, 중앙광장 출발 시간 제한, 실제 도착을 기다리는 학사 후속 사건, SSR 검사에서 CSS를 빈 로더로 처리(실제 CSS는 빌드/브라우저 검사). 기존 검사를 삭제하지 않았다.

검사 결과: 재개 기록을 합친 모델·정적 검사35종 전부 통과, 짧은 통합 시나리오9종 전부 통과(`verification-summary.json`). 마지막 무참석 활동 취소 보완 뒤 전용 계약·타입·빌드를 다시 검사했다. 빌드13.93초, 산출물 참조202개 검사 통과. 새 파일 ESLint 통과. UI 스모크의 가입 신청/뷰포트/모바일 검사 통과. 기존 번들 크기 경고는 남아 있다. 세계관 검사의 과거 고정33간선 가정도 현재 실제 연결 카탈로그와 모든 간선 값 보존 검사로 바꿨다. 초기 실패 로그와 이어서 실행한 결과를 모두 보존하며,35개 검사를 한 번에 처음부터 다시 실행했다는 의미는 아니다.

부분/미구현: 정식 제작·공연/탐험 결과, 축제 전체 실행/학교 행정 승인, 모든 기존 수업·약속을 아우르는 전역 시설 예약, 모든28사건의 자연 발생, 자동 졸업/신입생 충원,30/360일 세대 교체와 장기 성능. 학교 건의가 제출되었다고 시설 운영 시간이나 학사 규칙을 자동 변경하지 않는다. 조직 간 합동 일정은 공통 예약 API로 실행 가능하지만 복잡한 자율 행사 기획은 후속 범위다.
