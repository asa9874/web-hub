# 경제·화폐·학생 생활 v1

## 실제 구현

기존 아이템100종/소유권 원장·공통 효과 트랜잭션·세계 시계·일과·플레이어 직접 행동·학사 확정 성적·개별 기억·선택적 통합 저장을 재사용했다. 기존 화폐/지갑/상점 매매 엔진은 없었다. 아이템 `baseValue`는 동일 등급의 내부 평가값이었으며 통화 계약이 아니므로, 실제 거래의 동화 가격은 학생 가격표에 명시했다. 기존 물건의 등급·성능·명성·고유성은 바꾸지 않았다.

- 화폐: 정수C,100C=1S,100S=1G. 별도 인벤토리 화폐 물건을 만들지 않는다.
- 기본 생활: 기존 무료 기숙사·식사·정규 교육·기본 시설/의료 행동 유지. 돈을0으로 만들어도 기본 생활 행동에 결제하지 않는다. 추가 회복 서비스/개인실 유료화는 아직 없다.
- 배경5개: 풍족/안정/평범/어려움/무후원. 초기 범위300~800S/120~300S/40~120S/10~40S/0~10S. 월 지원200/100/40/10/0S. 플레이어가 새 게임에서 선택하며 능력·영향력과 독립이다. NPC는 독립 시드 스트림으로 배정한다.
- 상점3개: 학생 식당 매점(8~21시), 도서관 판매대(9~20시), 중앙시장 장비·재료점(9~19시). 기존22종의 일반 물건을 유한 재고로 최초 배치한다. 물품이 떨어지면 다른 물건을 생성해 대신 팔지 않는다.
- 가격: 간식15~30C/입문 교재12~15S/목검8S/철검65S/기초 재료3~5S/일반 선물3~5S 등. 일반 매입은40% 이하이고 상태·조잡 품질에 따라 감소한다. 상점 매입금도 유한하다.
- 거래: 실제 장소/출입/시간/자금·예약/대여/소유/소지 한도 검증. 동기 원자 처리로 돈·물건·상점 자금이 함께 바뀐다. UI 구매/판매 후5분 진행, 이동은 기존 경로를 따른다.
- 정기 수입: 월초 용돈·생활 지원 장학15S. 성적 우수 장학40S는 실제 학사 확정 `excellent`를 다음 월초에 확인하여 학기당 한 번 지급한다. 장학금 경쟁·지원서·연구 후원은 미구현이다.
- 일자리3개: 도서관 자료 정리2시간4S(INT15), 식당 보조2시간3.5S(VIT15), 훈련장 관리2시간5S(STR20). 정원2/3/2. 실제 현장 근무2시간 완료에만 보수를 지급한다. 수업과 겹치거나 긴급 욕구가 있으면 시작할 수 없다. 일정 중단·이탈은 보수 없음이다.
- UI: 생활비 메뉴, 좌측 소지금 바로가기, 상점/일자리·장학금/수입·지출3보기. 상품 그림·가격·재고·보유 수·조건·장소 이동·상세 팝업, 근무 시간/보수/미충족 사유를 구조화했다. 타인의 재산·원장은 일반 플레이어에게 공개하지 않는다.

## 아이디어 노트 대비 범위 판단

문서의 우선순위에 따라 학생 경제v1을 구현했다. 기존 장소를 판매대와 장비점의 실제 위치로 사용하고 새 상점 NPC/국가/시설을 임의로 생성하지 않았다. 무료 일상 식사는 개별 거래 없이 기존 욕구 회복을 사용한다. 유료 물품은 기존 장비·소비·선물 효과로 이어지며 구매 자체에 성장/성적/호감도 보너스를 부여하지 않는다.

NPC도 계정·배경·정기 지원·장학 자격과 같은 거래/근무 API를 갖지만, 자동으로 구직·저축·구매·공동 비용 분담을 판단하는 정책은v2다. 경제 사건16예시를 텍스트만 등록해 실행된 것으로 표시하지 않았다. 기존 선물 수락/취향/관계 보상 제한은 유지한다.

## 저장·결정성·성능

`AiSandboxSave.economy` 선택 필드에 계정·거래24건/인물·누적액·상점 자금·현재/최근 근무·다음 월 지급 시점·학기 장학 워터마크·일련번호를 저장한다. 물품 재고는 기존 ItemSave의 실제 인스턴스다. 로드에서 재고나 초기 자산을 다시 지급하지 않는다. 구형 세이브의 명시적 연결은 현재 이후 지원만 시작한다. 경제 정의·조회·상점 탭 전환은 RNG를 소비하지 않는다.

월초 경계와 활성 근무 종료를 예약하며 기존 시간 단계에서 **활성 근무만** 현장 시간을 누적한다. 월초에 지원 대상 계정을 한 번 순회하고, 일상 식사에 새 거래를 남기지 않는다. 모든 인물×상품을 매분 평가하지 않는다. 거래24건/계정·근무128건 상한이며 누적 수입/지출·실제 소유권은 보존한다. 유한 재고의 정기 재입고/지역 생산·장기 수급 균형은 후속이다. 이번 결과로100NPC7일1~3초 달성을 주장하지 않는다.

## 검증 기록

- 전용 엔진: 정수·환산, 실제 재고/소유 이전, 현장/잔액/소지 한도, 결제 후 의도적인 오류에서 두 원장 복구, 매매 차액,플레이어·NPC의 실제120분 근무/정원/중단/중간 저장·복원, 무일푼 학생의 무료 실제 식사, 폐점 후 거래 거부, 월초 생활 지원/중복 지급 방지, 비공개 기억, 구형 선택 저장 검사.
- UI/플레이 저장: 실제 새 플레이 세션·선택 배경·패널SSR·전체 세이브 복원. SSR은 실제 브라우저 조작 검증과 구분한다.
- 관련 기존 아이템·플레이어·기억 검사 통과. 기존 아이템 검사의100NPC10분은 경제가 없는 격리 원장 검사이며 경제 장기 성능 결과가 아니다.
- 브라우저 검증: IAB 탭 연결 시간 초과로 실제 클릭/시각/모바일 검수를 완료하지 못했다. 정책으로 막힌 오류 페이지를 우회하지 않았다. 코드와 SSR만으로 시각적 완성도를 검증했다고 보고하지 않는다.
- 원본 로그/결과: `test-results/academy-economy/`의 contracts/ui/items/player/memory/types-final/lint/build 로그와 results.json. 타입·최종 빌드/기능 검사 결과는 아래에 기록했다.
