# NPC 시뮬레이션 LOD·지역 활성화 v1

2026-10-23. 기준 저장소의 기존 미커밋 변경을 보존했다. 아이디어 노트의 계산 방식보다 실제 공통 엔진 계약을 우선했다.

## 실제 구현

- 같은 캐릭터와 세계 시계 위에 0~3 정밀도, 별도 중요도/영속성, 플레이어 그래프 반경·유예, 중요 참여자 보호를 추가했다. 관리자를 같은 AI에 중복 연결할 수 없다.
- LOD1은 원거리 실제 일과·이동을 계속 실행한다. LOD2/3은 필수/임시 일정과 기존 진행 활동을 존중한다. 원거리 중요 사건은 같은 세계 시각에 실제 참여자만 정밀 활성화한다.
- 활성 영역은 아카데미/제국 수도/마왕성 및 명시적으로 정의한 기존 장소다. 계층 전체 활성화/가상 외부 지도/제국-마계 통로/순간 위치 복원은 추가하지 않았다.
- 집계 인구와 실제 생성 NPC를 분리했다. 지역/슬롯/세계 시드로 개별화하며 동일 인물 재사용, 인구 초과/ID 충돌 차단, 실제 관계·기억 보존을 지원한다.
- AiProvider 실제 조합, 통합 스냅샷/구형 필드 없는 저장, 공통 캐릭터 개발 상세, 기능 노트29개 시스템/190개 항목에 연결했다.
- 상단 시뮬레이션 화면은 기존 세계의 독립 복제본이다. 10/50/100명 기존 생성기, 정상 플레이어/NPC 이동, 명시적 강제 배치, 정밀도/지역 명령, 인구·주민, 시간·인원·전환/명령 로그, 공통 상세 팝업, 초기화를 제공한다.

## 아이디어 노트 대비 설계 판단

- 지역별로 NPC 사본이나 별도 시계를 만들지 않고 기존 엔진에 정밀도 정책을 주입했다. 전투·조직·학사 엔진을 새로 가정하지 않았다.
- 상세 물리 이동은 유지했다. 활성 구간/도착 시각은 기존 이동 엔진이 관리한다. 반경 계산은 기본 도보 시간·지형을 사용하고 출입 허가/인지 범위를 부여하지 않는다.
- 일반 교류·장소 선택 빈도 차이는 허용된 LOD 추상화다. 정밀 정책의 전체 미시 이력과 일치한다고 주장하지 않는다. 확정된 사건·상호작용·약속·기억·효과는 공통 실행 경로를 유지한다.
- 주민의 문화권/직업 분포가 확정되지 않은 경우 새 공식 설정을 만들지 않는다. 생성기는 호출자가 기존 데이터에 맞게 제공한다. 개발 UI의 주민은 명시적인 샌드박스 기준 인물이다.
- 완전 lazy 상태/위치 복원 대신 공통 상태와 욕구 적분을 유지했다. 존재하지 않는 식사·대화·성장·전투 결과를 만들지 않기 위한 보수적 v1이다.

## 성능 측정

환경: win32 10.0.26200, Intel(R) Core(TM) Ultra 7 258V, 논리 CPU 8, Node v22.18.0. 시드 lod-benchmark-v1. 브라우저 UI 시간과 별개의 엔진 측정이다. 새 세계/학생100명/4학년·전공·성장 유형 무작위, 동일 초기 조건에서 전체 정밀 정책과 LOD 정책을 비교했다. 모든 시간/이동/일과/욕구/목표/상호작용/효과/기억/세계 사건 엔진은 연결되어 있다. 인구 집계를 AI 인원에 포함하지 않는다.

각1시간2회, 순서를 교차했다. 판단 횟수는 해당 진행 구간의 새 판단이며 같은 시드의 각 반복에서 동일했다.

| 시나리오 | 전체 정밀 평균/최대 | LOD 평균/최대 | 판단 횟수 전체/LOD |
| --- | ---: | ---: | ---: |
| 근거리 수업 | 529 / 565ms | 515 / 533ms | 539 / 539 |
| 원거리 수업 | 483 / 490ms | 373 / 379ms | 539 / 439 |
| 원거리 교류 다수 | 839 / 871ms | 621 / 624ms | 451 / 354 |
| 시험 안내 월 | 461 / 464ms | 352 / 355ms | 539 / 439 |
| 세계 사건 | 597 / 597ms | 413 / 413ms | 461 / 361 |

원거리8시간은 각1회: 전체 정밀 4.964초 → LOD 3.268초. **LOD도8시간 경고2초를 초과한다.** 전체 정밀1시간 목표0.3초와 장기 목표는 미달/미검증이다. 근거리 전체 정밀 판단은 유지했으며 작은 실행 시간 차이를 개선으로 확정하지 않는다.

시험 안내 월은 실제 시험/채점/행사 플레이가 아니다. 교류 시나리오는 기존 요청·수락·완료 규칙을 사용한20개 준비 요청이며, 진행 중 상세 참여자는 강등하지 않았다. 세계 사건 시나리오는 실제 rival-challenge와 후속 카탈로그 처리를 포함한다. 실제 사건/효과/기억/관계 변화/LOD 분포는 [측정 JSON](simulation-lod-v1.json)에 기록했다. 결과 차이를 동일 게임 결과의 캐시 최적화라고 표시하지 않는다.

추가한 비용 절감은 원거리 후보 수집·재판단 간격, 플레이어 구간별 반경 캐시, 변경 NPC 집합과 활성 유예 예약만 확인하는 관리자다. 휴면 전체를 매 틱 재분류하지 않는다. 기존 공통 욕구 적분/목표 검사/효과 트랜잭션 백업/물리 일과 비용은 남아 있다. 이전 프로파일의 전체 상태 백업 병목을 근거 없이 제거하지 않았다.

원본: test-results/academy-lod/benchmark-{60,480}/results.json. 이전 체크포인트 측정은 initial-results.json으로 보존했다. 측정 후 중복 관리자/로드 검증 방어, 기본 주민 시드의 기존 AI 시드 파생, 중요 사건 참여자 조회 인덱스를 추가했다. 참여자 목록 계약은 재검증했으며 이 후속 변경의 추가 속도 효과는 측정하지 않았다. 측정 번들의 SHA256은 보존 JSON에 기록했다.

## 미완료·미검증

- 100명30일/360일, 실제1,000명 휴면 객체,10년 누적 데이터, 오래된 저장 성능, 대표 환경7일1~3초, 브라우저 장기 응답 성능은 검증하지 않았다. 짧은8시간도 경고를 넘으므로 장기 실행을 반복하지 않았다.
- 완전한 lazy 구간 적분/지역 스트리밍·NPC 상태 언로드는 후속 최적화다. 기존 지속 인물을 버리거나 기억 상한을 낮추지 않았다.
- 성적·진급·졸업·조직 선거·정식/headless 전투·플레이어 중요 선택 자동 중단은 선행 공통 실행 계약이 없다. 이번에 더미 결과를 추가하지 않았다.
