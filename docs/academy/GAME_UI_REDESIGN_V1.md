# 게임 UI/UX 리디자인 v1

2026-10-26. 요청한 상용 PC 게임 수준을 목표로 화면 구조와 디자인 언어를 개편했다. 이는 출시 품질 인증이나 모든 콘텐츠/해상도의 완전 검증을 의미하지 않는다.

P0은 탐색/화면 경계/주요 조작, P1은 본문 대비/정보 분리, P2는 작은 전환/장식으로 처리했다. 모든 화면을 똑같은 카드 격자로 만들지 않았다.

## 디자인 언어

-잉크색 `#131d20`:고정 HUD/측면 메뉴/행동/공통 팝업.
-기록지 `#ede7d9`와 짙은 갈색 본문:장시간 읽는 정보 화면.
-적갈색 `#84483f`:선택·주요 목적,황동 `#c6ac78`:시간/강조,녹청 `#456a65`:생활/지도.
-장소 제목/인물/숫자/본문/출처를 서로 다른 크기로 사용한다. 기존 한글 서체와 원화만 재사용하며 새 외부 폰트/라이브러리를 추가하지 않았다.
-아이콘은 작은 인라인 SVG. 명칭/선택 상태/키보드 초점도 함께 제공하고 색만으로 구분하지 않는다.

## 구조·조작

-화면은 고정 viewport,상태/본문/로그/행동은 각각 내부 스크롤.메뉴도 작은 높이에서 자체 스크롤한다.
-현재 상황에서는 상태/장면/행동을 함께 본다.학사·지도·장비 등에서는 행동 패널을 접고 본문에 공간을 준다.상단 행동 버튼으로 **동일한 폼**을 서랍으로 연다.
-기존 장소/인물/아이템/학사/기록/설정집/저장 메뉴를 모두 유지한다.메뉴 버튼의 접근성 이름은 기존 전체 명칭을 유지하고,메뉴 전환 때 본문을 위로 되돌린다.
-Alt+1~9 메뉴 이동,Esc 행동 서랍 닫기.입력 중이거나 모달이 열려 있으면 메뉴 단축키를 실행하지 않는다.
-실제 다음 일정까지 진행 버튼은 기존 `session.advance`를 호출한다.중요한 선택/실제 이동/진행 중 제한을 우회하지 않는다.
-로그 이동 필터의 기본 OFF와 기존 유형/펼침을 유지한다.필터 UI만 필요할 때 열도록 이동했다.
-인물 창은 공통 CharacterStatusPanel의 선택적 UI 슬롯을 사용한다.플레이어/NPC 상태 계산을 복제하지 않았다.
-모달은 기존 닫기/Esc/초점 복귀/독립 스크롤/중첩 설명을 유지한다.전투 중 임의 닫기 제한도 그대로다.사용 가능한 전투 명령은 분류 표시를 붙인 공통 격자로 배치하여 빈 분류 행을 줄이고,사용 불가 행동은 기존 펼침 안에 유지한다.
-배경 미등록/로딩 실패 시에도 장면 크기를 유지한다.새 그림을 만들거나 기존 승인된 그림체를 교체하지 않았다.
-선택/호버/눌림/진행 중 표시와 짧은 팝업 전환만 추가했다.감소된 모션 설정을 존중한다.

## 코드·성능

`components/AcademyGameDesign.css`가 디자인 토큰/화면 구성/반응형/공통 컨트롤을 소유한다. `GameNavigation.tsx`와 `gameNavigationData.ts`가 내비게이션 표현과 메타데이터를 분리한다. Gameplay/CharacterStatusPanel/NpcActionPanel/AcademicPanel/AcademySurvival의 표시 구조를 조정했다.

시계·NPC AI·LOD·기억·정보·전투 규칙·학사 엔진·저장 스키마/RNG는 유지했다.예외적으로 전투 시작의 장소 검사를 상태 생성 전에 수행하도록 보완했다.새 폴링/타이머/장식용 시뮬레이션을 추가하지 않았다.기존 병목이나7일 진행 성능 목표가 해결됐다고 주장하지 않는다.이번에는 장기 시뮬레이션/성능 벤치를 반복하지 않았다.

## 화면 검증 중 발견한 기존 오류

도서관 실전 공격은 `getStartAvailability`에서는 허용됐지만,실제 시작 후 공통 `combat_exchange` 실행기의 장소 태그 검사에서 실패했다.전투/소유권이 먼저 생성되는 순서여서 실패 뒤 상태가 남을 수 있었다.

`systems/combat.ts`의 시작 검증에서 공통 활동 카탈로그의 동일한 장소 조건을 미리 검사한다.허용 장소나 전투 규칙을 새로 제한/완화하지 않고,원래 실패하던 요청을 상태 변경 전에 거부한다.버튼도 같은 API를 사용하므로 실제 불가능 사유를 먼저 표시한다.

`test-academy-combat.mjs`에 거부된 시작 전후 전체 스냅샷 동일성을 추가했고,전투 계약·NPC 행동 계약을 최종 변경으로 다시 실행해 통과했다.최초 자동22건은 이 보완 이전 실행이며 최종 보완의 새 검증과 구분한다.
