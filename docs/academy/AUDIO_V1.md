# Procedural SFX v1

Web Audio API만 사용하며 외부 효과음 파일·추가 오디오 라이브러리·BGM은 도입하지 않는다. 세계 엔진, 시드 RNG, 저장 데이터, 명령 실행은 변경하지 않는다.

## 음색과 실제 연결

종의 사인파, 현/나무의 삼각파, 짧은 종이·주사위 마찰 노이즈를 공통 음계로 구성한다. 9큐: click, select, page, event, growth, gift, dice, success, failure. 기본 길이 약0.08~0.96초이며 국소 순환 피치 변주를 사용한다. 소리 재생은 결과 생성·판정이나 시간 진행을 기다리게 하지 않는다.

- 공통 React 루트: 실제 버튼/선택/메뉴 입력(키보드 포함). 비활성화·입력란 타이핑·슬라이더 연속 조작은 제외.
- 새 게임: 자질 공개/입학 결과/실패 장면. 자질 재생성은 세계 생성 규칙 그대로.
- EventSceneDialog: 기존 비주얼/텍스트 공통 사건 장면. 문장 타이핑마다 재생하지 않는다.
- 플레이어의 새 pending 성장/중요 선택: 식별자 기준 한 번 알림. 일반 NPC의 매 행동을 울리지 않는다.
- 주사위: 실제 수동 판정 연출 시작/실제 표시 결과 성공·실패. 자동 전투의 매 판정에는 붙이지 않는다.

## 오디오 UX/수명

새 게임의 효과음 설정 및 두 모드의 저장·설정에 동일 패널을 제공한다. 볼륨/음소거/중요 순간만(조작·주사위 타격음 제외)과 미리 듣기. `academy.audio.v1` localStorage에 브라우저 설정으로 유지, 게임 세이브와 독립. 저장 불가·AudioContext 미지원·오디오 차단은 무음으로 진행한다.

첫 포인터/Enter/Space 입력에서만 AudioContext를 생성·재개한다. 렌더/자동 로드에서 소리가 시작되지 않는다. 숨김 탭에서 중단하고 다음 입력으로 재개한다. 음소거 시 예약 소스를 중단한다. 조작45ms/동일큐120ms 제한, 최대30이하 동시 소스, 끝난 소스·gain 연결 해제, 화면 전체 종료 시 context.close. 오디오 대기/타이머를 게임 실행기에 추가하지 않는다. 첫 브라우저 허용 제스처에서는 정책에 따라 첫 클릭음이 빠질 수 있다.

## 이번 검증

- `node scripts/test-academy-audio.mjs`: 9종 서로 다른 score/유한 envelope/변주·지연 생성·설정·반복 제한·중요음 우선·중단/해제·미지원 fallback. 실제 Web Audio의 start→stop 순서도 검사.
- `npx tsc -b`, `npx vite build`: 관련 UI를 포함한 루트 빌드. 기존 chunk 크기 경고는 유지.
- Chrome 실제 OfflineAudioContext:9종 모두 비영점 파형·peak0.0203~0.0325(기본 볼륨45%)·클리핑 없음. 최초 노드 예약 오류를 실제 검사로 발견 후 수정했다.
- 브라우저의 실제 공통 설정 패널에서 음소거/미리 듣기 비활성 및 reload 설정 유지 확인. 별도 QA 페이지는 `test-results/academy-audio/preview.html`이며 도메인 사건 발생을 모사하는 페이지가 아니다.
- 로그: `test-results/academy-audio-{test,types,build}.log`. 오디오만 변경하여 장기NPC성능/전체세계회귀는 실행하지 않는다.

## 남은 범위

상용 음질 달성을 단정하지 않는다. 스피커·헤드폰별 청감/상대 음량 튜닝, 소재별 전투 타격·환경음·개별 기프트 고유 효과음은 후속. BGM과 음성은 제외. 자연스러운 현장 소리가 필요한 항목은 `SoundCue` 재생 진입점에 추후 파일 source를 혼합할 수 있으며 지금 파일을 가짜 합성음으로 대체하지 않는다. 모든 개별 세계 사건/전투 타격에 전용 큐를 붙인 상태는 아니다.

관련 회귀: 기존 test-academy-visual-mode(실제 휴식/공유 세션/저장), test-academy-dice(판정 투영/실제 전투 동등/저장) 통과. 기능 레지스트리54시스템/495기능 및 검증 도구107검사 등록 확인. 브라우저 실제 새 게임 화면에서도 설정 패널을 확인했으며 settings.png와 browser-waveforms.txt에 보존했다.
