# 실제 판정 기반 3D 주사위 연출 v1

## 규칙과 연출의 경계

공통 엔진은 능력·숙련·제한된 합산 보정에 -10~+9 정수 운을 더한다. 이20개 값을 D20 1~20에 일대일 대응하고 `눈−11`로 설명한다. 기존 `resolveCheck`나 확률·피해·자원·시간 규칙을 수정하지 않았다. 눈20 자체를 대성공으로 만들지 않으며 기존 outcome을 그대로 표시한다. 기프트가 운을 변경하면 원본 주사위와 실제 운 보정을 분리한다.

새 물리/RNG 엔진이나 외부3D 라이브러리를 추가하지 않았다. Canvas에 실제 정이십면체의 삼각면·회전·조명·깊이 순서·라벨을 투영한다. 착지는 감쇠 반동의 연출이며 물리 시뮬레이션이 아니다. 스핀·클릭·드래그 강도는 판정에 영향을 주지 않는다.

## 실제 작동 범위

- 비주얼/텍스트 전투가 같은 `DiceProvider`를 사용한다. 플레이어의 공격/관찰/회복/도주처럼 실제 check가 있는 선택에만 연결한다. 방어/대기/항복에 허위 주사위를 만들지 않는다.
- 굴리기 전에는 돌아갈 수 있고 아직 행동을 실행하지 않는다. 버튼/주사위 영역을 놓으면 기존 `combatTurn`을1회 실행한 뒤 새로 기록된 플레이어 자신의 check만 읽는다. 결과창에서 계속하기 전까지 기존 전투창은 모달 뒤에 둔다. 자동전투/대량NPC/장기 시간 진행은 개별 주사위를 띄우지 않는다.
- 기본 중요 판정은 실전/important 전투/대련 첫 공방, 적극 연출은 직접 선택한 모든 지원 판정이다. 결과만 설정은 자동 실행 후 숫자만 확인한다. 빠른 설정/빠른 결과 공개와 reduced-motion을 지원한다.
- 실제 D20, 능력/숙련/합산 보정, 최종 내 점수, 기존 성공/부분성공/실패 결과를 표시한다. 대항 상대의 실제 능력/기프트/내부 점수는 공개하지 않는다. 고정 난이도 판정만 실제 목표 점수를 표시한다.
- 설정은 `academy.dice.presentation.v1`로 기존 세이브와 별도로 저장한다. 비주얼 기록 보관/텍스트 저장·이어하기에서 접근한다. 망가진 설정은 기본값으로 복구한다.
- D100은 이미 기록·공개된 원본 roll을100구간/두D10으로 표시하는 어댑터 기반만 구현했다. 판정 결과를 눈에서 다시 계산하지 않는다. 현재 실제 입학 상대 추첨/시험 선택 판정은 없으므로 연결했다고 주장하지 않는다. 이벤트 내부 감사 정보를 읽어 플레이어에게 공개하지 않는다.

## 결정성·저장·성능

주사위 UI 상태는 세계 저장을 바꾸지 않는다. 기존 엔진이 완료한 라운드/check는 기존 전투 저장에 그대로 남으며 불러오기나 결과 표시로 재실행하지 않는다. 연출 도중 브라우저를 닫으면 마지막으로 실제 저장한 세계가 복원된다. 애니메이션의 정확한 중간 프레임을 저장/재개하는 기능은 없다. 아직 실행하지 않은 선택을 굴리지 않고 닫으면 행동도 일어나지 않는다.

연출 중에만 작은 Canvas의 requestAnimationFrame을 사용하고 종료/언마운트에서 정리한다. NPC의 백그라운드 판정에 전역 listener나 매분 추가 탐색을 달지 않았다. 새 장기 성능 벤치마크는 수행하지 않았다.

## 검증

- `test:academy-dice`:20개 운값/D20 전수 대응, 기프트 전·후 운 구분, 상대 정보 제외, D100 경계, 설정 파싱, 준비한 실제 전투1라운드의 일반 명령/연출 어댑터 결과 동등성, 저장 후 재추첨 없음.
- 전투 fixture는 직접 제어/개발 배치로 준비한2참가자에 대해 기존 엔진의 실제 후보와 라운드를 사용한다. 출입·점유·의무 일정 검사를 엔진에서 제거하지 않았다.
- 기존 `test-academy-combat.mjs`, 타입 검사, 루트 Vite 빌드, 기능 노트54시스템/493항목 검사 통과. 기존 대형 청크 경고 유지.
- 브라우저1280×720: 실제 게임의 장소/점유 제약과 대련장 이동 확인. 그 시점에 상대가 없어 게임 화면에서 전투 진입은 완주하지 않았다. 별도 QA HTML에서 통합 검사의 실제 확정 기록을 읽기 전용 재생해 수동 굴림/착지/결과만 설정의 동일D20 14·운+3·최종48.4·실패를 확인했다. 이 QA 재생은 실제 게임 명령 입력의 브라우저 완주 검사를 대체하지 않는다. 결과 제목이 autofocus 스크롤로 가려지는 문제를 수정하고 재캡처했다. 이미지 `test-results/academy-dice/d20-result.png`. 원본 `test-results/academy-dice-{test,combat,types,build}.log`.

## 제한·후속

공식 시험·실험·비전투 도전·세계 이벤트의 자동 다이스 연결은 미구현이다. D100은 어댑터/메시만 있고 실제 발생 경로가 없다. 자동전투의 중요한 단일 판정을 별도로 고르는 정책과 판정 내역 UI 재열람은 후속이다. 플레이어가 알 수 없는 미래 분기·추첨표를 연출용으로 노출하지 않는다. 모든 기능이 상용 수준으로 검증되었다고 판정하지 않는다.
