## 생활 사건28종

귀환, 자기 방 취침, 기상, 늦은 기상, 아침 식사, 늦은 아침 식사, 방 휴식, 휴게실 휴식, 방 복습, 야간 독서, 정리 완료, 세탁, 위생 준비, 편지 작성, 산책, 첫 룸메이트 교류, 아침 인사, 밤 대화, 룸메이트 공동 공부, 공동 학습, 공동 식사, 휴게실 만남, 고민 상담, 화해 시도, 야간 소음 조정, 정리 분담, 취미 활동, 새로운 생활 취향.

정의는 `data/dailyLife/events.ts`, 실제 증거 감지는 `systems/dailyLife.ts`. 일부 명칭은 아이디어 노트의 더 넓은 사건을 실제 가능한 경험으로 바꿨다. 예를 들어 화해는 ‘시도 완료’이며 용서나 관계 개선을 보장하지 않는다. 편지 작성은 원격 배달이나 고향 소식을 생성하지 않는다. 실제 활동/공동 활동의 원래 효과가 결과이며 이벤트에서 같은 보상을 다시 지급하지 않는다.

일반 활동은 개인별 집계/기록에 보존하고 세계 이벤트는 대표 신호로 제한한다. 사소한 활동 때문에 모든NPC의 일과를 강제로 바꾸거나 플레이를 매번 중단하지 않는다. 중요한 사건은 기존 지식·중요도·개입 대기를 따른다.

## 주요 API·파일

- `types/dailyLife.ts`, `data/dailyLife/{index,events,README}`: 배정·방/침대·선호·집계·저장 계약.
- `systems/dailyLife.ts`: `assignResidence`, `endResidence`, `setExternalResidence`, `grantVisit`, `getRoommates`, `getIntents`, `canInteract`, `getSummary`, `save`.
- `systems/aiSandbox.ts`, `npcAi.ts`, `worldSimulation.ts`: 선택적 저장·로드/연결 생명주기, 공통 후보 평가, 개발 명령.
- `systems/locationWorld.ts`, `npcSchedules.ts`, `schedulePlanning.ts`: 전용 거주 참조와 거주 변경 일정의 버전 구분. 실제 이동은 기존 엔진.
- `data/locations/index.ts`, `data/schedules/index.ts`, `data/motivations/index.ts`, `data/interactions/index.ts`, `data/worldEvents/index.ts`: 기존 카탈로그 확장.
- `components/DailyLifePanel.tsx`, `DailyLifeCatalog.tsx`, `DailyLife.css`: 공통 생활 화면/도감/인물 상세. `Gameplay`, `Simulation`, `CharacterStatusPanel`, `AcademySurvival`에 연결.
- `data/features/index.ts`, `scripts/academy-validation-registry.mjs`, `package.json`: 실제 구현·검증 범위와 자동 검사 선택 연결.

## 검증·성능

원본 로그/JSON/스크린샷은 `test-results/academy-daily-life*`에 보존한다.

- 전용 계약: 방/침대/배정/원자적 만실 거부/실제 경로/방문 시간/룸메이트 변경/기존 감정/실제 청소·수면·공동 공부/세계 사건·기억/저장·중복 침대 거부/구형 저장/시드 재현/60분 단일·분할 동등성.
- 하루 스모크:10NPC 전체AI, LOD해제, 실제 수면/식사/수업/생활 수행. 하루 단일 진행과 시간별24회 진행의 정규화 상태가 일치.
-100NPC 전체AI1시간: LOD해제, 실제100AI 등록·기억/관계/상호작용/이벤트 유지, 위치·활동·저장 불변식 확인. Windows/Node22의 신선한 세계 엔진 단독 측정이며 UI 응답이나7일 성능을 증명하지 않는다.
- 관찰된 대표 실행은10NPC 하루 약5.99초,100NPC1시간 약1.47초. 후자는 목표0.3초/경고1초를 초과한다. 단일 실행이므로 평균·최악 성능 또는 개선률로 일반화하지 않는다. 정확한 최종 수치는 `smoke.json`을 따른다.
- 기존 장소/읽기 스냅샷/세계 이벤트/통합 세계/관찰 플레이/플레이어 생활 계약, 변경 화면·모바일·샌드박스 격리, 타입/정적 검사/빌드.

자동 영향 분석은 중앙 저장/일과 연결로 Extended를 제안한다. 전체브라우저/장기 실행을 기계적으로 확대하지 않고 위 직접 영향 검사부터 수행했다. 이번 성능 경고 때문에30일/360일로 확대하지 않았다.28종 모두의 장기 발생 빈도·관계 포화·10년 저장 안정성은 미검증이다.

## 제한·후속

- 원격 고향 소식/편지 배달, 실물 선물·소비 아이템·생활비, 청소 당번·벌점·방 꾸미기·동아리는 미구현.
- 기존 문화 활동/선물 콘텐츠는 계속 사용할 수 있으나 실물 재고를 새로 생성하지 않는다.
- ‘학술도시 외출’이나 귀향은 현재 실제 경로가 있는 장소만 가능. 마계와 제국 사이 임의 통로 없음.
-104실의 정적 초기 공급이 소진되면 pending. 자동 건물 증축이나 무한 방 생성 없음.
-28개 증거 분기의 모든 조합과 장기 발생률을 전수 검증한 것은 아니다. 특히 소음·생활 갈등·취향 변화의 장기 빈도는 후속 통합 검증 대상이다.
- 성능은 아직 목표 미달이다. 생활 정리는 날짜별 증분 처리, 거주 인원은 방별 인덱스, 일반 활동은 제한된 집계로 구현했다. 기존 경로/AI/전체 세계 스케줄 비용의 대규모 최적화는 이번 기능에 섞지 않았다.

최종 짧은 실행에서 기억 엔진 오류는 두 시나리오 모두0건이다. 생활 경험은 공통 도메인 사건 `DailyLifeExperienced`와 검증 가능한 `daily-*` 개인 주장으로 저장한다. 기존 약속·문화 주장과 구분하며 새 기록도 동일한 공개/출처/망각 정책을 따른다.100명1시간의 실제 판단 수는 712회, 해당 세계 사건 생성 4건, 생활 로그 120건이다. 이는 플레이 전 과정의 평균치가 아닌 이번 시나리오 결과다.
