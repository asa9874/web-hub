# 인물 원화·이벤트 창·게임 화면 정리 v1

2026-10-26. 현재 플레이 화면을 대상으로 적용했다. 시간·동의·소유·전투·선택 엔진을 새로 만들지 않았다.

## 적용 내용

- 로그의 중요/주의/대화·교류/성과/정보/이동 필터. 기본은 이동만 끔. 최근 기록과 전체 기록에서 같은 선택을 사용하며, 대화 전문은 접힌 로그를 펼쳐 읽는다. 개발용 대화 도구는 유지하고 일반 플레이의 별도 대화·사회생활 탭은 제거했다.
- `EventSceneDialog`: 실제 장소 배경, 인물 스탠딩, 표정, 인물 대사, 시스템 설명, 선택지/확인. 들어오는 응답·물건 제안, 나가는 전투 확인과 상호작용 결과가 같은 틀을 사용한다. 취소하면 실행하지 않고, 실행 시에는 기존 API가 현재 위치·동의·조건을 다시 검사한다.
- 결과 창은 저장·이어하기의 **내 상호작용 결과를 이벤트 창으로 표시**에서 끌 수 있다. 이 설정은 브라우저 UI 설정이며 결과·로그·필수 선택을 생략하지 않는다. 전투 확인은 이 설정과 무관하다.
- 실제 완료/거절/물품 원장을 읽어 표시한다. 대사를 위해 효과를 추가하지 않는다. 질문/답변이 친밀한 인사로 대체되던 표현 오류도 수정했다.
- 전투는 배경 위 양측 스탠딩과 이름, 바로 아래 체력/기력/마력. 기존 하단 인물 카드는 제거하고 행동 영역을 넓혔다. 수동/자동 전투·대련 내구도와 실제 체력의 구분은 유지한다.
- 관찰한 장비는 2행×5열. 실제 슬롯8개와 비활성 확장 공간2개이며 새 장비 슬롯을 엔진에 꾸며 넣지 않았다. 비공개 소지품을 노출하지 않는다.
- 학사 개요는 중복 요약을 제거하고 학기별 달력 카드/평가 시점/학점 기준을 정렬했다. 주요 인물 카드와 공통 상세에서 초상화를 사용한다. 전체 문서/개발 도구의 서술을 모두 다시 작성한 작업은 아니다.

## 원화와 로딩

- 고정15명 + 눈을 머리카락 그림자로 가린 남녀 모브2명 = **17종**. 동일한 남색·금색 테두리·버건디 리본 교복 규격. 기존 외모의 머리색·안경·뿔·수인 귀/꼬리·드워프 체형을 반영했다.
- 공통 표정: `neutral`, `happy`, `serious`, `worried`. 실제 대사의 감정을4표정으로 매핑하고 전투는 진지/걱정을 사용한다.
- Built-in **image_gen**으로17개 투명4표정 원화를 생성했다. `character-art-prompts.json`에 프롬프트/원본 위치를 보존했다. 파일 자르기/축소/압축만 Pillow 스크립트로 수행했으며, 생성된 그림을 코드로 대체하지 않았다.
- 런타임 파일: `public/assets/academy/characters/<key>/{neutral,happy,serious,worried,portrait}.webp`. **85개, 3,384,806바이트(약3.23MiB)**. 스탠딩384×800, 초상160×160. 초상 지연 로딩, 스탠딩은 열린 창의 표정만 요청. 모든 표정을 한 번에 내려받지 않는다.
- 이미지가 없거나 실패해도 같은 크기의 대체 영역을 유지한다. 생성 아틀라스의 투명한 인물 경계를 찾아 분리해 인물 위치 편차로 인한 잘림을 방지했다.
- 재패키징: `python scripts/prepare-academy-character-art.py` (Pillow 필요, 원본 PNG 접근 필요). QA 모음/용량 보고: `test-results/academy-presentation/`.

## 고정 인물 능력

세레나의 기존 용사 구성은 보존했다. 나머지14명에 개별 능력치·주 숙련8/보조7, 고유 특성14개·고유 기프트14개와 어울리는 기존 보조 능력을 연결했다. 서술만 있는 자동 승리/제작/순간이동 기능을 새 능력으로 주장하지 않는다. 새 고유 능력의 판정 보정은 공통 효과/판정 경로를 사용한다. 서명 능력은 일반 NPC 선천 추첨 풀에 들어가지 않는다.

공통 영향력 공식·시드 `presentation` 기준: 세레나726, 아델리아597, 루미엘616, 리제트616, 니아613, 카밀라640, 미엘602, 에스텔620, 피오나603, 노엘609, 브리나628, 엘리시아635, 테아614, 비올레타632, 이리스615. 고정 인물이라는 이유의 숨은 보정·허위 직위/칭호는 없다.

**새 게임 초기 구성**이다. 이전 저장의 인물 능력·성장치를 덮어쓰지 않으며, 불러오기 자체로 특성/기프트를 추가 지급하지 않는다. 기존 저장 일괄 재조정은 이 작업에 포함하지 않았다.

## 검증과 범위

- 자동 영향 선택 Standard:35개 통과·실패0·브라우저32개 미실행. 원본 `test-results/academy-presentation/validation/report.json`. 이 전체를 통과라고 표시하지 않는다.
- 별도 콘텐츠 계약:15인 유효 참조/실제 고유 기프트 판정 적용/구형 저장 무변경/85개 파일 용량. 카탈로그419특성·417기프트 검증 통과.
- 관련 대화·고정 학생 단위/연동, 질문 응답, 저장 재개, 비공개 전문과 공통 NPC 행동을 확인했다. 최종 타입·빌드·대상 린트는 `test-results/presentation-*.log`.
- 제한된 브라우저 경로: 필터 기본값/이동 토글, 별도 탭 제거, 2×5 장비, 전투 확인·취소/수동·자동 종료, 결과 창과 설정, 학사 카드, 실제85URL, 모바일390px, 페이지 오류·비공개 범위·저장/복제. 스크린샷은 같은 결과 폴더.
- 전체 브라우저 회귀와30일 이상 장기 시뮬레이션은 실행하지 않았다. 다년 밸런스/모든 장편 사건의 고유 분기 콘텐츠/7일 성능 목표 달성을 이번 UI 검사로 주장하지 않는다. 공통 이벤트 창은 향후 고정·확률·메인 이벤트의 선택 화면으로 재사용할 수 있는 표현 틀이다.
