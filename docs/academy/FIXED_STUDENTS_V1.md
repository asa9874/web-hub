# 고정 학생 15인·개인 서사 v1 — 부분 구현

2026-10-25. 기획 아이디어의 전체 완료를 뜻하지 않는다. 기존 세레나 1인과 세계 이벤트/공통 상호작용을 확장했다. 제작·공연·편지 수신 등의 결과를 꾸며내지 않는다.

## 실제 연결

- `data/characters/serena.ts` 원본은 변경하지 않았다. `fixed-serena`, 17세, 은발·기존 배경/성격·7개 기준 능력·숙련도·고정 특성4/기프트3 보존. 새 회차의 추가 특성 슬롯만 기존 적격성/상호 배타와 시드 RNG로 선택한다. 기존 미실행 계획 메모와 실제 사건 인스턴스를 구분한다.
- `students.json`은 사용자 노트의14명 설정을 추출한 원문 자료, `students.ts`는 명시적인 시작 능력과 공통 템플릿이다. 종족/출신의 정식 ID는 기존 세계관 생성기를 **고정 정의 시드**로 사용한다. 출신·계통·기본 문화는 회차 시드에 따라 바뀌지 않는다. 세레나의 미확정 출신 지명은 새 공식 지명으로 덮어쓰지 않았다.
- 정상 새 플레이는15명을 포함한다. 초기 NPC 기본25/최소20명으로 교수 등 기존 생활 역할도 남긴다. `createWorldSimulation`의 개발 fixture는 `enableFixedStudents:true`로 명시한다. 원래2~3인 플레이 계약은 기존 크기의 fixture를 명시하고, 별도 고정 인물 검사가 새로운 명단을 검사한다.
- 기존 저장은 원래 명단을 그대로 복원한다. 새 인물을 재삽입하거나 회차별 관계/목표를 초기화하지 않는다.
- 별도 NPC 런타임 모델 없음. Character, 일과, 실제 이동, 학사/기숙사/집단/아이템, 욕구·목표, AI/LOD, 관계, 기억, 세계 이벤트와 통합 저장을 사용한다. 가입·학생회 직책을 강제 부여하지 않는다.
- 고정 관계8쌍/16개 방향 기록은 지인·동료·라이벌 출발점이며 감정은 비대칭이다. 플레이어에 대한 호감은 부여하지 않는다. 랜덤 학생도 기존 AI/상호작용으로 관계를 만든다.
- 개인별 활동 선호7점은 기존 효용의 선호 항목에 더한다. 의무·긴급·중단·출입 정책은 그대로다.14명과 기존 세레나에게 공식 목표 문장에서 장기 목표를 연결하되, 아직 지원하지 않는 최종 성취 조건은 `external`로 보류한다. 서사 완료나 시간 경과로 목표를 자동 완수하지 않는다.

## 콘텐츠와 실행의 구분

`storyContent.json`에 개인50/다인물12개 원문과 ID, `stories.ts`에 배역·실제 조건·상호작용·결과·후속 의존성을 둔다. 총62개 중 **42개는 기존 엔진으로 실행 경로 연결**, **20개는 필요한 어댑터가 없어 차단**했다.42개 모두의 모든 분기/고유 연출을 실증했다는 뜻이 아니다.

- 사건은1~2인 공통 배역으로 한정한다.3인 이상 동시 배역, 복잡한 모임 협상은 후속 작업이다. ENS-09는 세레나와 실제 경쟁자2인 경로이며 세레나·니아·제3자3인 연출의 완성이 아니다.
- 친목·공동 공부·훈련·대련·도움·화해는 실제 요청/수락/거절/종료를 기다린다. 예: SER-01의 관찰 상대는 실제 학습/훈련 중인 학생이어야 하며, SER-02는 실제 대련 가능한 상대를 고른다. 이벤트가 승패를 정하지 않는다.
- NIA-02는 공통 전투가 발행한 **해당 전투자의 실제 defeat 결과**만 받는다. 결과를 발단 근거와 함께 저장하여 대기/복원 시에도 유지한다.
- ADE-01/ENS-11은 실제 참가한 같은 시험의 성적 차이를 확인한다. 시험 성적을 새로 생성하거나 조작하지 않는다. CAM-01은 실제 야간 소음 조정 경험을 이용한다.
- 후속 사건은 완료된 선행 사건을 조건으로 다시 기회를 평가하고, 실제 완료 인스턴스를 인과 원인으로 연결한다. 즉시 조건이 안 맞으면 장소를 강제로 옮기지 않는다.
- 완료1회, 최대 시도3회, 하루 쿨다운과 기존 공통 예산을 사용한다. 중요한 개인 사건의 이력/선행 참조는 기존 보존 정책에서 보호된다. `external`을 NOT으로 뒤집어 성공시키지 않는다.
- 일상에서 특정 개인 사건을 겪지 않아도 기존 AI는 계속 생활한다. 보류 조건이나 상대 부재를 채우려고 새 학생을 생성하지 않는다.
- 공통 대화에는 인물별 일상 말투/수락·거절 표현을 추가했다. 전문적 제안은 기존 의미 표현을 보존한다. 서사별 전용 대사 트리·전용 다지선다 선택지는 아직 없다. 플레이어 개입은 실제 공동 활동의 수락/거절과 기존 행동 명령을 사용한다.
- 사건은 restricted로 저장한다. 일반 세계 사건 목록/설정집은 비공개 개인 사건을 열거하지 않는다. 실제 참여/목격/전달 지식만 기존 기억 투영으로 보인다. 개발자 관찰만 전체 조건·이력을 표시한다.

### 최종 확인 기록

- 변경 영향 자동 선택은 Extended로 승격됐다. 최초24종 통과 후 기존 busy 문구 기대값에서 중단했다. 해당 기대값을 실제 문구에 맞게 고치고 실패/미실행만 이어서 검사했다. 정상 검사 전체를 처음부터 반복하지 않았다.
- 이어 검사9종 통과 후 UX의 저장 즉시 복원 비교에서 실제 AI 예약 문제가 발견됐다. **불러오는 순간 due-now 판단을 실행하지 않도록** `npcAi.connect`를 수정했다. 예약·시드·판단 횟수를 그대로 보존하고 다음 공통 시간 처리에 맡긴다. 이후 UX를 포함한8종 통과, 직접 영향12종 재검사 통과, 최종 고정 인물/세계 사건/기능 노트/타입/빌드5종 통과. 고유 검사 종류는41종이며 서로 다른 시점의 실행 기록을 최종 코드 전부의 일괄 실행으로 표현하지 않는다.
- 공통 짧은 시나리오9개(시간/이동/욕구/AI/상호작용/인과/분할 동등성/저장/학사 하루) 통과. `scenarios.json`에 각 실행을 기록했다.
- 전용 브라우저:15명 도감/일반 화면 비공개/격리 관찰/보류 이유/모바일 저장 진입 통과. 화면 캡처는 같은 결과 디렉터리의 `observer-desktop.png`, `observer-mobile.png`. 업데이트한 기존 전체 캐릭터 브라우저 검사는 별도로 실행하지 않았다.
- 최종 `npm run build`와 변경 핵심 파일 ESLint 통과. 기존 큰 청크 경고는 남아 있다.
- 추가 실행 비용 억제: 없는 배역·지원되지 않는 조건에는 주기 예약을 만들지 않는다. 행동 파생은 원본의 실제 주체/수신자를 먼저 필터한다. 일회성 서사 완료/시도 소진 후에는 정기 평가를 재예약하지 않는다. 실제 발생할 사건을 건너뛰는 LOD 변경은 하지 않았다.
