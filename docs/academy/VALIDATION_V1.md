# 시뮬레이션 자동 검증 v1

2026-10-24. 기존 게임 엔진/검사/CI를 재작성하지 않고 공통 실행·선택·재현 도구를 추가했다. 게임 규칙·저장 형식·NPC AI 계산은 변경하지 않았다.

## 기존 상태와 변경

- npm·TypeScript·Vite, Node `assert` + esbuild 모델 번들 검사, Playwright 브라우저 검사. 도입 직전 아카데미 검사 스크립트45개(브라우저22/그 외23). 스크립트 수이며 개별 assertion 수가 아니다.
- 기존 `academy-check.mjs`는 기억 중심4단계 프리셋·원본 로그 파일·짧은 실패 꼬리·장기 환경변수 정리를 제공했다. 통합 세계에는 이미 저장·시간 분할 검사와 진단이 있었다. 이 기능을 재사용했다.
- 자동 검증 도입 당시 레지스트리49항목: 기존 검사45 + 새 도구 계약/핵심 UI2 + 타입/빌드2. 관찰 플레이 v0.5 검사2개 및 플레이어 생활 검사2개가 추가된 현재는53항목이다. 비용 분류는 선택용 보수적 분류이며 모든 테스트의 실측 시간이라는 뜻이 아니다. 전체 브라우저·장기 검사를 비용 측정만을 위해 재실행하지 않았다.
- `scripts/academy-validation-registry.mjs`: 기존 검사 자동 등록 + 시스템 경로/명시 연동, TypeScript AST 역 import 탐색, Git 변경, 위험 승격. 레지스트리는 범용 의존성 증명기가 아니다.
- `scripts/academy-validation.mjs`: 계획/실행·순차 작업·원본 로그·JSON/짧은 요약·실패 중단·정확한 내용 지문 재사용. `academy-check.mjs`의 `runTask`에 인자/타임아웃과 추가 장기/부분 UI 환경변수 제거만 보완했다. 기존 프리셋은 유지한다.
- `scripts/academy-scenario.mjs`, `academy-static-check.mjs`: 실제 엔진 번들/격리 worker와 기존 tsc/Vite/산출물 검사 실행. 새 테스트 프레임워크나 시뮬레이션 엔진을 추가하지 않았다.
- `systems/worldInvariants.ts`, `validationScenarios.ts`, `types/validation.ts`: 읽기 전용 불변식·비의미적 키/힙 정규화·최초 차이·재현 가능한 세계. 기존 canonical 저장 로더가 수치/참조/큐/RNG/정보/DAG 계약을 검증한다.
- `components/ValidationPanel.tsx`, `WorldSimulationPanels.tsx`, `Simulation.css`: 기존 시뮬레이터의 자동 검증 탭. 로컬 report.json 수동 가져오기·상세·별도 세계 재현. 테스트 보고서를 public에 배포하거나 실제 저장에 쓰지 않는다.

## 프로파일과 안전 선택

| 프로파일 | 실제 범위 |
| --- | --- |
| Quick / FAST | 관련 빠른 기존 검사·타입·짧은 세계 스모크. 고정0.1초 보장 아님 |
| Standard / INTEGRATION | 관련 기존 headless 계약·빌드·기본5명 단기 이동/욕구/저장/시간 비교 |
| Extended / REGRESSION | 관련 주요 headless·기본100명60분 시나리오와 하루 일정·분할/복원 비교. 장기 반복을 자동 강제하지 않음 |
| Full | 등록 전체 검사·브라우저·장기 후보·미구현 범위까지 표시. URL/장기 승인 조건 부족은 deferred, 없는 기능은 not_available이며 전체 성공으로 표시하지 않음 |

중앙 시계/큐/RNG/공통 모델/직렬화/효과 엔진과 types/ 스키마 직접 변경은 Extended와 넓은 headless로 승격한다. 실행 시 사라지는 type-only 참조 사이클은 런타임 역의존 전파에서 제외하고 전체 tsc로 검사한다. 조합 루트에 간접 도달했다고 모든 계약이 바뀌었다고 해석하지 않으며, 그 루트를 직접 고치면 여전히 승격한다. 직접 UI 변경은 관련 브라우저를 포함한다. 논리 변경의 간접 UI import만으로 전체 E2E를 붙이지 않는다. 알 수 없는 파일·Git/정적 분석 실패는 보수적 기본 검사로 확대한다. 아무 항목도 선택되지 않아 성공 처리하는 경로는 없다.

실제 선택 예: `systems/interactions.ts` 한 파일은 Standard, AI/상호작용/기억/관계/검증/세계 이벤트/통합 세계 계약7개 + 타입/빌드2개와 짧은 시나리오5개, 브라우저0개다. 선택기 개발 중 type-only 순환으로 무관한 능력치 도감 검사까지 붙던 과잉 선택을 제거했고, 미등록/중앙 계약의 넓은 검사를 유지하는 계약 테스트를 추가했다.

작업 트리는 `git diff HEAD` + untracked, staged는 staged만, base는 명시 커밋 + 작업 트리/untracked다. 잘못된 ref는 임의 HEAD로 대체하지 않고 분석 실패로 기록한다. 검사 선택 이유와 분석 경고는 JSON plan에 보존한다.

30/360일 등의 장기는 먼저 작은 시나리오를 검증하고 **목적/수량/기간**을 정한 뒤 `--allow-long --count N --minutes M`을 명시한다. 기본 작업 제한은 기존 검사180초/시나리오120초이며 `--timeout-ms`로 명시 변경할 수 있다. Full의360일 후보는 이 조건 없이 실행되지 않는다. 이번 작업에서는 장기 조건을 만족하는 명령을 실행하지 않았다.

## 시나리오·불변식

등록22종 중 실행 가능21종(학사/플레이어 생활/약속 후속 포함): 세계 시각, 일정, 실제 이동, 활동, 욕구, AI, 공동 대화, 방향 관계, 기억·정보, 세계 사건, 인과 연쇄, 수업, 대화, 저장, 분할 시간, 아카데미 하루, 명시적 대량 통합. 이름이 비슷한 진입은 공통 준비/실행기를 공유한다. 일정/수업 스모크는 정식 수강신청·시험 성적 검사가 아니다.

플레이어 자동 생활은 실제 공통 생성·학습 이동·활동·자동 전환 시나리오를 연결했다. 학사 v1에서 수강신청 정원/대기와 실제 수업 평가 시나리오도 연결했다. 대화 v1에서 실제 약속 시나리오도 연결했다. 검사 수는 스크립트 레지스트리에서 자동 탐지한다. 남은 미구현1종: 문화 활동. `not_available`이며 가짜 입력으로 통과시키지 않는다. 학사 단기 계약의7일 분할 비교는3NPC이며100NPC 장기 검증이 아니다.

기본 직접 시나리오는5명60분이며 `--count`/`--minutes`로 명시 변경한다. `academy-day`는 항상 실제1440분, `large-integration`은 명시 장기 실행 후보다. 이동/욕구/대화/사건 시나리오는 각 동작의 실제 완료 경계를 사용하므로 보고서에 **요청과 실제 진행 기간**이 다를 수 있다. 10명7일/50명30일/100명360일을 기본 Standard로 실행하는 제안은 현재 성능 경고와 기존 정책에 맞춰 명시적 장기 후보로 분리했다.

불변식은 시간 역행/달력, 현재 배타 활동·공동 잠금·실제 위치/이동 인원, 시작/종료 시각, 중복 ID/효과 원장, 기존 저장 로더의 수치·상태·참조·기억 출처·예정 큐·RNG·사건 DAG 계약을 검사한다. 자동 수정하지 않는다. 임의 과거의 모든 순간이동/목격/보상 인과를 최종 스냅샷만으로 증명하지 않는다. 실제 경로/출입·완료 효과·정보 공개·멱등성의 세부 검증은 기존 관련 계약 검사로 보완한다.

Step vs Jump는 같은 엔진의1분 반복과 실제 일괄 API를 비교한다. Save vs Continuous는 절반 진행·JSON 저장/로드·나머지 진행과 연속 진행을 비교한다. 기본60분 비교를7일 비교로 표시하지 않는다. 정규화는 객체 키와 일과 wake 힙 순서만 바꾸며 인과/출처/경로/기억/이력의 의미 있는 배열 순서는 보존한다. SHA256 지문과 최초 차이 경로/예상/실제를 함께 남긴다.

## 보고서·재현·재사용

JSON은 프로파일/계획/시드/실제 기간/기본 환경/결과/시간/로그 경로/재현 명령/불변식/최초 차이/실패 직전 유효 스냅샷을 담는다. 기존 Node 검사 실패는 해당 프로세스 실패와 원본 로그를 제공하며 없는 엔티티 정보를 추정하지 않는다. 원인 확정과 관련 시스템 후보는 구분한다.

기본 콘솔은 성공/실패/미실행/재사용 수·시간·경고·첫 실패·재현 명령·보고서 경로만 출력한다. 원본 stdout/stderr는 파일로 남긴다. 메트릭은 실제 NPC/세계 분/AI판단/사건/대화 요청/기억/관계 변화/단계 호출/보존 로그/저장 바이트/worker RSS다. RSS는 해당 Node 프로세스 기준이며 전체 브라우저/자식 프로세스 메모리 합계가 아니다.

재사용은 명시적 `--reuse`만 허용한다. 모든 아카데미 소스·관련 스크립트·package/lock/TS/Vite 설정·프로파일/선택/인자·Node/OS/아키텍처/시간대/Node 옵션/브라우저 경로가 같은 최근 성공 지문이어야 한다. dirty 파일 내용도 포함한다. 결과 재사용은 새 실행 시간이 아니며 게임 계산을 빠르게 했다는 뜻도 아니다. 이전의 해시 없는 장기 기록은 자동 캐시에 넣지 않았다.

브라우저는 로컬 CLI에 직접 접근할 수 없으므로 사용자가 보고서를 가져온다. 시드 재현은 기존 실제 엔진으로 **별도 세계**를 만들어 실행 후 폐기하며 현재 시뮬레이터를 대체하지 않는다. UI 재현은10명/60분 이하만 허용한다. 더 큰 규모는 보고서의 원래 CLI 명령을 사용한다. 되감기/클라우드 실행/자동 버그 수정 서비스는 없다.

## 이번 검증·효과·한계

- 새 도구 계약:4프로파일, Git/미등록/분석 실패 안전 선택, 논리 변경의 E2E 제외와 직접 UI 포함, 타임아웃, dirty 해시, 관찰 무변경, 의도적 배타 활동 충돌의 NPC/시각/활동 보고, 같은 시드의 의도적 실패 재현, 미구현 구분.
- 실제 짧은 시나리오·시간 분할·저장 복원, 기존 기억 검증 실행기 호환, 기능 레지스트리와 핵심 UI를 검사한다. UI는 보고서 오류 처리·상세·격리 재현·모바일·실제/샌드박스 시각 보존을 확인한다.
- CLI 수락 실행8종은3명·기본60분 조건에서 성공했다. 첫 실행은4,471ms(구축/worker/검사 포함). 이는 게임1시간 처리 성능이 아니며 이후 실행/재사용 측정은 `test-results/academy-validation-*.json`/로그를 기준으로 본다.
- 최종 동일8종 신규 실행4,168ms, 원본 worker 출력301바이트/계산된 요약문211바이트. 정확한 내용 지문 재사용은215ms이며 신규 성공0/재사용8로 표시됐다. 선택기 안전 보완으로 지문이 바뀐 직후에는 이전 기록을 재사용하지 않고8종을 실제 재실행한 것도 확인했다. 캐시 조회 시간을 새 시뮬레이션 처리 시간으로 비교하지 않는다.
- 의도적 실패 fixture는 NPC1명으로 공동 대화를 요청해 `SCENARIO_SIZE`를 재현한다. 게임 결함으로 보고하지 않는다. 08:01 대화가08:30 의무 수업에 의해 정상 중단된 초기 fixture는19:00 자유시간으로 수정했고 게임 규칙은 그대로 유지했다.
