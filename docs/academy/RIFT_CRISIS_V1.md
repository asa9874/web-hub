# 균열의 시대 v1 — 첫 지역 수직 슬라이스

2026-10-26. **전체 메인 이벤트는 부분 구현이다.** 첫 전조·지역 균열·구조체 집계 행동·관할 대응·현장 조사·정보·저장·개발자 관찰을 실행했다.30개 사건 설계 중14개가 현재 엔진과 연결된다. 상세 전선/이계 외교/국가 정치/졸업 후 진로는 완료로 표시하지 않는다.

## 조사 결과와 설계 선택

기존 세계에는 에르디아·마르카디아·세피라와10국가/12지역이 있다. 마계는 같은 행성의 동대륙이며 네르바와 별개다. 기존 외교는 정적 설정, 일반 연구 성과·졸업/직업 전환은 부분 또는 미구현이다. 이를 완성된 국가 AI/연구 계약처럼 사용하지 않았다.

단일 달력/시계, 실제 장소·정상 이동·공통 일과/직접 행동, 기존 Utility AI, 개별 기억·정보 전달, 세계 이벤트 큐·인과 그래프, 전체 세계 저장, 일반 플레이/격리 시뮬레이터를 재사용했다. 새 고정 학생·국가·병사 수천 명·별도 NPC 전투 엔진을 추가하지 않았다.

네르바·에르하, 마력 순환 위기/위상 차이/생체·마도 기술/의사소통, 개척총국·교섭연합·보존의회·유실체,3구조체,10단서,30사건,5세계 결과를 `data/riftCrisis/index.ts`에 등록했다. 외부 세계로 가는 실제 이동 연결은 아직 없다.

## 실제로 동작하는 흐름

1. 회차 시작 이후45~90일 상대 시각에 기존 지역에서 전조가 시작된다. 첫 위치/정책은 시드에 따라 달라진다. 특정 날짜의 수도 파괴는 없다.
2. 잠재→미세→불안정→안정→관문. 운영 자원·통과 용량·유지 작업·지역 대응을 검사한다. 모든 균열이 관문까지 성장할 필요가 없다.
3. 탐사체는 관측 흔적/신호를 남기고 구축체는 유한 자원을 써 확장·환경 훼손, 호위체는 지역 방위와 집계 충돌한다. 실제 시민·개별 NPC가 죽었다고 가정하지 않는다.
4. 관할 조직의 조사/방위/봉쇄와 유한 운영 예산을 처리한다. 이는 이번 위기의 지역 집계 자원이며 기존 국고/인구/보급망을 가짜로 참조하지 않는다. 이계 세력 중 실제 투입은 개척총국부터다.
5. 지역 피해는 실제 접근 통제로 연결되고 경로/도착 시 검사한다. 일반 학사·동아리·생활을 전역 취소하지 않는다. 먼 사건을 플레이어에게 즉시 알려주지 않는다.
6. 실제 현장에 머물거나 정보를 받은 인물만 소식/단서를 보유한다.30분 현장 관측은 실제 공통 활동 완료 후만 반영한다. scholar/seeker/cautious 성향의 NPC도 알고 있는 곳에만 행동 후보를 얻으며 길·시간·동의·LOD를 우회하지 않는다.
7. 조기 봉쇄 뒤에도 보존한 신호와 표본 분석을 이어간다. 규모 확대와 언어 가능성 발견은 다른 축이다. 문명 고유명/정치/생존 위기를 가짜 분석 점수만으로 공개하지 않는다.
8. 지역 봉쇄·피해/복구 필요 상태와 역사 원인을 보존한다. 지역 하나의 결과를 전체 시대 결론으로 만들지 않았다. 졸업·세계 사건 해결로 게임을 끝내는 코드는 없다.

## 화면과 공개 정책

- 일반 플레이 **나의 사건 기록 → 세계 소식**: 실제 보유 정보, 출처/확신도, 관측 기록, 정상 이동 후30분 관측. 세계 지도는 인지한 곳에만 이상 표시를 붙인다. 안전 통제는 실제 통행 제한이며 그 원인으로 숨겨진 이계 이름을 공개하지 않는다.
- 기존 개발자 **시뮬레이션**: 균열·위협·단계/용량·구조체·지역 예산/정책·표본/신호/연구·지역 결과·역사 원인과 세계 이벤트 ID, 전체 공식 설계. 정책 변경은 명령 이력에 남고 실제 저장은 격리된다.
- 기존 세계 이벤트 그래프: 명시적 지역 발생 기록만 기존 큐/DAG에 연결. 참가자0의 private 집계 기록은 인물 효과/상호작용을 갖지 못한다. 일반 NPC 사건의 안전 검사를 약화하지 않았다.

## 저장·결정성·보존

선택적 `riftCrisis` 상태와 기존 기억/도메인 기록/세계 이벤트를 통합 저장한다. 구형 저장은 명시 초기화하며 과거 역사를 생성하지 않는다. 시드·지역 ID·평가 시각의 난수, 저장된 예약/예산/구조체·진실·중복 키를 사용한다. 지역별 결과가 공존하며 단일 chapter/global ending으로 덮어쓰지 않는다.

초기 콘텐츠는 최대3지역, 지역 평가는 기본 하루 단위다. 예약 전에는 처리하지 않는다. 지역/이계 예산 합계 보존, 단계별 용량·봉쇄·참조·이력 중복·인과 시각을 검증한다. 중요 역사는256개 한도, 현장 활동 키는14일/최대180,000개다. 사소한 일일 작업은 집계 상태로 유지한다.

## 검증

- 전용 지역 계약: 기본 전조 지연 범위, 플레이어 없는 지역 자율 진행,28일 분 단위/일괄 상태·DAG 일치, 조기 봉쇄와 봉쇄 뒤 언어 단서 분석,34일 조사 정책의 관문 확대/피해 분기, 자원 보존, 봉쇄 뒤 신규 통과 금지, 진행/봉쇄 저장 재개, 중복 기록, 잘못된 예산 거부, 구형 저장 무삽입, 시드 차이.
- 위28/34일은 **상세 NPC0명인 지역 집계 계약**이다. 시간 구간은31일 제한을 유지하며 분리 진행했다.100명 전체 AI의 장기 성능/안정성 결과로 사용하지 않는다. 테스트에서는 전조 예약을 가까운 미래로 옮겨 대기 비용을 줄였으며 기본45~90일 설정도 따로 확인한다.
- 실제 플레이 계약:30분 관측 완료, 현장 직접 정보/숨겨진 명칭 차단, 세계별 접근 규칙·캐시 격리와 정상 경로 차단, 공통 활동 실행.
- 제한 브라우저: 실제 보유 세계 소식·인지한 지도 표시·390px 모바일·격리 JSON 불러오기·정책 명령·개발자 전체 설정. 네르바/에르하/정치 세력은 일반 화면에 표시되지 않는다. 페이지 오류0건이며 원본/스크린샷은 `test-results/academy-rift-crisis/`에 있다.
- 중앙 저장/이동/이벤트 계약 변경으로 자동 선택이 Extended로 승격되었다. **55검사/시나리오 통과**, 경고0. 마지막 보완(봉쇄 뒤 분석·세계 결말 보류·현장 중복 키 보존/지각 검사) 이후 전용 계약, 세계 이벤트 FAST/INTEGRATION, 타입 검사 포함 전체 빌드, 변경 모듈 린트가 통과했다. 제한 브라우저도 통과했다. 기존 대형 번들 청크 경고는 남아 있다. 기능 노트47시스템/421항목의 참조·상태·의존성 검사를 통과했다. 원본은 `validation/report.json`, `test-results/rift-*.log`.
- NPC100명×360/720/1440일, 졸업/진로 실행, 활동 중 침공의 다년 균형은 이번에 실행하지 않았다. 기존 장기 검증을 이번 기능의 통과로 재사용하지 않는다.

## 성능

다른 검사/빌드와 분리하여 Windows / Node22.18.0 / Intel Core Ultra7 258V에서1회 측정했다. 시드 `rift-crisis-100-hour`, 건강한 랜덤 학생99+교수1, 모든100명 AI와 기존 세계 시스템 활성화, 첫 오후60분 **전조 이전** 구간이다. 고정15인/플레이어 선택 개입·활성 침공 장기 부하는 포함하지 않는다.

## 미구현·제약

주변 구조체를 실제 캐릭터/전투 표적으로 구체화하는 어댑터, 실제 NPC 피난/사망, 국가별 상세 전선·보급·영토 점유, 이계 세력 정치 행동, 교신/번역/외교 대표권·회담·협정, 복수 기관 연구·제작/유물 성과, 고정15인의 전용 메인 장면/진로, 졸업 후 직업·거주/재회, 이주·교역·세계 시대의 최종 결산은 미구현이다. 지역 규모의 손실과 구호를 개별 NPC의 전투/이동으로 표시하지 않는다.

단서1~6까지만 현재 발견 경로가 있다.7~10은 정식 설계이며 플레이어가 처음부터 알지 못한다. 세계 결과5종도 설계이며 실제 확정하지 않는다. 공통 이벤트 예산/카탈로그 제한으로 그래프 등록이 거부되면 지역 중요 이력·원인 ID는 보존하고 진단을 남긴다. 강제로 예산을 무시하거나 완료를 꾸미지 않으며, 그래프 재등록 큐는 후속 보완 대상이다. 지역 봉쇄 이후에도 조사 기록과 일반 생활은 유지된다. 마계와의 국가 협력/오해는 기존 정적 관계를 넘어 자동 전쟁으로 만들지 않았다.
