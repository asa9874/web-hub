# 장기 플레이 템포·생활 계획 v1

## 기존 구조와 선택

기존 `PlaySession.performAction/moveAndArrive/work/advance`는 이미 행동 시간을 자동 진행하고, 공통 시계는 내부 예약 경계를 순서대로 처리한다. NPC AI/학사/욕구/관계/기억/이벤트를 복제하지 않았다. 반복 입력과 중단 뒤의 목적지 유실을 줄이는 것이 이번 변경이다. 시간 버튼만 확대하거나 날짜만 변경하지 않는다.

`lifePacing`은 동일 세션 위의 진행 목적지·보고 조정기다. 주간 계획은 기존 `CharacterSchedule.overrides`에 `player-week/<요일>/<시간대>`로 저장한다. 별도의 일정 실행기나 NPC AI를 만들지 않았다. 정규 학사 entries는 보존한다.

## 실제 기능

- 텍스트 모드: ‘생활 계획·진행’을 주 기능으로 올리고 기존10분/1시간/6시간/1일/7일 버튼은 ‘시간 단위 조작’ popover로 분리했다. 툴바 내부 overflow에 가려지지 않는 브라우저 top layer를 사용한다.
- 비주얼 모드: 하단 주 행동을 생활 계획/생활 이어가기로 변경. 무대의 다음 일정도 같은 목표 보존 조정기를 사용한다.
- 반복 계획: 매일16:30~18:00/19:30~21:00, 주말09:00~11:00의16칸. 자동 생활/자율학습/독서/검술/마법/휴식/정원 산책을 선택해 한 번 적용하면 주간 반복한다. 휴식은 실제 거주지가 있으면 그곳을 사용한다. 개별 시각 자유 편집 대신 작은 수의 생활 구간으로 구성했다.
- 개인 계획은 priority75의 선택 일정 후보이며, 수업·식사·약속·이동·부상·긴급 욕구와 기존 Utility AI 조건에 따른다. 계획만으로 실제 수행/성장/출석을 보장하지 않는다. 목표/욕구/일정의 기존 규칙을 우회하지 않는다.
- 균형/학업/훈련/교류/회복 중심 방침 프리셋은 기존4가중치에 적용한다. 세부 방침은 기존 텍스트 조작에 남긴다. 특정 NPC 교류 고정/자동 구직·저축 전략은 신규 구현하지 않았다.
- 다음 실제 예정 일정/24시간/7일/다음 월1일00:00/다음 학기 성적 확정일/다음1월1일까지의 진행.360일 달력 사용. 학기 목표는 기존6·11월30일18:00에 맞추며 종료·평가를 가짜로 생성하지 않는다.
- `PacingSave`는 선택 필드이며 시작/목표 시각·본인 시작 상태·현재 상태와 최근12보고만 저장한다. 기존 세이브에 필드가 없어도 기존 일정은 그대로 읽는다. 중단 후 전투/대화가 진행 상태를 바꿔도 처음 정한 절대 목표 시각은 유지한다. 직접 사건 해결 후 ‘남은 생활 이어가기’로 재개한다. 별도 자동 재시작을 강제하지 않는다.
- 진행 중 취소는 현재 요청만 끝내며 실제 성장·NPC 결과를 되돌리지 않는다. 완료 보고는 이후 행동으로 재작성하지 않는다. 월/학기/연의 전체 계산을 프레임 건너뛰기로 대체하지 않는다.
- 보고: 실제 수행 구간의 활동 분/능력치/숙련 랭크/욕구/소지금/본인이 아는 자신의 관계 변화·보유 기억 증감. 수입/지출 합계가 아닌 실제 잔액 순변화이며 기억 증감에는 망각/보존 한도가 포함된다. NPC의 비공개 내면 평가나 미확인 원거리 사건을 공개하지 않는다. 보고 획득 자체의 보상 없음.
- 신규 스킬 습득·진화는 기존 skillBook.history에서 읽어 중요한 개인 사건 정책에 따라 중단한다. 같은 경계의 여러 습득은 한 번의 확인으로 묶는다. 일반 XP/숙련의 미세 증가마다 중단하지 않는다. 구버전 로드 시 과거32개 스킬 이력을 새 사건으로 쏟아내지 않는다.
- `student_work`가 실제 직접 행동 허용 목록에서 빠져 있던 문제를 보완했다. 반복 일정에 근무만 넣고 보수를 생성하지 않으며 일자리는 기존 workReasons/beginWork/실제 근무 처리로만 사용한다. 반복 근무·연구·대상 NPC 고정 계획은 후속이다.

## 보존·성능

공통 단일 시계/결정성/중간 선택/전투/학사/정보 습득/저장 상태는 유지한다. 기간을 길게 선택해도 AI·사건을 생략하지 않는다. `hasPendingChoices()`의 읽기 전용 boolean으로 진행 루프의 전체 PlayerLifeSave 반복 복사를 줄였고, 진행 HUD는 보고 전체를 복제하지 않고 짧은 현재 상태만 읽는다. 이 국소 변경의 속도 개선률은 별도로 계측하지 않았다.

100명 전체 AI 수업 시나리오의 독립 실행1분/1표본:551.1ms,38판단,세계 이벤트0건. Node22.18.0/Windows/Core Ultra7 258V. 새 세계의 엔진 진행만이며 초기화/DOM/저장 시간은 제외된다. 먼저 다른 검사와 겹친 표본717.6ms는 대표 성능값으로 사용하지 않았다. ‘1주3초’를 달성한 결과가 아니며 한 시간/하루/주/월/학기 실측으로 환산하지 않는다. 기존 플레이어 검사의3명 하루는 약15.9초였으나 동시 검증 조건이므로 성능 목표 비교 표본이 아니다.

원본 `test-results/academy-pacing/performance-solo/report.json`, `academy-pacing-performance-solo.log`. 장기 계산 병목은 여전히 남아 있고, UI 템포 개선과 실제 엔진 최적화를 구분한다.

## 검증 범위

- `test:academy-pacing`:360일 달력·연말/월말/학기 경계, 중단/직접 개입/저장 후 절대 목표 유지, 미응답 재개 거부, 완료 보고 고정/취소 보고, NPC 비공개 평가 제외,16반복칸/멱등 적용/잘못된 계획 원자 거부/학사 보존, 실제 공통 시계1분, 구버전 저장 복원, 준비한 습득/진화 이력의 묶음 알림/중복 방지, 실제 일반 잡담 제안의 백그라운드 처리 유지.
- 기존 `test-academy-player.mjs`:행동/위치/효과/중단/직접 동의/실제 정보 경계/분할 동등성/기존 저장·관찰 계약 통과. 기존 작은 세계 하루 검사가 포함되며 새로운100명 장기 검증이 아니다.
- 실제 브라우저1280×720: 새 게임→생활 계획 열기→월요일 방과 후 검술 훈련 적용→다음 일정08:00~09:00 실제 진행→문화 놀이45분/관계·소지금·보유 기억의 실제 보고 확인. 화면 `test-results/academy-pacing/{planner,weekly-plan}.png`. 월/학기 전체 실행이나 중요한 선택의 모든 브라우저 경로를 완주한 검사가 아니다.
- 기존 스킬 검사 통과. 원본 `test-results/academy-pacing-{test,player,skills,visual,types,build}.log`.
- 월/학기/연 기간은 목표 계산·짧은 중단/재개 계약을 검증하며 전체 기간을 실제로 완주했다고 보고하지 않는다.100명 월/학기/연·10년 전체 플레이 성능·졸업 이후 전체 콘텐츠는 미검증이다.

기능 노트에는 위 실행 범위와 남은 성능·콘텐츠 제한을 부분 구현으로 표시한다.

일반 NPC 잡담은 기존 대화 엔진이 백그라운드로 처리하는 경로를 유지했다. 별도 자동 거절 정책을 중복 추가하지 않았으며, 부탁/약속/고백/대련/히로인 등 중요한 제안은 기존 실제 의미와 직접 응답 조건을 따른다.
