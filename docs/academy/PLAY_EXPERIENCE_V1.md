# 플레이 경험 개선 — 2026-10-24

- 기존 단일 상단 바/고정 뷰포트/패널 내부 스크롤 유지. 장소 장면 → 주변 인물 → 개인 기록으로 시선 순서 정리.
- `DetailDialog`: 도감 링크를 URL 변경 없이 중첩 설명 팝업으로 연다. Escape/닫기는 가장 위 팝업을 닫고 이전 창의 포커스를 복구한다.
- NPC와 플레이어는 `CharacterStatusPanel` 공통 UI. 인물 이름·핵심 능력·보유 항목 우선, 상세 배경은 펼침. NPC 능력치는 표시하되 비밀 소속·개인 기억·비공개 목표의 기존 공개 정책은 유지한다.
- `playerViews`는 기존 인지 기록에 중요도/분류만 추가한다. 한 줄 요약 → 클릭 펼침, 중요/주의/이동/교류/성과/정보의 색상과 텍스트 표기를 병행한다. 구형 저장에 메타데이터가 없어도 동작한다.
- 방침 슬라이더는 정수·0~100·합계100을 유지하며 다른 항목을 비례 재분배한다. 적용 버튼과 실제 생활 엔진 계약은 유지한다.
- 직접 행동8종은3열 버튼(3행), 선택과 실행은 구분한다. 기존 이동/소요 시간/출입 조건은 그대로 사용한다.
- 생성 화면은 기본 이름 ‘아렌’, 성향 선택 카드, 선택적인 세계·출신 설정으로 구성한다.
- `PlayerResponseDialog`: 실제 pending 요청을 자동 표시하고 이름/한글 활동명을 현재 상호작용에서 조회한다. 수락/거절/대화 선택은 기존 `playerCommand` API. 닫아도 보류되며 상단 응답 버튼으로 재개한다. 시간/AI/동의 규칙은 변경하지 않는다.
