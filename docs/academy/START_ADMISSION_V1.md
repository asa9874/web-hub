# 게임 시작·자질·입학 평가·엔딩 도감 v1

## 실제 구현

새 게임 → 기본 정보/초기 조건/관심 분야 → 자질 공개 → 입학식 → 평가 결과 → 합격 시 기존 생활 세션, 불합격 시 BAD END 00. 제국력 427년 3월 1일 08:00과 기존 수강·기숙사·자동 생활 배정을 유지한다. 입학식은 평가 공개 전의 짧은 장면이며 별도 시간을 소비하거나 가짜 참석 성장 보상을 지급하지 않는다.

- 공통 NPC 생성기, 출생 적격성·배타·개수 확률, 기존 영향력 계산, 플레이어 생성·세계·학사·일과·기숙사·3슬롯을 재사용했다.
- 4종 초기 조건과 검술/마법/학술/균형/무작위의 5방향. 공통 생성기의 수치 프로필을 선택하며, 균형은 로컬 능력 편차를 균등화하고 학술은 실제 마법 이론 숙련도를 사용한다. 전역 NPC 설정을 변경하지 않는다.
- 기프트/특성 희귀도별 공개 카드, 차례로/모두 공개, 빠른 공개, 실제 효과 확장, 이전 단계, 명시적 재추첨. 최대 9,999 재추첨 인덱스, 각 생성은 기존 최대 16후보. 타깃 미충족 시 기존 최근접 유효 후보 정책이며 영향력을 덮어쓰지 않는다.
- 생성 화면은 세계를 만들지 않는다. 합격 확정 때 동일 시드·프로필로 재현한 캐릭터를 기존 플레이 세션에 넣는다. API에서도 미달 캐릭터의 새 생활 세션 생성을 거부한다.
- 일반 설정집과 타이틀의 엔딩 도감은 같은 별도 브라우저 저장소를 읽는다. 최초 발견 일시·회차 식별·세계 시각, 미발견 제목/조건 비공개, 해금된 연출 재감상을 제공한다.
- BAD END 00은 해당 입학 시도의 종료다. 기존 세이브 슬롯/이전 세션은 지우지 않는다. 실제 3,600일 경과는 별도의 삶의 이정표이며 진행을 멈추거나 게임을 끝내지 않는다.

## 아이디어 노트와 조정한 부분

현재 영향력 v1은 능력·숙련·특성·기프트뿐 아니라 사회적 직급·칭호를 포함한다. 1학년 보통 생성은 주로 100 전후다. 400~800을 일반 입학 조건으로 강제하면 기존 세계의 실력·사회적 위계를 바꾸게 되므로 다음 **초기 자질 탐색 목표**로 조정했다. 성장 한계·NPC 호감·세계 위험을 추가 변경하지 않는다. 기존 성장 유형의 공통 학습 효율(천재1.25/범재1/둔재0.8)은 그대로 적용된다. 초기 재능에 따른 기존 차이이며 새 난이도 전용 배율이나 낮은 성장 상한을 추가하지 않는다.

| 출발 | 목표 영향력 | 기존 생성 프로필 |
| --- | --- | --- |
| 순탄 | 180~350 | 천재 |
| 평범(추천) | 90~160 | 범재 |
| 험난 | 60~100 | 둔재 |
| 밑바닥 | 0~70 | 둔재 + 낮은 영향력 후보 선택 |

현재 공통 출생 확률은 특성 1개가 98%, 기프트 없음이 87%다. 기프트 1개 기본 보장은 기존 규칙과 충돌하므로 적용하지 않았다. 시작 화면에서 기프트가 없을 수 있음을 안내하며 가짜 잠재 기프트를 부여하지 않는다. 목표 범위 선별 후의 최종 표본은 조건부 분포이므로 기프트 비율이 원본 출생 확률과 같다고 주장하지 않는다.

## 평가·반 배정

`systems/admission.ts`의 순수 평가, RNG 소비 없음:

- 기초: 높은 기초 능력 3개의 평균.
- 실기: 보유 숙련도별 `관련 능력 평균 × 0.6 + 경지 × 12` 중 최고점. 같은 경지라도 실제 능력이 다른 분야를 구분한다.
- 필기: `INT × 0.65 + WIL × 0.2 + 마법 이론 경지 × 6`.
- 전문 강점: 위 세 평가의 최대치. 특이한 기프트의 설명만 보고 임의 실기 효과를 보장하지 않는다.
- 종합: 기초20% + 실기35% + 필기20% + 전문 강점25%. 각 영역은 0~100의 **시험 점수**로만 제한하며 원본 능력치에는 100 상한을 적용하지 않는다.
- 합격22점, F22/E29/D38/C48/B60/A72/S85점 이상. 원래 실력과 사회적 영향력은 별도로 유지한다.

새 흐름으로 시작한 세계의 학생 NPC도 같은 평가로 반을 배정한다. 이미 입학한 NPC의 학적을 소급 박탈하지 않으며 미달은 조건부 F반으로 분류한다. 기존 고정 인물에 명시된 S~F 설정이 있으면 우선 보존한다. 학생이 아닌 인물은 배정하지 않는다. 배정은 공통 Character.classId로 상세에 표시하고, 최초 평가 기록은 선택적 PlaySave.admission에 남긴다.

**부분 구현:** 반별 전용 강의·기회·사회 평가·학기 승강은 아직 없다. 현재 반은 실제 초기 배정/기록/표시이며 강의 난도나 NPC 인상을 바꾼다고 주장하지 않는다. 기존 학사·기숙사 엔진의 실제 배정을 사용한다.

## 저장과 데이터 경계

- 구형 PlaySave는 admission 없이 그대로 로드하며 재시험/재생성하지 않는다. 새 저장은 평가 점수·반·프로필·배정 참조를 검증한다. 일반 플레이 진행 중에는 RNG나 평가를 다시 수행하지 않는다.
- 엔딩은 `web-hub.academy.endings.v1`의 고유 발견 목록이다. 슬롯 키와 분리되며 새 회차/재추첨/이어하기가 초기화하지 않는다. 같은 엔딩 재발견 시 최초 기록을 덮어쓰지 않는다.
- 손상된 도감을 자동 초기화하지 않고 오류로 알린다. 숨겨진 도감 조건은 일반 UI에 출력하지 않는다. 개발자 도구/클라이언트 소스 열람을 막는 보안 장치는 아니다.
- 브라우저 저장소이므로 브라우저 데이터 삭제·다른 기기까지 영구 보존되는 것은 아니다. 클라우드 계정 동기화는 없다.

## 이번 검증

`test-results/academy-admission/results.json`: 4난이도 × 5방향 × 5시드 = 100표본, 각각 재생성하여 결정성 확인. 공통 영향력 재계산 일치, 16후보 예산, 이름/종류로 평가 차별하지 않음, 100초과 원본 능력 보존, 실제 합격 세션·세이브·구형 로드·손상 거부·입학 실패 API 거부·별도 도감 멱등/손상 보호·10년 경계 조건을 검사했다.

| --- | ---: | --- | ---: | ---: | ---: |

표본은 밸런스 보장이나 모집단 탈락 확률이 아니다. 테스트 전체 약1.35초는 생성·재현·준비된 소규모 저장 계약의 벽시계 시간으로, 100NPC 게임 시간 진행 성능이 아니다.

기존 `test-academy-player.mjs`는 개인 장면을 일반 계속 응답으로 우회하던 낡은 테스트를 실제 선택 API의 가능한 비참여/회상 선택으로 갱신했다. 기존 검증은 삭제하지 않았다. 통과: 실제 이동/활동/성장/중단·재개/동의/분할 시간/저장·복원, 요청 NPC3명 하루 자동생활 및100명 등록. 하루 검사는 선택 대기 등을 포함한 기능 검사이며 대표 성능 벤치마크가 아니다.

실제 브라우저(1280×720, 테스트용 localhost):

- 평범/균형의 자질 공개 → 입학식 → D반 합격 → 427년 3월 1일 생활 세션.
- `probe-2`/밑바닥/검술/빠른 공개 → 실제19점 미달 → BAD END 00 → 도감1/2 → 페이지 재로드 후 보존·재감상. 기존 세이브 슬롯을 저장/삭제하지 않았다.
- 내부 스크롤과 하단 고정 생성 버튼을 확인했다. 다른 해상도/기프트 복수 공개의 전체 수동 조합 검수는 미실행이다.

타입/빌드·lint와 기능 노트 검사는 로그에 실제 종료 결과를 기록한다. 30일 이상·10년 전체 AI 시뮬레이션/전체 브라우저 회귀는 실행하지 않았다. 10년 이정표 테스트는 실제 경과 시각의 경계 계약이며 10년 생활 완주 검증이 아니다.
