- C: 정보 과밀·동선/공간 혼동·대비 불량으로 사용을 방해함.

## 아트와 구현 결정

- `public/academy/maps/campus-v1.webp`: 인물 없는 캠퍼스 안내도. 지형·성격에 따라 교사동/도서관/실습/대련/생활/정문을 배치했다. 정확한 축척 측량 지도가 아니며 시간/거리/출입은 실제 엔진만 결정한다.
- `public/academy/items/items-atlas-v1-{0..3}.webp`: 25칸×4장,100개 서로 다른 아이콘. ID→칸 매핑은 `data/itemArt.ts`에서 고정한다. 나중에 아이템을 추가해도 기존 매핑이 밀리지 않는다.
- 내장 imagegen으로 생성했고 런타임은 WebP로 최적화했다. 합계1,873,382바이트(약1.79MiB). 같은 아틀라스는 브라우저 캐시로 공유하며100개 개별 대용량 요청을 만들지 않는다.
- 미확인 물건은 실제 아이콘을 보여주지 않는다. 그림 누락 시에도 이미지 칸/지도 영역의 크기는 유지된다. 새 폰트/대형 지도 라이브러리/시뮬레이션 타이머는 추가하지 않았다.
- 프롬프트 묶음과 제작 정보는 [UI_ASSET_PROMPTS_V1](UI_ASSET_PROMPTS_V1.md).

원본/결과: `test-results/academy-ui-polish/`, `test-results/academy-ui-*.log`. 전용 `test-academy-ui-assets.mjs`는100개 고유 칸/미확인 표시/안정적인 위치/실내 탐색/이동 그래프 불변을 검사한다. 게임 엔진/저장 형식은 바꾸지 않았다. UI 변경이므로 장기 시뮬레이션·전체 게임 회귀는 반복하지 않는다.
