# 공통 판정·전투 시뮬레이션 v1

2026-10-25. 실제 코드 기준. 아이디어 노트의 구현 방식은 기존 단일 시계·상호작용·효과·정보 공개 계약에 맞췄다.

## 구현과 연결

- 공통 판정19개: 물리 공격/방어, 마력탄/화염/냉기/번개, 마법 저항, 치유, 도주/추적, 설득/협상/위협, 정신 저항, 관찰/은신/제작/지식/힘.
- 점수 = 반올림((주능력×0.65+보조×0.35)×0.5)+숙련 랭크×5+보정(±15). 능력100 초과 보존. 단일 정수 난수-10~+9를 더한 마진0 이상 성공. 동일 조건의 확률은20개 결과를 정확히 열거한다. 대성공/부분 성공/치명적 실패를 구분하되, 부분/치명 결과는 명시된 비용/결과가 있는 정의에만 허용한다.
- 실제 특성/기프트/상태의 능력·점수 효과와 조건·중첩을 읽는다. %p를 점수로 변환하지 않고 SPECIAL_RULE 실행을 추정하지 않는다. 미지원 내역이 결과에 남는다. 영향력·캐릭터 종류 보정 없음.
- HP=60+VIT×2, SP=30+VIT+반올림(WIL×0.5), MP=20+MAG×2. 전투·외부 자원 효과를 경험한 인물만 상태를 저장한다. 대련은 현재HP의35% 별도 내구도를 사용하며 실제HP를 보존한다. SP/MP는 실제 소비한다.
- 20기술: 기본/강/신속/견제 공격, 방어, 회피, 반격, 마력탄, 화염, 냉기, 번개, 방벽, 집중, 치유, 관찰, 거리 조절, 도주, 항복, 동료 보호, 호흡 정돈. 초기 물리는 연습 검술이다. 모든 무기·장비 구현이 아니다.
- 공통 세계1분=1라운드. 최대3팀·6명·팀당3명·20라운드. 같은 장소/정지/출입/의무 일정·공동 활동 점유를 검사한다. 도주도 유효한 실제 이동 경로가 필요하다. 전투 불능·항복자는 전투 종료까지 예약을 유지한다.
- 수락된 기존 대련이 실제 라운드로 시작된다. 끝나면 기존 상호작용의 관계·성장 보상을 실제 시간과 사용 숙련도로 한 번 적용한다. 기존 XP 감쇠/일일 정책을 재사용한다. 실전의 라운드 자체에 임의 XP 보상을 추가하지 않는다.
- 실전은HP손상·기존 타박상을 적용한다. 사망/영구 장애 없음. 전투가 생성한 부상만 만료 예약으로 정확한 인스턴스를 제거한다. 다른 부위/출처 상태는 보존한다.
- HP0은 일반 이동/활동을 막는다. 현장 회복 또는 실제 휴식/수면 수행 시간으로 회복한다. 이동 자체는 시간을 진행하지 않는다. HP/SP/MP의 외부 변경은 기존 공통 효과 엔진의 원자적 어댑터를 사용한다.
- AI는 자기 능력·욕구·목표·성향·관계·현장 관찰/기억을 읽는다. 상대 숨은 숫자로 승률을 최적화하지 않는다. 전투 중에는 생활AI를 병행 실행하지 않는다. 플레이어 직접 선택/중요 전투는 선택 대기에서 세계 진행을 멈춘다.
- CombatStarted/Completed/Interrupted를 기존 도메인 기록/기억에 연결한다. 직접 참여/현장 목격과 다른 NPC의 무지를 유지한다. 실제 결과만 사용하는 세계 이벤트2개를 추가하며 효과를 재적용하지 않는다. 사건 출처ID로 기존 인과관계에 연결한다.
- 선택 필드 `AiSandboxSave.combat`: 자원·라운드·예약 행동·시드·원본 상호작용·부상 만료 저장. 구형 세계는 전투 미연결 상태로 유지하고 명시적 연결 가능. 최근 일반120전투/건당160행, 중요 요약 보존·최근40건 상세, 부상 참조가 있는 전투 보존.

## 화면과 API

- 플레이 상단 `전투·판정`: 실제 대련 요청, 명시적 실전 공격, 자동/직접 전투, 버튼형 기술/대상/비용, 다음 라운드, 필터 가능한 실제 기록, 판정 체계. 정상 화면은 자신의 자원만 정확히 표시하고 상대는 정성적 상태를 표시한다.
- 설정집 전투 도감의 테스트는 기존 통합 시뮬레이터 복제본을 사용한다. 팀 구성·강제 시작/행동·중단·NPC/자원·세부 판정 관찰. 강제 명령은 중앙 명령 기록을 남긴다. 플레이 저장을 수정하지 않는다.
- `resolveCheck`, `scoreCheck`, `getCheckDistribution`은 순수 조회/판정. `createCombatEngine`의 `start/requestSparring/getActive/getCandidates/queueAction/setManual/interrupt/getResources/save/diagnose`를 사용한다. 시간은 기존 세계 API로만 진행한다.

## 제한·후속

- %p/기프트 고유 규칙·전용 상태 효과의 완전 실행, 실물 무기/방어구/인벤토리, 모든 무기별 판정, 부상 부위별 전술은 미완성. 정의 존재만으로 실행 완료라 표시하지 않는다.
- 일반 설득은 동의 강제가 아니다. 학사 성적/출석의 기존 조건을 전투식으로 일괄 교체하지 않았다. 비전투 판정 정의는 API/실험 사용 가능하나 모든 생활 콘텐츠에 연결됐다는 뜻이 아니다.
- 실전 전투 시작API/플레이어 명시 공격/유효 사건 맥락은 지원한다. 생활AI가 관계 수치만으로 무작위 폭행을 일으키는 자동 후보는 추가하지 않았다.
- 장기 성능 최적화나 데이터 손실로 범위를 넓히지 않았다.100명 전투 다수 주간·30/360일·10년 캠페인, 사법/사망·대규모 군단 전투는 미검증 또는 미구현. 이번 단기 측정으로 장기 플레이 성능을 주장하지 않는다.


최종 확인: Extended45/45(실행 후 세계 교체 UI 초기화·표시 문구만 보완), 보완 후 타입·기능 레지스트리·최종 UI 빌드/배포 산출물 참조 검사 통과. 전체 npm build도 통과했다. AcademySurvival 번들 약1.89MB(압축633KB)의 크기 경고는 남아 있다. 배포는 수행하지 않았다.
