# 고정 NPC 대화·리액션 연출 v1

2026-10-25. 별도 관계·지식·전투·시간 엔진을 만들지 않았다. 기존 상호작용의 결과와 NPC가 실제 알고 있는 사실을 표현하는 계층이다.

## 콘텐츠와 실제 실행

- 세레나·아델리아·루미엘·리제트·니아·카밀라·미엘·에스텔·피오나·노엘·브리나·엘리시아·테아·비올레타·이리스 **15명**, 말투 프로필15개.
- 각 인물26개, 총 **390개의 서로 다른 수작업 대사**. 기본10상황군×2개에 관계별3개와 본인 성공/실패/무승부3개를 더했다. 이름 치환 복사본은 없다. 공동 장면48발화는390개 수에 포함하지 않는다.
-10상황군: 인사/공부/훈련/선물/부탁·약속/걱정/갈등·사과/성공·실패/개인 서사/정보. 조건이 없는 인사와 제안도 결과·약속·물건을 만들어내지 않는다.
- NPC 조합12개×4발화: 아델리아·미엘, 루미엘·피오나, 니아·카밀라, 리제트·노엘, 에스텔·테아, 브리나·피오나, 엘리시아·이리스, 비올레타·미엘, 세레나·니아, 아델리아·에스텔, 테아·브리나, 루미엘·노엘.
- 장면은 실제 친목/상담/공동 공부/공동 훈련이 **수락되고 수행된 시간**에서 발화한다. 가상의 제작·연구 성공·공연 완성을 주장하지 않는 준비/협의 장면이다. 실제 효과는 원래 공동 활동 한 번만 적용한다.
- 수락 전, 갈등 관계, 활동 시간이4분 미만, LOD1~3에서는4회 대화 장면을 실행하지 않는다. LOD0 진행 중 이탈/중단/정밀도 하락은 남은 발화 중단. 실행하지 않은 대사를 나중에 복원해 채우지 않는다. 시간 직접 설정도 진행 중 장면을 중단한다.

## 선택과 사실 관계

- `createDialogueDirector`는 현재 단방향 관계, 실제 상태, 공동 일정, 명시적으로 선택한 기억/정보, 개인 사건 참조를 조회한다. 상황별 후보는 화자 인덱스에서 찾는다.
- 낯섦/지인/친밀/라이벌/갈등의 표현을 구분한다. 상대의 교수·선배 호칭을 친밀도만으로 제거하지 않는다. 한국어 조사 처리는 `withParticle`을 사용한다.
- 선택은 시드+발화 ID+대사 ID의 독립 해시로 결정한다. React 렌더·후보 조회는 선택 이력을 갱신하거나 세계 RNG·시간을 소모하지 않는다.
- 최근24개/화자, 전체2400개 이하. 최근 사용 문장에는 페널티를 주고 직전2개와 겹치면 안전한 기존 의미 대사로 돌아간다. 반복을 피하려고 모르는 사실을 말하지 않는다.
- 실제 `CombatCompleted`의 본인 승리/패배/무승부와 다른 사람의 결과를 분리한다. 전투의 구체적인 공격 순서를 추측해서 말하지 않는다.
- 학사 평가는 실제 참가한 중간/기말 평가 기록의 점수로 판단한다. 선물은 실제 원장의 수락/거절·기억으로 판단한다. 거절은 물품 이동·관계 보상을 추가하지 않고, 같은 장소에서 실제 전달된 거절 사실만 기록한다.
- 직접 경험/목격과 전언·추론을 구분한다. 전언은 세계의 원본 사실을 NPC에게 제공하지 않는다. 보유한 정보를 전달하는 기존 상호작용을 거치며, 표현 코드가 비밀을 임의 공유하지 않는다.
- 진행 중인 개인 사건의 발화는 실제 `sourceWorldEventId`와 참가자를 확인한다. 완료 후 반응은 실제 사건 기억이 있어야 한다. 기존62개 사건을 새로 복제하지 않았다. **실행 경로42개/보류20개라는 기존 개인 서사 범위는 그대로**다. 서사별 전용 다지선다 선택지·미구현 사건의 장편 대사는 이번 변경으로 완성되지 않았다.

## 저장·공개·성능

- 기존 `conversation-v1`에 선택적 `dialogue-v1`을 저장한다. 기존 턴에 선택한 대사 ID/감정/호칭/출처를 붙이고, 현재 관계가 바뀌어도 이미 한 말을 다시 고르지 않는다.
- 진행 장면의 다음 발화 시각·실제 발화·당시 관찰자, 최근 선택과 중복 키를 복원한다. 구형 저장은 새 이력이 비어 있으며 과거 대화를 새 장면으로 재구성하지 않는다.
- 보존 상한: 최근 이력2400, 리액션160, 공동 장면80, 처리 키2048. 일반 잡담마다 영구 기억을 추가하지 않는다.
- 원래 기억 엔진의 위치/의식/목격 정책을 재사용한다. 공개 대사의 실제 관찰자는 각 발화 시점에 기록하고, 사적 대화 전문은 당사자에게만 공개한다. 소문을 들었다고 과거 전문이 열리지 않는다. 일반 투영에서 다른 관찰자의 목록과 NPC의 내부 기억 참조를 숨긴다.
- 공통 대화 타임라인에 실제 발화 예약만 추가한다. 매분 전체 NPC/전체 대사를 전수 검사하지 않는다. 효과·목표·관계 변화는 기존 엔진이 담당하며 읽기와 회상은 보상을 다시 적용하지 않는다.

## UI

- 실제 대화 기록의 화자/감정/행동 묘사/문단을 통일했다. 감정은 색만으로 표현하지 않고 이름을 표시한다.
- ‘한 마디씩 읽기’, ‘다음 대사’, ‘모두 보기’는 텍스트만 제어한다. 기본은 즉시 표시이며 읽는 시간으로 세계 시간이 흐르지 않는다. 중요한 응답은 기존 동의·선택 창에서 제출한다. 창을 닫아도 미제출 선택을 자동 실행하지 않는다.
- 현재 상황의 기존 로그 칸과 사회생활 화면에 인지한 리액션/공동 대화를 표시한다. 원거리 NPC의 비공개 대화는 일반 UI에 표시하지 않는다.
- 개발자 대화 패널은 말투 프로필·현재 조건·후보/제외 이유·최근 ID를 보여 준다. 상황 재현은 기존 세계 제어(관계/욕구/실제 전투/물품/시간)와 격리 샌드박스를 재사용한다.
