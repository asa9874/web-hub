# 게임 연대기·427년 전조 v1.1

2026-10-26. 기존 균열 지역 엔진·달력·공통 세계 이벤트·학사 활동·개별 기억을 확장했다. 새 스토리 엔진이나 세계급 전쟁/졸업 시스템을 만들지 않았다.

## 실제 구현과 설계의 구분

- 단일 세계 시간과360일 달력/427-03-01 시작은 기존 구현을 재사용했다.
-427~430 재학,431 전후 진로 전환,431~436 세계 변화,이후 자유 진행은 설계 연대기로 등록했다. 학사는 학년1~4를 지원하지만 실제 졸업/진로 전환은 아직 미구현이다.
-436년이나 지역 봉쇄를 게임 종료 조건으로 사용하지 않는다. 지역 집계 세계를437년까지 진행해 시계/위기 상태가 유지됨을 검사했다. 이는 실제 졸업/진로 검증이 아니다.

## 새 회차의 진행 정책

`chronicle-v1`은 최초 잠재 이상10~35일/최대3지역120일 간격,427년7일·이후14일의 지역 평가를 사용한다.5개 별도 전조 예약도 기존 시계의 다음 경계에 포함하므로 시간 점프에서 누락되지 않는다. NPC마다 매분 전조를 검사하지 않는다.

-427년6월까지 잠재 이상,7월 이후 미세 교란,11월 이후 소형 탐사 개체가 가능하다. 기본적으로 구축체/대형 통로/공식 위협 발표/지성 문명 단서는 첫해에 발생하지 않는다.
-428년부터 구축체,429년부터 대형 관문이 **가능**하다. 실제 통과 용량·세력 예산·누적 안정도·방위/봉쇄 조건은 그대로 필요하다. 특정 날짜의 전쟁을 예약하지 않는다.
-기존에 압력80/안정도40/크기10 이상인 실제 위기에는 조기 확대를 허용한다. 첫해의 일반적인 새 세계에서는 이 조건을 자동 조작하지 않는다.
-연구 범위는427년12/428년30/이후100. 이미 높은 연구 값을 가진 저장의 수치를 낮추지 않는다. 첫해에는 확정 진실ID를 새로 주지 않고,지성 가능성은429년 이후에도 연구35/신호3을 요구한다.
-기존 자원·성장·전투 엔진을 복제하거나 NPC 일상을 침공 일정으로 강제 변경하지 않았다.

## 증거·후속 인과관계

-고유 ID `rift-prelude/427/<kind>`에 발생 시각/실제 지역/측정값/시드 기반 현상 파형/공통 세계 사건 ID를 저장한다. NPC 기억의 망각·보존 한도와 별개의5개 중요 자료다.
-428년 이후 해당 지역에 실제 신호3/연구15 이상이 쌓이면 현재 측정 파형·값과 과거 자료를 비교한다. 일치할 때만 `rift-prelude/revisit` 사건을 생성하고 과거 사건→후속 비교의 공통 DAG 관계를 만든다. 당시와 현재의 원인 사건 참조를 보존한다.
-현장 자료 열람 또는 완료된 실제 학사 활동(30분 이상)에서 NPC/플레이어가 자료를 알 수 있다. 열람 장소와 현재 시각으로 기억하며,과거 현장의 목격자로 만들지 않는다. 재검토 결과도 별도 현재 정보다.
-정보 전달·소문·출처/확신도·망각은 기존 기억/상호작용 엔진을 재사용한다. 원격 NPC에게 전역 배포하지 않으며,알게 된 현장은 기존 성향 기반 조사 후보가 된다.
-관할 기관의 조사는 기존 지역 집계 행동이다. 교수별 독창 논문/실험/계약,고정15인 전용 신규 연구 서사는 추가하지 않았다. 교수가 논쟁 상호작용을 완료했다고 기록하지 않는다.
-일반 UI는 개인이 실제 보유한 관측/자료/전해 들음만 표시한다. 초기 문명명/원인/정치/미래 결말은 개발자 화면에만 존재한다.

## 저장 호환성

기존 v1 저장에 `chronicle` 선택 상태를 추가했다. 없는 저장은 기존의 실제 역사와 진행 정책을 보존한다. 개발자 균열 패널의 **기존 역사 보존 · 앞으로의 진행에 연대기 적용** 버튼은 `rift_chronology` 명령으로 현재 이후만 전환하며,명령 이력이 저장된다. 반복 호출로 예약이나 과거 증거를 복제하지 않는다. 이미 열린 관문/피해/기억을 되돌리지 않는다.

5개 예약/증거/후속 비교·정책을 저장/복원한다. 중복 ID·잘못된 지역 참조·측정 변조·시간 역행·누락된 다음 예약은 거부한다. 기존 공통 세계 저장/기억/학사 형식은 재사용한다.
