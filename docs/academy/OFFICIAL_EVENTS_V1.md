# 아카데미 공식 행사 v1

2026-10-26. 아이디어 노트를 실제 코드에 맞게 통합했다. **대회와 문화제 운영 기반은 실행되며, 제작·음악·연구 성과 연동을 포함한 전체 기획은 부분 구현이다.**

## 실제 구현

6유형: 신학기 환영식, 동아리 공개 모집, 춘계 공식 개인 대련 통합 부문, 아카데미 문화제, 학술 공개 발표회, 학기 종료 표창. 표창은6월·11월에 각각 열려 연간7회다. 대회/문화제는 권장일 이후 첫 토요일, 표창은 실제 성적 확정 이후다. 다음 연도에 새 ID와 참가/결과 상태를 생성한다.

예정→모집·준비→명단 확정→진행→종료/취소. 실제 학생 자격/의무 일정/상태·피로/운영 인력/시설을 검사한다. 신청·철회, 예약 전 연기/장소 변경, 취소 시 임시 일정과 전투 정리를 지원한다. 학내 공지 전달은 현재 학내에 있는 학생만 기록하며, 출처 없는 학외 자동 지식 전파는 없다. NPC가 등록 도중 추가되는 경우의 대기 상태도 저장한다.

NPC 선호는 실제 관련 숙련·성향·활성 목표·기존 고정 학생 행동 선호를 사용한다. 고정 인물 참가·승리·우선 선발은 없다. 초과 신청은 신청 시각, 동시 신청은 시드 추첨으로16명을 선발한다. 동아리 모집에서 실제로 활동한 NPC는 기존 동아리 관심/자격/정원 규칙으로 가입을 신청한다. 플레이어도 같은 가입 API를 사용한다.

## 대회

- 8인7경기/16인15경기, 홀수 부전승·기권·불참·취소·다음 라운드·결승/준우승 기록.
- 기존 전투 엔진의 실제 HP/SP/MP, 기술·장비·대항 판정·AI·비살상 내구도를 재사용한다. 같은 라운드 중복 출전과 패자 진출을 저장 검증에서도 거부한다.
- 공식 참가 동의는 정확한 현재 경기/장소/등록자에 한해서만 전투를 허용한다. 임의 `officialMatchId`나 개발자 강제 모드로 참가를 위조하지 않는다.
- 실제 임시 일과와 경로를 예약한다. 늦거나 통행 불가하면 실제 불참/기권이며 순간이동하지 않는다. 대기/이동/경기는 하나의 시계를 공유한다.
- 30분 경기 슬롯,5분 체크인 유예. 기본 전투20라운드 종료 시 잔여 대련 내구 비율, 실제 가한 피해 순으로 심판한다. 완전 동률은 양측 진출 없음이므로 우승자가 없을 수 있다. 임의로 결승 승자를 추첨하지 않았다.
- 플레이어60분 전 확인→이동→기존 수동 전투/자동 선택. 다른 NPC 경기로 매번 멈추지 않는다. 공식 결과/중요 전투 요약은 보존하고 상세는 기존 보존 정책을 따른다.

## 문화제·행사 결과

9부스: 연금술, 마도공학, 검술, 마법, 음악, 요리, 역사·문헌, 탐험 기록, 학생회 안내. 실제 동아리와 회원, 보유 준비물, 시설 슬롯에 연결된다. 공동 운영 신청, 준비 일정, 운영·방문 예약과 실제 수행 분, 설명/운영 판정, 부족 시 축소·취소가 동작한다.

플레이어의 방문은 실제 이동과 체험 시간으로 진행한다. 방문자는 같은 장소에 실제 운영 중인 담당자가 있어야 체험으로 인정된다. 음식 선물은 실제 일반/고급 소지품만 기존 제안·동의·소유권 시스템을 거치며 화폐나 제작 성과를 새로 만들어 주지 않는다.

16개 공통/문화제 상태 신호가 기존 세계 이벤트 카탈로그에 연결된다. 공지·마감·갈등·불참·경기 결과·인지한 친구의 응원·후속 훈련 제안·준비물 부족·실제 판정·친구 방문·종료는 실제 조건에서만 신호를 낸다. 후속 제안은 상대가 거절할 수 있으며 약속을 강제로 확정하지 않는다. **FEST-04 자작 발명품 공개는 제작 이력 어댑터 부재로 발생시키지 않는다.** 조건을 만족하지 않은 신호는 생성하지 않는다.

공식 수상 기록은 실제 대회 우승/실제 확정된 성적 우수 기록을 사용한다. 자료 설명과 독창적 연구 성과는 구별하며 연구 결과 원장이 없으면 연구 수상을 보류한다. 고정15인 결과 표현은 기존 대사와 직접/목격 기억을 재사용한다. 회상·표현으로 관계/성장을 다시 지급하지 않는다.

## 화면·API·저장

학사 **공식 행사** 탭: 일정/단계, 신청/철회, 공개된 명단, 라운드별 대진, 경기 요약, 우승/준우승, 부스/준비물 부족/방문, 기록. 기존 복제 시뮬레이터의 학사 화면에서도 관찰·연기·취소·검증할 수 있다. 플레이어 출전은 기존 공통 이벤트 창과 전투 창을 사용한다.

`ai.getAcademyEvents()`에서 `getEvents/getLogs/eligibility/apply/withdraw/registerBooth/visit/pending/confirmMatch/cancel/reschedule/diagnose/save`를 제공한다. 계산/선택은 UI 밖에 있다. 시간 진행은 기존 시계 참가자로 처리하며, 일반 조회는 다른 인물의 신청·전달/처리 이력을 숨긴다.

통합 저장 `AiSandboxSave.academyEvents`는 선택 필드다. 활성 경기, 대진/참가/준비 분/중복 방지 키/신규 인물 공지 대기를 복원한다. 구형 저장은 자동으로 과거 기록을 만들지 않고, 학사 탭의 **현재 시점부터 공식 행사 연결**로 명시적으로 초기화할 수 있다. 기존 능력·성장·세계 시각은 보존한다. 연결 명령의 동일 시각 작업 처리는 기존 세계 명령 정책을 따른다.

## 제한·후속

제작품의 실제 제작 이력, 악기와 음악 전문 평가, 독창적 연구 성과/심사, 화폐 매출, 모든 갈등의 전용 분기 선택지, 공연·제작 관련 보류 개인 서사 완결은 구현하지 않았다. 준비물/선행 시스템이 없으면 문화제 전체를 성공으로 표시하지 않고 축소/보류를 기록한다. 완전 동점의 재경기/공동 우승 정책과 고급 관전 UI도 후속 대상이다. 공식 대진·관계·기억을 생략해 성능을 맞추지는 않았다.
