# 종족·문화·생활양식 상세 v1

2026-10-24. 이전 세계관은10문화의 기본 설명/출신 프로필이었다. 이번에는14문화의 생활 설정과 개인 취향을 기존 대화·활동·기억·세계 이벤트에 연결했다. 별도 관계/AI/시계/기억 엔진은 없다.

## 구현과 설계 결정

- 기존10문화 ID는 유지하고 제국 궁정·엘프 학술도시·라우렌 도시교역·그라크하르 상업도시를 추가했다. 각 문화에 역사·일상·예절·가족·선물·교육·내부 다양성·이름 표기 참고와 상반된 인물상2개를 작성했다. 종족의 일반 수명과 계통은 이전 설정 그대로다.
- 음식18, 의복12, 취미18, 선물18: 의복은 설정 자료, 나머지는 대화/행동에 쓰는 콘텐츠다. 실물 재고·식품 구매·상점 매출·마법 장비를 만들지 않는다. 개인의 선물 선호가 문화적 친숙도보다 큰 영향을 주며 거절/부담/중립도 가능하다.
- 24관습은 장소·실제 활동·시간·주제·의미·비공개 범위·반응 조건·관련 사건을 참조한다. 첫잎·백년의 서가·첫 작품·흑유리 서신·붉은 깃발제·천 가지 가게 등은 각각 다른 의미와 실제 활동을 갖는다.
- 행사24종은 공식 날짜 미확정의 **학내 소규모 교류**로 실행한다. 계절/현장 기회·참여 의사·공통 동의·실제 완료를 검사한다. 국가 축제 일정·상점 경영·방학 귀향을 실행한 것으로 대신 표시하지 않는다.
- 새 활동은 기념 정원 돌보기/손작품 제작/편지·기록 작성/문화 놀이4종이다. 도서관·광장의 적합한 공간에서 공통 스케줄러가 수행하며 실제 활동 구간의 욕구 효과만 적용한다. 식사는 기존 lunch, 공동 공부/훈련은 기존 활동을 재사용한다.
- `Character.culturalProfile`의 별도 시드 생성, 복수 성장 문화/현재 문화·친숙도·선호/거부·습관을 저장한다. 생성 폼에서 혼합 문화를 선택할 수 있다. 구형/고정 인물의 미설정은 보존한다. 가족 구성·계층·비공개 경험을 임의 생성하지 않는다.
- 공통 대화 제안 `kind:'culture'`의 함께 경험/상징 선물/뜻 질문·설명이 실제 공동 상호작용에 연결된다. 당사자 선택·의무 일정·장소·출입·이동·실제 시간·실패와 완료 증거를 우회하지 않는다. 같은 관습은 양쪽 모두 하루 대기한다.
- 완료 시 관계 효과는 기존 효과 엔진, 실제 문화 경험/선호/친숙도는 개인 프로필, 경험 출처는 공통 도메인 사건·NPC 기억으로 기록한다. 둘 다 모르는 관습을 설명만으로 학습하지 않는다. 회상은 보상을 재적용하지 않는다. 세 번 이상 경험하고 좋아하게 된 활동은 개인 습관이 될 수 있다.
- 문화 효용은 제한된 보정이다. 개인 취미는 정밀 AI의 기존 장소 후보가 되며 필수 수업/근무·긴급 상황을 무시하지 않는다. 미시 활동의 원거리 실행은 기존 LOD 정책을 따른다.
- 설정집의 종족/문화 상세, 공통 인물 상세, 기존 격리 세계의 문화 관찰·조건/교류/선물·선호 변경·기억/기록을 제공한다. 개입은 `culture_preference`, `conversation`, `event_request` 공통 명령으로 기록한다. 기존 생성/배치/시간/초기화/전체 JSON 도구를 재사용한다.

## 성능 및 미검증

Windows/Node.js22.18, 새 아침 세계/고정 시드, NPC100·AI활성·LOD해제(100/0/0/0), 엔진1시간 진행 **3.084초** 단일 측정. 목표0.3초 및 경고1초를 넘었다. UI·평균/느린 사례·상호작용 다수 주간·7일 성능의 증거가 아니다. 초기화4.049초는 별도다. 앞선 LOD 포함 측정과 전체 정밀 측정은 구분하며, 후속 코드 변경 전1.073초 단일 진단도 현재 버전 평균으로 재사용하지 않는다. 비교 조건을 통제한 전후 성능 개선율은 주장하지 않는다.

기존 이벤트 기회/예산·보존 한도·대화 기록 제한을 재사용하고 매 프레임 문화 전체를 실행하지 않는다. 프로필은 카탈로그 키의 제한된 수치/횟수다.100NPC30/360일·10년 안정성은 이번에 실행하지 않았다. AI 후보·사건이 추가되었으므로 과거 장기 검사만으로 현재 문화 버전의 장기 안정성을 완료 처리하지 않는다.

후속: 실물 인벤토리/제작·우편 배달·귀향 교통·생리적 식이 제한·상세 언어/종교/혈통·문화 동화·국가 경제·고급 축제 운영. 이번 버전의 편지 작성은 배달이 아니며 상징 선물은 아이템 소유권 이전이 아니다.
