# 스킬·숙련·분기 진화 v1

## 분석과 설계 결정

기존49숙련도 XP/랭크는 실제 행동 효과·학사·전투와 연결되어 있었다.419개 특성은 주로 정의/출생 슬롯/효과/진화 참조로 존재했고, 실제 일반 획득·진화 실행기는 없었다. 도감의 추상 `training/assessment` 플래그를 실제 완료로 가장하지 않고, 새 실행기는 완료 원장·실제 수련 시간·기초 역량·선행 스킬 숙련·검증된 도전으로 판단한다.

스킬 정의는49기초+기존419계보+검술3전문=471개다. 이는471개의 고유 효과를 새로 완성했다는 뜻이 아니다. 기존 ID·설정·효과 참조는 유지했고,47개 고유/구형 항목은 일반 수련 신규 습득에서 제외했다. 기존 효과 중 전용 어댑터가 없었던 고유 옵션·생산/생활 분야의 상위 도전은 남아 있다. 기프트의 정체성·보유·효과는 바꾸지 않았다.

## 실제 플레이 변화

- 실제 완료한 수업·훈련·학습·연구 관측·정리/근무/손작업과 충분한 교류에서 관련 계열 수련이 쌓인다. 기초49숙련의 성장은 원래 도메인 규칙을 사용하고 별도 전역 레벨은 만들지 않았다.
- 개별 습득 스킬의 숙련0~9는 관련 경험으로 증가한다. 피로·일180분 상한과 실제 도전 조건을 사용한다.4단계 이상은 단순 반복만으로 무한히 성장하지 않는다. UI에 반복 수련 상한과 부족한 도전 조건을 알린다.
- 짧은 인사와 잡담만 반복하면 성장하지 않는다.15분 이상 실제 대화도 같은 상대와 하루 한 번만 인정한다. 공동 공부·훈련은 서로 완료된 상호작용에서만 양쪽에 반영한다.
- 선형 진화는 이전 단계를 대체하고 과거 ID를 보존해 재습득 중첩을 막는다. 플레이어는 열린 분기를 선택한다. NPC는 같은 조건에서 실제 전문/능력·기술 사용과 기존 캐릭터 방향을 바탕으로 자율 선택한다.
- 스킬 숙련은 관련 판정에서 최선의 보정 하나, 최대3점을 기존±15 한도 안에 제공한다. 영향력/희귀도/기프트 등급을 직접 전투력으로 더하지 않는다.

## 검술 전문화

| 분기 | 실제 행동 | 플레이 방식 |
| --- | --- | --- |
| 쾌검술 | 쾌검·연속 공방: 기력4, 피해−4, 명중+1, 선행+8, 근접 | 자원 보존·선행·지속 공방 |
| 중검술 | 중검·파쇄 일격: 기력16, 피해+12, 명중−4, 선행−5, 재사용2 | 상대 방어 자세의 피해 경감을 절반 관통, 강타 뒤 호흡 관리 |
| 정밀 검술 | 정밀·관찰 찌르기: 기력9, 피해+4, 명중+5, 근접/중거리 | 실제 분석 성공이 필요하고 다음 공격에서 관찰 기회를 소비 |

세 전문화는 상호 배타이며 공통 검술 기초를 유지한다. 선행 중급 이상 스킬·숙련2/기초 검술2 이상·수련480분이 기준이다. 이미 중급 이상의 시작 검술 경험과 기초3 이상이 있는 인물은 시작 실력을 인정한다. 동일 조건의 플레이어는 직접 선택하고 NPC는 자신의 방향으로 전문화한다. 과거 수련 시간을 숫자로 만들어 주지는 않는다. 기존20전투 기술을 유지하고3개를 추가했다.

실제 전투 라운드에서 세 기술의 소모·분석 조건·피해/방어 관통을 확인했다. NPC도 같은 가용성/자원/판정 후보를 사용하며, 정밀 전문 NPC는 분석이 없을 때 관찰을 우선할 수 있다.

## 저장·인과관계·기존 기능

`Character.skillBook`이 실제 습득/숙련·수련·도전·사용 기술·발견·대체된 ID·최근32개 이력을 가진다. 기존 `traitIds`는 현재 보유한 구형 스킬의 호환 투영이다. 기존 효과를 두 번 적용하지 않으며 기프트는 별도다. 기초49숙련 XP는 기존 `GrowthState`/`proficiencyRanks`만 사용한다.

`AiSandboxSave.skills`에 현재 시각의 완료 원인 키·진행 하한·연결 인물을 저장한다. 스킬 상태는 기존 캐릭터 저장에 함께 포함한다. 로드/조회/트리 선택으로 경험을 지급하거나 추첨을 재실행하지 않는다. 새 활동 시간 메타데이터는 효과 결과의 구형 지문과 충돌하지 않도록 처리했다. 구형 저장은 자동 주입하지 않으며 현재 시점에서 명시적으로 연결한다. 이전 사건을 다시 보상하지 않는다.

## UI

공통 캐릭터 상세의 ‘스킬 트리’, 플레이 설정집의 ‘스킬 계보’, 전체 개발 도감이 같은 컴포넌트를 사용한다. 정의의 실제 선행/진화 관계에서 선을 생성한다. 분야/검색/보유·전체 계보·최대72개 부분 표시·노드 선택/숙련 게이지·분기 확정·확대·빈 공간 드래그·방향키 스크롤·내부 상세를 제공한다.

보유·성장 가능·잠금·다른 분기를 색/아이콘/명암으로 구분한다. 일반 플레이에서는 미발견 상위 이름/조건을 숨기며, 전체 개발 설계 도감과 구분한다. 이동·전투·교류 도중 플레이어가 즉석 진화하는 것을 막았다. 새 무거운 그래프 라이브러리나 비트맵 에셋은 추가하지 않았다.

## 검증과 제한

전용 검사:471노드 고유ID/DAG, 기존 능력/기프트/기초 숙련과15인 참조 보존, 실제 훈련·교류/NPC 성장, 중단/중복 제외, 일 수련 상한, 선형 대체/재습득 금지,3전문 상호 배타/실제 전투 라운드, 구형 지문·전체 저장, 단일/시간 분할/분 단위 동일 결과. UI SSR은 새 세션/노드·연결/세 분기·플레이어 숨김/저장을 확인했다.

관련 기존 판정·전투, 상호작용/효과, 고정 학생, 플레이어, 기억 검사를 수행했다. 원본 로그는 `test-results/academy-skills/`에 남긴다. 잘못된 초기 검사 명령 `test-academy-action-effects.mjs`는 존재하지 않아 실행되지 않았고, 실제 등록된 `test-academy-interactions.mjs`로 효과 계약을 검증했다.

**남은 범위:** 기존419개 개별 고유 효과의 완전한 재작성/실행 보장, 제작·공연·탐험의 고급 도전 어댑터, 검술 이외 분야의 전용 활성 분기, 고정15인·모든 빌드의 수년 성장/밸런스, 실제 브라우저의 입력/시각·모바일 전체 검수. 기존 기프트 미연동 권능을 이번에 실행됐다고 처리하지 않았다. 학교/세계 콘텐츠의 생산·연구 성공 엔진이 없는 곳에서 가짜 성과를 만들지 않는다.

매분 NPC×471개를 검사하지 않는다. 완료 사건에서 해당 계열의 후보/보유 스킬만 갱신하고, 관련 판정은 실제 보유 스킬만 확인한다.471노드를 동시에 렌더링하지 않는다. 이번 짧은 검사로100NPC7일1~3초나10년 성장 균형을 달성했다고 주장하지 않는다.
