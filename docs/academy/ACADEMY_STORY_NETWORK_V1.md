# 아카데미 사건망·개인 서사 연쇄 v1 — 부분 구현

## 기준과 설계 판단

2026-10-26. 기존 WorldEventDefinition/Instance, 단일 EventQueue, 공통 상호작용·효과·개별 기억·통합 저장을 확장했다. 기존 누적 미커밋 작업을 되돌리지 않았다. 개인50/다인물12 중42개 연결·20개 의존 보류를 확인했다. 설계만 있는 제작/연구/편지/공연 결과를 구현된 것처럼 사용하지 않았다.

이번 추가 일상30개까지 **정의92개, 실행 경로 연결58개, 의존 보류34개**다. 이 수는 모든 고유 선택/분기가 완성·검증됐다는 뜻이 아니다. 전 세계 카탈로그는236개다.

## 실제 확장

- 실제 원인 인스턴스에 미발생 후속 기회를 보존한다. 해금·지연·수정·우회·차단/만료가 공통 큐를 사용한다. 성공/실패 단일 플래그와 구분한다.
- 해금된 기회는 현재 배역·위치·출입·관계·일정 조건이 맞아야 발생한다. 상대가 떠나면 기다리거나 만료하며 순간이동시키지 않는다. 플레이어가 아닌 원래 NPC도 처리한다.
- 수정은 조건을 통과한 기존 결과의 가중치에만 적용한다. 우회는 대체 정의를 사용한다. 차단 원인 ID를 저장하고 이미 끝난 사건을 지우지 않는다.
- 개인 선행 조건의 결과 ID/경과 시간 범위를 지원한다. 아델리아 새벽 공부와 루미엘 공동 공부에 누락됐던 뿌리 선행 조건을 연결했다. 리제트 갈등 후속은 실제 경계/갈등 결과와 현재 반감을 확인한다.
- 기존 개인 후속은3시간 이후부터 최대180일 기회로 처리하고6시간 간격으로 재검사한다. 현재 상태가 이미 다음 사건 조건을 만족하면 기존 독립 기회/개발자 요청도 가능하다. 다음 학기/학년/졸업 전용 콘텐츠까지 구현한 것은 아니다.
- 실제 공동 활동을 마친 개인 사건은 당시 관계에 따라 갈등/신뢰/조심스러운 접점으로 나눈다. 이 표현이 모든 인물의 고유한 장기 결말3종을 대체하지 않는다. 거절/중단은 공통 실제 실패 이력이다.
- 12개 교차 사건과 일상 사건의 연결표를 등록했다. 새로운 원인에 관련 인물이 실제 참가해야 교차 배역을 맡을 수 있다. 보류 선행이 있는 연결은 자동 활성화되지 않는다.
- ACA-06/CLB-06은 실제427년 측정/표본 기록을 열람한 `RiftChanged` 신호와 원본 세계 사건 ID만 사용한다. 평범한 실습을 자동 이계 사건으로 바꾸거나 이계 문명의 정체를 공개하지 않는다.
- 플레이 UI는 기존 요청·수락·거절/VN 결과·기억 기반 로그를 사용한다. 별도 선형 퀘스트 창이나 강제 수락을 추가하지 않았다.

## 인물·기억·관계

15명 뿌리 ID/주제는 `data/academyStories/roots.ts`에 등록했다. 원래 개인50개를 복제하지 않았다. 피오나·브리나·테아·비올레타의 핵심 실험/제작/탐험/공연 실행 어댑터와 일부 후속을 비롯한 기존20개 보류는 남아 있다. 신규34개 보류의 전체 목록은 테스트 결과 JSON과 데이터의 blocked/deferred 필드에 있다.

공통 상호작용 결과를 다시 보상하지 않는다. 목표를 선택/완료하거나 성격을 강제로 바꾸지 않는다. 관계 효과는 실제 공동 활동 엔진의 결과이며 서사 분기 조회/회상에는 보상을 지급하지 않는다. 개인 사건을 모르는 사람의 기억을 생성하지 않는다.

개발자 시뮬레이션 → 고정 학생·개인 서사에 사건망 관찰을 추가했다.15명 주제, 가능한 연결 SVG, 현재 조건, 실제 원인의 최근32개 후속 기회/결과/차단/만료,30개 콘텐츠의 보류 이유를 볼 수 있다. 가능한 경로는 점선으로 표시하고 실제 이력 그래프와 구분한다. 일반 플레이에 내부 평가나 미래 분기를 공개하지 않는다.
