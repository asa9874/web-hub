# NPC 대화·사회생활·플레이어 대화 v1

2026-10-24. 기획의 의도를 기존 상호작용/일과/기억/플레이어 계약에 연결한 구현 기록이다.

## 구현 차이와 설계

기존23종 상호작용에는 실제 동시 예약·수락/거절·배타 활동·소요 시간·효과·정보 전달이 있었다. 별도 대화 시뮬레이터나 관계 DB를 만들지 않고, 공통 상호작용에 선택적 `ConversationController`를 붙였다. 식사 약속의 실제 식사를 위해 `meal_together`를 추가해 상호작용은24종이다. 기존 모욕/위협 등 부정적 상호작용의 판정은 기존 경로를 유지한다.

- `types/conversation.ts`: 일반/기억/학사/정보/약속/약속 응답을 구분하는 의미 데이터, 발화, 대화 기록, 약속, 일별 집계와 `conversation-v1` 저장.
- `data/conversations/index.ts`: **28개 의도·10개 주제 계열**, 의도별 시간·표현·중요 선택·개별 결과 프로필,6개 약속 유형, 빈도/보존 규칙.
- `systems/conversations.ts`: 기존 요청·활동·효과 실행 위에서 의미/반응·선택·약속을 처리한다. 현장에 실제 도착한 두 인물의 공동 활동만 완료한다.
- `systems/conversationPresentation.ts`: 별도 결정 해시로 문장을 표현하는 순수 함수다. 세계 RNG/결과/능력치를 바꾸지 않는다. 외부 LLM을 사용하지 않는다.

대화는 인사2분, 질문10분, 위로12분 등 실제 시간을 소비한다. NPC별 수락 여부와 표현 반응은 분리한다. 장소/이동/배타 활동·의무 일정까지 남은 시간·피로/긴급 필요·동의 조건은 공통 엔진에서 검사한다. 중단된 대화에 완료 효과나 약속을 지급하지 않는다.

## 실제 행동과 결과

- 기존 Utility AI가 같은 장소의 알려진 상대와 제한적인 첫 만남 후보를 평가한다. 낯선 인물 전체에 모든 사회 행동을 확장하지 않고 사회 욕구·시드 기회에 따른 인사 후보로 제한한다.
- 주제는 실제 공동 강의·관련 개인 기억·알고 있는 정보·관계·활성 목표·성향·피로·개인 시드를 참고한다. 고정 캐릭터의 미확정 과거나 목표를 만들지 않는다.
- 28개 의도는 일반 대화, 근거 기억, 공동 강의, 실제 보유 정보, 실제 약속 및 응답으로 구분된다. 칭찬/감사/사과/자랑은 관련 기억이 필요하다. 사과는 자신의 부정적 사건 근거가 필요하다.
- 반응은 성향·관계·기억·상태에 따라 달라지고, 의도별 관계·인정/안전/호기심의 일회성 결과를 기존 효과 엔진으로 적용한다. 시간에 따른 사회 욕구/피로 효과는 기존 욕구 엔진만 적용한다. 같은 결과 ID는 재적용하지 않는다.
- 관계 감정은 방향별로 독립적이다. 일일 상한/친밀도 감쇠를 재사용한다. 친구 인식은 실제 의미 있는 호의적 대화3회 이상과 관계 조건을 함께 요구한다. 라이벌은 실제 공동 강의에서 명시적인 경쟁 선언과 호의적 반응이 필요하다. 교제/정리는 명시적인 제안·응답으로 처리한다.
- 일반 인사는 영구 기억을 남기지 않는다. 의미 있는 대화는 의도/주제/반응이 있는 개인 기록으로 남긴다. 정보 공유·소문은 기존 실제 완료 전달·신뢰·확신·출처 사슬·왜곡 정책을 사용한다. 직접 경험을 전해 들음으로 바꾸거나 세계 사실을 덮어쓰지 않는다.
- 모든 구조화된 대화 내용은 보수적으로 당사자 비공개다. 기존 공개 대련 사건은 기존 목격 규칙을 유지한다. 일반 UI는 본인의 대화·관계 변화만 보여주고 타인의 숨은 감정/욕구나 성적을 출력하지 않는다.

## 플레이어와 약속

플레이어 자동 생활도 같은 엔진을 사용한다. 가벼운 대화는 자동 처리하고 고백·공식 대련·연구/약속·중요 비밀 및 직접 대화 선택은 기존 `playerLife`를 통해 정확한 세계 경계에서 대기한다. 응답 전 결과는 적용하지 않는다. 직접 선택지의 질문/격려/경쟁/약속/종료는 다른 의미와 결과를 가진다. 거절·나중에·종료를 제공하며 나중에는 제안을 종료할 뿐 새 약속을 임의 생성하지 않는다.

약속 수락 대화가 실제 완료되면 두 인물의 공통 임시 일과표에 날짜/장소가 있는 대기 일정을 등록한다. 자동 생활은 이동을 미리 시작하고(플레이어 수동 모드는 직접 이동 또는 자동 생활 전환) 현장 도착·출입·상대 수락·실제 공동 활동 완료를 검사한다. 공부/훈련/대련/상담/식사/만남6종을 지원한다. 수업·근무와 충돌하면 의무 일정을 우회하지 않는다.10분 유예 후 불이행을 기록하고 실제 불참자에 대해 제한적인 신뢰 결과를 한 번만 적용한다. 수업/근무/심한 부상 같은 확인 가능한 사유는 벌점을 면제한다. 개발자 시간 직접 설정은 약속을 취소하며 불이행 벌점을 만들지 않는다.

학사 주제는 실제 공동 수강 또는 담당 교수 관계를 검증한다. 다른 학생의 비공개 점수를 임의로 알거나 언급하지 않는다. 연구 제안은 실제 교수 역할이 있는 인물만 생성한다. **성적 구간별 전용 상담 내용과 독립 연구 진행 엔진은 부분 구현/후속**이다.

## UI·저장·API

실제 플레이 **대화·사회생활** 메뉴와 관찰 인물의 말 걸기 버튼, 개인 대화/첫 만남/정보 집계, 최근 기록·약속을 제공한다. 설정집 `kind=conversation`에 의도 도감/테스트 버튼, 기존 격리 시뮬레이터에 전체 관찰·인물/주제/장소/기간/중요도 필터와 실제 요청/거절 사유/선택을 연결했다. 개발 개입은 세계 `conversation`/`conversation_choice` 명령으로 기록한다.

`interactions.getConversations()` API:

- `options(source,target)`, `request(source,target,proposal,direct?)`
- `getPending(player)`, `choose(player,conversation,proposal|accept|decline|later|end)`
- `getRecords(viewer?)`, `getCommitments(viewer?)`, `getSummary(viewer,from,to)`
- `save/load/connect`; 로더가 시각·ID·참조·상태·한도·당사자를 검사한다.

플레이어 직접 요청/응답은 `playerLife.requestConversation`/`respondConversation`을 통하며 기존 대기/시간 재개/3슬롯에 포함된다. 저장은 `interaction-v1.conversations` 선택 필드이고 `snapshotAi`와 통합 세계 JSON에 포함된다. 데이터가 없는 기존 저장은 종전 상호작용 모드를 유지한다. 진행 중인 기존 활동에 새 의미나 결과를 소급 부여하지 않는다.

상세600개, 일별 집계90일, 약속100개를 제한하며 유지 중인 약속의 원인 대화를 보호한다. 종료 약속은14일 또는 보존 용량에 따라 정리한다. 활성 약속 때문에 새 약속이 거절되는 경우는 실제 활성 한도100개일 때이며, 완료 이력만으로 새 약속을 막지 않는다. 이행/불이행은 개인별 `SocialCommitmentChanged` 사실과 기억에 남기며 멀리 있는 상대의 실제 상황을 자동으로 알려 주지 않는다. 자신의 불참 기억은 이후 사과의 근거가 된다. 중요한 기억과 도메인 사실은 별도 기존 보존 정책을 따른다. 모든 긴 대사를 영구 저장하지 않고 구조화된 발화와 결과를 저장한다.

## 제한과 후속

v1은 보통2개의 구조화된 발화와 짧은 선택 흐름이다. 자유 입력 대화·그룹 대화·고급 기만·성격 변화·복잡한 청취/거리·전용 장기 연구/연애 서사는 미구현이다. 약속 변경은 취소 후 다시 제안하며 자동 재협상은 하지 않는다. 중요 선택 대기 중 외부 원거리 대화는 제공하지 않는다. 일반 대사 변형은 제한적인 어조/관계 반응이며 고정 캐릭터의 새 공식 말투를 임의 확정하지 않는다. 장기 성능/저장 크기는 추가 검증이 필요하다.

신규 파일: `types/conversation.ts`, `data/conversations/index.ts`, `systems/conversations.ts`, `systems/conversationPresentation.ts`, `components/ConversationPanel.tsx`, `scripts/test-academy-conversations{,-browser}.mjs`, 계약 README와 이 문서.

연동 파일: `systems/{interactions,actionEffects,aiSandbox,playerLife,npcMemory,worldSimulation,validationScenarios}.ts`, `types/{interaction,actionEffects,memory,worldSimulation}.ts`, `data/{interactions,features}/index.ts`, `components/{Gameplay,Simulation,PlayerControls,SimulationPlayerControls,CharacterAiPanel,AiProvider}.tsx`, `AcademySurvival.tsx`, 패키지/검사 선택기·직접 영향 계약 및 진입 문서. 이전 작업부터 존재하던 전체 변경 파일 수를 이번 작업의 변경 수로 보고하지 않는다.
