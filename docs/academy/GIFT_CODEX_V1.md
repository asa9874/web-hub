## 기존 감사·호환성

기존417개 전체에 짧은 원문·실행 공백·유사 효과 구조를 검사했다. 이것은417개 모두의 독창성/문장 품질을 수작업으로 승인했다는 뜻이 아니다. 검사 결과는 `test-results/academy-gifts/audit.json`에 전체 ID별로 남는다. 원본 비교는 수정하지 않은 기존 원시 배열을 조합한 `legacy-source.json`을 사용한다.

설명 개선8개: borrowed-edge, empty-scabbard, honest-wound, roof-memory, warm-hem, threshold-step, pocket-snow, shadow-measure. 설명만 보강했으며 기존 미연동 효과를 새로 실행됐다고 표시하지 않는다.

퇴역16개: biscuit-initial, sugar-cube-corner, hat-weather-report, belt-hole-memory, cup-handle-polite, pillow-cold-corner, chalk-dust-sleeve, candle-wax-flower, sneeze-paperboat, potato-face, uninvited-confetti, wooden-fork-complaint, bathroom-tile-count, teabag-last-sigh, soup-spoon-shadow, marmalade-moon. 실제 ID에는 `gift-x-` 접두사가 붙는다. 소박함 자체가 아니라 고유 실행/전략적 가치 부족을 기준으로 선별했다. 삭제하지 않고 신규 생성에서만 제외했다.

## 실행·UI·성능 설계

기존 GiftRegistry·출생 가중치·공통 판정·NPC 기억 감쇠를 확장했다. 새 독립 기프트 엔진이나 전체 NPC×기프트 매분 루프는 없다. 운 변환은 기존 추첨 뒤 결정적으로 적용하고 추가 RNG를 소비하지 않는다. 분포 미리보기도 같은 계산을 사용한다. 기억 감쇠는 기존 갱신 시점에서 해당 소유자만 확인한다.

도감은 요약→권능 기록→발동/한계→실제 적용 순서로 표시한다. 실행 대기/부분/퇴역과 신규 추첨 제외를 명시한다. 실제 효과가 없는 SPECIAL_RULE 원문은 접힌 규칙 정의로 분리한다. 캐릭터 상태와 시작 공개에서는 긴 원고 대신 요약/실행 상태를 사용한다.
