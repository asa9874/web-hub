# 통합 세계 실행·관찰 v1

2026-10-24. 아이디어 노트의 기존 기능은 재사용하고 실행 조정·관찰·통제의 차이만 구현했다. 기존 미커밋 변경과 앞선 LOD/세계 이벤트 작업을 되돌리지 않았다.

## 구현

- `src/AcademySurvival/systems/worldSimulation.ts`, `types/worldSimulation.ts`: 단일 세계 런타임·명령·감사 이력·전체 스냅샷·읽기 전용 정합성 검사. `createWorldSimulation`, `advance`, `advanceTo`, `advanceToNext`, `command`, `snapshot`, `getLogs`, `getStatistics`, `diagnose`, `retain`/`dispose`.
- `systems/aiSandbox.ts`: 신규/복원 세계의 동일 엔진 조합과 멱등 연결/해제. 기존 통합 저장 형식 유지.
- `systems/gameTime.ts` 및 각 엔진의 timeline 등록: 명시 단계 ID, 안정 순서, 동일 시각 재예약256회 제한, 처리 경계/호출 진단. 각 엔진의 실제 큐와 중복 방지 원장은 유지한다.
- `systems/npcAi.ts`, `types/npcAi.ts`: 개별 판단 일시정지/재개와 선택적 저장 필드. 이동·물리적 일정은 계속 처리한다.
- `systems/locationWorld.ts`, `systems/npcSchedules.ts`와 해당 타입: 발생 당시 장소를 로그에 보존해 장소 필터에서 현재 위치를 추측하지 않는다.
- `components/Simulation.tsx`, `WorldSimulationPanels.tsx`, `Simulation.css`: 기존 시뮬레이션 화면 확장. 신규 세계/복제 세계, 시드·NPC수·날짜·위치, 재생/정지/배속, 시간·일·주/목표시각/다음 예약, 인물 추적과 공통 팝업, 장소·조직·사건, 실제 누적 통계, 명령·로그, JSON 저장/복원, 정합성 검사.
- `components/WorldEvents.tsx`: 기존 SVG 그래프/연대기를 재사용하며 조정기 게시 시점으로 관찰 갱신 가능. 개별 세계 이벤트 도감의 기존 구독은 유지.
- `data/features/index.ts`: 통합 관리/관찰 두 시스템과 증거·장기 미검증 등록. `package.json`, 새 테스트2개, 기존 LOD 브라우저 진입 제목 갱신, 컨텍스트/현황/작업 정책/시뮬레이션 계약 문서 갱신.

## 설계 판단

거대한 통합 상태 저장소·별도 이벤트 큐를 추가하지 않았다. 기존 단일 시계가 예약 경계와 같은 시각의 후속 작업을 처리하고 조정기는 수명·명령·오류 경계만 맡는다. 기존 AI/일과/욕구/기억/관계/상호작용/효과/세계 사건/LOD 계산을 생략하지 않는다.

개발 명령과 실제 세계 사건을 구분한다. 상태 효과는 공통 원자적 효과 엔진을 호출하며 목표 표시 진행도는 완료 조건을 대신하지 않는다. 강제 배치는 명시적으로 표시하고 일반 이동과 분리한다. 전체 세계·비밀 정보는 개발 샌드박스 범위이며 일반 캐릭터 공개 규칙을 바꾸지 않는다.

UI 게시를 최대4회/초로 제한하고 짧은 계산 구간 사이 프레임을 양보한다. 1배속은 실제1초당 세계1분이다. 배속은 요청 속도이며 처리 성능을 보장하는 수치가 아니다. 시간 진행 감사 기록은 요청량과 실제 진행량을 구분한다.

## 검증

- 신규 계약: 같은 시드/명령 재현, 단일 시계, 개별 AI 정지, 정상 이동/강제 배치, 욕구/방향성 관계/공통 상태 효과, 전체 저장 복원 연속성, 구형 저장, 관찰 무변경, 1분×60=1시간, 소규모1시간×24=하루, 단계 순서·중복 ID·무한 재예약 차단.
- 10/50/100명 각각 실제 엔진10분 진행 및 진단 오류0. 초기 단독 계약 실행의 계산 시간은 약13/77/148ms(후속 계약 실행14/76/156ms). Node22.18.0·Windows 로컬·새 세계·역할 혼합·LOD 활성·AI 판단 연결 조건이며 진단 시간 제외. 전원 정밀100명·7일 대표 플레이 성능 측정이 아니다. 기계별 변동이 있으므로 성능 목표 달성으로 해석하지 않는다.
- 핵심 브라우저: 새 세계10명, 재생/정지, 욕구·AI 통제, 장소·조직·인과 그래프, 검사, 전체 JSON 복원,390px 가로 넘침 없음, 종료 후 실제 게임 날짜/인원 보존. 별도 LOD 브라우저도 기존 인구·주민·팝업·경로 거부·초기화 확인.
- 영향 범위 회귀: 시간, 배치 제외 AI(6시간 분할 비교 포함), 세계 이벤트 FAST/INTEGRATION, 기억 계약, 상호작용·효과, LOD 계약 통과. 장기 스트레스 실행이 아니다.
- 원본 로그: `test-results/academy-world-{contract,browser,lod-browser,time,ai,events,memory,interactions,lod}.log`. 신규 결과: `test-results/academy-world/results.json`, 모바일 캡처 `test-results/academy-world/mobile.png`.
- 앱/빌드 설정 타입 검사, 변경 파일 ESLint, 기능 레지스트리31시스템/206항목, Vite 프로덕션 빌드와 배포 산출물38개 프로젝트 참조 검사 통과. Vite500kB 초과 청크 경고는 남아 있다. 로그 `academy-world-{typecheck,node-typecheck,lint,final-lint,final-guard-lint,features,build,dist}.log`.

## 미완료·미검증

- 30/90/360일·10년 누적 저장·대표 수업/시험/행사 주간7일 성능은 새로 실행하지 않았다. 기존 LOD 원거리8시간3.268초 경고는 해결됐다고 주장하지 않는다. UI 반응성 개선과 엔진 처리량 최적화는 별도다.
- 실제 선택 개입을 요구하는 플레이어 사건 대기 계약, 성적/진급/졸업/선거, 정식/headless 전투, 영구 캠페인 슬롯은 기존 선행 미구현 범위다. 이 화면에서 가상의 결과를 생성하지 않는다.
- 진단은 동결된 모든 세계 불변식의 수학적 증명이 아니며 실제 계약과 교차 상태를 검사한다. 로그는 기존 엔진별 보존 한도 내 기록이다. 모든 과거 기록의 무한 보관/복원 기능은 제공하지 않는다.
- 스냅샷 복원과 동일 명령열 결정성은 검증했지만 UI의 임의 과거 시점 되감기/명령 자동 리플레이 편집기는 후속 제안이다.
