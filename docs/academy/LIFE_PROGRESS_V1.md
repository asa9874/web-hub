# 플레이어 성장·명성·평판·장기 목표 v1

2026-10-26. **전체 아이디어 노트는 부분 구현이다.** 공통 성장과 실제 기록/Goal·개별 지식을 연결했으며, 연구·제작·졸업 및 세부 평판 피드백은 선행 기반이 필요하다. 기존 공식 행사 v1의 부분 구현 상태를 완료로 바꾸지 않았다.

## 설계와 실제 연결

- 성장: 기존 공통 효과 엔진의 능력치/숙련도 XP·경지·피로/환경·실제 완료 정책을 유지한다. 새 전역 레벨, 목표 완료 보상, 특성 자동 획득은 없다. 월별 최초/최종 수치·XP·대표 원인을 집계한다. 기존 능력치200 성장 제한은100상한과 다르며 이번 작업에서 재조정하지 않았다.
- 업적:30개 정의, 실제 활동/전투/학사/조직/행사 원장 확인. 최초 업적은1회, 대회/학기 등 실제 새 공식 성과는 별도로 기록한다. 다른 NPC가 우승하면 그 NPC에게 기록한다. 공지를 수동으로 흉내낸 사건만으로 우승 업적을 만들지 않는다.
- 명성: 현재 실제 정보 보유자에 근거한 분야/지역별 인지도다. 실력 수치에서 자동 산출하지 않는다. 다른 지역으로 정보를 순간 전파하지 않는다. 원거리 알려짐과 호감·존경은 별개다.
- 평판: NPC가 직접/목격/전달·추론으로 가진 기억을 조회한 투영이다. 주제별 현재 근거/확신도와 실제 성향을 사용한다. 세계의 원본 결과를 믿음에 맞춰 수정하지 않는다. 별도의 전원×전원 평판 테이블을 만들지 않았다. 승인 조직의 실제 기여 평가는 조직 구성원 전체의 속마음을 대체하지 않는다.
- 목표:25개 생활 목표는 기존 Goal 도메인과 저장/기한/우선순위/Utility 후보를 사용한다. 기존 NPC 자동 생성 목표 풀에는 넣지 않는다. 다중 선택·포기·재선택, 선택 이후 근거와 기한 실패를 지원한다. 목표가 없어도 진행 가능하다. 특정 학문 향상은 선택 당시 가장 높은 보유 학문을 기준으로 한다.
- 행동/기회: 인지한 상대에 대한 기존 대련/훈련·공부 후보에 제한 보정한다. 실제 주변 인물·경로·동의·일정·LOD를 우회하지 않는다. 기존15인 대사/리액션을 재사용하며 모든 인물의 칭찬이나 새 제안을 강제하지 않는다.
- UI: 공통 캐릭터 상세의 성장/목표/업적/명성 탭과 일·주·월 보고. NPC 내부 평가와 정확한 전파 인원은 개발자 모드만 표시한다. 일반 화면은 공개 성과/실제 본인 조직 기여를 표시한다. 복제 시뮬레이터의 공통 상세도 같은 엔진을 읽는다.
- 저장: 선택적 `lifeProgress`, 기존 Goal/기억/효과 저장을 함께 복원한다. 구형 저장은 공통 상세의 ‘현재 시점부터 기록 시작’으로 명시 연결하며 과거를 소급 생성하지 않는다.

## 콘텐츠

업적30개와 목표25개는 `src/AcademySurvival/data/lifeProgress/index.ts`에 타입 안전하게 등록했다. 연구 시작/공동 연구/실험/직접 제작/공식 연구 성과와 졸업은 실제 원장이 없어 획득을 보류한다. 일과의 `self_study`를 독창 연구 성공으로 바꾸지 않는다. 업적의 공개 범위는 개인 성과와 공식 성과를 구분한다.

목표는 학업4·전투4·연구4·제작3·조직5·사교3·생활2다. 준비 시스템 미구현7종은 선택할 수 있지만 ‘판정 보류’이며 자동 완료하지 않는다. 학업·건강·취미 목표는 명시된 실제 기간과 활동이 필요하다. 기존 기한 실패 상태를 유지하고 이유로 만료를 구분한다.

## 검증 기록

- 전용 계약: 실제 검술 훈련3회와 목표 완료, 허위 완료 기록 제외, 실제 XP/성장, 목표 포기/미지원 조건, 비공개 업적, 실제 정보 인지 범위·AI 점수 보정, 무변경 조회, 저장/복원·새 회차 격리·1분/1시간 일치.
- 공식 대회 계약에 실제8/16인 우승 NPC의 업적과 패자 미획득 검사를 추가했다. 대회 격리 조건은 기존과 동일하며 전체 AI 장기 성능을 뜻하지 않는다.
- 공통 계약 변경에 따른 자동 선택은 Extended로 승격되었다. 최초4개 통과 후 전투1개 실패. 상호작용 ID를 전투 ID로 조회한 새 관찰기의 결함을 수정했고 전투 검사를 단독 재실행하여 통과했다. 이어4개 통과 후 기능 노트 ID3개가 기존 생활 시스템과 충돌해 수정했다. 남은36검사와9시나리오를 재검증하여 **45종 검사·9개 시나리오를 단계별 통과**했다. 이전 통과를 매번 다시 실행하지 않았다. 최초 실패 보고서도 보존했다.
- 최종 보완 뒤 전용 계약(수신자별 XP 정확성·잘못된 성장 저장 거부·구형 저장 명시 연결 추가),8/16인 공식 대회 업적 검사, 공통 상세의 목표 선택/우선순위 키보드 조작/비밀 필터/390px 모바일 검사를 통과했다. 페이지 오류0건. 최종 타입 검사 포함 전체 빌드·변경 엔진/타입/화면 린트도 통과했다. 빌드의 기존 대형 청크 경고는 남아 있다. 상태창 화면은 `goals-desktop.png`, `progress-mobile.png`다. 기능 노트는46시스템/411항목의 참조·상태·의존성 검사를 통과했다.
- 원본: `test-results/life-*.log`, `test-results/academy-life-progress/{results,browser}.json` 및 검증 보고서. 기존 통과 기록과 이번 실행을 구분한다.
- 30/180/360/720일과 성장 인플레이션 장기 분석은 실행하지 않았다. 이번 작업의 정확한 범위는 짧은 인과·저장·정보·실행 연동이다.

## 짧은 성능 진단

다른 검증/빌드가 끝난 뒤 `diagnose-academy-life-progress.mjs`를1회 실행했다. Windows / Node22.18.0 / Intel Core Ultra7 258V, 시드 `life-progress-100-hour`, 제국력427년3월6일16:00의 건강한 랜덤 학생99명+교수1명이다. 전체100명 AI, 기존 일과/욕구/관계/상호작용/기억/세계 이벤트/학사/공식 행사/동아리/전투/아이템/생활/LOD를 연결했다. 고정15인·플레이어 선택 개입이 없는 신선한 첫 오후1시간이며, 실제 UI 응답·평균·느린 사례·주간 성능을 뜻하지 않는다.

## 미완료·제약

독창 연구/제작/졸업, 조직별 고급 심사 정책, 전달된 평판 피드백·오해 정정 전용 UI, 모든15인별 신규 평판 대사, 자동 특별 프로젝트 초청, 고난도 자격 기반 성장 제한, 다학년도 성장/인지도 밸런스는 미완료다. 기존 경지 감쇠 외에 저난도 반복을 고랭크에서 강제 차단하는 규칙은 없다. 충분한 성장 속도 측정 없이 균형을 바꾸지 않았다.

성장 기록은144개월 보존하며 현재 능력/공식 업적은 별도 유지한다. 사소한 상세 출처는 대표값만 보존한다. 일·주·월 활동은 달력 날짜별, 성장량은 월별 교차 집계이므로 임의 시각으로 잘라낸 정확한 구간 XP와 다르다. 평판은 현재 기억 기반 평가라 망각/정정에 따라 달라질 수 있다. 일반 플레이의 정확한 인지도/개인 평가 수치는 의도적으로 비공개다.
