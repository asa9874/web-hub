# 별도 비주얼 플레이 모드 v1

## 디자인과 구현 경계

기존 텍스트 화면의 배치·카드·내비게이션을 디자인 원본으로 사용하지 않았다. 장소를 꽉 채우는 무대, 좌측 플레이어의 간단한 자원, 우측 다음 일정, 실제 주변 인물의 초상, 하단 활동 커맨드로 새로운 화면을 구성한다. 짙은 청록/남색, 상아색 글자와 금색의 얇은 강조선을 사용한다. 새 CSS는 `avn-*`로 격리하며 기존 `ac-play` 레이아웃 밖에서 렌더링한다. 배경·초상·스탠딩은 기존 원화 파일을 공유한다. 신규 그림을 생성한 작업은 아니다.

참고 자료: [Princess Maker 2 Regeneration 공식 소개](https://store.steampowered.com/app/2311530/Princess_Maker2_Regeneration/). 육성 활동과 상태를 빠르게 판단하는 목적을 참고했으며 해당 게임의 화면을 복제하지 않았다. VN의 인물 중심 무대/하단 대화, RPG의 전투 행동 분류를 조합한 독립 구성이다. 상용 수준의 시각 품질을 실증했다고 주장하지 않는다.

## 실제 연결

- `Gameplay`에서 기본 비주얼/텍스트 전환. 동일 세션 객체/Provider를 유지하고 화면 전환에서 새 세계·시간 요청을 생성하지 않는다. 모드 선택은 UI 상태이며 세이브 스키마를 바꾸지 않는다.
- 활동: 기존 공부·검술·마법·독서·휴식·수면·식사 명령과 30/60/120분 선택. 기존 학사/위치/이동/자원/중요 선택 조건을 엔진이 검사한다. 아르바이트는 기존 실제 일자리와 신청 가능 사유를 사용한다.
- 자동 생활: 다음 일정 또는 하루 진행. 중요한 선택에서는 기존 세션이 중단한다. 가상의 하루 보상을 생성하지 않는다.
- 교류: 현재 실제 주변 인물만 표시. 공통 NPC 행동 후보/금지 사유/실행을 사용한다. 위험·전투 선택은 기존 EventScene 응답 계약으로 확인한다. 실제 대화 기록이 있으면 그 NPC의 실제 턴을 표시한다. 대화 기록이 없는 경우 임의의 감사·칭찬 대사를 만들지 않는다.
- 이동: 장소 검색/목적지 선택, 실제 경로 가능 여부·분 표시 후 기존 이동 완료 명령. 목록은 선택 시 펼치는 전용 시트이며 기존 그래프 지도를 복제하지 않았다.
- 피드백: 기존 생활 baseline의 실제 시간·능력치/숙련 랭크 변화만 표시. 변화가 없으면 명시한다. 빠른 진행에서는 일상 결과창을 생략한다. 새로운 성장 계산이나 보상을 추가하지 않는다.
- 중요 대화/히로인 선택: 기존 EventSceneData/선택 handler를 신규 전체화면 `VisualSceneDialog`로 표현. 새로운 인물·선택·기억을 별도로 저장하지 않는다. 선택 전 세계 정지 유지. 빠른 공개는 등장 연출만 단축하며 선택을 자동 처리하지 않는다.
- 전투: 기존 후보/자원/대련 내구/턴 명령을 신규 `VisualCombat`으로 표시. 범주 탭/불가 사유/자동전투와 실제 확정 승패·최근 로그 결과 장면을 제공한다. 승패를 다시 판정하지 않는다.
- 기록: 플레이어 투영의 실제 습득 기록만 표시. 내부 NPC 결정·비밀 사건을 읽지 않는다.
- 저장: 기존3슬롯/기존 형식 그대로 사용. 기존 텍스트 모드와 모든 게임 기능을 보존한다.
- 접근성: 네이티브 dialog의 모달 포커스·Escape, 버튼 이름·선택 상태, reduced-motion 대응. 1280×720 브라우저에서 활동 모달 진입/Escape 닫기는 확인했다. 작은 화면 레이아웃과 전체 키보드 동선은 미검증이다.

## 검증

- `test:academy-visual-mode`: 2 NPC의 준비 세계, SSR 양쪽 UI 진입/읽기 불변식, 실제10분 휴식, 중복 효과 없음, 기존 저장/로드 동등성. 테스트 fixture는 장기 플레이 검증이 아니다.
- 타입 검사와 루트 Vite 앱 빌드. 로그 `test-results/academy-visual-{types,build}.log`, 테스트 `test-results/academy-visual-mode.log` 및 `academy-visual-mode/results.json`.
- 최초 샌드박스 서버 접근은 연결 시간 초과. 이후 제한 밖 localhost:5203 미리보기에서 정상 연결했다. 1280×720 새 게임→평가→비주얼 진입, 텍스트 왕복 시08:00 보존, 활동 모달/Escape와 화면 캡처 확인. 전투/개별 장면/다중 해상도 전체 입력 검증은 미완료. 화면은 `test-results/academy-visual-mode/{visual-play,activity-sheet}.png`.
- UI 전환/표시는 세계 실행 명령을 추가하지 않는다. 새로운 장기 성능 측정/전체 장기 회귀는 실행하지 않았다. 기존 큰 청크 경고는 유지된다.

## 남은 범위

이번은 실제 활동·교류·선택·전투·저장을 연결한 첫 수직 슬라이스다. 장비/아이템·전체 스킬 트리·학사 시간표·생활방침/장기 목표·공식 행사 상세 등의 비주얼 전용 화면은 미구현이며 텍스트 모드에서 계속 사용할 수 있다. 실제 수업 참가 자체는 동일 자동생활·기존 일정으로 진행된다. 시각적 주간 일정 편집기는 구현하지 않았다. 활동별 플레이어 포즈/CG·시간대별 배경 그림·전용 음향은 없다. 스킬 진화/업적별 전용 획득 연출과 모든 전투의 자동 결과 장면(텍스트 모드에서 시작한 전투 등)은 후속이다. 신규 UI만을 위해 성장 규칙·확정 대사·NPC 자율성을 대체하지 않는다.

## 로딩 진단 후속

연결 거부는 샌드박스 네트워크 경계 문제였다. 제한 밖 서버로 브라우저 접근 해결. 별도로 실제 세계 초기화는25NPC 약1.95초/100NPC 약10.61초(플레이어 별도, headless 단일 샘플). 프로파일은 초기 일과/후보 구성의 반복 복사·경로 조회 비용을 보여준다. 대규모 최적화는 이번 진단에서 적용하지 않았다. `LOADING_DIAGNOSTIC_V1.md`와 원본 JSON을 참조한다.
