# 플레이 화면 구조 정리

2026-10-24. 실제 플레이 화면만 고정 뷰포트로 변경했다. 타이틀/캐릭터 생성·전체 설정집·개발 시뮬레이터의 기존 탐색 방식은 유지한다.

- 외부 Web Hub 이동·게임 브랜드·중복 날짜·푸터를 플레이 중 렌더링하지 않는다. 좌상단의 이름/학년·장소·현재 활동 중복 요약을 제거했다. 메뉴 → 시간 진행 → 현재 시각/인물 상세를 상단 한 줄에 배치한다. 장소·활동·인물 정보는 각 패널에서 확인한다.
- 데스크톱은 상태 요약 / 현재 장면과 기록 / 생활·행동의3열이다. 허기·피로·졸음과 실제 다음 일정을 상시 요약하고 긴 위치 경로·방침·세부 욕구/목표·날짜 진행은 접어서 표시한다.
- 화면은 `100dvh` 그리드의 고정 프레임이다. 긴 메뉴 내용·기록·행동·목록은 초점 가능한 영역 안에서 스크롤한다. 시간 조작은 상단 도구 줄 안에 있고 하단 시간 바는 없다.1440×1000에서 주요 패널 높이는 약917px다.
- 태블릿/모바일은 선택한 메뉴 패널을 크게 보여준다. 생활·행동 탭에서 동일한 PlayerControls를 표시하며 복제 실행기나 중복 폼을 만들지 않는다. 상단 메뉴/시간 조작은 한 줄 내부 가로 스크롤, 현재 날짜/시각은 우측 고정이다. 휴대폰은 날짜 표기를 짧게 표시하고 상세 날짜는 툴팁에 유지한다. 작은 가로 화면에서는 장면의 부가 설명/주변 인물 미리보기를 줄이고 해당 메뉴에서 전체 내용을 확인한다.
- 현재 장소/활동·시각·주요 행동은 강조하고 출처·부가 설명·저장/설정 메뉴는 작게 표시한다. 원본 기록을 삭제하거나 임의의 요약 사건을 생성하지 않는다.
- 스크롤 잠금은 `.ac-playing`이 존재하는 동안의 CSS 범위다. 설정집으로 나가면 복구된다. 상세 모달은 기존 독립 스크롤을 사용한다.
- 자체 인물 상세 확인 중 발견한 `CharacterAiPanel`의 NPC LOD 조회 오류를 수정했다. 일반 표시에서 불필요한 LOD 조회를 하지 않고, NPC 디버그 정보에만 조회한다. 플레이어를 NPC LOD 레코드로 처리하지 않는다.

## 파일과 검증

주요 변경: `AcademySurvival.tsx`, `components/Gameplay.tsx`, `GameplayViewport.css`, `PlayerControls.tsx`, `CharacterAiPanel.tsx` (`src/AcademySurvival/` 기준). 기존 시계·AI·행동·저장 엔진과 저장 형식은 변경하지 않았다.

`test:academy-play-layout-browser`는1440×1000 /1024×768 /390×844 /320×568 /844×390에서 문서 폭/높이·스크롤0·메뉴/시간/시각 한 줄 정렬·패널 확장을 확인한다. 실제6시간 진행 후 기록 내부 스크롤, 펼친 행동 패널 스크롤, 상세 모달·학사 목록·저장/불러오기·설정집 스크롤 복구·복귀를 검증한다.

기존 `test:academy-player-browser`도 실제 이동/활동 완료·방침 편집·자동 시간 진행·저장/복원·개발 샌드박스 격리를 검증했다. 타입·빌드를 확인한다. UI 변경이므로 장기 시뮬레이션·전체 게임 브라우저 회귀는 실행하지 않는다.

증거: `test-results/academy-ui-layout/browser.json`, desktop/mobile PNG, `test-results/academy-ui-layout-*.log`. 작업 전4개 UI 원본은 같은 결과 폴더의 `before/`에 보존한다. 이후 추가하는 패널도 페이지 전체를 늘리지 않고 내부 스크롤과 정보 위계를 유지한다.

## 2026-10-26 디자인 개편 (위의 초기 한 줄 메뉴 배치를 대체)

사용자의 새 UI/UX 재설계 요청에 따라 측면 메뉴+상단 시간 HUD로 변경했다. 화면/패널 내부 스크롤·직접 행동의 자동 시간 진행·저장/개인 지식 계약은 유지한다. 현재 상황은 상태/장면/행동, 다른 목적지는 상태/넓은 본문으로 표시하고 동일한 행동 패널을 서랍으로 연다. 상세 방향/검증·한계는 `GAME_UI_REDESIGN_V1.md`.
