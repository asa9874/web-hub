## 이동 연결 관계

```
A1 ──── B1 ──── B5 ──── C1 ──── C2 ──── D1
         │       │       │
         B2      B4      B6

         B3
```

### 상세 연결

- **A1 ↔ B1** : 아파트 1층 출입구 → 골목 서쪽 진입로
- **B1 ↔ B2** : 골목 동쪽 → 편의점 서쪽
- **B1 ↔ B5** : 골목 북쪽 → 회색 거리 남쪽
- **B1 ↔ B3** : 골목 잔해 지하 경로 → 지하철역 (숨겨진 경로, 발견 필요)
- **B2 ↔ B3** : 편의점 남쪽 → 지하철역 지상 입구
- **B3 ↔ A2** : 지하철역 플랫폼 A 터널 → 지하 3구역 (허가 필요)
- **B5 ↔ B4** : 회색 거리 동쪽 → 병원 서쪽
- **B5 ↔ B6** : 회색 거리 서쪽 → 연세대 동문
- **B5 ↔ C1** : 회색 거리 북쪽 대로 → 한강변 남쪽
- **B6 ↔ C1** : 연세대 북문 → 한강변 남서쪽
- **C1 ↔ C2** : 한강변 북쪽 → 심층 구역 경계
- **C2 ↔ D1** : 경계선 통과 → 부정의 탑 인근 (마법소녀 동반 필수)
