# 지하철역 (폐역) [B3]

## 개요

| 항목 | 내용 |
|------|------|
| 구역 코드 | B3 |
| 구역 분류 | 회색 구역 (지하) |
| 위험도 | ★★★☆☆ (주간) / ★★★★☆ (야간, 특정 구간) |
| 규모 | 지하 2층 구조. 총 연장 약 500m |

검은 10월 이전부터 공사 중이던 신규 노선의 미완성 역. 공식 개통된 적이 없어 지도에 나오지 않는다. 지하 3구역(A2)으로 이어지는 공식 연결 통로이자, 외부에서 지하로 내려오는 주요 진입 경로.

역 자체는 부정의 영향을 어느 정도 차단하는 구조를 가지고 있다 — 왜 그런지는 알 수 없다. 지하 3구역 생존자들은 이것을 "행운"이라고 부른다. 정도석 박사는 이것에 대해 다른 생각을 가지고 있는 것 같다.

---

## 분위기

에스컬레이터는 멈췄고, 조명은 비상등 일부만 살아 있다. 적색 비상등이 터널을 물들이면, 이 곳이 원래 무엇이었는지 기억하기 어렵다. 공사 중 쌓아놓은 자재들이 그대로 있고, 미완성 타일 공사가 벽 중간에 멈춰 있다. 문명이 진행형으로 멈춘 곳이다.

플랫폼 안쪽 어둠에서 가끔 바람이 분다. 터널 저쪽 어딘가에서 오는 바람이다. 그쪽에는 아무것도 없어야 한다.

---

## 세부 공간

### [B3-01] 지상 진입구
- **상태**: 두 개의 진입구 중 하나는 잔해로 막힘. 나머지 하나(남쪽 입구)는 개방.
- **구성**: 계단 + 비상등
- **특이사항**: 입구 바깥쪽에 누군가 그어놓은 화살표 표시가 있음. 최근에 그어진 것 같다.

### [B3-02] 대합실 (지하 1층)
- **상태**: 미완성 개찰구, 자동판매기 (전원 없음), 안내 데스크 (비어 있음).
- **구성**: 넓은 홀. 천장이 높아 소리가 울림.
- **특이사항**: 자판기 중 하나의 하단 칸이 억지로 열린 흔적. 내용물은 거의 없음. 바닥에 수기로 적힌 방향 표시 ("3구역 →")
- **획득 가능**: 빈 음료 캔 (용기로 활용), 안내 팸플릿 (공사 중단 전 배포된 것, 역 구조 파악 가능)

### [B3-03] 에스컬레이터 구간
- **상태**: 멈춘 에스컬레이터. 걸어 내려갈 수 있음.
- **특이사항**: 에스컬레이터 측면 틈새에 누군가 메모를 끼워두었음. "이쪽으로 오지 마시오. 아래 3구역으로 바로 가세요." 날짜 없음.

### [B3-04] 플랫폼 A (지하 2층 — 3구역 방향)
- **상태**: 비교적 안전. 3구역 방향 터널 입구가 있음.
- **구성**: 플랫폼 길이 약 120m. 공사 자재, 임시 작업대 잔류.
- **특이사항**: 터널 입구에 검문 신호용 램프가 설치되어 있음 (3구역 측에서 관리). 이 램프가 녹색이면 진입 가능, 적색이면 대기.
- **접근**: 3구역 생존자의 허가 없이 터널 진입 시 경고 후 추방.

### [B3-05] 플랫폼 B (지하 2층 — 반대 방향)
- **상태**: 조명 전무. 비상등도 꺼져 있음.
- **구성**: 플랫폼 B에서 이어지는 터널은 봉인되어 있음 (콘크리트 블록).
- **특이사항**: 봉인된 터널 저쪽에서 가끔 소리가 난다. 두드리는 소리인지, 그냥 구조물 수축음인지 구분이 안 됨. 3구역 생존자들은 이 쪽을 쳐다보지도 않는다.
- **위험 요소**: 부정 농도 ★★★★☆. 플랫폼 B 끝에 오래 있으면 두통과 불안감이 생김.

### [B3-06] 유지보수 터널
- **상태**: 플랫폼 A에서 측면 문을 통해 진입. 문이 잠겨 있음 (역 건물 도면이나 마스터키 필요).
- **구성**: 폭 약 1.5m의 좁은 터널. 배관과 전선이 노출된 채 이어짐.
- **특이사항**: 이 터널은 두 플랫폼을 하부로 연결하고, 추가로 외부 비상 출구로 이어짐. 3구역 비상 탈출 시 사용 가능.
- **숨겨진 요소**: 터널 중간 벽면에 뭔가를 긁어 새긴 흔적. 보면 좌표처럼 보이는 숫자들.

### [B3-07] 공사 자재 창고 (플랫폼 A 끝)
- **상태**: 공사 중단 당시 자재가 그대로 남아 있음.
- **획득 가능**: 철근 (무기/소재), 방수포, 공구 (렌치, 해머), 안전모, 반사 조끼

## 획득 가능 주요 자원

- 건설 공구 (렌치, 해머, 드라이버)
- 철근, 방수포 (건축 소재)
- 안내 팸플릿 (역 구조도)
- 좌표처럼 보이는 긁힌 메모 (정보 단서)

## 특이사항

- 플랫폼 B 봉인 터널은 후반부 핵심 진입로.
- 유지보수 터널 좌표 메모는 중반부 퀘스트 단서.
- 3구역에 처음 가는 경우 이 역이 진입 관문 역할. 검문을 통과하는 방식이 첫 오기범 조우 방식을 결정.
