## 이동 가능 경로 요약

```
옥상 ← (잠긴 문 해제 후)
  │
4층 ← (일부 붕괴, 우회 경로 있음)
  │
3층 ← [302호 시작], [304호 이벤트]
  │
2층 ← [203호 정보]
  │
1층 ← [관리실 마스터키], [출입구 → B1 외부]
  │
지하1층 ← [배전반·창고], [이상한 소리]
```
