# 카드 보상 시스템

## 개요

전투 승리 후 플레이어에게 골드와 카드를 보상으로 제공하는 시스템.
`VictoryScene`(승리 화면)과 `CardRewardScene`(카드 드래프트)으로 구성되며,
카드 보상은 전투 승리 외에도 이벤트 등 다양한 트리거에서 재사용 가능하다.

---

## 씬 흐름

```
BattleScene (모든 적 HP=0 감지)
  └─ gold = Phaser.Math.Between(40, 70)
  └─ fadeOut → scene.start('VictoryScene', { gold })

VictoryScene
  ├─[카드 선택 버튼] → scene.start('CardRewardScene', { cards, returnScene: 'HubScene' })
  └─[메인 메뉴 버튼] → scene.start('HubScene')

CardRewardScene
  ├─[카드 클릭]     → GameState.addBonusCard(card) → 확인 메시지 → scene.start(returnScene)
  └─[건너뛰기]      → scene.start(returnScene)
```

---

## VictoryScene

### 표시 내용

| 요소 | 내용 |
|------|------|
| 제목 | "전투 승리!" (금색, 52px) |
| 골드 획득 | "+N G" (대형, 금색) |
| 누적 골드 | "보유 골드: N G" |
| 카드 선택 버튼 | CardRewardScene으로 이동 |
| 메인 메뉴 버튼 | HubScene으로 이동 |

### 골드 계산

```typescript
// BattleScene — 승리 감지 시
const gold = Phaser.Math.Between(40, 70);  // 40~70 랜덤
scene.start('VictoryScene', { gold });

// VictoryScene.init()
GameState.gold += data.gold;  // 정적 누적 합산
```

## CardRewardScene

### 표시 내용

- 카드 N장 (기본 3장) 나란히 표시
- 각 카드에 비용 배지, 이름, 구분선, 설명 텍스트 포함
- AoE 카드: 주황 테두리 + "전체" 태그
- 호버 시 1.07배 확대 + 금색 테두리
- 하단 "건너뛰기" 버튼

### 카드 제공 방식

```typescript
// VictoryScene에서 호출
GameState.getRandomRewardCards(3)
// → CARD_LIBRARY에서 이름 기준 중복 제거 후 Fisher-Yates 셔플 → 앞 3장 반환
```

현재 라이브러리 7종 (strike_a/b 중복 제거): 타격·방어·강타·쌍격·폭발·연쇄공격·폭풍격

### 카드 추가 처리

```typescript
GameState.addBonusCard(card)
// → { ...card, id: `${card.id}_bonus_${n}` } 형태로 GameState.bonusCards에 push
// → 다음 GameState.reset() 시 기본 CARD_LIBRARY와 함께 셔플
```

---

## GameState 정적 상태 (전투 간 유지)

| 필드 | 타입 | 설명 |
|------|------|------|
| `GameState.gold` | `number` | 누적 골드 (초기값 0) |
| `GameState.bonusCards` | `Card[]` | 보상으로 획득한 카드 목록 |

이 두 값은 `GameState.reset(mode)` 호출 시 **초기화되지 않는다**.
`reset()`은 새 인스턴스를 만들 뿐이며, 정적 필드는 유지된다.

---

## CardRewardScene 재사용

임의의 씬에서 카드 보상을 트리거할 수 있다:

```typescript
this.scene.start('CardRewardScene', {
  cards: GameState.getRandomRewardCards(3),  // 1~4장 자유롭게 지정 가능
  returnScene: 'MyScene',                    // 보상 후 돌아갈 씬
});
```

---

## 전체 덱 구성

```
전투 시작 시 덱 = shuffle(CARD_LIBRARY + GameState.bonusCards)
```

카드를 여러 번 보상으로 받을수록 해당 카드의 드로우 확률이 높아진다.
