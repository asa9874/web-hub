# 보스·엘리트 몬스터 시스템

## 개요

기존 일반 몬스터보다 강하고 전투 종료 시 유물을 드롭하는 보스·엘리트 전투를 추가한다.
- **보스 (암흑 군주)** — HP 240, 순차 패턴, 50% HP에서 페이즈 2 전환
- **엘리트 1 (숲 거인)** — HP 120, 가중치 랜덤 패턴, 유물 드롭
- **엘리트 2 (독거미 여왕)** — HP 80, 독 특화 패턴, 유물 드롭

---

## 클래스 계층

```
Monster (abstract)
├── Slime / Goblin / Orc / Skeleton / Bat   (일반)
├── Boss (abstract)                          (순차 패턴 + 페이즈 전환)
│   └── DarkLord                             (보스)
├── ForestGiant    (isElite = true)          (엘리트)
└── SpiderQueen    (isElite = true)          (엘리트)
```

## Boss 추상 클래스 (`src/monsters/Boss.ts`)

```typescript
abstract class Boss extends Monster {
  abstract phasePatterns: AttackPattern[][];  // [phase1패턴[], phase2패턴[]]
  abstract phaseChangeMessage: string;        // 페이즈 전환 시 플래시 메시지
  get patterns(): AttackPattern[]             // 현재 페이즈 배열 반환
  override prepareNextAction(): void          // seqIdx 순차 실행
  checkPhaseTransition(): boolean             // HP ≤ 50% → 페이즈 2 전환, true 반환
  protected onPhaseChange(): void             // 전환 시 훅 (DarkLord: 힘 +3)
}
```

### 페이즈 전환 흐름

```
플레이어 카드 사용 → boss HP ≤ 50%
  └─ handlePostCardPlay() → boss.checkPhaseTransition()
       ├─ phase = 2, seqIdx = 1, onPhaseChange()
       ├─ nextPattern = phase2[0]
       └─ flashMessage(phaseChangeMessage) + updateAllIntents()
```

## 전투 승리 흐름 (`src/scenes/BattleScene.ts`)

```
handleVictory()
  ├─ mode === 'boss'
  │    GameState.pendingGold = 120~160G
  │    → RelicRewardScene (boss 3개) → VictoryScene
  ├─ mode === 'elite_*'
  │    GameState.pendingGold = 80~110G
  │    → RelicRewardScene (common/rare 3개) → VictoryScene
  └─ default / five_monsters
       → VictoryScene (gold = 40~70G 직접 전달)
```

### GameState.pendingGold

RelicRewardScene은 씬 전환 시 데이터를 전달하지 않으므로, 보스/엘리트 골드를
`GameState.pendingGold`에 저장해두고 VictoryScene의 `init()`에서 읽는다.

```typescript
// VictoryScene.init()
this.goldEarned = data?.gold ?? GameState.pendingGold;
GameState.pendingGold = 0;
```
