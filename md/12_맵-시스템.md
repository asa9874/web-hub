# 던전 맵 시스템

## 개요

노드 기반 던전 맵. Act 1은 10개 row(0~9)로 구성되며, row 0에서 시작해 row 9 보스까지 한 row씩 이동한다.
맵은 런 시작 시 랜덤 시드로 생성되며, 런이 끝날 때까지 GameState에 유지된다.

---

## 씬 흐름

```
HubScene [던전 탐험 버튼] → MapScene
  MapScene
    ├─ battle 노드   → BattleScene(mode=default, returnScene=MapScene) → VictoryScene → CardReward → MapScene
    ├─ elite 노드    → BattleScene(mode=elite_*, returnScene=MapScene) → RelicReward → VictoryScene → MapScene
    ├─ boss 노드     → BattleScene(mode=boss, returnScene=MapScene) → RelicReward → VictoryScene → MapScene
    ├─ event 노드    → EventScene(returnScene=MapScene) → MapScene
    ├─ shop 노드     → ShopScene(returnScene=MapScene) → MapScene
    ├─ rest 노드     → RestScene(returnScene=MapScene) → MapScene
    └─ treasure 노드 → CardRewardScene(returnScene=MapScene) → MapScene
  Act 클리어 (row 9 보스 처치) → 오버레이 → hardReset → HubScene
```

---

## Act 1 맵 구조

| Row | Col 마스크 | 노드 수 | 타입 풀 |
|-----|-----------|---------|---------|
| 0 | 0b111 | 3 | battle×3 (시작 선택) |
| 1 | 0b111 | 3 | battle×2, event×1 |
| 2 | 0b111 | 3 | battle×1, event×1, shop×1 |
| 3 | 0b101 | 2 | elite×1, event×1 (엘리트 보장) |
| 4 | 0b111 | 3 | battle×2, treasure×1 |
| 5 | 0b111 | 3 | battle×1, event×1, shop×1 |
| 6 | 0b101 | 2 | elite×1, rest×1 (엘리트 보장) |
| 7 | 0b111 | 3 | battle×1, event×1, shop×1 |
| 8 | 0b111 | 3 | rest×1, shop×1, treasure×1 |
| 9 | 0b010 | 1 | boss (고정) |

- Col 마스크 `0b101` → col 0(x=290)과 col 2(x=990)만 활성
- Col 마스크 `0b010` → col 1(x=640)만 활성 (보스 중앙)

---

## 연결 규칙

현재 row의 col C는 다음 row의 col NC 중 `|NC - C| ≤ 1`인 활성 col과 연결.

예시: row 3(cols 0,2) → row 4(cols 0,1,2)
- col 0 → [0, 1]
- col 2 → [1, 2]

모든 경로가 row 9 col 1(보스)로 수렴되도록 설계.

## 맵 생성 (`src/data/mapGenerator.ts`)

```typescript
function generateMap(seed: number): MapNode[][]
```

- LCG(선형 합동 생성기) 기반 시드 난수
- 각 row의 타입 풀을 시드로 셔플 후 col에 배치
- row 3, row 6은 elite가 풀에 포함되어 있어 항상 등장 보장

---

## GameState 맵 관련 필드/메서드

```typescript
static mapSeed: number               // 현재 런의 시드
static mapNodes: MapNode[][]         // 생성된 맵 (row × active nodes)
static visitedNodeKeys: string[]     // "row_col" 형식 방문 완료 키 목록
static currentMapNode: { row, col } | null   // 진행 중인 노드 (전투용)
static lastBattleWon: boolean        // 전투 승리 여부 (MapScene에서 방문 처리)

static initMap(seed?: number): void            // 맵 초기화 (seed 생략 = 랜덤)
static markNodeVisited(row, col): void         // 방문 완료 기록
static getAvailableMapNodes(): MapNode[]       // 현재 진입 가능한 노드 목록
```

---

## 전투 결과 처리 (`MapScene.create()`)

```
MapScene.create()
  └─ if currentMapNode && lastBattleWon → markNodeVisited()
  └─ currentMapNode = null, lastBattleWon = false
  └─ if mapNodes 없음 → initMap()
  └─ renderMap()
  └─ if 9_ 노드 방문 → showActComplete()
```

- 비전투 노드: MapScene에서 즉시 `markNodeVisited()` 후 씬 이동
- 전투 노드: VictoryScene.init()에서 `lastBattleWon = true` 설정 → MapScene에서 처리

---

## returnScene 체인

BattleScene, VictoryScene 모두 `returnScene` 필드 추가:
- BattleScene.init(): `returnScene = data?.returnScene ?? 'HubScene'`
- VictoryScene.init(): `returnScene = data?.returnScene ?? GameState.pendingReturnScene`
- 보스/엘리트: `GameState.pendingReturnScene = this.returnScene` 설정 후 RelicRewardScene 경유

## MapScene 레이아웃 (1280×720)

```
y=2    : 보라 악센트 바
y=28   : "Act 1 — 던전 탐험" 제목
y=52   : HP / 골드 상태
y=65   : 구분선
y=1240 : "런 포기" 버튼 (우측 상단)
y=80~648 : 맵 노드 영역 (col X = 290/640/990)
```

Row y 위치: `y = 648 - row × 63`
- row 0 (시작): y=648
- row 9 (보스): y=81
