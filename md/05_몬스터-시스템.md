# 몬스터 시스템

## 개요

몬스터는 `Monster` 추상 클래스를 상속받아 독립적인 객체로 존재한다.
각 몬스터는 자신만의 이름, 설명, 행동 패턴 목록을 가지며, 확장 시 해당 클래스만 추가하면 된다.

```
src/monsters/
  Monster.ts   ← 추상 기반 클래스 (공통 로직)
  Slime.ts     ← 슬라임 구현체
  index.ts     ← 일괄 export
```

---

## Monster 기반 클래스

```typescript
abstract class Monster implements Entity {
  abstract name: string
  abstract description: string
  abstract patterns: AttackPattern[]

  hp: number
  maxHp: number
  block: number
  nextPattern: AttackPattern | null  // 예약된 다음 행동 (의도 표시용)

  selectPattern(): AttackPattern    // 가중치 기반 무작위 선택
  prepareNextAction(): void         // 다음 행동 예약
  executeTurn(target): AttackPattern  // 예약 행동 실행 + 재예약
}
```

### 행동 선택 알고리즘

```
totalWeight = sum of all pattern.weight
roll = random(0, totalWeight)
순서대로 weight를 차감 → 0 이하가 되는 첫 패턴 선택
```

weight가 클수록 선택 확률이 높다.

---

## AttackPattern 인터페이스 (`src/types.ts`)

```typescript
interface AttackPattern {
  id: string
  name: string          // 한국어 행동 이름 (UI에 표시)
  description: string   // 짧은 설명 (의도 패널에 표시)
  weight: number        // 선택 확률 가중치
  execute: (target: Entity, self: Entity) => void
}
```

`target` — 피해를 입을 대상 (플레이어)
`self` — 몬스터 자신 (방어도 획득 등 자기 버프에 사용)

---

## 슬라임 (`Slime`)

| 패턴 ID | 이름 | 가중치 | 효과 |
|---------|------|--------|------|
| `slime_smash` | 점액 강타 | 5 | 플레이어에게 8 피해 |
| `slime_double` | 연속 공격 | 3 | 플레이어에게 5 피해 × 2회 |
| `slime_shield` | 점액 막 | 2 | 자신 방어도 +6 |

선택 확률: 강타 50%, 연속 공격 30%, 방어 20%

## 턴 흐름과 의도 표시

```
GameState 생성 시
  └─ enemy.prepareNextAction()  ← 첫 행동 예약

[플레이어 턴 진행 중]
  └─ BattleScene이 gs.monsterIntent 를 읽어 우측 패널에 표시

[몬스터 턴 시작]
  └─ gs.executeMonsterTurn()
       └─ enemy.block = 0       ← 방어도 초기화
       └─ pattern.execute()     ← 예약된 패턴 실행
       └─ enemy.prepareNextAction()  ← 다음 행동 재예약
```

플레이어는 몬스터가 **무엇을 할지** 미리 알 수 있으므로, 방어 카드 사용 여부를 전략적으로 결정할 수 있다.

## 새 몬스터 추가 방법

1. `src/monsters/` 에 새 파일 생성 (예: `Goblin.ts`)
2. `Monster`를 상속받고 `name`, `description`, `patterns` 세 가지만 구현
3. `src/monsters/index.ts`에 export 추가
4. `GameState.ts` 생성자에서 `new Goblin()` 으로 교체하거나, 씬에서 원하는 몬스터를 주입

```typescript
// Goblin.ts 예시
export class Goblin extends Monster {
  readonly name = '고블린';
  readonly description = '날카로운 단검으로 빠르게 공격한다.';

  readonly patterns = [
    {
      id: 'goblin_slash',
      name: '단검 베기',
      description: '6의 피해를 입힌다.',
      weight: 4,
      execute: (target, _self) => applyDamage(target, 6),
    },
    {
      id: 'goblin_double',
      name: '연속 베기',
      description: '3의 피해를 3회 입힌다.',
      weight: 3,
      execute: (target, _self) => {
        applyDamage(target, 3);
        applyDamage(target, 3);
        applyDamage(target, 3);
      },
    },
    {
      id: 'goblin_dodge',
      name: '회피 자세',
      description: '방어도 4를 획득한다.',
      weight: 3,
      execute: (_target, self) => { self.block += 4; },
    },
  ];

  constructor() { super(35); }
}
```
