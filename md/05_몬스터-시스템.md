# 몬스터 시스템

## 개요

몬스터는 `Monster` 추상 클래스를 상속받아 독립적인 객체로 존재한다.
각 몬스터는 자신만의 이름, 설명, 행동 패턴 목록을 가지며, 확장 시 해당 클래스만 추가하면 된다.

```
src/monsters/
  Monster.ts    ← 추상 기반 클래스 (공통 로직)
  Slime.ts      ← 슬라임 (HP 50, 패턴 3종)
  Goblin.ts     ← 고블린 (HP 30, 패턴 3종)
  Orc.ts        ← 오크 (HP 80, 패턴 3종)
  Skeleton.ts   ← 스켈레톤 (HP 40, 패턴 3종)
  Bat.ts        ← 박쥐 (HP 20, 패턴 2종)
  index.ts      ← 일괄 export
```

---

## Monster 기반 클래스

```typescript
abstract class Monster implements Entity {
  abstract readonly name: string
  abstract readonly description: string
  abstract readonly patterns: AttackPattern[]

  hp: number
  maxHp: number
  block: number = 0
  nextPattern: AttackPattern | null = null  // 예약된 다음 행동 (의도 표시용)

  selectPattern(): AttackPattern    // 가중치 기반 무작위 선택
  prepareNextAction(): void         // 다음 행동 예약
  executeTurn(target): AttackPattern  // 예약 행동 실행 + 재예약
}
```

### 행동 선택 알고리즘

```
totalWeight = sum of all pattern.weight
roll = random(0, totalWeight)
순서대로 weight를 차감 → 0 이하가 되는 첫 패턴 선택
```

weight가 클수록 선택 확률이 높다.

## AttackPattern 인터페이스 (`src/types.ts`)

```typescript
interface AttackPattern {
  id: string
  name: string          // 한국어 행동 이름 (UI에 표시)
  description: string   // 짧은 설명 (의도 레이블에 표시)
  weight: number        // 선택 확률 가중치
  execute: (target: Entity, self: Entity) => void
}
```

`target` — 피해를 입을 대상 (플레이어)
`self` — 몬스터 자신 (방어도 획득 등 자기 버프에 사용)

## 턴 흐름과 의도 표시

```
GameState 생성 시
  └─ enemies.forEach(e => e.prepareNextAction())  ← 모든 몬스터 첫 행동 예약

[플레이어 턴 진행 중]
  └─ BattleScene이 각 monster.nextPattern 을 읽어 의도 레이블에 표시

[몬스터 턴 시작] — 1번부터 N번까지 순차 실행
  └─ gs.executeMonsterTurn(idx)
       └─ monster.block = 0       ← 방어도 초기화
       └─ pattern.execute()       ← 예약된 패턴 실행
       └─ monster.prepareNextAction()  ← 다음 행동 재예약
```

플레이어는 몬스터가 **무엇을 할지** 미리 알 수 있으므로, 방어 카드 사용 여부를 전략적으로 결정할 수 있다.

## 새 몬스터 추가 방법

1. `src/monsters/` 에 새 파일 생성 (예: `Dragon.ts`)
2. `Monster`를 상속받고 `name`, `description`, `patterns` 세 가지만 구현
3. `src/monsters/index.ts`에 export 추가
4. `GameState.ts` 생성자에서 원하는 BattleMode에 추가

```typescript
export class Dragon extends Monster {
  readonly name = '드래곤';
  readonly description = '불꽃을 뿜는 고대 용.';

  readonly patterns = [
    {
      id: 'dragon_fire',
      name: '화염 브레스',
      description: '20의 피해를 입힌다.',
      weight: 3,
      execute: (target: Entity, _self: Entity) => applyDamage(target, 20),
    },
  ];

  constructor() { super(200); }
}
```
