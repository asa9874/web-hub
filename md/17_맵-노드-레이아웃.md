# 17. 맵 노드 레이아웃 및 경로 시각화

## 개요

5열 시스템으로 노드를 배치하고, 희소한 연결과 베지어 곡선 경로로 맵을 표현한다.

---

## 열 구성 (5열 시스템)

| Col 인덱스 | 화면 X 좌표 |
|-----------|------------|
| 0         | 130        |
| 1         | 385        |
| 2         | 640 (중앙) |
| 3         | 895        |
| 4         | 1150       |

---

## Row별 노드 수

| Row         | 노드 수 | 활성 Col       |
|-------------|---------|---------------|
| 0 (시작)    | 3 고정  | 0, 2, 4       |
| 1 – 8       | 3 ~ 5 무작위 | 무작위 선택 |
| 9 (보스)    | 3 고정  | 0, 2, 4       |

### 무작위 노드 수 확률
- 3개: 40%
- 4개: 35%
- 5개: 25%

중간 row(1–8)는 `[0,1,2,3,4]` 중 n개를 무작위로 선택·정렬.

---

## 연결 (희소 방식)

- **소스당 최대 1개** 아웃고잉 엣지 (이전 2개에서 감소)
- **인접 제약**: `|srcCol - dstCol| ≤ 1` 인 목적지만 허용
- **교차 금지**: 시각적으로 교차하는 엣지 생성 안 함
- **최소 보장**: 연결이 없는 소스는 가장 가까운 목적지로 폴백 연결

---

## 노드 풀 구성

각 액트의 기본 풀은 3개의 노드 타입을 정의한다.  
무작위로 4–5개 노드가 생성된 경우 초과 슬롯은 `'battle'`로 패딩된다.  
Row 0·9는 고정 풀을 사용하며 셔플하지 않는다.

---

## 지터 (시각 오프셋)

| 축 | 범위         |
|----|-------------|
| X  | ±30 px      |
| Y  | ±12 px      |

보스 row(9)는 지터 없이 정렬된 위치에 표시.

---

## 경로(엣지) 시각화

### 3-상태 분류

| 상태       | 조건                             |
|-----------|----------------------------------|
| inactive  | 현재 이동 불가                    |
| visited   | 소스·목적지 모두 방문 완료         |
| navigable | 소스 방문 완료 + 목적지 이동 가능  |

### 렌더링 스타일

| 상태       | 레이어       | 굵기   | 색상      | 투명도 |
|-----------|-------------|--------|----------|--------|
| inactive  | 단일         | 1.5 px | 0x2A1A3A | 0.30   |
| visited   | 단일         | 2.5 px | 0x8A4A8A | 0.85   |
| navigable | 글로우 (하)  | 10 px  | 0xFF69B4 | 0.25   |
| navigable | 코어 (상)   | 3.5 px | 0xFF69B4 | 1.00   |

렌더 순서: inactive → visited → glow → core (z-order)

### 베지어 S-커브

제어점을 수직 중앙(midY)에 배치한 3차 베지어 곡선(16세그먼트):

```
cp1 = (x1, midY)
cp2 = (x2, midY)
midY = (y1 + y2) / 2
```

- 수직 연결 → 직선
- 대각 연결 → 자연스러운 S-커브
