# 디자인 시스템 — Magical Girl 테마

## 개요

전체 게임 UI/UX의 통일된 비주얼 언어를 정의한다.  
컨셉: **마법소녀 (Magical Girl)** — 파스텔·핑크·라벤더 기반, 다크 퍼플 배경, 골드 포인트.

모든 상수는 `src/theme.ts`에 집중 관리된다.

---

## 색상 팔레트

### 배경 계층

| 상수 | 값 | 용도 |
|------|-----|------|
| `BG_DEEP` | `0x1A0A2E` | 씬 전체 배경 |
| `BG_PANEL` | `0x2D1550` | 카드·패널 배경 |
| `BG_HOVER` | `0x3D1F60` | 인터랙티브 호버 상태 |
| `BG_DIVIDER` | `0x3D1F5A` | 구분선·테두리 선 |

### 테두리

| 상수 | 값 | 용도 |
|------|-----|------|
| `BORDER_DIM` | `0x5A2A5A` | 비활성·기본 테두리 |
| `BORDER_MED` | `0x8A3A8A` | 중간 강도 테두리 |
| `BORDER_BRIGHT` | `0xC050C0` | 호버 강조 테두리 |

### 핑크 계열 (주요 액센트)

| 상수 | 값 | 용도 |
|------|-----|------|
| `PINK` | `0xFF69B4` | 핫 핑크 — 메인 액센트 |
| `ROSE` | `0xFF1493` | 딥 핑크 — 강조·플레이어 |
| `PINK_SOFT` | `0xFFB6C1` | 라이트 핑크 — 부드러운 요소 |

### 보조 액센트

| 상수 | 값 | 용도 |
|------|-----|------|
| `LAVENDER` | `0xC8A0FF` | 라벤더 — 스킬 카드·일반 유물 |
| `GOLD` | `0xFFD700` | 골드 — 보상·골드·상점 |
| `GREEN` | `0x4CAF70` | 그린 — 힐링·휴식·턴종료 |

### 기능색

| 상수 | 값 | 용도 |
|------|-----|------|
| `RED` | `0xE74C3C` | 피해·적 |
| `TEAL` | `0x55EFC4` | 독·상태이상 |

### 텍스트 (CSS hex)

| 상수 | 값 | 용도 |
|------|-----|------|
| `TEXT_PRIMARY` | `#FFE4F0` | 메인 텍스트 (따뜻한 화이트 핑크) |
| `TEXT_SECONDARY` | `#C8A0CC` | 서브 텍스트 (소프트 라벤더-핑크) |
| `TEXT_DIM` | `#7A4A7A` | 흐린 텍스트 |
| `TEXT_SOFT` | `#4A2A4A` | 매우 흐린 텍스트 |
| `TEXT_PINK` | `#FFB6C1` | 소프트 핑크 액센트 |
| `TEXT_LAVENDER` | `#C8A0FF` | 라벤더 텍스트 |
| `TEXT_GOLD` | `#FFD700` | 골드 텍스트 |
| `TEXT_GREEN` | `#4CAF70` | 그린 텍스트 |
| `TEXT_RED` | `#FF7675` | HP·피해 텍스트 |

## 폰트

```css
@font-face {
  font-family: 'SchoolSafetyWizard';
  src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2402_keris@1.0/TTHakgyoansimMabeopsaR.woff2') format('woff2');
  font-weight: normal;
  font-display: swap;
}
```

- 상수: `FONT = "'SchoolSafetyWizard', Arial"`
- 모든 텍스트 오브젝트에 `fontFamily: FONT` 추가
- `index.html` `<head>`에 `@font-face` 스타일 블록 포함

## 인터랙션 패턴

```
기본 패널:     fill = BG_PANEL,  stroke = BORDER_DIM
호버 패널:     fill = BG_HOVER,  stroke = 액센트 색
비활성 버튼:   fill = BG_DEEP,   stroke = BORDER_DIM,  text = TEXT_DIM
```
