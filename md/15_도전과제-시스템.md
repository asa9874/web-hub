# 15. 도전 과제 시스템

## 개요

특정 플레이 조건을 달성하면 **도전 과제(Achievement)** 가 잠금 해제되고, 즉시 보상이 적용된다.  
달성과 동시에 우측 상단에 **토스트 팝업**이 슬라이드 인되어 알림을 제공하며, 효과음이 재생된다.  
도전 과제는 런(run) 단위로 추적되며, **런 종료 시 초기화**된다.

---

## 도전 과제 목록

| ID | 이름 | 달성 조건 | 보상 |
|----|------|-----------|------|
| `first_victory` | 첫 승리 | 첫 번째 전투에서 승리 | 골드 +20 |
| `untouchable` | 무적 | 피해를 받지 않고 전투 승리 | HP +15 회복 |
| `boss_slayer` | 보스 처치 | 다크 로드 처치 | 골드 +50 |
| `elite_slayer` | 엘리트 사냥꾼 | 엘리트 몬스터 처치 | HP +20 회복 |
| `relic_collector` | 유물 수집가 | 유물 3개 이상 보유 | 골드 +30 |
| `card_master` | 카드 수집가 | 덱에 카드 15장 이상 보유 | 최대 HP +10 |
| `big_earner` | 재물의 신 | 골드 200개 이상 동시 보유 | 골드 +30 |
| `survivor` | 생존자 | HP 10 이하 상태에서 전투 승리 | HP +20 회복 |

## 보상 종류

| 타입 | 설명 |
|------|------|
| `gold` | `GameState.gold` 에 즉시 추가 |
| `heal` | `GameState.playerHp` 증가 (최대 HP 초과 불가) |
| `max_hp` | `GameState.playerMaxHp` + `playerHp` 동시 증가 |

## 아키텍처

### AchievementManager (정적 싱글톤)

- `unlock(id)` — 보상 즉시 적용 후 구독 리스너에 알림
- `subscribe(fn)` — 잠금 해제 이벤트 구독, unsubscribe 함수 반환
- `reset()` — 런 종료(`hardReset`) 시 호출하여 잠금 해제 목록 초기화
- 각 트리거 포인트별 `check*()` 헬퍼 제공

### ToastScene (항상 실행 오버레이)

- `HubScene.create()` 에서 `scene.launch('ToastScene')` 으로 최초 1회 실행
- 씬 전환과 무관하게 계속 살아있으며, `depth: 200` 으로 최상위 렌더링
- `AchievementManager.subscribe()` 로 이벤트 수신
- 팝업 큐 (`queue: AchievementId[]`) 로 동시 다발적 달성 처리
- 슬라이드 인(360 ms, Back.Out) → 2.8 s 유지 → 슬라이드 아웃(300 ms, Back.In)

```

║ ★ 도전 과제 달성!                      ║
║ ────────────────────────────────     ║
║ [달성 이름]                            ║
```

- **위치**: 우측 상단 (x = 1266, y = 64 기준)
- **크기**: 310 × 96 px
- **애니메이션**: 화면 오른쪽 밖 → 최종 위치 슬라이드 인, 유지 후 슬라이드 아웃

- **색상**: 금색 테두리 + 좌측 강조 바, 어두운 보라 배경

## 상태 추적 필드 (GameState 정적)

| 필드 | 용도 |
|------|------|
| `GameState.totalBattlesWon` | 런 내 전투 승리 횟수 → first_victory 판정 |
| `GameState.battleStartHp` | 전투 시작 HP → untouchable 판정 |

두 필드 모두 `hardReset()` 시 초기화된다.
