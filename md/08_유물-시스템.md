# 유물(Relic) 시스템

## 개요

전투 간 지속되는 패시브 아이템. 최대 **5개** 장착 가능하며 런 종료 시 초기화된다.

---

## 유물 등급 (Tier)

| 등급 | 색상 | 획득처 |
|------|------|--------|
| Common (일반) | 파랑 `#74b9ff` | 일반 전투 보상, 이벤트 |
| Rare (희귀) | 황금 `#fdcb6e` | 엘리트 전투 보상, 상점 |
| Boss (보스 전용) | 주황 `#e17055` | 보스 격파 보상에서만 등장 |

---

## 유물 목록 (`src/relics/relicLibrary.ts`)

| 이름 | 등급 | 효과 | 트리거 시점 |
|------|------|------|------------|
| 불꽃 부적 | Common | 매 턴 첫 공격 카드 비용 -1 | `playCard()` — 첫 attack 카드 감지 |
| 뼈 반지 | Common | 플레이어 턴 시작 시 방어도 +4 | `startPlayerTurn()` |
| 독성 결정 | Rare | 독 부여 시 스택 +1 | `playCard()` — 독 스택 증가분 감지 |
| 낡은 동전 | Rare | 상점 가격 10% 할인 | `GameState.getShopDiscount()` |
| 피의 검 | Boss | HP ≤ 50%일 때 공격 피해 +3 | `playCard()` — attack 카드에 bonusDmg 설정 |
| 마나 수정 | Boss | 최대 마나 +1 (영구) | `GameState.addRelic()` — 획득 즉시 적용 |

## 트리거 구현 세부 (`src/GameState.ts`)

### 불꽃 부적 (Flame Amulet)
```typescript
// playCard() 내부
let costReduction = 0;
if (hasRelic('flame_amulet') && !this.firstAttackPlayedThisTurn && card.cardType === 'attack') {
  costReduction = 1;
  this.firstAttackPlayedThisTurn = true;
}
// firstAttackPlayedThisTurn은 startPlayerTurn()에서 false로 리셋
```

### 뼈 반지 (Bone Ring)
```typescript
// startPlayerTurn() 내부
if (GameState.hasRelic('bone_ring')) this.player.block += 4;
```

### 독성 결정 (Toxic Crystal)
```typescript
// playCard() 내부: 카드 실행 전 독 스냅샷 → 실행 후 비교
const poisonBefore = this.enemies.map(e => e.statuses.poison);
card.onPlay(this.player, targets);
if (GameState.hasRelic('toxic_crystal')) {
  this.enemies.forEach((e, i) => {
    if (e.statuses.poison > poisonBefore[i]) addStatus(e, 'poison', 1);
  });
}
```

### 피의 검 (Blood Sword)
```typescript
// playCard() 내부: attack 카드 실행 전 bonusDmg 설정
this.player.bonusDmg =
  hasRelic('blood_sword') && player.hp <= player.maxHp / 2 && card.cardType === 'attack'
    ? 3 : 0;
// applyDamage()에서 bonusDmg 반영 (combat.ts)
```

### 마나 수정 (Mana Crystal)
```typescript
// addRelic() 내부: 획득 즉시 정적 상태에 반영
if (relic.id === 'mana_crystal') GameState.playerMaxMana += 1;
// 다음 GameState.reset() 시 constructor에서 playerMaxMana를 사용
```

### 낡은 동전 (Old Coin)
```typescript
// 상점 가격 계산 시 사용
const discount = GameState.getShopDiscount(); // 0.1 (10%) or 0
const price = Math.floor(basePrice * (1 - discount));
```

## applyDamage 수정 (`src/utils/combat.ts`)

```typescript
if (attacker) {
  if (attacker.statuses.strength > 0) dmg += attacker.statuses.strength;
  const bonus = (attacker as { bonusDmg?: number }).bonusDmg ?? 0;
  if (bonus > 0) dmg += bonus;
  if (attacker.statuses.weak > 0) dmg = Math.floor(dmg * 0.75);
}
```

`bonusDmg`는 `Player` 인터페이스에만 존재. `Entity`를 오염시키지 않고 타입 캐스트로 접근.

## CardType 시스템

Flame Amulet과 Blood Sword가 공격 카드를 구분하기 위해 `cardType` 필드 추가:

| cardType | 해당 카드 |
|----------|----------|
| `'attack'` | 타격, 강타, 쌍격, 폭발, 연쇄공격, 폭풍격, 독침, 취약화 |
| `'skill'` | 방어, 독기방출, 역량강화, 독폭풍 |

## 유물 보상 UI (`src/scenes/RelicRewardScene.ts`)

- 1~3개 유물 카드 가로 배치
- 유물 이름·설명·등급 표시 (등급별 테두리 색상 구분)
- 클릭 시 획득 플래시 → returnScene으로 이동
- "건너뛰기" 버튼으로 획득 없이 이동
- 슬롯 초과(5개) 시 카드 비활성화

### 데이터 전달 방식
```typescript
// 보스 보상
this.scene.start('RelicRewardScene', {
  relics: GameState.getRandomRelics('boss', 3),
  returnScene: 'BattleScene',
});
```

---

## BattleScene 유물 표시

화면 좌측 상단(x=10, y=44)에 유물 이름 목록을 렌더링.
등급별 색상 점(`●`)으로 시각적 구분. 전투 중 변하지 않으므로 `create()`에서 1회만 렌더링.

## 정적 메서드 요약

```typescript
GameState.addRelic(relic)          // 장착 (Mana Crystal 즉시 적용)
GameState.hasRelic(id)             // 장착 여부 확인
GameState.getRandomRelics(tier, n) // 미획득 유물 중 n개 랜덤
GameState.getShopDiscount()        // 상점 할인율 (Old Coin)
GameState.hardReset()              // equippedRelics, playerMaxMana 포함 전초기화
```
