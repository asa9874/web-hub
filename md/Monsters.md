> 그들은 모두 한때 무언가였던 것들이다. — 세계관 문서

---

## 조우 시스템 (RNG 스폰 로직)

### 노드 유형별 호출 규칙

| 노드 유형 | 조우 방식 |
|----------|----------|
| 전투 (battle) | 해당 Act 일반 몬스터 테이블에서 가중치 무작위 1종 선택 |
| 엘리트 (elite) | 해당 Act 엘리트 몬스터 테이블에서 가중치 무작위 1종 선택 |
| 보스 (boss) | 해당 Act 보스 테이블에서 균등 확률(각 33.3%)로 1종 선택 |

### 가중치 선택 알고리즘

```
전체 가중치 합 = sum(모든 몬스터 weight)
rand = Math.random() * 전체 가중치 합
누적 합을 순서대로 더하다 rand를 넘는 첫 몬스터 선택
```

### 보스 선택 (Act별 3종 균등)

```
bossIndex = Math.floor(Math.random() * 3)   // 0, 1, 2
→ bossPool[act][bossIndex] 호출
```
