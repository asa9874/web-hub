# 전투 시스템

## 개요

`BattleScene` (렌더링·입력) + `GameState` (로직) 의 2-레이어 구조.
씬은 상태를 읽고 표시하는 것만 하고, 실제 수치 계산·턴 관리는 전부 `GameState`에서 처리한다.

---

## 턴 흐름

```
플레이어 턴
  └─ 카드 드래그 & 드롭으로 적에게 사용
  └─ "턴 종료" 버튼 클릭
       ↓ (0.9초 딜레이)
몬스터 턴
  └─ 예약된 패턴 실행 (확률 기반 선택)
  └─ UI에 행동명 플래시 표시
       ↓ (1.4초 딜레이)
플레이어 턴
  └─ 방어도 초기화, 마나 전량 회복
  └─ 몬스터 다음 의도 표시 갱신
```

- 몬스터 턴 중: 카드 드래그 및 턴 종료 버튼 비활성화
- 플레이어 HP ≤ 0: "게임 오버" → HubScene으로 이동

## GameState — 상태 관리 싱글톤

```typescript
class GameState {
  player: Player   // HP 80/80, 마나 3/3, 방어도 0
  enemy:  Monster  // Slime 인스턴스 (HP 50/50, 행동 패턴 3종)
  hand:   Card[]   // 초기 5장

  static get instance(): GameState  // 싱글톤 접근
  static reset(): void              // 완전 재초기화 (씬 재진입 시 호출)

  playCard(cardId, target): boolean  // 마나 검사 → 차감 → onPlay → 패에서 제거
  get monsterIntent(): AttackPattern | null  // 몬스터 다음 예약 행동

  endPlayerTurn(): void      // 플레이어 턴 종료 처리
  executeMonsterTurn(): AttackPattern  // 몬스터 행동 실행 → 사용된 패턴 반환
  startPlayerTurn(): void    // 방어도 초기화 + 마나 회복
}
```

### 피해 계산 (`src/utils/combat.ts`)

```typescript
function applyDamage(target: Entity, amount: number): void {
  const absorbed = Math.min(target.block, amount);
  target.block -= absorbed;
  target.hp = Math.max(0, target.hp - (amount - absorbed));
}
```

카드 `onPlay`와 몬스터 `AttackPattern.execute` 양쪽에서 공통으로 사용.

## BattleScene — 렌더링 구조

### 화면 레이아웃 (800 × 600)

```
┌──────────────────────────────────────────────────────┐
│  ◀뒤로                          [다음 행동 패널]     │ y=0~50
│                                  점액 강타            │
│               [슬라임]           8의 피해를 입힌다.   │ y=115~310
│                HP 50/50                               │
│                방어도: 0                              │
│                                                       │
│  [영웅]                                               │ y=330~480
│  HP 80/80                                            │
│  방어도: 0                                            │
│  마나: 3/3                                           │
├──────────────────────────────────────────────────────┤ y=460
│  [타격][타격][방어][강타][쌍격]              [턴종료] │ y=480~600
└──────────────────────────────────────────────────────┘
```

- **다음 행동 패널**: 화면 우측(x≈650), 플레이어 턴 중 몬스터의 예약 행동 표시
- **턴 종료 버튼**: 플레이어 턴에는 초록색(활성), 몬스터 턴에는 회색(비활성)

### 드래그 & 드롭 흐름

```
dragstart  → 컨테이너 depth=10
drag       → container.setPosition(dragX, dragY)
dragend    → turnPhase !== 'player' → returnCard() (몬스터 턴 차단)
           → pointer가 enemyDropZone 내부?
               Yes + playCard 성공  → destroy() + updateUI() + handlePostCardPlay()
               Yes + 마나 부족      → returnCard() + flashMessage('마나가 부족합니다!')
               No                  → returnCard()
```

### 전투 후 분기 (`handlePostCardPlay`)

```
적 HP ≤ 0         → scene.pause() + launch('DialogueScene', battle_victory)
적 HP ≤ 절반(최초) → scene.pause() + launch('DialogueScene', battle_mid)
그 외              → 계속 진행
```
