# 전투 시스템

## 개요

`BattleScene` (렌더링·입력) + `GameState` (로직) 의 2-레이어 구조.
씬은 상태를 읽고 표시하는 것만 하고, 실제 수치 계산은 전부 `GameState`에서 처리한다.

---

## GameState — 상태 관리 싱글톤

```typescript
class GameState {
  player: Player   // HP 80/80, 마나 3/3, 방어도 0
  enemy:  Entity   // HP 50/50, 방어도 0
  hand:   Card[]   // 초기 5장

  static get instance(): GameState  // 싱글톤 접근
  static reset(): void              // 완전 재초기화 (씬 재진입 시 호출)

  playCard(cardId, target): boolean  // 마나 검사 → 차감 → onPlay → 패에서 제거
  endTurn(): void                    // 마나 회복 + 방어도 초기화
}
```

### 피해 계산 규칙 (`applyDamage`)

```
피해량 → 방어도로 먼저 흡수 → 남은 수치를 HP에 적용
HP는 0 미만으로 내려가지 않음
```

```typescript
function applyDamage(target: Entity, amount: number): void {
  const absorbed = Math.min(target.block, amount);
  target.block -= absorbed;
  target.hp = Math.max(0, target.hp - (amount - absorbed));
}
```

### 카드 추가 방법

`GameState.ts`의 `CARD_LIBRARY` 배열에 객체 한 개만 추가하면 된다.
씬 코드, 조건문, 별도 등록 작업 일절 불필요.

```typescript
{
  id: 'poison_dart',       // 패 내 고유 ID
  name: '독 화살',
  cost: 1,
  description: '적에게 4 피해\n+ 독 2 부여.',
  onPlay: (_user, target) => {
    applyDamage(target, 4);
    // target.status.poison += 2;  ← Phase 2에서 추가 예정
  },
},
```

## BattleScene — 렌더링 구조

### 화면 레이아웃 (800 × 600)

```
┌──────────────────────────────────────────┐
│  ◀뒤로                                   │ y=0~50
│                                          │
│               [슬라임]                   │ y=115~310
│                HP 50/50                  │
│                방어도: 0                 │
│                                          │
│  [영웅]                                  │ y=330~480
│  HP 80/80                               │
│  방어도: 0                               │
│  마나: 3/3                              │
├──────────────────────────────────────────┤ y=460
│  [타격][타격][방어][강타][쌍격] [턴종료]  │ y=480~600
└──────────────────────────────────────────┘
```

### 카드 뷰 (CardView)

각 카드는 `Phaser.GameObjects.Container`로 구성된다.

```
Container(x, cardY)
  ├── Rectangle  배경 (짙은 회색)
  ├── Circle     마나 비용 배지 (보라)
  ├── Text       비용 숫자
  ├── Text       카드 이름
  ├── Rectangle  구분선
  └── Text       카드 설명
```

- `container.setSize(w, h)` + `container.setInteractive()` → 히트 영역 등록
- `this.input.setDraggable(container)` → 드래그 가능

### 드래그 & 드롭 흐름

```
dragstart  → 해당 컨테이너 depth=10 (최상위)
drag       → container.setPosition(dragX, dragY)
dragend    → pointer 좌표가 enemyDropZone 내부?
               Yes + playCard 성공  → container.destroy() + updateUI() + handlePostCardPlay()
               Yes + 마나 부족      → returnCard() + flashMessage('마나가 부족합니다!')
               No                  → returnCard() (Back.Out 트위닝)
```

### 전투 후 분기 (`handlePostCardPlay`)

```
적 HP ≤ 0  →  scene.pause() + scene.launch('DialogueScene', battle_victory)
적 HP ≤ 절반 && 첫 도달  →  scene.pause() + scene.launch('DialogueScene', battle_mid)
그 외  →  계속 진행
```

`midBattleTriggered` 플래그로 중간 대화가 같은 전투에서 1회만 발동한다.
