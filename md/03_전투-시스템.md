# 전투 시스템

## 개요

`BattleScene` (렌더링·입력) + `GameState` (로직) 의 2-레이어 구조.
씬은 상태를 읽고 표시하는 것만 하고, 실제 수치 계산·덱 관리·턴 처리는 전부 `GameState`에서 처리한다.

---

## 덱 메커니즘

### 카드 세 더미

| 더미 | 설명 |
|------|------|
| `deck` | 뽑기 더미. 전투 시작 시 라이브러리 전체를 셔플해 생성. |
| `hand` | 손패. 턴 시작 시 `deck`에서 3장 드로우. |
| `discard` | 버림 더미. 사용한 카드와 턴 종료 시 남은 손패가 쌓임. |

### 흐름

```
[전투 시작]
  deck = shuffle(CARD_LIBRARY)
  drawCards(3) → deck에서 3장 → hand

[카드 사용]
  hand → (onPlay 실행) → discard

[플레이어 턴 종료]
  endPlayerTurn(): 남은 hand 전부 → discard

[플레이어 턴 시작]
  startPlayerTurn(): block=0, mana 회복, drawCards(3)

[덱 소진 시 자동 보충]
  drawCards(): deck 비면 → shuffle(discard) → deck, discard=[]
```

---

## 턴 흐름

```
플레이어 턴
  └─ 카드 드래그 & 드롭으로 적에게 사용
  └─ "턴 종료" 버튼 클릭 (패 영역 위쪽 우측)
       ↓ 남은 손패 비주얼 제거 + endPlayerTurn()
       ↓ (0.9초 딜레이)
몬스터 턴
  └─ 예약된 패턴 실행 (확률 기반 선택)
  └─ UI에 행동명 플래시 표시
       ↓ (1.4초 딜레이)
플레이어 턴
  └─ startPlayerTurn(): block=0, 마나 회복, drawCards(3)
  └─ renderHand(): 새 손패 렌더링
  └─ 몬스터 다음 의도 표시 갱신
```

- 몬스터 턴 중: 카드 드래그 및 턴 종료 버튼 비활성화
- 플레이어 HP ≤ 0: "게임 오버" → HubScene 이동

## GameState API

```typescript
class GameState {
  player: Player   // HP 80/80, 마나 3/3, 방어도 0
  enemy:  Monster  // 현재 전투의 몬스터 인스턴스
  hand:   Card[]   // 현재 손패
  deck:   Card[]   // 뽑기 더미
  discard: Card[]  // 버림 더미

  static readonly DRAW_PER_TURN = 3

  static get instance(): GameState
  static reset(): void

  drawCards(n): void           // 덱에서 n장 드로우 (덱 소진 시 버림 더미 재활용)
  playCard(cardId, target): boolean  // 사용 성공 시 hand→discard
  get monsterIntent(): AttackPattern | null

  endPlayerTurn(): void        // 남은 hand → discard
  executeMonsterTurn(): AttackPattern
  startPlayerTurn(): void      // block=0, 마나 회복, drawCards(3)
}
```

### 피해 계산 (`src/utils/combat.ts`)

```typescript
function applyDamage(target: Entity, amount: number): void {
  const absorbed = Math.min(target.block, amount);
  target.block -= absorbed;
  target.hp = Math.max(0, target.hp - (amount - absorbed));
}
```

카드 `onPlay`와 몬스터 `AttackPattern.execute` 양쪽에서 공통으로 사용.

### 드래그 & 드롭 흐름

```
dragstart  → 컨테이너 depth=10
drag       → container.setPosition(dragX, dragY)
dragend    → turnPhase !== 'player' → returnCard() (몬스터 턴 차단)
           → pointer가 enemyDropZone 내부?
               Yes + playCard 성공  → destroy() + updateUI() + handlePostCardPlay()
               Yes + 마나 부족      → returnCard() + flashMessage('마나가 부족합니다!')
               No                  → returnCard()
```

### 전투 후 분기 (`handlePostCardPlay`)

```
적 HP ≤ 0         → scene.pause() + launch('DialogueScene', battle_victory)
적 HP ≤ 절반(최초) → scene.pause() + launch('DialogueScene', battle_mid)
그 외              → 계속 진행
```
