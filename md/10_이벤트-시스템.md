# 이벤트(Event) 시스템

## 개요

텍스트 기반 선택지 이벤트. 선택에 따라 골드·HP 변화, 카드/유물 보상, 카드 제거 등의 결과가 주어진다.
`EventScene`에서 처리되며 `eventId`를 넘기지 않으면 `EVENT_LIBRARY`에서 무작위로 선택된다.

## 이벤트 목록 (`src/data/events.ts`)

| ID | 제목 | 선택지 A | 선택지 B |
|----|------|---------|---------|
| `shady_merchant` | 수상한 상인 | 75G 지불 → 카드 1장 보상 | 거절 → 아무 일 없음 |
| `cursed_altar` | 저주받은 제단 | HP -10 → 유물 1개 보상 (Common/Rare) | 무시 → 아무 일 없음 |
| `ancient_library` | 낡은 도서관 | 카드 1장 무료 업그레이드 | 카드 1장 무료 제거 |
| `herb_pile` | 약초 더미 | HP +20 (최대 HP 상한) | 지나침 → 아무 일 없음 |
| `demon_contract` | 악마의 계약 | 최대 HP -5 → 카드 2장 보상 | 거절 → 아무 일 없음 |

## 선택지 조건 (비활성 처리)

| 조건 | 표시 |
|------|------|
| `requireGold` 미충족 | 골드 부족 메시지 + 버튼 비활성 |
| `requireHp` 미충족 | HP 부족 메시지 + 버튼 비활성 |
| 업그레이드 가능 카드 없음 | 카드 없음 메시지 + 버튼 비활성 |
| 제거 가능 카드 없음 | 카드 없음 메시지 + 버튼 비활성 |

## EventEffect 타입 (`src/data/events.ts`)

```typescript
type EventEffect =
  | { type: 'none' }
  | { type: 'gold'; amount: number }           // GameState.gold 증감
  | { type: 'hp'; amount: number }             // playerHp 증감 (최소 1, 최대 maxHp)
  | { type: 'max_hp'; amount: number }         // playerMaxHp 증감 (최소 1)
  | { type: 'card_reward'; count: number }     // CardRewardScene으로 전환
  | { type: 'relic_reward'; count: number }    // RelicRewardScene으로 전환
  | { type: 'card_upgrade' }                   // 인라인 카드 업그레이드 화면
  | { type: 'card_remove_free' };              // 인라인 카드 제거 화면 (무료)
```

## 흐름도

```
EventScene.showEvent()
  └─ 선택지 클릭 → executeChoice()
       ├─ 즉시 효과 적용 (gold / hp / max_hp)
       ├─ [card_reward/relic_reward] → 씬 전환 후 returnScene 복귀
       ├─ [card_upgrade]      → showCardUpgradeScreen() → showOutcome()
       ├─ [card_remove_free]  → showCardRemoveScreen()  → showOutcome()
       └─ [none/outcome only] → showOutcome() → returnScene 복귀
```
