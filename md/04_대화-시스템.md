# 대화 시스템 (비주얼 노벨)

## 개요

`DialogueScene`은 Phaser 씬으로 구현된 비주얼 노벨 대화 시스템이다.
스크립트 데이터는 `data/dialogues.ts`에 분리 보관되며,
씬은 데이터를 읽어 표시만 한다.

## 캐릭터 강조 시스템

말하는 캐릭터를 확대·선명하게, 침묵하는 캐릭터를 축소·흐리게 처리한다.
`scene.pause()` 오버레이로 진입할 때도 동일하게 동작한다.

| 상태 | scale | alpha |
|------|-------|-------|
| SPEAKING (말하는 중) | 1.06 | 1.00 |
| IDLE (상대가 말하는 중) | 0.90 | 0.48 |
| NEUTRAL (내레이터 or 초기) | 0.96 | 0.76 |

전환은 `duration: 220ms, ease: Power2.Out` 트위닝으로 처리한다.

### 우측 캐릭터 좌우 반전

우측 캐릭터의 그래픽 오브젝트에 `setScale(-1, 1)`을 적용해
주인공을 바라보는 방향으로 표시한다.
컨테이너 레벨의 scaleX 트위닝은 양수값을 사용하므로 반전이 유지된다.

## 타이프라이터 효과

`this.time.addEvent`로 30ms마다 한 글자씩 추가한다.
출력 중 클릭/스페이스 → 전체 텍스트를 즉시 표시한다.
출력 완료 후 클릭/스페이스 → 다음 줄로 진행한다.

```
타이핑 중  →  ▼ 숨김
타이핑 완료 →  ▼ 나타남 (0.25 ↔ 1.0 Sine.InOut 반복 깜빡임)
```

## 대화 스크립트 구조

```typescript
interface DialogueScript {
  id: string;
  showOtherCharacter: boolean; // false면 우측 캐릭터 숨김
  lines: DialogueLine[];
}

interface DialogueLine {
  speaker: 'protagonist' | 'other' | 'narrator';
  characterName?: string; // 대화창 이름 배지에 표시 (narrator는 생략)
  text: string;
}
```

### 화자별 표시 규칙

| speaker | 이름 배지 | 텍스트 스타일 | 강조 |
|---------|-----------|--------------|------|
| `protagonist` | 파란 배지 + 이름 | 일반 밝은 색 | 주인공 SPEAKING |
| `other` | 초록 배지 + 이름 | 일반 밝은 색 | 다른캐릭터 SPEAKING |
| `narrator` | 없음 | 이탤릭 회색 | 둘 다 NEUTRAL |

## 스크립트 목록

| id | 용도 | 캐릭터 |
|----|------|--------|
| `battle_intro` | 전투 시작 전 주인공 독백 | 주인공만 |
| `battle_mid` | 적 HP 절반 도달 시 중간 대화 | 주인공 + 슬라임 |
| `battle_victory` | 전투 승리 후 대화 | 주인공 + 슬라임 |
| `test_intro` | 테스트용 대화 (허브 메뉴 버튼) | 주인공 + 슬라임 |
| `solo_monologue` | 테스트용 독백 | 주인공만 |

### 스크립트 추가 방법

`data/dialogues.ts`의 `DIALOGUE_SCRIPTS` 객체에 키-값 하나만 추가한다.

```typescript
my_new_dialogue: {
  id: 'my_new_dialogue',
  showOtherCharacter: true,
  lines: [
    { speaker: 'narrator', text: '새로운 만남.' },
    { speaker: 'protagonist', characterName: '영웅', text: '...' },
  ],
},
```

## DialogueScene 호출 방법

어느 씬에서든 아래 한 줄로 대화 씬을 시작할 수 있다.

```typescript
// 일반 전환 (완전히 씬을 바꿈)
this.scene.start('DialogueScene', {
  scriptId: 'my_script',
  returnScene: 'HubScene',   // 대화 종료 후 이 씬으로 이동
});

// 오버레이 (현재 씬 상태 보존)
this.scene.pause();
this.scene.launch('DialogueScene', {
  scriptId: 'mid_battle_talk',
  returnScene: 'BattleScene',  // resumeScene이 있으면 사용 안 됨
  resumeScene: 'BattleScene',  // 대화 종료 후 이 씬을 재개
});
```
