# 포션 / 소모품 시스템

## 개요

전투 중 언제든 사용 가능한 일회용 아이템. 슬롯 2개를 제공하며 이벤트·상점에서 획득한다.

---

## 포션 종류

| ID | 이름 | 효과 |
|----|------|------|
| heal_potion | 치유 포션 | HP +20 회복 |
| strength_potion | 힘 포션 | 이번 전투 힘 +3 |
| explosive_potion | 폭발 포션 | 모든 적에게 10 피해 |
| draw_potion | 드로우 포션 | 카드 3장 드로우 |

---

## 파일 구조

- `src/potions/potionLibrary.ts` — POTION_LIBRARY (4종 포션 정의)
- `src/types.ts` — PotionId, Potion 인터페이스 추가
- `src/GameState.ts` — potionSlots, addPotion(), getRandomPotion(), getPotionShopPrice()
- `src/scenes/BattleScene.ts` — 포션 슬롯 UI, usePotionAtSlot()
- `src/scenes/ShopScene.ts` — 3열 서비스 레이아웃, renderPotionService()
- `src/data/events.ts` — potion_reward 효과 타입, potion_stash 이벤트
- `src/scenes/EventScene.ts` — potion_reward 처리

---

## GameState 포션 관련 필드/메서드

```typescript
static potionSlots: (Potion | null)[] = [null, null]  // 슬롯 2개

static addPotion(potion: Potion): boolean   // 빈 슬롯에 추가, 가득 차면 false
static getRandomPotion(): Potion            // 라이브러리에서 무작위 반환
static getPotionShopPrice(): number         // 50–80G + 할인 적용
```

hardReset() 시 potionSlots = [null, null] 초기화.

## BattleScene 포션 UI

위치: PILE_MANA_Y 행 좌측 (x=120, x=184)

- 포션 있음: 포션 종류별 색상 배경 + 이름 표시, 클릭으로 즉시 사용
- 포션 없음: 회색 빈 슬롯
- 플레이어 턴에서만 사용 가능

사용 후 `renderPotionSlots()` 재호출로 시각 갱신.

폭발 포션으로 모든 적 처치 시 → `handleVictory()` 즉시 호출.

## 이벤트 시스템 연동

### EventEffect 추가

```typescript
| { type: 'potion_reward'; count: number }
```

### potion_stash 이벤트

- title: "포션 창고"
- 선택지 1: 포션을 챙긴다 → potion_reward count:2 (슬롯 가득 시 비활성)
- 선택지 2: 지나친다 → none

### EventScene 처리

- `isAvailable()`: potionSlots 모두 찼으면 비활성
- `effectPreview()`: "포션 N개" 표시
- `unavailableReason()`: "포션 슬롯이 가득 찼습니다"
- `executeChoice()`: 즉시 getRandomPotion() × count 추가, 결과 텍스트 표시
