# 상점(Shop) 시스템

## 개요

런 중 골드를 소비해 카드·유물을 구매하고 카드를 영구 제거하는 씬.
방문할 때마다 인벤토리가 무작위 생성되며, 구매된 상품은 매진 처리된다.

---

## 가격 체계

### 카드 판매 가격 (`GameState.getCardShopPrice(card)`)

| 카드 코스트 | 기본 가격 범위 | Old Coin 적용 시 |
|------------|--------------|----------------|
| 0~1 코스트 | 50 ~ 75 G    | 45 ~ 67 G      |
| 2 코스트   | 75 ~ 110 G   | 67 ~ 99 G      |
| 3+ 코스트  | 120 ~ 180 G  | 108 ~ 162 G    |

### 유물 판매 가격 (`GameState.getRelicShopPrice(relic)`)

| 등급   | 기본 가격 | Old Coin 적용 시 |
|--------|---------|----------------|
| Common | 120 G   | 108 G          |
| Rare   | 200 G   | 180 G          |
| Boss   | 320 G   | 288 G          |

### 카드 제거 비용 (`GameState.cardRemovalCost`)

- 초기값: **75 G**
- 제거할 때마다 **+25 G** 증가 (런 내 누적)
- 초기화: `GameState.hardReset()` 시 75 G로 복원

---

## 상품 구성

### 카드 (3장)
- `GameState.getRandomRewardCards(3)` — 이름 중복 없이 무작위 3장
- 가격은 씬 진입 시 1회 확정 (`generateInventory()`)

### 유물 (1개)
- Common 60%, Rare 40% 확률로 등급 결정
- 이미 장착된 유물은 제외
- 유물이 없으면 유물 칸 미표시

---

## 카드 제거 흐름

```
메인 화면 → [카드 선택] 버튼 클릭
  → showCardRemovalScreen(): 현재 런 덱 전체 표시
  → 카드 클릭 → 확인 오버레이
  → 확인 → GameState.removeCard(cardId) + gold 차감
  → showMain() 복귀
```

- 덱이 비었으면 "제거할 카드가 없습니다" 표시
- 골드 부족 시 버튼 비활성화

## GameState 변경 사항 (`src/GameState.ts`)

### 신규 정적 필드

```typescript
static cardRemovalCost = 75;
static removedCardIds: string[] = [];
```

### 신규 정적 메서드

```typescript
GameState.removeCard(cardId)          // removedCardIds에 추가, cost +25
GameState.getCardShopPrice(card)      // 코스트 기반 가격 + 할인
GameState.getRelicShopPrice(relic)    // 등급 기반 가격 + 할인
```

### 수정된 메서드

```typescript
// constructor — 덱 생성 시 제거된 카드 필터링
this.deck = shuffleArray([
  ...CARD_LIBRARY.filter(c => !removedCardIds.includes(c.id)).map(applyUpgrade),
  ...bonusCards.filter(c => !removedCardIds.includes(c.id)).map(applyUpgrade),
]);

// getAllRunCards() — 동일하게 removedCardIds 필터링
// hardReset() — cardRemovalCost=75, removedCardIds=[] 초기화
```
