## 구현된 시스템

### 전투 시스템
- 카드 드래그 → 적 영역 드롭 → `GameState.playCard()` 호출
- 방어도 선흡수 피해 계산 (`applyDamage`)
- 마나 부족 시 카드 원위치 복귀 (Back.Out 트위닝)
- **최대 5적 동시 전투** — 동적 위치 계산으로 배치

### 덱 메커니즘
- `deck` / `hand` / `discard` 세 더미 분리
- 턴 시작: 덱에서 3장 드로우, 덱 소진 시 버림 더미 셔플 후 재활용
- 카드 사용: `hand → discard`
- 턴 종료: 남은 `hand → discard`

### 카드 풀 (13종)
- 단일 대상 공격: 타격(6), 강타(14), 쌍격(5×2), 연쇄공격(3×3)
- 단일 대상 방어: 방어(방어도+5)
- **전체 대상 공격(AoE)**: 폭발(4), 폭풍격(8) — 오렌지 테두리+전체 태그 표시
- **상태이상 카드**: 독침(5+독3), 독기방출(독5), 취약화(8+취약2), 역량강화(힘2), 독 폭풍(전체 독3)

### 턴 시스템
- 플레이어 턴: 카드 사용 → 턴 종료 버튼
- 몬스터 턴: 1번→N번 순차 실행 (700ms 간격)
- 플레이어 턴에 **각 몬스터**의 다음 행동(의도) 개별 표시

### 몬스터 시스템
- 추상 `Monster` 클래스 + 가중치 기반 패턴 선택
- 5종 구현: 슬라임·고블린·오크·스켈레톤·박쥐

### 대화 시스템
- 말하는 캐릭터 확대(×1.06) · 상대 축소(×0.90) 트위닝 강조
- 내레이터는 아무도 강조 안 함, 이탤릭 회색 텍스트
- 30ms 타이프라이터 효과, 클릭으로 즉시 전체 표시
- `showOtherCharacter: false`면 우측 캐릭터 숨김

### 카드 보상 시스템
- 전투 승리 시 골드 40~70 랜덤 지급, `GameState.gold`에 누적
- VictoryScene: 획득 골드 + 누적 골드 표시, 카드 선택 진입 버튼
- CardRewardScene: 3장 제시 → 1장 선택(덱에 영구 추가) 또는 건너뛰기
- 보상 카드는 `GameState.bonusCards`에 저장 → 다음 전투 덱에 포함
- 재사용 가능: 임의 씬에서 `scene.start('CardRewardScene', { cards, returnScene })`

### 게임 리셋 시스템
- `GameState.hardReset()`: gold, bonusCards 초기화 (런 종료 시 호출)
- 자동 트리거: 게임 오버 시 HubScene 복귀 전, VictoryScene "메인 메뉴" 버튼
- 수동 트리거: HubScene 상태 바의 "런 초기화" 버튼
- HubScene은 현재 런 상태(gold, 보너스 카드 수)를 표시하며 진행 시 없으면 숨김

### 덱/버림 더미 뷰어
- BattleScene에서 덱 아이콘 또는 버림 더미 아이콘 클릭 시 오버레이 팝업
- PileViewerScene: 5열 그리드, 최대 15장 표시, 초과 시 나머지 장 수 표시
- 패널 외부 클릭 또는 ✕ 버튼으로 닫기
- BattleScene은 일시정지 없이 유지됨

### 유물(Relic) 시스템
- 6종 유물: 불꽃 부적(Common) · 뼈 반지(Common) · 독성 결정(Rare) · 낡은 동전(Rare) · 피의 검(Boss) · 마나 수정(Boss)
- 최대 5개 슬롯, 런 종료 시 `hardReset()`으로 초기화
- `GameState.addRelic / hasRelic / getRandomRelics / getShopDiscount` 정적 API
- `Card.cardType: 'attack' | 'skill'` — Flame Amulet / Blood Sword 판별용
- `Player.bonusDmg` — Blood Sword 등 조건부 공격 보너스를 `applyDamage`에 전달
- RelicRewardScene: 등급별 색상 카드 UI, 건너뛰기 지원

### 상태이상 시스템
- 4종: 독(매 턴 HP 직접 감소), 힘(공격+), 취약(피해 ×1.5), 약화(공격 ×0.75)
- 모든 Entity에 `statuses: StatusEffects` 필드 — 각 상태이상은 정수 스택
- 독은 방어도를 무시, 매 턴 스택값 피해 후 스택 1 감소
- 힘/약화/취약은 `applyDamage(target, amount, attacker)` 호출 시 자동 반영
- BattleScene: 플레이어·몬스터 각각 상태이상 표시, 독 플래시 메시지, 독 사망 승리 처리

### 씬 전환
| 방식 | 사용처 |
|------|--------|
| `scene.start()` | 완전 전환 (상태 초기화) |
| `scene.pause()` + `scene.launch()` | 오버레이 (상태 보존) |

## 테스트 시나리오 흐름

```
HubScene (카드 3종)
  ├─[전투 시스템]      → DialogueScene(battle_intro) → BattleScene (슬라임 1마리)
  │                         ├─[적 HP 50%]   → DialogueScene(battle_mid, 오버레이) → 전투 재개
  │                         └─[모든 적 HP 0] → VictoryScene (골드 보상)
  │                               ├─[카드 선택] → CardRewardScene → HubScene
  │                               └─[메인 메뉴] → HubScene
  ├─[대화 시스템]      → DialogueScene(test_intro) → HubScene
  └─[5인 전투 테스트]  → BattleScene (슬라임·고블린·오크·스켈레톤·박쥐)
                              └─[승리] → VictoryScene → CardRewardScene → HubScene
```

|------|------|

| 전투 중 대화 | `scene.pause()` + `scene.launch('DialogueScene', { ..., resumeScene })` |

| 이벤트 카드 보상 | `scene.start('CardRewardScene', { cards: GameState.getRandomRewardCards(3), returnScene })` |

## Phase 2 예정

### 🗺️ 던전 / 맵 시스템
- 노드 기반 던전 맵 (전투 → 엘리트 → 보스 경로 선택)
- 층(Act) 구조 — Act 1 / 2 / 3 + 최종 보스
- 노드 종류: 일반 전투, 엘리트 전투, 이벤트, 상점, 캠프파이어, 보물방, 보스
- 분기 경로 선택 (한 번 지나친 노드는 재방문 불가)
- 층 간 보스 격파 보상 (유물 획득)
- 맵 시드(seed) 기반 재현 가능한 런

### ⚔️ 전투 시스템 확장
- **보스 몬스터** — 고유 패턴 시퀀스, 페이즈 전환
- **엘리트 몬스터** — 일반보다 강하고 유물 드롭
- 전투 특수 조건 (저주받은 방 — 카드 비용 +1, 독 방 — 매 턴 독 1 부여 등)
- 반격(가시) 메커니즘 — 공격받을 때 역피해
- 카드 사용 콤보 카운터 (연속 공격 시 보너스)
- 다중 플레이어 타겟팅 (카드 드래그 방향으로 타겟 선택)
- 전투 중 포션 사용 슬롯

### 🃏 카드 시스템 확장
- **카드 등급**: 일반(Common) / 고급(Uncommon) / 희귀(Rare) — 테두리 색상 구분
- **카드 업그레이드** — 캠프파이어 또는 NPC에서 강화 (비용 감소 / 효과 증가)
- **카드 제거** — 상점에서 골드 소모하여 약한 카드 덱에서 제거
- **특수 카드 속성**
  - `exhaust`: 사용 후 버림 더미에 가지 않고 소멸
  - `innate`: 턴 시작 시 항상 손패에 포함
  - `retain`: 턴 종료 시 버려지지 않고 다음 턴 유지
  - `ethereal`: 손패에서 사용하지 않으면 자동 소멸
  - `power`: 전투 내내 지속 효과 (덱에 남지 않음)
- **X비용 카드** — 남은 마나 전부 소모, 소모량에 비례한 효과
- **저주 카드** — 핸드에 있으면 불이익, 제거 불가
- 카드 복사 / 무작위 카드 생성 카드
- 클래스별 전용 카드 풀 (캐릭터마다 다른 스타터 덱 + 카드 풀)

### 🧪 상태이상 확장
- **출혈(bleed)** — 이동 시마다 HP 감소 (전투 외 적용 가능)
- **화상(burn)** — 독과 유사하되 스택 감소 없이 일정 턴 후 소멸
- **빙결(freeze)** — 1턴 행동 불가
- **기절(stun)** — 다음 행동 패턴 건너뜀
- **재생(regen)** — 턴 시작 시 HP 회복
- **분노(enrage)** — 피격 시 힘 증가 (일부 보스 전용)
- **방어도 붕괴(brittle)** — 받는 피해로 방어도가 쌓이지 않음
- **소환(summon)** — 전투 중 추가 몬스터 등장

### 💎 유물(Relic) 시스템
- 전투 간 유지되는 패시브 아이템 (최대 N개 장착)
- 유물 등급: 일반 / 고급 / 보스 전용
- 예시 유물
  - *불꽃 부적*: 공격 카드 비용 -1 (턴당 최초 1회)
  - *뼈 반지*: 턴 시작 시 방어도 4 획득
  - *독성 결정*: 독 스택 부여 시 +1 추가
  - *피의 검*: HP가 50% 이하일 때 공격 +3
  - *낡은 동전*: 상점 가격 10% 할인
  - *마나 수정*: 최대 마나 +1
- BossRelic: 보스 격파 시 3종 중 1개 선택

### 🧴 포션 / 소모품 시스템
- 전투 중 사용 가능한 일회용 아이템 (슬롯 2개)
- 예시: 치유 포션(HP +20), 힘 포션(힘 3), 폭발 포션(전체 10피해), 드로우 포션(카드 3장 드로우)
- 이벤트 / 상점에서 획득

### 🏪 상점(Shop) 시스템
- ShopScene: 골드 소모로 카드 구매 / 카드 제거 / 유물 구매 / 포션 구매
- 카드 가격: 일반 50~75G, 고급 75~110G, 희귀 120~180G
- 카드 제거 비용: 75G (이후 점진 증가)
- 방문당 상품 무작위 선정, 일부 상품 매진 처리

### 🎲 이벤트(Event) 시스템
- EventScene: 텍스트 + 2~3가지 선택지 (선택 결과 랜덤 보상/패널티)
- 예시 이벤트
  - *수상한 상인*: 골드 75 지불 → 희귀 카드 / 또는 거절
  - *저주받은 제단*: HP -10 → 유물 획득 / 또는 무시
  - *낡은 도서관*: 카드 업그레이드 1장 / 카드 제거 1장 중 선택
  - *약초 더미*: 즉시 HP 20 회복
  - *악마의 계약*: 최대 HP -5 → 희귀 카드 2장 선택

### 🔥 캠프파이어(Rest) 시스템
- RestScene: 두 가지 행동 중 1개 선택
  - **휴식**: HP 30% 회복
  - **단련**: 손패에서 카드 1장 업그레이드
  - (유물에 따라 추가 선택지 해금)

### 🧙 캐릭터 / 클래스 시스템
- 플레이어블 캐릭터 2~3종 (각기 다른 스타터 덱 + 전용 카드 풀 + 고유 능력)
- 예시 클래스
  - *전사*: 방어도 중심, 반격 특화
  - *도적*: 독 / 연속 공격 특화, 마나 0비용 카드 다수
  - *마법사*: AoE 및 상태이상 특화, 마나 풀이 넓음
- 클래스 선택 씬 (런 시작 시)

### 📊 메타 진행도 / 재미 요소
- **어센션(Ascension)** — 런 난이도 단계 (0~20), 격파 시 해금
- **도전 과제(Achievement)** — 특정 조건 달성 시 잠금 해제 보상
- **런 기록** — 최고 층수, 처치 수, 사용 카드 통계
- **데일리 챌린지** — 고정 시드 + 특수 규칙으로 매일 새 런
- **잠금 해제 콘텐츠** — 플레이 횟수/조건으로 새 카드·유물·캐릭터 해금

### 💾 저장 / 설정
- 런 자동 저장 (중단 후 재개 가능)
- 설정 씬: BGM 볼륨, SFX 볼륨, 언어 선택
- 키보드 단축키 지원 (숫자 키 카드 선택, Enter 턴 종료)

### 🎨 연출 / 음향

- BGM — 전투/탐험/보스/메뉴 트랙 분리
- SFX — 카드 드로우, 공격, 방어도 흡수, 레벨업 효과음
- 스프라이트 에셋 교체 (현재 Rectangle → 실제 이미지)

### 🧩 대화 / 서사 확장
