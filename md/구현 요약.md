# 구현 요약

**Vite + TypeScript + Phaser 4 | 800×600 | 외부 에셋 없음**

---

## 파일 구조

```
src/
├── main.ts           씬 등록 + Phaser 설정
├── types.ts          타입 정의 전체 (Entity, Card, AttackPattern, TurnPhase …)
├── GameState.ts      상태 싱글톤 + 카드 라이브러리 + 덱 관리
├── utils/
│   └── combat.ts     applyDamage 공통 헬퍼
├── monsters/
│   ├── Monster.ts    몬스터 추상 기반 클래스
│   ├── Slime.ts      슬라임 구현체 (패턴 3종)
│   └── index.ts      일괄 export
├── data/
│   └── dialogues.ts  대화 스크립트 데이터
└── scenes/
    ├── HubScene.ts       테스트 허브
    ├── BattleScene.ts    전투
    └── DialogueScene.ts  대화 (비주얼 노벨)
```

## 구현된 시스템

### 전투 시스템
- 카드 드래그 → 적 영역 드롭 → `GameState.playCard()` 호출
- 방어도 선흡수 피해 계산 (`applyDamage`)
- 마나 부족 시 카드 원위치 복귀 (Back.Out 트위닝)

### 덱 메커니즘
- `deck` / `hand` / `discard` 세 더미 분리
- 턴 시작: 덱에서 3장 드로우, 덱 소진 시 버림 더미 셔플 후 재활용
- 카드 사용: `hand → discard`
- 턴 종료: 남은 `hand → discard`

### 턴 시스템
- 플레이어 턴: 카드 사용 → 턴 종료 버튼
- 몬스터 턴: 가중치 기반 패턴 선택 → 실행 → 다음 행동 예약
- 플레이어 턴에 몬스터 다음 행동(의도) 미리 표시

### 대화 시스템
- 말하는 캐릭터 확대(×1.06) · 상대 축소(×0.90) 트위닝 강조
- 내레이터는 아무도 강조 안 함, 이탤릭 회색 텍스트
- 30ms 타이프라이터 효과, 클릭으로 즉시 전체 표시
- `showOtherCharacter: false`면 우측 캐릭터 숨김

### 씬 전환
| 방식 | 사용처 |
|------|--------|
| `scene.start()` | 완전 전환 (상태 초기화) |
| `scene.pause()` + `scene.launch()` | 오버레이 (상태 보존) |

## 테스트 시나리오 흐름

```
HubScene
  └─[전투] → DialogueScene(battle_intro)
               └─ BattleScene (새 전투, deck=5, hand=3)
                    ├─ 턴 반복: drawCards → 카드 사용 → endPlayerTurn → 몬스터 행동
                    ├─[적 HP 50%] → DialogueScene(battle_mid, 오버레이) → 전투 재개
                    └─[적 HP 0]  → DialogueScene(battle_victory, 오버레이) → HubScene
```

## 확장 방법

| 목표 | 작업 |
|------|------|
| 새 카드 | `GameState.ts` `CARD_LIBRARY`에 객체 추가 |
| 새 몬스터 | `Monster` 상속 + `patterns[]` 정의, `GameState` 생성자에서 교체 |
| 새 대화 | `data/dialogues.ts` `DIALOGUE_SCRIPTS`에 키-값 추가 |
| 전투 중 대화 | `scene.pause()` + `scene.launch('DialogueScene', { ..., resumeScene })` |
