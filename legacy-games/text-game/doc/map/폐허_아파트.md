# 폐허 아파트 [A1]

## 개요

| 항목 | 내용 |
|------|------|
| 구역 코드 | A1 |
| 구역 분류 | 생존 구역 (회색 구역 경계) |
| 위험도 | ★★☆☆☆ (낮음 — 단, 야간은 ★★★☆☆) |
| 최초 접근 | 게임 시작 장소 |
| 층수 | 지하 1층 + 지상 4층 + 옥상 |

주인공 한재이가 머물고 있는 6층 아파트 건물. 검은 10월 이후 주민 대부분이 탈출하거나 타락했으며, 현재는 재이를 포함한 2~3명의 생존자만이 잔류 중이다. 건물 서쪽 외벽 일부가 무너져 있어 바람이 상시 불어들어오고, 3층 이상은 발소리가 나면 타락자들이 반응할 수 있다.

부정의 농도는 낮지만 제로가 아니다. 특히 지하 주차장 깊은 곳에서는 가끔 기이한 소리가 들린다. 이유는 불명확하다.

---

## 분위기

낡은 아파트 특유의 냄새가 났었는데, 이제 곰팡이와 눅눅함이 그 위를 덮었다. 엘리베이터는 멈춘 지 오래다. 계단을 오를 때마다 낡은 철근이 미세하게 진동한다. 복도 창문에서 보이는 바깥 풍경은 회색빛 하늘과 무너진 인근 건물들이 전부다.

밤이 되면 복도 어딘가에서 이유 없는 발소리가 들린다. 확인하러 가면 아무것도 없다. 가지 않는 것이 현명하다.

## 세부 공간

### [A1-01] 302호 — 주인공의 방
- **상태**: 겨우 거주 가능. 창문은 담요와 테이프로 막혀 있음.
- **구성**: 방 1개 + 작은 거실 + 화장실 + 주방
- **특이사항**: 이전 거주자가 남긴 소품들이 있음 (가족사진, 어린이 그림). 재이의 물품들이 일부 정리되어 있음.
- **획득 가능**: 진통제 (소량), 라이터, 낡은 지도, 메모지

### [A1-02] 3층 복도
- **상태**: 조명 완전 차단. 자연광이 복도 끝 창문으로만 들어옴.
- **구성**: 복도 전체 길이 약 30m. 301호~308호 8세대.
- **특이사항**: 304호 문이 안쪽에서 잠겨 있음. 노크에 반응이 없으나, 가끔 안에서 소리가 남. 결정이 필요한 선택지.
- **위험 요소**: 야간에는 2~3층 사이 계단에 타락자 1개체 순찰 패턴 존재.

### [A1-03] 301호 — 이웃의 흔적
- **상태**: 문이 열려 있음. 서둘러 떠난 흔적.
- **구성**: 방 2개, 주방, 화장실
- **특이사항**: 탁자 위에 반쯤 먹다 남은 음식이 굳어 있음. 냉장고가 열려 있고 내용물은 부패. 아이 방에 크레파스로 그린 그림이 있음 — "엄마 빨리 와."
- **획득 가능**: 통조림 (열 수 없는 상태), 가위, 손전등 (배터리 소진)

### [A1-04] 계단실
- **상태**: 1층~4층 이동 가능. 옥상 계단은 문이 잠겨 있음 (열쇠 필요).
- **구성**: 중앙 개방형 계단. 3~4층 구간 난간 일부 파손.
- **특이사항**: 계단 벽에 누군가 새긴 긁힌 자국들. 날짜처럼 보이는 패턴. 검은 10월부터 시작해서 어느 날 갑자기 끊김.
- **위험 요소**: 1층과 지하 연결 계단 근처에서 부정 농도 소폭 상승.

### [A1-05] 2층 복도 및 세대
- **상태**: 201호와 203호 문이 개방 상태.
- **특이사항**: 203호 내부에 바리케이드 흔적. 누군가 오랫동안 머물렀다가 떠난 것 같음. 벽에 생존 기록이 적혀 있음.
- **획득 가능**: 생존 기록 메모 (정보 아이템), 깡통 여러 개 (빈 것)

### [A1-06] 1층 로비
- **상태**: 출입구는 바리케이드로 부분 봉쇄. 오른쪽 출입구만 겨우 열 수 있음.
- **구성**: 우편함 구역 + 엘리베이터 홀 + 관리실 + 출입구
- **특이사항**: 관리실 유리창이 깨져 있고 내부에 관리인의 물품 일부 잔존. 우편함 중 일부에 검은 10월 이전 우편물이 아직 들어 있음.
- **획득 가능**: 마스터키 (관리실 서랍, 일부 세대 잠금 해제), 건물 도면 (지하 주차장 구조 확인 가능)

### [A1-07] 지하 주차장 (B1F)
- **상태**: 조명 전무. 손전등 필수.
- **구성**: 주차 구역 A/B + 전기실 + 창고 + 지하 출구 (봉쇄)
- **특이사항**: 주차된 차량 여러 대. 일부 차량 내부에 인간의 흔적(말라버린 핏자국, 소지품). 전기실에 배전반이 있으며, 건물 일부 전력 복구 가능.
- **위험 요소**: 부정 농도 ★★★★☆. 지하 깊은 쪽에서 낮고 단조로운 소리가 남. 접근 권장 안 함.
- **획득 가능**: 차량 내 잡화, 점프 케이블, 공구 일부

### [A1-08] 옥상
- **상태**: 계단 문 잠금 해제 후 접근 가능.
- **특이사항**: 서울 전경이 보임. 검은 구름 아래로 부정이 점령한 지역과 그렇지 않은 지역의 경계가 희미하게 보임. 이세아가 가끔 옥상에서 정찰을 한다는 소문이 있음.
- **활용**: 고지 관측, 인근 지역 상황 파악 (특정 정보 획득 가능), 이세아와의 첫 접촉 가능 장소.

## 특이사항

- 304호는 게임 전반부의 핵심 선택 장소 중 하나. 열면 돌아올 수 없는 결과가 발생할 수 있음.
- 지하 주차장의 소리는 후반부 심연과 연관된 복선.
- 옥상은 게임 초반 이세아 조우 이벤트 장소로 활용 가능.
- 203호 생존 기록은 이 건물에 누군가 더 오래 살아 있었음을 암시하는 단서.
