## 탑 외벽 반사 현상

```
일반 유리 건물:
  [하늘] ──► 유리 ──► [반사: 하늘]

부정의 탑:
  [하늘] ──► 유리 ──► [반사: 어둠]
                       (밝은 낮에도)
  ↑ 이 현상의 원인 = 지하의 심연이 탑 전체에 영향

  시간대별 반사 이미지:
  - 새벽: 검은 안개
  - 낮: 깊은 어둠
  - 저녁: 붉은 빛이 섞인 어둠
  - 밤: 탑이 스스로 빛나는 것처럼 보임 (어두운 빛)
```
