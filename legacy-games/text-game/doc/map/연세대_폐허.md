# 연세대학교 폐허 [B6]

## 개요

| 항목 | 내용 |
|------|------|
| 구역 코드 | B6 |
| 구역 분류 | 회색 구역 |
| 위험도 | ★★★☆☆ (캠퍼스) / ★★★★☆ (지하 연구실) |
| 규모 | 캠퍼스 전체 면적 약 5만㎡ |
| 주요 NPC | 정도석 (지하 연구실) |

검은 10월 이전에도 스핑크스 프로젝트와 연관된 비밀 연구가 이루어지던 장소. 정도석 박사가 현재 지하 연구실에서 은거 중이다. 부정 에너지가 기이하게도 건물 내부에서 낮은 편인데, 이는 지하 연구실의 특수 차폐 구조 때문이다.

---

## 분위기

가을이면 은행나무가 노랗게 물드는 캠퍼스였다. 이제 나무들은 검은 반점으로 덮여 있다. 잎이 제 색을 잃은 것인지, 부정이 스며든 것인지 구분이 안 된다. 강의실 창문들이 대부분 깨져 있어, 빈 강의실 안으로 바람이 들어간다. 어딘가에서 강의 자료가 날리는 소리가 간헐적으로 난다.

본관 건물 앞 조각상은 쓰러지지 않았다. 왜인지 모르겠다.

## 세부 공간

### [B6-01] 정문 및 진입로
- 교문과 경비실. 경비실은 비어 있음.
- **특이사항**: 교문 한쪽이 안쪽으로 구부러져 있음. 무언가 강한 힘으로 밀어붙인 것처럼.

### [B6-02] 중앙 광장
- 대형 조각상, 게시판 잔해, 벤치들.
- **특이사항**: 게시판에 마지막 공지가 붙어 있음 — "10/15 모든 수업 취소. 학교 측의 안내를 기다려주십시오." 그 이후 공지는 없다.

### [B6-03] 본관 (1~3층)
- 행정실, 강의실들.
- **획득 가능**: 사무용품 (종이, 펜), 복사기 (전원 없음), 행정 서류 (대부분 무의미하지만 일부는 연구 관련)

### [B6-04] 도서관
- **상태**: 상당수 책이 훼손되거나 수분에 의해 부식. 그러나 지하 서가는 비교적 잘 보존.
- **특이사항**: 지하 서가에 자연과학, 의학 관련 서적이 많음. 정보 아이템으로 활용 가능.
- **획득 가능**: 의학 교재 (한재이 능력 업그레이드), 부정 관련 학술 논문 사본 (단서)

### [B6-05] 이공계 건물 (연구동)
- **상태**: 1~4층. 실험실 장비 잔류.
- **특이사항**: 3층 실험실에 지하로 내려가는 별도 계단이 있음. 일반 도면에는 표시되지 않음.

### [B6-06] 지하 연구실 (스핑크스 프로젝트 분소)
- **상태**: 정도석이 거주 중.
- **구성**: 연구실 3개 + 소형 거주 공간 + 서버실 (전원 없음)
- **특이사항**: 벽 가득 문서와 다이어그램이 붙어 있음. 대부분은 마법소녀 변환 과정, 타락 속도 계산, 감응자 데이터. 이것이 진실의 집합소.
- **차폐**: 이 공간만 부정 농도가 극히 낮음. 이유는 벽 속에 매립된 특수 소재 때문. 정도석이 설계에 참여했다.
- **위험 요소**: 정도석이 원하지 않으면 들어올 수 없다. 문이 안에서 잠겨 있음.
- **NPC**: 정도석. 신뢰를 쌓거나 특정 조건 충족 시 이야기가 열림.
- **획득 가능**: 스핑크스 프로젝트 문서 (핵심 스토리 아이템), 감응자 데이터 (한재이 관련)
