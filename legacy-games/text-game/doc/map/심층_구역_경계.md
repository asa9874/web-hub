# 심층 구역 경계 [C2]

## 개요

| 항목 | 내용 |
|------|------|
| 구역 코드 | C2 |
| 구역 분류 | 경계 구역 / 심층 구역 경계 |
| 위험도 | ★★★★★ (최고 위험 생존 접근 가능 지점) |
| 규모 | 동서 약 500m 경계선 구간 |
| 주요 NPC | 은별 (경계선 근처 거점) |

회색 구역과 심층 구역의 물리적 경계. 이 선을 넘으면 타락이 빠르게 진행된다. 마법소녀 없이는 넘을 수 없다고 알려져 있다.

은별이 이 경계에서 싸운다. 부정의 확장을 막는 것이 그녀의 일이다. 경계선은 매달 조금씩 남쪽으로 밀린다. 은별이 버티고 있기 때문에 그 속도가 느린 것이다.

---

## 분위기

경계선 이쪽에서 바라보면 안개가 있다. 인위적인 안개다. 움직임이 있고, 소리가 흡수된다. 경계선 너머는 시야가 약 10미터 이상 확보되지 않는다.

은별의 빛이 가끔 그 안개를 뚫고 나온다. 밝은 섬광. 그리고 다시 어둠. 저쪽에서 그녀가 싸우고 있다는 것을 알 수 있는 유일한 표시다.

---

## 세부 공간

### [C2-01] 경계선 관측 지점
- 은별이 설치한 간이 표식들이 경계선을 표시. 붉은 천 조각들.
- **특이사항**: 표식들이 어제보다 5미터 더 남쪽에 있음. 경계가 밀렸다.

### [C2-02] 은별의 거점
- 경계선 바로 남쪽의 폐건물 1층.
- **구성**: 간이 침구, 성냥과 소촉, 식량 (매우 소량), 부서진 라디오.
- **NPC**: 은별이 여기서 쉬고 있을 때 만날 수 있음.
- **특이사항**: 벽에 손으로 쓴 숫자가 있음 — 날짜와 숫자가 교대로. 경계가 밀린 거리를 기록한 것 같음.

### [C2-03] 부정 분출구 (봉쇄된 구역)
- 경계선 근처, 은별이 표시해둔 "절대 접근 금지" 구역.
- **특이사항**: 이 지점에서 부정이 주기적으로 분출됨. 분출 주기가 짧아지고 있음.
- **위험 요소**: 접근 시 즉각 타락 가속. 은별만이 이 근처에서 버틸 수 있음.
