# 씬 구조 및 흐름

## 등록된 씬 목록

| 씬 키 | 클래스 | 역할 |
|-------|--------|------|
| `HubScene` | `HubScene` | 개발자 테스트 메뉴 |
| `BattleScene` | `BattleScene` | 카드 전투 |
| `DialogueScene` | `DialogueScene` | 비주얼 노벨 대화 |

`main.ts`의 `scene` 배열 첫 번째 항목(`HubScene`)이 게임 시작 씬이다.

---

## 씬 전환 방식 두 가지

### A. 완전 전환 — `scene.start(key)`

현재 씬을 종료하고 대상 씬의 `create()`를 새로 호출한다.
이전 씬의 모든 상태가 초기화된다.

```
HubScene ──(start)──► DialogueScene ──(start)──► BattleScene
```

### B. 오버레이 — `scene.pause()` + `scene.launch(key)`

현재 씬을 **일시정지** 상태로 두고 대상 씬을 위에 올린다.
일시정지된 씬의 게임 오브젝트·상태가 그대로 보존된다.
오버레이 씬이 `scene.stop()` + `scene.resume(key)`를 호출하면 원래 씬이 재개된다.

```
BattleScene ──(pause + launch)──► DialogueScene(오버레이)
                                       │
                                  (stop + resume)
                                       │
BattleScene ◄──────────────────────────┘  (상태 보존, 재개)
```

## 테스트 시나리오 전체 흐름

```
┌─────────────┐
│  HubScene   │  [전투 시스템 클릭]
└──────┬──────┘
       │ scene.start('DialogueScene', { scriptId: 'battle_intro',
       │                                returnScene: 'BattleScene' })
       ▼
┌──────────────────────────────────────┐
│  DialogueScene — battle_intro        │
│  주인공 독백 (다른 캐릭터 없음)       │
│  "드디어 이 층의 지킴이와 만나는군." │
└──────┬───────────────────────────────┘
       │ endDialogue() → scene.stop('BattleScene') + scene.start('BattleScene')
       ▼
┌──────────────────────────────────────┐
│  BattleScene                         │
│  GameState.reset() → 새 전투 시작    │
│  카드 드래그로 전투 진행...           │
│                                      │
│  [적 HP ≤ 25 (절반)]                 │
└──────┬───────────────────────────────┘
       │ scene.pause() + scene.launch('DialogueScene',
       │   { scriptId: 'battle_mid', resumeScene: 'BattleScene' })
       ▼
┌──────────────────────────────────────┐
│  DialogueScene — battle_mid (오버레이)│
│  "아직이다... 끝을 내자."            │
└──────┬───────────────────────────────┘
       │ endDialogue() → scene.stop() + scene.resume('BattleScene')
       ▼
┌──────────────────────────────────────┐
│  BattleScene (재개, 상태 보존)        │
│  전투 계속...                         │
│                                      │
│  [적 HP = 0]                         │
└──────┬───────────────────────────────┘
       │ scene.pause() + scene.launch('DialogueScene',
       │   { scriptId: 'battle_victory', returnScene: 'HubScene' })
       ▼
┌──────────────────────────────────────┐
│  DialogueScene — battle_victory      │
│  (오버레이) "더 깊이, 더 멀리."      │
└──────┬───────────────────────────────┘
       │ endDialogue() → scene.stop('BattleScene') + scene.start('HubScene')
       ▼
┌─────────────┐
│  HubScene   │
└─────────────┘
```

## DialogueScene 진입 데이터 규칙

```typescript
interface DialogueSceneData {
  scriptId: string;     // 재생할 스크립트 키
  returnScene: string;  // resumeScene 없을 때 이동할 씬
  resumeScene?: string; // 설정 시 → stop() + resume(resumeScene)
                        // 미설정 시 → stop('BattleScene') + start(returnScene)
}
```

| 용도 | resumeScene | 종료 동작 |
|------|------------|-----------|
| 일반 대화 (허브↔대화) | 없음 | `scene.start(returnScene)` |
| 전투 중 대화 (오버레이) | `'BattleScene'` | `scene.stop()` + `scene.resume('BattleScene')` |
| 승리 후 대화 (오버레이) | 없음 | `scene.stop('BattleScene')` + `scene.start('HubScene')` |
