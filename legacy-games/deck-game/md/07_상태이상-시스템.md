# 상태이상 시스템

## 개요

전투 중 플레이어와 몬스터 모두에게 적용되는 4종의 상태이상. 모든 상태이상은 `Entity.statuses: StatusEffects`에 저장되며 정수 스택으로 관리된다.

---

## 타입 정의 (`src/types.ts`)

```typescript
export type StatusId = 'poison' | 'strength' | 'vulnerable' | 'weak';
export type StatusEffects = Record<StatusId, number>;

export interface Entity {
  // ...
  statuses: StatusEffects;
}
```

---

## 상태이상 종류

| 상태이상 | StatusId | 효과 | 지속 방식 |
|---------|---------|------|---------|
| 독 | `poison` | 턴 시작 시 스택만큼 HP 직접 감소 (방어도 무시) → 스택 1 감소 | 매 턴 스택 -1 |
| 힘 | `strength` | 공격 시 데미지에 스택값 추가 | 영구 유지 |
| 취약 | `vulnerable` | 받는 피해 ×1.5 | 매 턴 스택 -1 |
| 약화 | `weak` | 주는 피해 ×0.75 | 매 턴 스택 -1 |

---

## 유틸리티 함수 (`src/utils/combat.ts`)

```typescript
// 상태이상 초기값 (Entity 생성 시 반드시 호출)
emptyStatuses(): StatusEffects

// 공격 (attacker 선택적 — 힘/약화 반영, target 취약 반영)
applyDamage(target, amount, attacker?)

// 독 처리 — 방어도 무시, 스택 -1, 반환값: 실제 피해량
applyPoison(target): number

// 스택 추가 (음수 불가)
addStatus(target, id, amount)

// 지속 상태이상 1회 감소
tickDuration(target, id)
```

## 턴별 처리 순서

### 플레이어 턴 시작 (`GameState.startPlayerTurn()`)
1. 방어도 초기화
2. 독 처리 (`applyPoison`) → 반환값 = 피해량 (BattleScene에서 플래시 표시)
3. 마나 회복
4. 카드 드로우

### 플레이어 턴 종료 (`GameState.endPlayerTurn()`)
- 손패 버림
- `vulnerable`, `weak` 스택 각 -1

### 몬스터 턴 (`GameState.executeMonsterTurn(idx)`)
1. 방어도 초기화
2. 독 처리 (`applyPoison`) → 사망 시 `null` 반환 (행동 건너뜀)
3. 행동 실행 (`monster.executeTurn`)
4. `vulnerable`, `weak` 스택 각 -1
5. 반환: 실행된 `AttackPattern | null`

## 상태이상 카드 (플레이어)

| 카드 | 비용 | 효과 |
|------|------|------|
| 독침 | 1 | 5 피해 + 독 3 |
| 독기 방출 | 1 | 독 5 부여 |
| 취약화 | 1 | 8 피해 + 취약 2 |
| 역량 강화 | 1 | 힘 2 획득 (자신) |
| 독 폭풍 | 2 | 모든 적에게 독 3 |

> **역량 강화**는 `targetType: 'single'`이지만 `onPlay`가 `targets`를 무시하고 `u`(플레이어)에게 적용한다. 기존 드래그-드롭 시스템을 그대로 재사용.

## BattleScene 표시

- 플레이어: `cy + 92` 위치에 상태이상 텍스트 (보라색 `#a29bfe`)
- 몬스터: `cy + 76` 위치에 상태이상 텍스트 (동일 색)
- 형식: `독N 힘N 취약N 약화N` — 0인 항목은 생략

### 독 이벤트 플래시 메시지
- 플레이어 독 피해: `독 피해 -N` (청록 `0x55efc4`)
- 몬스터 독 사망: `{이름}: 독으로 쓰러짐` (청록)
- 독으로 모든 적 사망 시 VictoryScene으로 전환
