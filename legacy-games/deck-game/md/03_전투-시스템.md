# 전투 시스템

## 개요

`BattleScene` (렌더링·입력) + `GameState` (로직) 의 2-레이어 구조.
씬은 상태를 읽고 표시하는 것만 하고, 실제 수치 계산·덱 관리·턴 처리는 전부 `GameState`에서 처리한다.

---

## 덱 메커니즘

### 카드 세 더미

| 더미 | 설명 |
|------|------|
| `deck` | 뽑기 더미. 전투 시작 시 라이브러리 전체를 셔플해 생성. |
| `hand` | 손패. 턴 시작 시 `deck`에서 3장 드로우. |
| `discard` | 버림 더미. 사용한 카드와 턴 종료 시 남은 손패가 쌓임. |

### 흐름

```
[전투 시작]
  deck = shuffle(CARD_LIBRARY)
  drawCards(3) → deck에서 3장 → hand

[카드 사용]
  hand → (onPlay 실행) → discard

[플레이어 턴 종료]
  endPlayerTurn(): 남은 hand 전부 → discard

[플레이어 턴 시작]
  startPlayerTurn(): block=0, 마나 회복, drawCards(3)

[덱 소진 시 자동 보충]
  drawCards(): deck 비면 → shuffle(discard) → deck, discard=[]
```

## 턴 흐름 (다중 적)

```
플레이어 턴
  └─ 카드 드래그 & 드롭으로 적에게 사용
  └─ "턴 종료" 버튼 클릭
       ↓ 남은 손패 비주얼 제거 + endPlayerTurn()
       ↓ (0.9초 딜레이)
몬스터 턴 (1번 → 2번 → … → N번 순차 실행)
  └─ 각 몬스터: 예약된 패턴 실행 + 행동명 플래시 표시 (700ms 간격)
       ↓ (마지막 몬스터 완료 후 1.4초 딜레이)
플레이어 턴
  └─ startPlayerTurn(): block=0, 마나 회복, drawCards(3)
  └─ renderHand(): 새 손패 렌더링
  └─ updateAllIntents(): 모든 몬스터 의도 표시 갱신
```

- 몬스터 턴 중: 카드 드래그 및 턴 종료 버튼 비활성화
- 플레이어 HP ≤ 0: "게임 오버" → HubScene 이동
- **모든** 적 HP ≤ 0: 승리 처리

## GameState API

```typescript
class GameState {
  player:   Player    // HP 80/80, 마나 3/3, 방어도 0
  enemies:  Monster[] // 최대 5마리
  hand:     Card[]
  deck:     Card[]
  discard:  Card[]

  static readonly DRAW_PER_TURN = 3
  static readonly MAX_ENEMIES   = 5

  static get instance(): GameState
  static reset(mode: BattleMode): void  // 'default' | 'five_monsters'

  drawCards(n): void
  playCard(cardId, primaryTarget: Monster): boolean
  executeMonsterTurn(idx: number): AttackPattern | null

  endPlayerTurn(): void
  startPlayerTurn(): void
}
```

### 카드 타겟 처리

```typescript
// targetType='single' → [primaryTarget]
// targetType='all'    → 살아있는 모든 적
const targets: Entity[] = card.targetType === 'all'
  ? this.enemies.filter(e => e.hp > 0)
  : [primaryTarget];
card.onPlay(this.player, targets);
```

### 피해 계산 (`src/utils/combat.ts`)

```typescript
function applyDamage(target: Entity, amount: number): void {
  const absorbed = Math.min(target.block, amount);
  target.block -= absorbed;
  target.hp = Math.max(0, target.hp - (amount - absorbed));
}
```

## 카드 라이브러리

| id | 이름 | 비용 | 타겟 | 효과 |
|----|------|------|------|------|
| `strike_a` | 타격 | 1 | single | 적에게 6 피해 |
| `strike_b` | 타격 | 1 | single | 적에게 6 피해 |
| `defend_a` | 방어 | 1 | single | 방어도 +5 |
| `heavy_blow` | 강타 | 2 | single | 적에게 14 피해 |
| `twin_strike` | 쌍격 | 1 | single | 5 피해 × 2회 |
| `explosion` | 폭발 | 2 | **all** | 모든 적에게 4 피해 |
| `chain_attack` | 연쇄 공격 | 1 | single | 3 피해 × 3회 |
| `storm_blast` | 폭풍격 | 3 | **all** | 모든 적에게 8 피해 |

AoE 카드(`targetType:'all'`)는 드래그 목표와 무관하게 살아있는 모든 적에게 적용된다.

## BattleScene — 화면 레이아웃 (1280 × 720)

```
┌──────────────────────────────────────────────────────────────────────┐
│  [적1] [적2] [적3] [적4] [적5]          (y≈185, 5마리 동적 배치)   │
│  의도  의도  의도  의도  의도                                          │
│                                              [턴종료 1155,515]       │
│  [영웅 90,400]                                                       │
│  HP 80/80                                                            │
├──────────────────────────────────────────────────────────────────────┤ y=492
│ [덱 65,615]  마나 ●●●  3/3  [카드][카드][카드]  [버림 1215,615]     │
└──────────────────────────────────────────────────────────────────────┘
```

### 레이아웃 상수

| 상수 | 값 | 설명 |
|------|----|------|
| `W` | 1280 | 화면 너비 |
| `ENEMY_CY` | 185 | 적 스프라이트 중심 y |
| `PLAYER_CX` | 90 | 플레이어 x |
| `PLAYER_CY` | 400 | 플레이어 y |
| `DIVIDER_Y` | 492 | 전투 영역 / 패 영역 구분선 y |
| `PILE_Y` | 615 | 덱·버림 아이콘 y |
| `PILE_MANA_Y` | 515 | 마나·턴종료 버튼 y |

### 적 동적 배치

```typescript
getEnemyPositions(n: number): number[]
// n=1 → [640]
// n>1 → 200~1080 균등 분배
```

### AoE 카드 시각 표시

- 카드 테두리: 주황색 (`0xe67e22`)
- 카드 우상단에 `전체` 태그 표시

### 드래그 & 드롭 흐름

```
dragstart  → 컨테이너 depth=10
drag       → container.setPosition(dragX, dragY)
dragend    → turnPhase !== 'player' → returnCard() (몬스터 턴 차단)
           → 어떤 enemyDropZone에 올라가 있는가?
               target 없음 또는 죽은 적 → returnCard()
               playCard 성공  → destroy() + updateUI() + handlePostCardPlay()
               마나 부족      → returnCard() + flashMessage('마나가 부족합니다!')
```

### 전투 승리 조건

```
enemies.every(e => e.hp <= 0) → 승리
```

## BattleMode

| 모드 | 몬스터 구성 | 진입 방법 |
|------|-------------|-----------|
| `'default'` | 슬라임 1마리 | DialogueScene → BattleScene |
| `'five_monsters'` | 슬라임·고블린·오크·스켈레톤·박쥐 | HubScene "5인 전투 테스트" 카드 |

```typescript
GameState.reset('five_monsters');
// 또는 씬 시작 데이터로 전달:
scene.start('BattleScene', { mode: 'five_monsters' });
```
