# AI그림 프롬프트 — 제작 원칙

## 목적

다양한 프롬프트와 실제 결과물을 함께 보관하고, 나중에 비슷한 그림체를 만들 때 참고하고 재사용한다. 실제 제출한 전체 프롬프트, 원본 PNG, 정확한 스타일 지시문, 한국어 재사용 메모를 한 작품 단위로 유지한다.

## 반드시 유지할 창작 방향

**각 스타일에 가장 잘 맞는 장면을 먼저 설계한다. 서로 다른 그림체에 같은 장면을 반복해서 적용하지 않는다.** 이는 사용자가 명시적으로 강조한 원칙이다. 장면과 구도도 해당 매체의 장점을 살려야 하며, 화면 비율을 일률적으로 맞출 필요가 없다.

- 픽셀: 읽기 쉬운 게임 공간, 타일 구조, 명확한 실루엣, 제한된 팔레트와 큰 픽셀 덩어리.
- 일본 전통 만화: 강한 동작과 감정, 대각선 구도, G펜 선의 강약, 검정 면과 흰 여백, 필요한 부분의 스크린톤.
- 일본 라이트노벨: 인물의 표정과 관계가 읽히는 삽화, 선의 강약, 절제된 채색, 인물 중심의 여백.
- 애니메이션 캡처: 이야기 중간의 자연스러운 연기, 간결한 캐릭터 선과 셀 채색, 캐릭터와 다른 방식으로 그린 배경. 포스터처럼 연출하지 않는다.

일률적인 광택, 플라스틱 같은 피부, 과도한 눈 반짝임, 모든 곳에 동일하게 촘촘한 디테일, 불필요한 빛 입자와 블룸, 과장된 포스터 조명을 피한다. 필요한 곳의 디테일과 생략할 곳을 구분한다. AI 생성 사실은 기존 표시처럼 유지한다.

## 캐릭터 일러스트의 깨끗한 화면

사용자는 미소녀·서브컬처 캐릭터 중심의 다양한 스타일과 고품질 결과를 원하며, 생성 이미지 특유의 지글거리는 미세 질감을 최대한 억제할 것을 강조했다. 캐릭터는 성인으로 설정한다.

- 필름 그레인, 스캔 먼지, 종이 알갱이, 무작위 점, 색수차, 과한 샤프닝과 미세한 번쩍임을 생성 지시문에서 제외한다.
- 머리카락은 큰 묶음으로, 피부와 의상은 명확한 색면으로 그린다. 손과 소품의 접촉, 팔다리의 겹침을 읽기 쉽게 설계한다.
- BD/OVA 느낌은 실제 노이즈 대신 선의 굵기, 색 조합, 셀 명암과 구도로 만든다. 수채 느낌도 종이 질감 대신 큰 색면과 가장자리의 강약으로 만든다.
- 마법 효과는 연결된 기하 형태와 큰 명암 대비로, 시네마틱 장면은 표정과 상징 및 여백으로 표현한다. 게임 스플래시 등에는 해당 스타일에 필요한 동세를 적극 쓰되 효과와 소품의 수를 제한한다.
- 의도한 픽셀 격자나 규칙적인 만화 스크린톤은 무작위 노이즈와 구분한다. 미리보기 압축은 눈에 띄는 테두리 아티팩트를 만들지 않도록 하고 생성 PNG 원본도 보존한다.

## 저장과 수정

`artworks.json`은 현재 전시 목록이다. 프롬프트를 다듬어 새 결과를 만들면 **이미지와 프롬프트를 함께 갱신**하고, 과거 이미지 파일을 덮어쓰지 않는다. 이전 항목은 `public/ai-prompts/archive/`에 메타데이터를 보관한다. 과거 비 오는 역 시리즈는 이전 방향의 기록이며 새 작품의 공통 장면으로 재사용하지 않는다.

`stylePrompt`는 실제 `prompt`에 포함된 원문이어야 한다. `reuseNote`에는 그림체의 조건뿐 아니라 어떤 장면에 강점이 있는지도 설명한다. 새 파일은 `public/ai-prompts/`에 놓고 원본과 미리보기의 경로, 실제 크기, 생성 프롬프트를 `ASSETS.md`에 기록한다.

`qualityPrompt`가 있으면 실제 제출한 미세 노이즈 억제 조건을 원문으로 저장한다. ‘그림체만 복사’는 스타일 지시문과 이 품질 조건을 함께 복사하며, 장면과 구도 지시문은 포함하지 않는다. 새 작품 묶음을 먼저 전시하고 기존 작품과 원본은 유지한다.
