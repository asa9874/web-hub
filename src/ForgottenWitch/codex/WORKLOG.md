### 구현

- 기존 React/Vite 허브에 `/games/forgotten-witch/` 독립 페이지 및 프로젝트 카드/OG 등록.

- 1280×720 / 연속된 4구역 무대. 가속/감속/점프, 발판/장애물/바닥 틈, coyote 및 jump buffer, 카메라/패럴랙스.
- 종이 다리 드래그/스냅과 실제 충돌 활성화, 낙하 시 안전 복귀.
- 플로라 대화: 초상화, 감정 상태, 타이핑/즉시 완료/다음/종료, 최초/재방문/조명 이후 분기.
- 조명 팝업: 판넬 드래그/교환, 오답 흔들림, 달 → 별 → 꽃 정답, 실제 조명과 커튼 트윈, 완료/재시작.
- 로딩 실패 안내/재시도, 상태별 입력 잠금, 일시정지, 리사이즈, 인스턴스/입력/오디오 정리.
- 실제 image_gen 인형 2종/초상화 2종/종이 나무. 종이 소품은 독립 Canvas bitmap으로 생성.

### 검증 및 수정 이유

- 짧은 탭이 render frame 전에 keyup으로 사라지는 Phaser Key 문제를 action edge 큐로 처리.
- 대화 버튼의 native Enter와 엔진 입력이 동시에 실행되지 않도록 한 경로에서 한 번 진행.
- 모드 복귀 시 물리적으로 누른 방향키를 잃지 않도록 action 큐만 비움.
- 닫힌 커튼 진입 차단. 화면 앞 소품이 마지막 문을 가리지 않도록 위치 조정.
- 오디오 정리는 SHUTDOWN뿐 아니라 DESTROY에도 연결.
- 전체 빌드/OG/이력/기존 프로젝트 브라우저 회귀 검증 및 개발·production preview 실제 입력 전체 플레이 통과.

## 2026-10-13 — 화면 끝 연결 막대 / 동작 이미지 / PC 인수인계

### 사용자 요청

기존 짧은 막대가 점프 때 화면 아래와 끊어졌다. 나무 등에도 조종 막대가 없었다. 모든 무대 소품은 화면 끝과 연결해야 하고, 주인공 걷기/점프는 별도 실제 이미지로 표현해야 한다. 다른 PC에서 Git으로 받아 바로 이어서 개발할 수 있도록 README와 게임 내부 Codex 문서를 남긴다.

### 변경

- `rig.ts`: 고정 길이 사각형 대신 소품의 실제 변환된 연결점 → 화면 위/아래 바깥으로 막대 생성.
- 회전/스케일/원점/좌우 반전/패럴랙스를 반영하고 resize 시 논리 화면 경계를 다시 사용.
- 주인공/플로라/세 레이어 나무/발판/다리/꽃/장치/문/달/별/커튼/바닥 판넬 지지대 등록.
- 바닥이 뒤쪽 막대를 전부 가리는 문제는 바닥 전면 아래 구간을 별도 렌더링해 해결. 소품 뒤 연결점과 충돌 영역은 별도 유지.
- `witch-walk.png`, `witch-jump.png`: 원래 인형을 image_gen의 편집 대상으로 사용해 정체성/재질/의상을 유지한 실제 포즈 생성. 이미지에 짧은 막대를 굽지 않음.
- `poses.ts`: 포즈 전환 조건, 표시 높이, 몸체 중심/연결점. 좌우 반전 시 원점도 반전해 몸과 막대가 함께 유지됨.
- `DomPaperRods.tsx`: 시작 화면 인형과 조명 팝업 판넬/드래그 중 판넬에도 DOM 좌표 기준 막대 제공.
- `test-witch.mjs`: 걷기/점프 실제 텍스처, 반전, 화면 끝 막대, 모든 소품 종류 등록, 점프/카메라/다리/리사이즈 중 연결 검증 추가.
- root README와 게임 README 갱신, `AGENTS.md`, 이 폴더의 이어받기 문서 및 사용자 레퍼런스 복사본 추가.
- 작업 코드/원본 PNG/생성 프롬프트/레퍼런스는 Git에 포함. 특정 PC의 이미지 생성 폴더나 대화 기록이 필요하지 않음.

## 2026-10-13 — 타이틀 / 대화 일러스트 / 기존 플레이 반응

### 사용자 요청과 범위

기능 브랜치 push 승인. 게임 타이틀 화면을 호평받은 인디 UI를 인터넷에서 조사한 뒤 고품질로 구성. 대화 인물을 창 밖의 좌우 뒷편에 배치하고 무릎 위까지 그린 그림으로 교체. 모든 인물 그림체는 원래 주인공의 그림체가 기준. 새 게임 시스템은 추가하지 않고 기존 플레이의 움직임/반응을 보강.

### 실제 변경

- Hades/Hollow Knight/GRIS 실제 메뉴 스크린샷을 확인. 채택한 구성과 출처는 `UI-REFERENCES.md`에 기록. 외부 게임 에셋은 제품에 포함하지 않음.
- `TitleScreen.tsx`: 큰 고운바탕 타이틀, 간결한 실제 메뉴, 오른쪽 주인공, 달 궤도, 독립 종이 극장 프레임, 부드러운 빛/호흡. 키보드 메뉴 탐색/활성화와 기존 소리/허브 이동 연결.
- 새 `witch-knee.png`, `flora-knee.png`, `title-arch.png` 생성. Flora의 첫 후보는 이전 회화풍이 남아 재생성했고, 원래 주인공 그림만 스타일 레퍼런스로 사용한 두 번째 후보를 선택.
- 대화 인물 z-index 2 / 종이 대화창 z-index 4. 인물은 창에 갇히지 않는 무릎 위 독립 레이어이고, 비화자는 투명하게 만들지 않고 밝기만 낮춤.
- 로컬 Gowun Batang TTF 서브셋과 OFL 라이선스 포함. 타이틀에 외부 폰트 요청 없음.
- `StageLife.ts`: 작은 먼지, 별 흔들림, 발걸음/착지 재질 반응, 시계꽃 바늘. 플로라 인형의 작은 시선 방향 기울기, 다리 연결 판넬 떨림, 조용한 발걸음 효과음.
- 충돌/퍼즐/진행/카메라 입력 기능은 유지. 추가 표현은 reduced-motion 설정에서 줄임.
- 메뉴 소리 버튼 및 무릎 그림/창 뒤 레이어 배치까지 브라우저 자동 검증에 포함.
- 타이틀 장식이 화면 밖으로 넘는 상황에서 메뉴 재조작 시 hidden 스크롤 컨테이너가 이동하는 문제를 확인. 타이틀을 `overflow:clip`으로 자르고 키보드 포커스에 preventScroll을 적용해 프레임이 움직이지 않도록 처리. 회귀 검증에 scrollTop=0 조건 추가.

### 검증

개발 서버에서 새 타이틀/작은 화면을 시각 확인했고, 대화 장면과 실제 입력 전체 플레이를 확인했다. 최종 production 검증 결과는 아래 완료 기록에 남긴다.
