## 스크롤 교정

- 패널 모서리를 내부로 옮겨 1px 장식이 가로 스크롤을 만들지 않게 했다.
- PC 거래내역의 이중 스크롤을 제거하고 패널 하나가 스크롤을 담당한다. 모바일은 문서 세로 스크롤을 유지하며 긴 거래내역만 높이를 제한한다.
- 뉴스 목록은 남은 패널 높이를 사용하고 차트는 flex 잔여 높이를 사용한다.
- 설정/도움말/정산창은 화면 높이 안에서 스크롤하며 배경 문서 스크롤을 잠근다. 팝업 안의 Tab 포커스를 유지하고 Esc로 상단 팝업을 닫는다. 해제/페이지 이탈 시 이전 overflow와 포커스를 복구한다.
- 브리핑 등에서도 메인으로 돌아갈 수 있게 팝업 내부 버튼을 추가했다. 연습 버튼의 표기를 실제 길이인 75초로 수정했다.

## 검증 기록

- 이번 변경: npm run build 통과. TypeScript, 37개 프로젝트 엔트리, 38개 OG 페이지 및 177개 로컬 참조 검증 포함.
- 이번 변경: NeonTrader ESLint, diff 검사 통과.
- 이번 변경: test-neon-scroll.mjs 통과. 1366×768, 1920×1080, 900×650, 390×740 및 텍스트 130%; 수평 넘침, 팝업 휠/Tab/Esc, 일시정지 복귀, 브리핑 메인 이동, 연습 상환/저장 독립성, 허브 복귀 시 스크롤 정리 확인.
- 앞선 구현에서 통과: 엔진 단위 검사(20시드 시장, 거래/복구/청산/콤보, 12개 기준 캠페인), 9상태 오디오 파형 검사, GOOD/BAD/BANKRUPT 엔딩 UI, 전체 37개 경로 및 보존 Git 이력 확인. 사람의 실시간 30일 수동 완주를 뜻하지 않는다.
- 기존 브라우저 테스트의 다음 날 브리핑→메인 버튼 접근 실패는 팝업 내부 버튼 추가 후 관련 흐름으로 재검증했다.
- 기존 게임 전체 E2E/기존에 통과한 엔진 검사를 로컬에서 다시 실행하지 않았다. 변경 범위에 맞춘 검증 정책을 적용했으며 기존 CI 검증은 유지한다.
- 기존 CSS의 .animate-* 구문 경고 및 큰 번들 경고는 남아 있다.

## 다른 PC에서 이어받기

git pull 후 npm ci, npm run dev. /web-hub/games/neon-trader/에 접속한다. 저장은 브라우저 localStorage에 있으므로 PC 간 자동 이동하지 않는다. 코드/이미지/명세/프롬프트는 저장소 안에 포함된다.
