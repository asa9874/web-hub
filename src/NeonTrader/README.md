# NEON TRADER — 오늘도 청산당했습니다!

허당 트레이더 니아와 빚 1억원을 갚는 30일 캠페인. 모든 돈과 종목은 가상이며 금융 API/백엔드/결제는 없다. 원본 요구사항은 [SPEC.md](SPEC.md).

## 실행과 조작

`npm ci` → `npm run dev` → `/web-hub/games/neon-trader/`.

새 캠페인 → 브리핑 → 장 시작 → 거래 → 자동 마감 → 상환 → 다음 날 → 엔딩. 시작 현금100만원/빚1억원/30일을 유지했다. 기본 하루4분, 새 캠페인 설정3~5분, 배속0.75~4배. 숫자 시드는 표시된 숫자를 그대로 입력하면 재현되고, 문자열은 FNV 해시로 변환한다.

- A 롱, D 숏, Space 청산, Q/E 증거금 비율, 1~4 레버리지, T 종목, 차트/빈 영역의 Tab도 종목. 버튼의 Tab은 정상 포커스 이동을 유지한다. 텍스트 입력/설정 중에는 거래 키를 무시한다.
- 동시에 전체 종목에서1포지션. 진입 전 증거금/명목금액/진입 수수료/대략적 청산가격을 확인한다. 실제 체결은 엔진 가격과 유동성·명목금액 기반 슬리피지를 쓴다.
- 마감10초 전 안내, 열린 포지션은 시장가 정리한다. 상환은 현금과 빚을 함께 줄이며 되돌릴 수 없다. 다음 거래를 위해 현금을 남길 수 있다.
- 75초 거래 연습은 별도 샌드박스다. 롱/숏/청산부터 실제 마감·상환까지 익히고 메인으로 돌아온다. 본 캠페인 저장과 결과 기록을 덮어쓰지 않는다.
- 탭을 벗어나면 자동 정지하며 복귀 후 직접 재개한다. 명시적 일시정지는 시장·타이머·음악을 함께 멈춘다. 수익 팝의 시각적 히트스톱은 시장을 멈추지 않는다.

## 저장과 에셋

버전1 진행은 `neon-trader-campaign-v1`, 설정은 `neon-trader-settings-v1`, 최근20개 결과는 `neon-trader-records-v1`. 진행은2초마다 및 거래/상환/화면 이탈에 저장한다. RNG/시장/뉴스/캔들/포지션까지 복구하며 손상된 진행은 새 시작 화면으로 되돌린다. localStorage 차단 시 세션 플레이는 계속된다. 저장은 같은 브라우저·같은 origin에 한정된다.

`public/neon-trader/character-sheet.png`는 built-in image_gen으로 생성한8표정 원본이다. 프롬프트는 같은 폴더 `PROMPT.md`, 참조는 `docs/reference.png`. 원본을 수정하지 않고 런타임 Canvas에서120×90으로 nearest-neighbor 샘플링한 뒤 정확한16색으로 매핑한다. 원본에 미세한 추가 색이 있어도 인게임 출력에는16색만 남는다. 배경과 캐릭터가 합쳐진 캠 전용 아트이며 거래소 UI를 이미지로 대체하지 않는다. 새 유료 에셋/폰트/패키지/API 키는 없다.

## 검증

아래는 검증 명령 목록이며 매 변경마다 전부 실행하는 절차가 아니다. 로컬에서는 루트 AGENTS.md에 따라 영향받는 검사만 실행한다. 스크롤 수정 확인은 `npm run test:neon-scroll`로 한정할 수 있다.

```powershell
npm run test:neon
npm run build
npm run preview -- --host 127.0.0.1 --port 4178
$env:NEON_TEST_URL='http://127.0.0.1:4178/web-hub'
npm run test:neon-browser
npm run test:neon-audio
npm run test:neon-endings
```

`test:neon`은20시드 가격/캔들/거래량/국면, 동일 시드와 주문 독립성,10시드 BTC/ETH 상관, 수수료·청산·복구·상환·30일·3엔딩·콤보·감정과12시드 캠페인 기준 전략을 검사한다. 기준 전략은 **UI에 표시되는 국면**을1초마다 읽어5배/현금50%로 거래하며, 사람의 승률 또는 미래 가격을 아는 최적 전략을 뜻하지 않는다. 최신 기준은12/12 완납,17~29일. 실제 사람의 난도·피로도는 추가 플레이 피드백이 필요하다.

브라우저 검사는 실제 키/버튼으로 하루 마감·상환·다음 날, 연습의 저장 독립성,1366×768/1920×1080/소형 화면, 재로딩/정지/오디오 정리를 확인한다. 오디오 검사는 실제 파형 에너지와9상태/박자별 레이어/무음/청산 정적을 확인한다. 엔딩 UI는 엔진에서 합법적으로 플레이해 얻은 GOOD/BAD/BANKRUPT 저장본을 복구해 검증한다. **브라우저에서30일을 실시간 수동 완주했다고 보고하지 않는다.**

## 통합 조정과 남은 범위

- 기존 허브 관례에 맞춰 lazy React 라우트와 projects.json에 추가했다. 기존 빌드가 개별 URL의 초기OG HTML/1200×630이미지를 생성하므로 별도 프레임워크/서버를 넣지 않는다.
- 480×270은 픽셀 디자인 기준이며 PC 계기판의 한글/숫자/차트는 명세가 허용하는 고해상도 계층으로 렌더링한다. 캠120×90·16색·nearest-neighbor는 고정한다. 좁은 화면은 차트 우선 세로 스크롤로 전환한다.
- 기본4분/1억/30일은 유지했다. 유동성은 호가창 전체가 아니라 거래량·뉴스에 연동한 단순 체결 모델이다. 체결이 시장 가격 자체를 바꾸지 않는다.
- M4의 추가 종목/일일 챌린지/온라인 랭킹/방 성장/고급 지표는 미구현이다. 외부 음원은 쓰지 않고 실제 합성 칩튠을 제공한다.
- 다음 개선: 사람 플레이로 국면 힌트와 상환 난도 튜닝, 캐릭터 전용 손수 픽셀 프레임 확장, 차트 확대/지표 선택.
복구는 저장된 시드·날짜·고정 틱으로 해당 시장을 재생성한다. 주문이 시장에 영향을 주지 않으므로 뉴스/캔들/PRNG도 정확히 복원되며, 저장된 객체가 클래스 메서드를 덮어쓰지 못하도록 인스턴스 필드만 복사한다.
