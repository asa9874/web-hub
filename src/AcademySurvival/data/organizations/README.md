# 소속 시스템 v1 인계

## 데이터와 경계

정식 조직 정의는33개이며 초기 루트는제국·마계2개다. 요청 트리31개에 기존 연구원 프로필의 중앙 마탑과 비생도 가입 프로필의 강가 정착지2개를 더했다. 이 목록은 초기 데이터일 뿐 루트 수나 계층 깊이를 제한하는 분기문은 없다.

- `types/organization.ts`: OrganizationDefinition, CharacterAffiliation, CharacterAffiliations, PositionAffiliationBinding.
- `data/organizations/index.ts`:33개 조직의 안정 ID·부모·유형/세부 유형·개요·세계관 설정·0~1000영향력·규모·공개 정책·목적·특징·가입/이탈 조건·태그·이전 이름 별칭.
- `bindings.ts`:11개 직급의 선택적 가입 연계. 학년4/학생회3/기사단3/연구원1개. 직급의 상하 서열과 조직 계층을 섞지 않는다.
- `systems/organizations.ts`: registry/path/descendant lookup, 직접 소속 정규화·추가·제거·대표 변경·정보 공개·검색.
- `organizationValidation.ts`: 정식 조직 그래프와 가입/직급/학적 검증. 초기 오류는 도감에 표시하며 공통 캐릭터 검사와 생성기 진단에도 연결한다.
- `OrganizationCatalog.tsx`: 검색·독립 펼치기/선택·전체 펼치기/접기·계층 경로·상세·키보드·반응형. 행은 반복 스택으로 평탄화하여 깊이3에 고정하지 않는다.
- `CharacterAffiliationPanel.tsx`: 실제 직접 소속과 전체 경로/대표/공개·비밀/도감 연결. 상태창 헤더도 현재 공개 가능한 대표 소속을 사용한다.

진입: `/web-hub/games/academy-survival/?view=catalog&kind=organization`.

## 기존 조직 범위와의 호환

예전 social/config.ts의14개 ORGANIZATIONS는 직급의 관할·소속 범위를 검사하는 얕은 ID 목록이었다. 기존ID는 전부 유효하게 유지했다.

정식 조직과 겹치는empire/academy-main/royal-order/central-tower/river-town은 동일 ID를 재사용한다. 기존 본교 아카데미·왕실 기사단 표기는 별칭 검색으로 찾을 수 있다. 표시명 변경은 보유 직급 ID·영향력·확률·효과를 바꾸지 않는다.

기존 새벽 왕국/북부 공국/협약 아카데미/변경 수비대/새벽 교단/상인조합/도시 법원/경계 협약/세계 공인 협약의9개 범위는 **LEGACY_POSITION_SCOPES**로 보존했다. 제국의 속국·산하 조직이라는 관계를 임의로 만들지 않았다. POSITION_ORGANIZATION_SCOPES(기존 ORGANIZATIONS alias)는 정식 정의와 기존 범위를 합쳐 직급 참조를 유지한다. 이는 소속 도감의 루트나 직접 가입 목록이 아니다. 신규 가입·계층 조회는 반드시 organizationRegistry를 사용한다.

이9개 중 실제 가입을 지원하려면 세계관상 올바른 부모 또는 새 루트로 정식 정의를 작성해야 한다. 그때까지 직접 소속으로 참조하면 오류다. 기존 법원 시민권이나 세계 공인 용사 직급만으로 해당 기관의 직원/회원으로 간주하지 않는다.

## 공통 캐릭터 계약

```ts
interface CharacterAffiliation {
  organizationId: string;
  visibility: 'public' | 'secret';
  joinedAt?: string; // 현재 게임 시간 체계가 없으므로 임의 시간 시뮬레이션은 하지 않음
  sourceId?: string;
}
interface CharacterAffiliations {
  affiliations: CharacterAffiliation[];
  primaryOrganizationId?: string;
}
```

Character는 위 구조를 공통으로 확장한다. 고정 템플릿도 같은 구조의 affiliations 필드를 가진다. 세레나는 기존 설정에 맞게 academy-main 직접 가입만 추가했으며 핵심 설정·수치·능력·직급은 바꾸지 않았다. 기존 CharacterIdentity.affiliation 문자열은 과거 소개 표기 호환용으로 유지하지만 가입·국적·거주·계층 판단의 근거로 쓰지 않는다. 과거 저장 데이터를 도입할 때 실제 가입 근거로 새 필드를 채워야 하며 문자열 이름을 자동 가입으로 변환하지 않는다.

가장 구체적인 직접 소속만 저장한다. 검술학부 가입 시 아카데미와 제국은 경로로 조회한다. 검술학부와 학생회처럼 서로 다른 가지는 동시에 가입할 수 있다. normalizeAffiliations는 중복/상위 직접 가입을 정리하고 대표가 사라졌다면 남은 직접 가입 중 첫 항목을 선택한다. raw 데이터 검증은 이런 중복을 오류로 진단하므로 무단 데이터 정리를 숨기지 않는다. addAffiliation은 없는 조직을 거절한다. setPrimaryOrganization은 미보유를 거절하며 대표 변경은 가입 목록·직급·효과·영향력을 바꾸지 않는다.

비밀 여부는 조직의 공개 정책과 캐릭터 가입 인스턴스에 각각 있다. 일반 상태창은 비밀 가입과 비밀 조직이 포함된 경로를 숨긴다. 비밀 대표만 있을 때 이름을 노출하지 않고 공개 소속 없음으로 표시한다. DEBUG는 모두 표시하고 대표 선택을 임시 변경할 수 있다. 변경은 원본 캐릭터/템플릿에 저장하지 않는다. 설정집은 개발용 세계관 문서이므로 비공개 조직 정의도 공개 범위 표기와 함께 열람한다. 실제 게임의 지식·첩보 엔진은 아직 없다.

## 직급과 가입의 독립성

직급을 추가하는 함수는 가입을 자동 실행하지 않는다. 학년/연구원/실제 기사단 직위는 보유 직급의 organizationId를 기준으로 해당 조직 또는 하위 조직 가입을 검사한다. 본교 학생회 직위는 academy-council 가입을 별도 검사한다. 명예 기사나 법적 시민권 등에는 일반 가입 의무를 강제하지 않는다.

학년 직급은 schoolYear와 일치해야 한다. 재학생이면 학년 직급이 필요하고 그 학적 기관에 가입해야 한다. 교수/일반 비생도는 schoolYear0이며 조직 가입이 있다고 학생으로 자동 전환하지 않는다. 중복 학년 직위는 기존 positionConflict와 validateSocialIdentity가 함께 검사한다. 미구현 조직 범위에서 필수 가입 직위를 실제 캐릭터에 부여하려면 정식 조직 정의도 먼저 추가해야 한다.

**조직 영향력은 캐릭터 영향력v1에 합산하지 않는다.** 가입/대표/비밀 여부를 바꾸어도 같은 능력·직급·칭호의 계산 결과는 같다. 소속 규모·대표성 등을 반영하는 후속 공식은 별도 버전에서 검토한다.

## NPC 생성 연결

NPC 스키마 확장을 기록하기 위해 프로필 버전은npc-generation-v1.1이다. 기존 시드의 이름·능력·점수 난수 스트림은 유지하면서 가입 근거를 별도로 추가했다.

- 검술/은신·단검 → 검술학부. 마법/연금술 → 마법학부. 신성술 → 신성학부.
- 궁술/전술·지휘 → 연결 학부가 아직 없으므로 아카데미 직접 가입. 새 학부를 추가하면 해당 전공 organizationId만 연결한다.
- 학생회 선출 배경 → 학생회 가입과 직급을 각각 명시적으로 부여.
- 비생도 → 규약에 동의한 강가 공동체 가입. 거주·시민권과 가입이 별개라는 근거를 남긴다.
- 계약 연구원 배경 → 중앙 마탑의 가입 기록을 직급과 별도로 부여.

생성 컨텍스트에 정식 organizations와 normalizeAffiliations를 주입한다. 없는 조직이나 전공 학부가 학적 아카데미 밖에 연결된 프로필은 setup 오류다. 생성 뒤 공통 가입·직급·학년 검사도 실행한다. 대표 소속은 실제 보유한 직접 소속만 사용하며 대량 결과에 표시한다. 가입은 난수를 더 소비하지 않으므로 기존 audit 시드100명 평균171.08/기프트11% 등 능력 통계가 유지된다.
