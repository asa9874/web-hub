# 학생 경제 v1 계약

- `systems/economy.ts`의 계정이 금전의 단일 권위다. 최소 단위는 정수 동화:100C=1S,100S=1G. 부채·음수·소수·안전 정수 초과는 거부한다. Character 영향력/능력치를 재산으로 사용하지 않는다.
- 신규 실제 세계는 아이템 원장 뒤 경제를 연결한다. `createFreshAiSandbox`는 `enableEconomy` 명시 옵션만 사용하므로 기존 격리 시험의 아이템 수 계약은 유지한다. 구형 저장은 선택 필드가 없으면 자동 지급하지 않는다. 플레이어가 현재 시점에 연결 가능하며 과거 용돈을 소급하지 않는다.
- 경제 배경5개는 독립 시드 스트림. 플레이어는 새 게임에서 선택하며 기본 ordinary. 초기 소지금은 배경 범위, 월 지원은 해당 배경 고정액이다. 기존 캐릭터 능력·기프트·성격을 바꾸지 않는다.
- 정규 학생 역할/1~4학년은 공동 기숙사·기본 식사·수업·기본 시설/학교 의료를 기존 무료 행동으로 유지한다. 기본 식사마다 거래를 만들지 않는다. 졸업 전환은 기존 학적이 실제 변경될 때 지원 대상에서 빠지며 졸업 이후의 생계비·급여는 후속이다.
- 등록3상점·22상품은 기존 실제 아이템 인스턴스/유한 재고다. 최초 보충만 명시적으로 생성하며 화면 조회/로드/재입장으로 재생성하지 않는다. 영업 시간·현재 장소·출입·소유/대여·예약·소지 한도·자금 검사를 모두 다시 수행한다.
- 상점은 비공개 shop 보관함이며 일반 회수/보관 권한이 없다. 구매/판매는 `items.marketTransfer`와 기존 `applyActionEffects`의 동기 commit/rollback으로 결제·소유권·수량·상점 자금을 함께 반영한다. 실패 시 두 원장과 알림을 복구한다. 판매가는 기본가40% 이하이며 상태·조잡 품질을 반영한다. 고등급/비밀/고유품은 일반 상점 대상 밖이다.
- 매월1일0시 용돈, 어려운 가정/무후원 재학생에게 생활지원15S. 확정 학기 성적 `excellent`는 학기당40S를 다음 월초에 심사한다. 수강 화면 열람·연습 성적·능력치만으로 장학금을 지급하지 않는다. 최신 처리 학기 워터마크로 중복 지급을 막는다.
- 등록3일자리: 도서관/식당/훈련장. 자격·현장·영업/의무 일정·긴급 욕구·정원을 검증하고, 기존 student_work 활동의 실제 현장 활성 구간만 누적한다.2시간 완료에만 보수 지급, 중단/이탈은 미지급이다. 플레이어는 기존 자동 시간 진행/중요 사건 중단을 재사용한다. NPC도 같은 API로 실제 근무 가능하지만 자율 구직·소비 정책은 v2다.
- 월 경계/활성 근무 종료만 예약한다. 모든 NPC의 구매 의향을 매분 검사하지 않는다. 계정별 최근 거래24건·누적 수입/지출, 근무 이력128건 상한. 활성 근무와 정기 지급 예약을 저장한다. 급여/장학금은 비공개 EconomyChanged→기존 기억, 거래는 기존 ItemChanged를 사용한다.

검사: `npm run test:academy-economy` (실제 소유·원자 복구·근무/중단·복원·월 지급 및 새 실제 세션/패널SSR). 보고: `docs/academy/ECONOMY_V1.md`. 자동 소비/저축 목표·대출·공동 구매·동아리 예산·가격 변동·후원/의뢰·재입고·졸업 후 경제는 이번 v1에 포함하지 않는다.
