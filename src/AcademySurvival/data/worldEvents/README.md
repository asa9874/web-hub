# 세계 이벤트 v1 — 시간축 인과관계 그래프

도메인 사건은 실제 상태 변화 기록이고, 세계 이벤트는 명시적인 카탈로그·트리거를 가진 별도 사건 인스턴스다. 기존 예정 이벤트 참조 21개를 실행 카탈로그로 암묵 변환하지 않는다.

아이템 v1은 실제 `ItemChanged`의 `domainOutcomes`를 정확히 필터하는3개 정의를 추가한다. 과거의 일치하는 사실만으로 다른 결과의 새 도메인 사건을 재사용하지 않는다. 원장의 소유권/선물 보상은 이벤트 단계에서 다시 적용하지 않는다. 실제 카탈로그 수는 `test-academy-world-events`가 검사한다.

## 모듈 / API

- `types/worldEvent.ts`: 12개 카테고리, 선언형 조건, 트리거·단계·결과·후속 규칙, 인스턴스·관계·예약·저장.
- `data/worldEvents/index.ts`: 기존21종과 학사 경고/실제 자율학습 점검2종(총23종) 정의와 예산/보존 설정. 학사2종은 `data/academic/events.ts`를 참조한다. 고정 인물의 서사를 새 공식 설정으로 확정하지 않는다. 아래21종 설명·장기 결과는 최초 세계 이벤트 범위이며 새 학사 장기 검증이 아니다.
- `systems/eventQueue.ts`: 시각·일련번호 순서의 안정적인 최소 힙.
- `systems/worldEvents.ts`: 공통 시간 참가자 priority 29. 이동0/일과10/욕구20/상호작용25/효과26/기억28 뒤, AI30 앞에서 처리한다.
- `createWorldEventEngine(motivation, graph, effects, interactions, knowledge, options)`.
- `requestEvent(definitionId, context)`: 개발자 요청은 트리거 확률만 우회한다. 참여자·출입·쿨다운·예산·단계·실제 상호작용은 우회하지 않는다.
- `scheduleEvent(definitionId, futureMinute, context)`: 예정 상태, 도달 시 재검증. `cancel`, `interrupt`, `relate`, `evaluateCondition`, `getIntents`, `getDiagnostics`, `save/load`.
- `evaluateOpportunity`: 실제 예약된 현재 기회만 판정한다. 이미 처리한 기회를 재추첨하지 않고 다음 기회 시각·확률·판정값을 반환한다. 미래 기회를 미리 강제 실행하지 않는다.
- `bindInteraction`: AI가 사건 의도로 요청한 실제 상호작용 ID를 연결한다. 수락·결과는 공통 상호작용 엔진이 소유하며, 이후 도메인 파생 사건이 원래 세계 사건을 추적한다.
- `getAppliedEffects`: 사건이 직접 적용한 실제 변화 요약. 일반 UI는 내부 수치 변화를 숨기고 개발자 상세에서만 표시한다.
- `getInstances/getRelations`의 기본은 공개 사건만이다. 내부 사실·비밀을 볼 수 있는 테스트에서만 debug 인수를 사용한다.

## 인과관계 / 실행

시간·순번의 전체 순서로 DAG를 검증한다. 분기 결과는 시드+인스턴스 기반으로 선택하고 미선택 경로의 인스턴스는 만들지 않는다. AND 합류는 같은 참여자들의 실제 완료 원인 집합 키로 중복 방지한다. OR 합류는 같은 정의 집합·참여자·게임 날짜를 한 기회로 묶으며 먼저 충족한 원인을 사용한다. 이미 발생한 사건에 뒤늦은 원인을 소급 연결하지 않는다. 이전 활성 사건 취소는 과거 원인을 수정하는 대신 현재 시점의 취소 기록과 blocks 관계를 남긴다. 미래 예정 사건은 직접 blocks로 연결할 수 있다. 종료 사건은 소급 삭제/취소하지 않는다.

정기/확률은 명시적인 기회 예약에만 평가한다. 확률 RNG는 `seed + definition + trigger + opportunity`의 독립 하위 스트림이다. 별도의 변경 가능한 RNG 커서는 필요 없으며 시드·기회 키·순번·예약을 저장한다. 조건부는 60분 경계와 관련 인물/도메인 변화에서 재평가하며 전체 NPC×모든 정의를 매분 검사하지 않는다. 행동 파생은 등록된 도메인 유형/상호작용 ID만 구독한다. 당사자가 이미 이동하기 시작했다면 최대 60분 pending으로 기다리고 실제 장소·조건이 충족될 때 시작한다.

현재 확률 기회는 60분, 지각 위기의 짧은 시간창은 15분 주기다. 실제 수업·훈련·식사 구간을 평가 주기가 통째로 건너뛰지 않도록 한다. 예정 평가는 날짜를 건너뛰어도 힙의 각 기회를 처리한다.

단계 진입/완료 시 실제 위치·이동·출입을 검사한다. 상호작용 단계는 기존 request/수락/거절/진행/완료를 기다린다. 단순한 대화 완료와 실제 정보 전달 성공, 실제 화해 성공을 구분한다. 같은 상호작용의 기존 보상은 이벤트에서 다시 지급하지 않는다. 별도 이벤트 효과는 안정적인 결과 ID로 공통 효과 엔진에 적용하며 실패하면 사건도 실패한다.

`WorldEventCompleted` 도메인 사건만 기억 엔진에 전달한다. 직접 참여/당시 실제 목격/공개 범위/정보 계보 정책을 그대로 사용한다. 회상 보상을 추가하지 않는다. 후속 사건이 원인의 비밀 등급을 자동 공개로 낮추지 않는다. AI는 자기 참여 사건의 활동 동기를 기존 효용 후보에 병합하며 일정/긴급/중단/접근 정책을 유지한다.

수업 의도는 실제 시간표의 목적지, 학습 안내는 등록된 도서관, 휴식은 거주지를 사용한다. 대련 의도에는 실제 상대와 상호작용 ID가 필요하다. 부상·사고의 도움 후보는 해당 사건의 실제 보유 기억과 방향성 관계를 확인하고 현재 현장에서 상대를 인지할 수 있을 때만 제안한다. 원격 친구의 위치를 기억만으로 조회하지 않는다.

## 보존 / 저장

통합 `ai-sandbox-v1`의 선택 필드 `worldEvents`에 `world-events-v1`을 저장한다. 기존 저장에 필드가 없으면 기존 실행을 유지한다. 새 이벤트 저장은 동일 세계 시각·시드·정의/인물/장소/단계·예약·그래프를 검증한 뒤 복원한다. 과거 이동은 통합 스냅샷 복원을 사용한다.

연쇄 깊이8, 단계 전이12, 분당 생성24, 일일100, 보유 인스턴스4000, 예약4000, 중복 키20000 한도다. 60일이 지난 저중요도·종료·연결 없는 사건만 정리한다. 연결된 중요한 사건을 임의 삭제하지 않으며 예산이 찬 경우 생성 제한 사유를 기록한다. 무제한 역사 기록 저장소/디스크 아카이브는 후속 범위다.

동일 정의는 한 연쇄 안에서 2회까지다. 차단은 같은 사건 참여자 집합을 대상으로 하며 한 명만 겹치는 다른 결투까지 취소하지 않는다. 직접 효과의 변화 요약은 사건에 보존하므로 공통 효과 상세 이력의 별도 한도가 지나도 사건의 결과가 사라지지 않는다. 종료된 사건의 과거 상호작용 ID는 외부 이력의 보존 기간이 끝나도 기록으로 유지한다. 진행 중인 사건은 실제 상호작용/단계/예약 참조가 필요하다.

## UI / 검증

`?view=catalog&kind=world-event`, `?view=world-event-tester`. 카드·상세 팝업, 시간순 연대기와 실제 SVG 노드/엣지 그래프, 확대/축소/드래그/키보드 선택/원인·후속 추적, 시간/NPC/장소/분류/상태/중요도 필터. 최근100개 부분 그래프로 렌더링을 제한한다. 긴 시간 간격은 압축하고 같은 행은 왼쪽부터 처리 순서다.

테스트는 통합 저장을 깊은 복제하며 NPC 생성/수동 준비/강제 발생/AI 선택 실행/시간 진행/취소/저장 복원/초기화를 제공한다. NPC 생성 시드는 인물 생성에 사용하고 이벤트 RNG 시드는 통합 저장에 보존한다. 시간 설정은 앞으로 진행하며 과거는 초기화/복원한다.

테스트의 시드 적용은 초기 스냅샷에서 재시작한다. 장소·활동·욕구 준비는 명시적인 샌드박스 조작이다. UI 시간 진행은 벽시계 예산(호출 목표12ms·묶음24ms)에 따라1~60게임분으로 조절하며 닫을 때 중단한다. 매게임분1프레임을 강제하지 않고, 실제 일정·도착·상호작용·사건은 공통 시계가 모두 처리한다. 하드 실시간 지연 보장은 아니며 Worker 분리는 후속 범위다.

- `npm run test:academy-world-events`: 계약·효과·DAG·분기/합류/차단·저장·실제 대련 파생·비밀/목격·7일 분할/일괄 비교.
- `WORLD_EVENT_REPLAY=1`: 실제 AI를 켠1명·7일의 분 단위/일괄 통합 스냅샷 비교를 추가한다. 기본 짧은 검사와 별도다.
- `npm run test:academy-world-events-browser`: 변경 UI 경로만 검사.
- `WORLD_EVENT_STRESS=1`, `WORLD_EVENT_COUNT=100`, `WORLD_EVENT_DAYS=30`: 기본은 실제 자율 AI 전체 통합 실행이다. `WORLD_EVENT_STRESS_PROFILE=schedules`를 지정하면 AI 의사결정만 끄고 실제 일과·이동·욕구·상호작용·효과·기억·이벤트를 실행한다. 두 프로필의 검증 범위를 구분한다. 결과는 `test-results/world-events/stress.json` 또는 `stress-schedules.json`에 기록한다.

## 제한 / 계획

21종은 현재 실행 가능한 소규모 생활 사건이다. 시험 안내는 시험 점수를 생성하지 않고, 분실물은 재산을 생성하지 않는다. 부상은 명시적 사고의 타박상 적용이며 정식 전투 피해 계산이 아니다. 다자간 행사, 플레이어 선택/개입, 전쟁·정치·경제·재난 시뮬레이션, 고급 소문 판정은 v2/v3 계획이다. 현재 그래프는 무한 캔버스 라이브러리를 도입하지 않은 제한된 SVG 보기다.

문화·생활 v1에서24개 학내 문화 교류 정의를 추가해 현재47종이다. 날짜 미확정의 현장 기회를 개인 문화/선호와 실제 공통 공동 활동으로 판정한다. 상태·예산·기억·원자적 관계 효과·저장 규칙은 유지하며 `../culture/README.md`를 따른다.

## 균열 지역 기록 어댑터

`recordRegionalOccurrence(definitionId,locationId,key,causeId?)`는 `regional-occurrence` 정의의 참가자0 집계 기록이다. 일반 인물 사건의 위치/동의 규칙을 바꾸지 않는다. 해당 정의는 인물 효과·상호작용·자동 트리거/후속을 가질 수 없고 private으로 등록한다. 실제 상태 검증과 변경은 균열 엔진이 소유하며 기존 큐/DAG/저장을 재사용한다. 현재14종이며 전체 카탈로그는200종이다. 원본 지역 발생 키로 중복 방지한다. 카탈로그/이벤트 예산 제한 시 균열의 중요 이력·인과관계는 유지하고 공통 그래프 미등록을 진단에 남긴다. 강제로 전체 예산을 무시하거나 인물을 발명하지 않는다. `../riftCrisis/README.md` 참고.

## 아카데미 사건망 확장

`../academyStories/README.md`를 따른다. 현재236정의 중 신규30개는16개 실행 경로 연결/14개 의존 보류다. 정의92개 서사와 실제 실행 완료를 구분한다. 선택적 후속 기회는 실제 원인 인스턴스에 저장하고 공통 큐에서 조건을 재검사한다. 일반 투영에서 미발생 가능성을 제거하며 기존 예산/원인 보존/통합 저장을 유지한다.
