# 아이템 v1 계약

- `types/item.ts`와 `systems/items.ts`가 정적 정의와 실제 소유권 원장의 단일 출처다. Character에 장비 복사본이나 두 번째 인벤토리를 저장하지 않는다.
- 등급/품질/명성/고유성/유래는 별개다. 명성은 판정·피해에 가산하지 않는다. 100종 분포는30/22/18/12/9/5/3/1/0. 기본 생성은 일반 생활 물품5종만, 고등급은 명시적 개발/시나리오 생성만 허용한다. 세계 유일 상한은 소멸 후에도 생성 원장에 남는다.
- 물리 위치는 휴대/착용/보관/지면 중 하나다. 대여는 원소유권을 유지한다. 보류 제안은 실제 인스턴스를 예약하며 중복 제안·소비·보관을 막는다. 반환은 대여 스택 전체를 처리한다. 선물 수량 분할은 새 스택 ID를 사용하고 원래 수량을 감소시킨다.
- 사용·선물·반환·각성은 `applyActionEffects`의 선택적 동기 commit/rollback 참가자로 처리한다. 효과 미리보기 실패 시 원장은 바뀌지 않고 커밋 실패 시 원장과 공통 효과를 함께 복구한다. 트랜잭션 중첩·비동기 커밋은 금지한다.
- 장비 보정은 `CHECK_MODIFIER(score)`만 현재 실행한다. 장비 전체6점과 기존 최종±15점 상한을 유지하며 품질은 제한적으로만 보정한다. 전투·감정·개발 판정 조회는 같은 어댑터를 쓴다. 자원 소모/기술 해금 등 별도 효과는 구현했다고 표시하지 않는다.
- 교재·생활 도구는 실제 완료 활동의 성장 효과에 최대5% 보조를 제공하며 소모되지 않는다. 음식/회복약은 공통 욕구/HP·MP 효과를 사용한다. 식당의 집계 식사는 기존 생활 시스템이며 음식 객체를 무단 생성하지 않는다.
- NPC는 획득/활동 준비에서 자기 소지품만 검사한다. 새 NPC의 욕구 등록 이전에는 준비를 공통 시간 경계로 미룬다. 사용할 수 없는 장비를 강제로 착용하지 않는다. 재고가 없다고 보충 생성하지 않는다. 소비는180분 간격, 선물 검토는 자유시간 하루1회/실제 친구·소지품에 한정한다. 대여 기한이 지난 물건은 실제 재회 시 반환을 시도한다. 원거리 자동 반환/강제 이동은 없다.
- 선물 판단은 방향 관계·개인 문화 선호·음식 필요·중복·부담을 사용한다. 고정 종족 취향을 만들지 않는다. 동일 상대의 관계 보상은7일1회이며 기존 공통 일일 관계 예산도 적용한다. 플레이어 수신은 직접 수락/거절한다.
- 모든 변경은 실제 현장/소유/접근/현재 상태를 다시 검사한다. 개인 보관함은 같은 방의 다른 사람에게 열리지 않는다. 구형 저장은 자동 아이템 지급 없이 읽고 사용자가 명시적으로 연결한다. 신규 실제 세계와 등록된 지속 인물은 생활 키트를 한 번만 받는다.
- `ItemChanged`는 실제 변경 뒤 출처/공개 범위로 기억을 생성한다. 미확인 유물의 이름/등급을 기억 문구로 누출하지 않는다. 감정은 개인별 지식이며 실패하면 공개하지 않는다. 각성은 별길 관측기1종만 지정 장소·숙련·재료로 한 번 수행하고 ID/등급/원소유권을 유지한다.
- 최근 상세 이력24건, 완료 제안/반환 이력256건을 유지한다. 소유자별 최초/최근 보유 시각과 이전 횟수 요약, 활성 대여, 세계 유일 생성 원장은 보존한다. 모든 역사적 행동의 원문 무한 보존을 뜻하지 않는다. 일반 스택은 짧은 provenanceKey로 이전 출처를 구분한다.
- LOD가 원장을 복제/재생성하지 않는다. NPC별·장비별 인덱스를 사용하며 매분 전체 아이템/전체 인맥을 순회하지 않는다. 저장에는 다음 준비 ID도 포함해 분할 시간/복원 순서를 보존한다.

검사: `scripts/test-academy-items.mjs` → 관련 효과·전투·상호작용·기억·세계 이벤트·저장 검사, UI는 `test-academy-items-browser.mjs`. 장기 검사는 짧은 전량 AI 검사 이후 별도 목적을 정한다. 실제 결과/제한: `docs/academy/ITEMS_V1.md`.

- 학생 상점은 `marketTransfer`로만 비공개 shop 재고를 이전한다. 외부 결제 참가자는 기존 동기 효과 트랜잭션의 commit/rollback 안에서 함께 처리한다. 일반 회수/보관 권한으로 shop 재고를 가져갈 수 없다. `data/economy/README.md` 참고.
