# 행동 기반 스킬 v1 계약

- 단일 정의는 `index.ts`: 기존49숙련도(기초 스킬)+기존419trait 계보(안정 ID)+검술 전문3개=471노드다.471개 새 권능 구현을 뜻하지 않는다. 기존 기프트617개는 별도이며 변경하지 않는다.
- `Character.skillBook`은 습득 스킬의 숙련/경험·실제 계열 수련·도전·사용 방식·진화 이력 권위다. `traitIds`는 기존 저장/전투/조건/설정 참조를 위한 **현재 보유 구형 스킬의 투영**이다. 새 전문 스킬은 여기에 끼워 넣지 않는다. 기초49숙련의 XP/랭크는 기존 actionEffects GrowthState/proficiencyRanks만 사용한다.
- `systems/skills.ts`는 공통 결과 원장에 성공 적용된 완료 활동, 실제 종료된 상호작용/전투·공식 시험만 읽는다. 활동 원본의 실제 시간·학사 활동 메타데이터를 사용하며 조회/버튼/취소만으로 수련하지 않는다. 학사/공동 활동의 중복 보상을 피한다.
- 관련 실제15분 이상 경험만 인정, 계열당 하루180분 상한. 피로에 따라 숙련 XP 감소. 충분한 기초 역량과 적합한 실제 도전2/5회가 없으면 반복 수련 숙련은4/6단계에서 멈춘다. 기초49랭크 성장 곡선은 재작성하지 않는다.
- 대화는 실제15분 이상 종료·동일 상대 하루1회만 인정한다. 인사/짧은 잡담 반복으로 사교 스킬을 무한 성장시키지 않는다. 실제 공동 공부/훈련은 해당 완료 사건을 사용한다.
- 플레이어는 실제 수련/선행 숙련/기초 역량/도전 조건이 열린 노드에서 습득·진화를 직접 선택할 수 있다. 작은 첫 발견은 실제 경험당 하나만 자동으로 알려 준다. NPC는 같은 실제 조건에서 성향·자기 사용 기술/능력으로 선택한다. 매분 모든 인물×스킬을 검사하지 않는다.
- 선형 계보는 이전 스킬을 대체하고 supersededIds에 기록해 재습득 중첩을 막는다. 검술 전문3개는 공통 기초를 유지하는 추가 전문화이며 서로 상호 배타다. 과거 경험/기억은 삭제하지 않는다. 이동/전투/교류 중 플레이어의 임의 진화는 거부한다.
- 쾌검: 실제 전용 공격(기력4/낮은 일격 피해/선행8). 중검: 기력16/강타/방어 자세 경감 절반 관통/재사용2. 정밀: 실제 상대 분석 성공 필요/근접·중거리 찌르기/기력9. 같은 전투 자원·판정·NPC 후보 선택기를 사용한다.
- 스킬 숙련은 관련 공통 판정에서 최선의 보정 하나(최대3점)만 제공하며 기존 전체±15점 한도 안에 포함된다. 옛 효과의 미연동 고유 옵션/성장 문구를 전부 실행했다고 간주하지 않는다. 고유 설정·금기 등47개는 기존 보유를 보존하되 일반 수련 신규 습득에서 제외한다.
- 신규 시작 빌드는 기존 실제 능력/기초 숙련·15인 방향 데이터로 구성한다. 고정 인물의 기존 능력치/기프트/기초 숙련/원래 보유 ID를 보존한다. 이미 중급 이상의 시작 검술 기록이 있는 경우 NPC와 플레이어에 동일 자격을 적용하되 플레이어는 전문 분기를 직접 고른다. 과거 사건이나 수련 시간을 지어내지 않는다.
- `AiSandboxSave.skills`는 선택 필드다. 구형 저장은 자동 주입하지 않고 플레이어가 현재 세계에 연결한다. 과거 활동 보상을 재생하지 않는다. 현재 시각의 완료 원인 키·진행 하한, 캐릭터별 최근 이력32건·유한 정의 집합을 저장한다. `trait-*` ID·기프트 ID·구형 결과 지문은 보존한다.
- 실제 플레이 트리는 미발견 상위 제목/조건을 숨긴다. 전체 개발 설계 도감과 분리한다. 가족/검색/보유·계보·72노드 부분 표시/드래그·확대·방향키/상세·진화 버튼을 제공한다. 같은 정의에서 연결을 추출하며 UI용 계보를 중복 작성하지 않는다.
