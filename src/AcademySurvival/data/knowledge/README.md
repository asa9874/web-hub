# 능력치·숙련도 정의 인계

현재 실행 기준(2026-10-27): 기존49숙련도는 스킬 트리의 기초 숙련이며 XP/랭크는 `data/actionEffects/config.ts`·`systems/actionEffects.ts`를 단일 권위로 사용한다. 기존 특성419개는 안정적인 ID를 유지한 스킬 계보로 연결했다. 실제 수련·습득·진화 계약은 `data/skills/README.md`를 따른다. 아래 최초 설계의 미구현/독립 문구는 당시 기록이며 최신 실행 계약을 대체하지 않는다.

## 현재 콘텐츠

| 데이터 | 개수 | 개별 설명 |
| --- | ---: | ---: |
| 기본 능력치 | 7 | 70 |
| 숙련도 | 49 | 490 |
| 합계 | 56 | 560 |

능력치는 근력·민첩·체력·마력·지능·정신·매력이다. 추가 기본 능력치는 도입하지 않았다. 기존 특성의 지구력·체력 자원·마나량·집중력 같은 대상은 기본 능력치에 자동 합산하지 않고 파생 지표 연결 후보로 구분한다.

숙련도는 무술 8, 마법 7, 마법 응용 9, 학문 7, 사회 6, 탐험 5, 생활 7종이다. 권장 기술에 의식술·의학·행정·정밀기계와 신성마법을 추가해 관련 분야를 다룬다. `proficienciesHoly.ts`의 신성마법은 신앙의 강도나 치유마법과 같은 수치가 아니며 별도 기술이다. 하위 경지는 구체적인 작업 실수와 기초를, 중위 경지는 전문적인 판단을, 상위 경지는 분야 자체의 깊이와 전승을 묘사한다. 생활 기술의 신역을 공격력으로 환산하지 않는다.

## 공통 설정과 개별 문장

`config.ts`의 `STAT_GRADE_BANDS`가 등급 구간의 단일 원본이다. F 0–9, E 10–29, D 30–49, C 50–69, B 70–89, A 90–100, S 101–120, SS 121–150, SSS 151–199, EX 200 이상이다. 현재 수치는 정수로 조회한다.

`PROFICIENCY_RANKS`가 0–9 경지의 이름과 한자만 공유한다. 숙련도의 경험치 임계값은 **미설정(null)** 이며 임의의 영구 성장 규칙을 만들지 않았다.

`stats.ts`와 각 `proficiencies*.ts`에 모든 인게임 설명을 개별 작성했다. `TenTexts`와 `P()`는 정확히 10개 문장을 요구하고 공통 이름을 붙일 뿐 문장을 생성하지 않는다. 새 기술은 안정적인 `proficiency-*` ID, 소개, 유효한 기본 능력치 ID, 판정 태그, 관련 효과 대상, 개별 문장 10개로 추가한다. 해당 계열 파일과 레지스트리에 등록하면 UI가 자동 반영한다.

## 실제 수치 및 기존 효과와의 경계

- `StatDefinition`/`ProficiencyDefinition`은 정의이고 `CharacterKnowledge`는 향후 캐릭터가 보유할 수치의 타입이다. 현재 캐릭터 생성·성장·전투 엔진은 없다.
- 검술 종사와 낮은 단계 검술 특성, 검술 입문과 높은 단계 검술 특성은 모두 허용한다. 숙련도가 특성을 획득·진화시키거나 반대로 특성이 경지를 올리지 않는다.
- `effectReferencesFor()`는 실제 존재하는 특성·기프트의 STAT/GROWTH/CHECK 효과를 조건부 효과 내부까지 탐색한다. 등록된 관련 대상 키와 정확히 일치하는 효과만 출처 ID·효과 ID·타입·조건을 보존해 표시한다.
- 이 연결은 **열람용 관련 참조**다. 예를 들어 연구 성장 효과가 마법이론과 관련 있어도 마법이론 숙련도를 올리는 실행 코드가 생긴 것은 아니다. 기존 소문자 효과 키나 효과 해석기를 바꾸지 않았다.
- 파생 지표에 대한 효과는 기존 데이터의 존재만 보여 주고 기본 능력치와의 변환을 ‘예정·미설정’으로 표시한다. 마나량=마력, 지구력=체력으로 임의 치환하지 않는다.
- 이벤트는 실제 등록된 예정 이벤트에서 태그가 맞는 것만 표시한다. 이벤트 발생 및 실행은 미구현이다.
- 높은 등급의 서술은 문학적 성취이며 확정 성공·전지·강제 복종·부활 같은 실행 규칙을 추가하지 않는다.

## 검증

`npm run test:academy-knowledge`는 콘텐츠 수, 모든 등급 경계와 능력치별 설명, 경지 순서, ID/이름/문장 중복, 이름만 치환한 중복 문장, 빈 설명, 능력치 참조, 실제 효과 출처, 예정 이벤트, 잘못된 데이터 검출을 검사한다. 독창성이나 문학적 완성도는 스키마만으로 보장할 수 없으므로 개별 문장 검토도 유지한다.

`node scripts/test-academy-knowledge-browser.mjs`는 이 화면의 4개 탭, 목록·검색·필터·빈 결과, 경지 펼치기, DEBUG, URL 복원, 기존 콘텐츠로 이동, 기프트 정렬 및 390px 배치를 확인한다. `ACADEMY_KNOWLEDGE_CASE=remaining`은 숙련도 이후, `tail`은 기존 기프트 URL·모바일 구간만 수행한다. 다른 게임의 E2E는 이 작업 범위에서 생략한다.

신규 의존성, 이미지, 게임 실행 엔진은 추가하지 않았다. 빌드 결과와 정확한 검증 내역은 PR에 기록한다.
