# 설정집 기능 노트 v1

`?view=catalog&kind=features`. 세계관 도감과 구분되는 개발 현황 화면이다.27개 시스템·150개 버전별 항목을 `index.ts`의 타입 안전 레지스트리로 관리한다.

- 실제 코드·문서·검사 경로를 기록한다. `test-academy-features`가 ID·근거 경로·의존성·순환·버전·집계를 검증한다.
- 현재 버전 기능 항목만 시스템 상태에 집계한다. 전부 구현+검사 통과면 완료, 미구현/부분 항목이 섞이면 부분, 전부 미구현이면 미구현, 검증이 남으면 검증 필요다.
- `verificationScope=recorded`는 이전 검사 기록이며 이번 작업의 재실행을 뜻하지 않는다. `current`는 이번 작업에서 실행한 검사, `none`은 아직 확인하지 못한 범위다.
- v2/v3는 모두 **제안**으로 표시한다. 확정 계획이나 구현 완료 수에 합산하지 않는다.
- 도덕/카르마와 평판, 훈련 활동과 버전별 실제 XP 성장, 간이 대련 승패와 정식 전투/부상, 고유 효과 정의와 실행, 런타임 스냅샷과 실제 캠페인 저장소를 구분한다.
- 기존 선천 능력은 정식 이름인 기프트로 등록한다. 별도의 은총 시스템이 존재한다고 표시하지 않는다.
- 검색·분류·상태 필터, 코드 근거·검사·v1/v2/v3·의존 시스템 이동을 공통 상세 팝업으로 제공한다.

추가 기능은 실제 코드와 검사를 확인한 뒤 항목·검증 범위를 함께 수정한다. 자동 CI 실행 결과 수집이나 런타임 기능 탐지는 현재 구현하지 않았으며 레지스트리는 근거가 있는 정적 점검 기록이다. 코드가 바뀌면 기록도 갱신해야 한다.
