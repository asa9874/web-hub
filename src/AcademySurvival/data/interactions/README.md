# NPC 상호작용 v1

대화·사회생활 v1 추가 후 현재24종이다(기존23종+실제 공동 식사). `data/conversations/README.md`의 선택적 공통 의미/표현 엔진과 실제 약속·플레이어 선택을 연결했다. 대화가 없는 이전 저장과 모욕/위협 등 기존 부정적 판정은 유지한다. 아래는 원래 상호작용 단계의 기록이며 대화/약속 미구현 설명은 당시 범위다.

정의 `index.ts`, DTO `types/interaction.ts`, 실행 `systems/interactions.ts`. 제안/수락/실행/종료를 기존 일정 실행기와 공통 절대 분에서 처리한다. `AiProvider`가 결과·상호작용·AI를 조합하며, 위치·욕구·관계를 AI 상태에 복제하지 않는다.

## 카탈로그와 실행

18종: 잡담, 친목 대화, 진지한 대화, 함께 공부, 함께 훈련, 대련, 격려, 위로, 칭찬, 사과, 말다툼, 모욕, 위협, 화해, 도움 요청, 도움 제공, 회피, 경쟁.

- `createInteractionEngine(motivation, graph, effects, {seed, autoConnect})`: 독립 게임 로직. `request(a,b,type)`, `canRequest`, `getCandidates`, `getInstance/getInstances/getActive`, `cancel`, `interruptCharacter`, `resolveInteractionOutcome`, `getStatistics`, `save/load/connect`.
- 실제 같은 장소·정지 상태·활동 태그·입장 조건, 피로/긴급 필요, 수업·업무·수면·중단 불가 활동을 검사한다. 전지적 인물 위치 조회로 원격 대화를 시작하지 않는다.
- 제안이 승인 대기 중인 1분부터 참여자를 예약한다. 수락 시 하나의 공유 인스턴스로 양쪽 `ai/interaction/…` 활동을 실행한다. 활동 완료 시각의 실행 증거를 확인해야 보상을 지급한다. 한쪽의 위치나 활동 변경은 양쪽 중단으로 이어진다.
- 회피는 일방적인 비접촉 행동이라 상대를 예약하거나 동의를 강요하지 않는다. `traveling`은 향후 만남 예약을 위한 타입만 준비했고 v1은 현장 요청만 실행한다.
- 수락 확률은 상대→행위자 감정, 상대의 실제 욕구·성향, 최근 접촉 빈도와 시드로 정한다. 결과는 대화/공감/협력/갈등/회피/간이 경쟁별 판정이다. 거절 자체의 관계 벌점은 없다.
- 전투 모듈이 연결된 세계의 수락 대련은 공통 라운드 엔진을 실행한다(`data/combat/README.md`). 대련은 실제HP를 보존하고SP/MP·수행 시간을 기록한다. 종료 후 기존 성장/관계 보상을 한 번 적용한다. 구형 미연결 세계의 경쟁은 공통 판정 간이 승패를 유지한다. 영향력·캐릭터 종류 보정은 없다.
- 결과의 관계 변화는 방향별로 다르며 관용 성향 보정·일일 한도·친밀도 감쇠를 적용한다. 동일 쌍·정의의 재시도 대기와 하루 부정적 접촉 한도가 있다.
- 실제 공동 활동 시간의 욕구 변화는 기존 `ACTIVITY_NEED_RATES`가 처리한다. 완료 시 관계·성장·제한적인 심리 결과만 공통 결과 엔진에 전달한다.

## AI·저장·도메인 사건

상호작용 엔진을 주입한 AI는 과거 3종 사회 활동 실행기를 병행하지 않는다. 후보 수집과 공동 활동 요청/현재 상태/통계 모두 이 엔진으로 위임한다. 기존 API 이용자를 위한 미주입 호환 경로는 남아 있다.

`interaction-v1`은 시드·공유 인스턴스·전이 이력·일련번호·쿨다운·부정 접촉 일일 수·누적 통계를 저장한다. 복원 전 시각·인물·장소·정의·전이 연결·중복 참여를 검사한다. 최근 인스턴스는 1,000개, 통계는 누적이다. `ai-sandbox-v1`에 `interactions`와 `outcomes`를 쌍으로 추가했다. 두 필드 없는 이전 저장도 읽되 없는 결과를 새로 지급하지 않는다. 런타임 저장 어댑터이며 캠페인 영구 슬롯 구현을 뜻하지 않는다.

공통 시계 처리 순서: 이동0 → 일정10 → 욕구20 → 상호작용25 → 결과26 → AI30. 다른 NPC 때문에 전역 시간을 다시 증가시키지 않는다.

## UI·검증

설정집 `NPC 상호작용`은 간결한 카드와 상세 팝업, `[테스트]`를 제공한다. 테스트 화면은 깊은 복제 세계에 기존/생성 인물, 실제 시간·일정·관계·효과 엔진을 사용한다. 수동 준비는 명시적인 개발자 강제 배치·대기이며, 수락·출입·일정 조건을 우회하지 않는다. 자동 AI 실행을 켜 10/50/100명 시뮬레이션할 수 있다. 시간 진행은 최대 1시간 단위로 UI를 양보한다. 과거 세계 복원에는 초기화/JSON을 사용한다.

`test:academy-interactions`: 카탈로그/참조/전이, 같은 장소·이동/예약/거절/완료/중단, 방향성·일일 한도, 실제 XP·상태·도덕·카르마, 사전 검증·커밋 실패 롤백, 중복 적용·저장 이어 진행, 분할/일괄 시간 일치, 기존 AI 어댑터를 검증한다. `INTERACTION_BATCH=1`은 기본 100명·7일 실제 통합 검사를 추가하며 `INTERACTION_COUNT`/`INTERACTION_MINUTES`로 진단 범위를 지정할 수 있다. 이는 기존 검사/CI 축소와 무관하다.

`test:academy-interactions-browser`: 20탭/18카드·팝업·생성·준비·요청·시간·효과 적용/중복/실패·캐릭터 성장·JSON·390px·초기화·원본 격리를 확인한다. 전체 게임 브라우저 회귀는 변경 범위 밖이라 실행하지 않았다. 통합 실측은 `verification.json`을 참고한다.

## 후속 범위

실제 대화 문장·기억·정보/소문, 약속과 원격 만남 예약, 다자간 활동, 정식 전투/부상, 경제적 도움, 복잡한 협상·정치·조직 갈등은 구현하지 않았다. 기능 노트의 v2/v3는 제안이다. 고정 인물의 미확정 관계나 목표를 공식 설정으로 추가하지 않는다.

최종 실행 결과와 변경 파일 목록은 [구현 보고](implementation-report.md)에 기록했다. 100명7일은 요청1,406/수락687/거절719/완료641/중단44/진행중2, 효과9,518회·실패0, 실제 능력치 상승100회·경지 상승33회·목표 완료93건이다. 일부 욕구 미충족과 목표 기한 실패는 초기 AI 밸런스 과제로 남아 있다.

기억·정보 v1 이후 정보 공유·소문·비밀·질문·확인 대화5종을 추가해 현재23종이다. 일반 정보 대화 완료와 실제 정보 제공 결과(공유/보류/없음/확인/모순)는 구분한다. 원격 소통이나 없는 정보를 만들어내지 않는다. 자세한 내용은 ../memory/README.md를 따른다.
