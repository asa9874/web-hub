# 기프트 원고·실행 계약 v1

`index.ts`는 9개 분야의 개별 집필 원고 200개를 기존 Gift 모델에 등록한다. 기존417개와 합쳐617개다. ID는 `gift-v1-<key>`이며 이름을 바꾸어도 ID를 재사용한다.

- 각 원고는 이름/기존 등급/원리/발동 범위/한계/활용 예시를 가진다. 설정 설명과 실행 효과를 구분한다.
- **실행4 / 부분1 / 대기195**. 실행4개만 신규 출생 추첨에 참여한다. 미연동 권능을 일반 수치 보정으로 대체하지 않는다.
- 실행: level-sea(공통 판정 운0), edge-toss(운 양극화), needle-verdict(관찰·제작 근소 성공 분류), testimony-anchor(중요 직접 기억 감쇠 완화).
- silent-proof는 제작 판정 API만 부분 연결되었고 실제 제작 행동 어댑터가 없으므로 출생 제외다.
- 구현 권위는 `systems/checks.ts`, `systems/npcMemory.ts`. 공통 판정의 기존 능력/숙련/비용/±15 보정 한도와 기억의 직접 인지·수동 망각·보존 한도를 유지한다.
- `legacy.ts`: 기존 ID/효과/영향력을 보존하고 8개 설명 개선, 16개 신규 생성 퇴역. `protectedIds.json`의 고정 인물 참조30개는 설정/효과/생성 정책까지 보존한다.
- 원문417개 구조 감사는 문학적 독창성 전수 검수를 의미하지 않는다. 비슷한 효과 구조 플래그도 동일 권능 확정 판정이 아니다.

검사: `npm run test:academy-gift-codex`. 보고: `docs/academy/GIFT_CODEX_V1.md`. 결과 원본은 `test-results/academy-gifts/`에 남긴다. 미래 어댑터 추가 시 도감 상태·출생 정책·실제 실행 테스트를 함께 갱신한다.
