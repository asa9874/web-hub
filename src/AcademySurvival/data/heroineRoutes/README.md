# 선택적 히로인 루트 v1

`serena.ts`는 기존 개인4사건에18개를 더하는 콘텐츠다. WorldEventDefinition/PersonalSceneDefinition, 기존 상호작용·대화·기억·관계·달력·저장을 재사용한다. 다른14명의 심화 루트는 등록하지 않는다.

조건/선택은 의향이며 성공·성장·약속 이행을 대신하지 않는다. 연애는 양방향 조건과 실제 고백 대화 완료가 필요하다. 일반 UI에는 현재 가능한 만남과 알려진 기록만 표시한다. 미구현 졸업/진로를 시간만으로 확정하지 않는다.

공통 계약과 실제 검사 범위: `docs/academy/SERENA_ROUTE_V1.md`. 검사는 `test:academy-personal-scenes`, `test:academy-serena-route`부터 선택한다. 4년/10년 전체 시뮬레이션을 기본 실행하지 않는다.
