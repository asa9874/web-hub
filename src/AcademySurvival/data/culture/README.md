# 종족·문화·생활양식 v1 계약

- `index.ts`: 기존 세계관 문화 ID를 유지한14문화 상세·28참고 인물상, 음식18/의복12/취미18/선물18, 관습24. 종족과 문화·계층·전공·가치관은 독립적이다. 언어 문법·생리적 식이 제한·정확한 축제 날짜는 확정하지 않는다.
- `events.ts`: 학내 소규모 문화 교류24종. 공통 세계 이벤트 조건/예산·같은 장소·실제 공동 활동·완료 결과를 사용한다. 공식 국가 축제의 전원 참석이나 세계 경제를 실행하지 않는다.
- `systems/cultureLife.ts`: 생성은 별도 시드 스트림. Character의 선택적 `culturalProfile`에 성장/현재 문화·친숙도·개인 선호·습관·관습별 마지막 시각/경험 횟수를 저장한다. 오래된/고정 인물에 새 정체성을 추정해 부여하지 않는다.
- 문화/선물의 의미는 `ConversationProposal.kind='culture'`로 공통 상호작용에 전달한다. 동일한 동의·의무 일정·이동·출입·활동 완료 증거를 검사한다. 4개 새 활동도 공통 일정/욕구 엔진의 실제 수행 구간을 사용한다. 새 생활 AI나 세계 시계를 만들지 않는다.
- 개인의 선호를 배경보다 크게 반영한다. 낯선 문화 자체는 관계 벌점이 아니다. 거절된 선물로 자동 호감을 얻지 않는다. 원격 편지 배달·실물 인벤토리·판매 수익·귀향 방문·진명 마법을 생성하지 않는다.
- 실제 완료 후에만 친숙도/개인 선호/습관을 갱신한다. 설명은 둘 중 한 명에게 실제 문화 친숙도가 있어야 한다. 경험의 원천은 공통 도메인 사건/기억에 기록하며 회상으로 관계 효과를 재적용하지 않는다.
- 문화 지식은 개인의 문화 이해 수준이며 특정 인물의 비밀을 알고 있다는 뜻이 아니다. 사적 관습의 내용은 당사자 선택과 기존 기억 공개 정책을 따른다.
- 활동 효용은 기존 AI에 제한 보정하며 의무·긴급 정책을 우회하지 않는다. 익힌 취미는 정밀 AI의 실제 장소 후보가 된다. LOD 정책과 원거리 미시 활동 생략 여부는 기존 계약을 따른다.
- 프로필은 고정 크기 카탈로그 키의 수치·횟수이며 무한 행동 배열을 저장하지 않는다. 기존600대화/기억·사건 보존/하루 대기/이벤트 예산을 재사용한다.
- 검사: `test:academy-culture`, `test:academy-culture-browser`, 관련 대화/세계 이벤트/생성/저장 단기 계약, 타입/빌드. 장기 문화 변화로 과거30/360일 결과의 현재 버전을 보증할 수 없으며 이번 장기는 미실행이다.
