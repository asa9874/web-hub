# 균열의 시대 v1 계약

전체 메인 스토리의 완성이 아니라 **기존 세계 안에서 실행되는 지역 집계 수직 슬라이스**다. 세계관/30사건 설계와 실행14사건을 구분한다. `index.ts`가 새 공식 설계 데이터이며 기존 마르카디아·마계의 지리/종족을 변경하지 않는다. 네르바는 별도의 물리 세계다. 네르바로 향하는 가짜 도보 연결이나 새 고정 학생은 만들지 않는다.

## 실행 범위

- 단일 절대 분 시계의 priority27 참가자. 새 회차는 `chronicle-v1`: 시작 후10~35일의 잠재 이상,120일 간격 최대3지역,427년7일/이후14일 평가. 별도 전조 예약도 같은 시계의 다음 경계에 포함한다. 날짜는 최소 준비 기간이며 실제 확장에는 자원·안정도·표본 조건이 필요하다. 기존 chronicle 없는 저장은 이전 일일 정책을 보존하고 `rift_chronology` 명령으로 미래만 전환한다.
- 실제 기존 지역/국가/관할 조직 ID. 초기 정책은 지역별 시드 선호이며 `investigate/defend/contain`이다. 국가 전체 정치 AI가 완성된 것은 아니다.
- 지역별 조사·방위·압력·크기·안정도·접촉·환경 피해·표본·신호·유한 대응 예산. 신규 위기 운영 예산은 지역90, 이계 세력180의 **집계 자원 단위**다. 기존 국고/아이템/인구 원장이 있다고 주장하지 않는다. 보급 무한 생성은 없다.
- 탐사체는 신호/환경 관측, 구축체는 실제 예산으로 통로 유지/확장과 환경 훼손, 호위체는 지역 방위와 시드 기반 집계 충돌을 수행한다. 통과는 단계별 일일 용량을 소비한다. 단계 용량은 잠재/미세0, 불안정3, 안정8, 관문16, 봉쇄0이다. 고정된 총 병력 수와 일일 통과량을 혼동하지 않는다.
- 이 충돌은 지역 전력 판정이며 가짜 Character를 만들거나 개별 NPC 전투/부상/사망/성장으로 기록하지 않는다. 대피 수치는 집계 구호 작업 단위이며 실제 NPC가 이동했다고 표시하지 않는다. 실제 주변 구조체 구체화·표적 전투는 후속이다.
- 개척총국만 초기 투입/유지 자원을 실제 사용한다. 교섭연합·보존의회·유실체는 공식 정의와 보유 상태까지다. 외교/통역/대표권/국가 간 전쟁/세력 정치 행동은 미구현이다.
- 봉쇄는 조사25/표본/지역 예산12 등 실제 조건을 요구하며 통과 용량/구축체를 정리한다. 봉쇄 이후 새로운 개체가 들어오지 않는다. 이미 남은 개체를 NPC 사망으로 바꾸지 않는다. 환경 피해는 별도 예산으로 복구해야 하며 봉쇄만으로 접근 제한이 풀리지 않는다.
- 봉쇄 뒤에도 보존 신호/표본 분석을 이어가며 언어 가능성의 단서를 얻을 수 있다. 침공 크기와 진실 발견은 별개다. 지성 문명 고유명/정치 구조/침공 이유(7~10단계)는 아직 발견시키지 않는다.
- 지역 봉쇄/복구 필요 상태는 실제 지역 결과다. 이를 세계 전체의 시대 결론으로 선언하지 않는다. 세계 결과5종·RIFT-30은 설계이며 자동 엔딩이나 졸업 처리를 호출하지 않는다.

## 공통 시스템 경계

- 실행된 지역 변화만 `worldEvents.recordRegionalOccurrence`로 기존 인스턴스·큐·DAG에 기록한다. 지역 집계 기록은 참가자0이며 private이다. 인물 효과·상호작용·자동 후속 트리거를 가질 수 없는 정의만 허용한다. 일반 인물 사건의 위치/출입/동의 규칙은 그대로다. 상태 변경은 균열 엔진이 소유하며 그래프 조회/개발자 사건 요청이 균열 상태를 변경하지 않는다.
- 실제 현재 현장 관측·조사 기록은 `RiftChanged` 도메인 사건으로 기존 기억 엔진에 들어간다. 당사자·실제 인지 가능한 목격자만 획득한다. 과거 위치로 목격자를 만들지 않는다. 기존 정보 공유/소문/망각/출처 정책을 재사용한다.
- 지역에 도착했을 때 현재 관측/현장 기록을 열람하는 것은 새로운 지각이다. 이동 중인 출발지 인물을 목격자로 취급하지 않는다. 의도는 실제 해당 장소를 알며 실제 성향이 맞는 NPC에게만 제공한다. 고정15인 전용 강제 배역이나 새 특수 재능은 없다.
- `rift_observation`은 실제 적합 장소·이동·30분 완료를 요구한다. 중단/허위 완료를 집계하지 않는다. 공통 일과/플레이어 직접 행동을 사용하고 독창 연구·논문·제작·XP를 가짜로 지급하지 않는다.
- 접근 통제는 `LocationWorld.setEnvironmentAccess`의 세계별 런타임 오버레이다. 공용 장소 카탈로그를 변형하지 않는다. 실제 경로/도착에서 검사하고 정책 갱신 시 해당 세계의 경로 캐시를 무효화한다. 정적 경로 캐시로 동적 통제를 우회하지 않는다. 기존 체류자를 임의로 추방하지 않는다.
- 일반 화면은 개인 기억의 관측/전해 들음/확신도만 표시한다. 비밀 지역의 좌표나 정치·미래 분기를 전지적으로 공개하지 않는다. 안전 통제는 원인명을 숨긴 실제 통행 제한이고, 지도에서 마력 이상 표시는 인지한 곳에만 붙인다.

## 저장·보존

`AiSandboxSave.riftCrisis` 선택 필드. 새 세계에는 연결하고 구형 저장은 `rift_initialize` 명령으로 현재부터 명시 연결한다. 과거 피해를 소급 생성하지 않는다. `rift_policy` 개발 명령은 명령 이력에 남는다. 시드·예약 시각·자원·구조체·지역 결과·진실·역사·중복 키를 저장하며 기존 기억/세계 이벤트와 함께 복원한다. RNG는 시드+지역+평가 시각으로 재현한다.

지역/세력 예산은 합계 보존을 검증한다. 중요한 이력은 최대256, 현재 콘텐츠는14종×3지역 이하이며 반복된 사소한 일일 처리를 역사로 쌓지 않는다. 현장 활동 중복 키는14일/최대180,000개로 제한한다. 중요 이력·현재 세계 상태를 지워 성능을 맞추지 않는다.

API: `getKnownSites/getDebugState/getIntents/setPolicy/save/diagnose/connect/disconnect`. `setPolicy`는 개발자 통제 API이며 플레이어에게 국가 대표 권한을 주는 기능이 아니다. 전체 범위·파일·검증: `docs/academy/RIFT_CRISIS_V1.md`.

## 연대기·전조 v1.1

`chronology.ts`:427~436년 기본 연대기/이후 자유 진행, 427년 5개 관측 창. 제국력360일 달력을 사용한다. 학사 모델은4년까지 정의되어 있으나 실제 졸업·진로 변경은 미구현이므로431년 학적 전환을 완료로 표시하지 않는다.

- 기본427년은6월까지 잠재,7월 이후 미세 교란,11월 이후 소형 탐사 개체가 가능하다. 구축체는 기본428년부터, 대형 관문은429년부터 누적 안정도/자원으로 허용한다. 기존에 형성된 매우 높은 압력80·안정도40·크기10은 조기 확대 예외다. 날짜만으로 침공을 보장하지 않는다.
- 연구 상한은427년12/428년30/이후100. 이미 높은 연구를 가진 구형 저장의 수치를 낮추지 않는다. 첫해에는 진실ID를 추가 발견시키지 않으며, 지성 가능성은429년 이후에도 실제 연구/신호 조건을 요구한다.
-5개 전조의 고유 ID/시각/지역/측정값/파형/세계 사건 ID를 기억과 별도로 보존한다. 물증은 실제 미세 교환 가능한 현장에만 기록한다. 미충족 또는 늦게 시작한 창은 미발생이며 소급 생성하지 않는다.
-428년 이후 연구15/실제 신호3 이상이면 현재 표본과 보존 파형·측정값을 비교하고 과거 사건→재검토 사건을 공통 DAG에 연결한다. 원격 NPC가 자동으로 그 결과를 아는 것은 아니다.
-현장 도착 또는 실제30분 이상 완료한 학사 활동을 통해 보존 자료를 현재 열람한다. 당시 목격자로 기록하지 않는다. 정보는 기존 공통 기억/상호작용을 통해 전달되고 원래 증거 식별자를 유지한다. 교수가 독창 논문을 작성하거나 별도 연구 계약을 수행했다고 가정하지 않는다.
-신규 저장은 정책/5개 예약/증거/후속 비교를 보존한다. 구형 저장은 개발자 화면에서 명시적으로 정책 전환하며 이미 발생한 사건/피해/기억을 되돌리지 않는다. 연대기 이후에도 종료 명령을 발생시키지 않는다.

검사·제약은 `docs/academy/RIFT_CHRONOLOGY_V1.md`. 지역 집계 연간 검사를100NPC 전체AI 연간 생활·성능 검증과 혼동하지 않는다.
