# 동아리·학생회 운영 v1

- `index.ts`:12동아리·학생회·3비공식 모임. 운영 정의는 정적 조직 도감의 영향력과 다르다. 기존 `academy-council`만 정식 소속 ID로 연결하며 동적 집단 ID를 정적 소속/직급 참조에 삽입하지 않는다.
- `systems/academyGroups.ts`: 회원/임원/안건/선거/시설 예약·실제 활동의 원천. 조직 자체의 신체·새 세계 시계·새 XP/기억 엔진은 없다. 활동은 기존 일과·이동·상호작용·효과를 사용한다.
- 운영 평가는 일1회 예약, 개별 집단 검토는 주1회. 참석 집계는 기존 시간 경계의 실제 위치·활동 구간만 계산한다. 매분 전체 조직×NPC를 판단하지 않는다. 시설은 예약 시간 중 배타 사용한다. 다른 기존 수업/약속 엔진 전체를 포괄하는 전역 시설 예약 서비스는 아직 없다.
- NPC는 최대2개를 자율적으로 고려하며 이는 자동 생활 부담 예산이다. 수동 복수 가입은 시간 충돌/정원/조건을 검증하며 임의의 개수만으로 거부하지 않는다. 성별·종족 가입 제한은 없다.
- 새 세계에는16개 빈 조직 정의가 생기지만 고정 인물의 가입/직책을 확정하지 않는다. NPC가 실제로 신청한다. 과거 저장에 `groups`가 없으면 조직을 덧씌우지 않고 연결 버튼으로 초기화한다.
- 선거는 등록/운동/투표/확정 단계. 해시 기반 동점 처리·NPC 개인 투표. 다른 NPC의 비밀 목표/기억은 후보 비교에 읽지 않는다. 일반 조회에서 개별 투표는 결과 확정 후에도 숨긴다. 플레이어 후보/투표/해산은 수동이다. 당선된 플레이어는 수락 대기 중 시간 진행을 정지한다.
- 조직 해산/탈퇴는 기존 인간관계·기억을 삭제하지 않는다. 교수/학적 자격 변화는 기존 캐릭터를 읽는다. 새로운 자동 졸업/입학생 대체 엔진은 구현하지 않는다.
- 최근600로그·120활동·12종료 선거·120종료 안건, 완료 목표12개를 보존한다. 미종료 기록과 회원/임원 이력은 유지한다. 종료한 조직 임시 일정은14일 뒤 정리하되 기존 활동 실행 이력은 보존한다. 세계 사건·개인 기억은 기존 정책을 따른다.
- `events.ts`:28개 상태 전이 신호를 공통 도메인/세계 사건으로 연결. 상태를 먼저 변경한 실제 직접 당사자에게만 신호를 내보내며, 세계 이벤트는 기존 효과를 재지급하지 않는다. 관계·숙련도 효과는 실제 공동 활동 엔진이 적용한다.

검사: `npm run test:academy-groups`, `node scripts/diagnose-academy-groups.mjs`, 변경 영향 기억/일과/세계 이벤트/스냅샷 검사. 상세 범위와 제한: `docs/academy/ACADEMY_GROUPS_V1.md`.
