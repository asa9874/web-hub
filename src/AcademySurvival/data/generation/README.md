# NPC 생성 엔진 v1 / 테스트기 인계

## 경계와 API

- 엔진: `systems/npcGeneration.ts` — React, DOM, 시간, 저장소, 전역 난수에 의존하지 않는다. 순수 시드 스트림과 주입된 카탈로그/규칙으로 공통 Character를 만든다.
- 기본 어댑터: `systems/npcGenerationContext.ts` — 실제 특성·기프트의 slotPool, 직급 충돌, 상태 makeInstance/applyStatus, validateCharacters, 기존 calculateCharacterImpact(v1)를 연결한다. 고정 인물은 이름 예약만 참조하며 수정하지 않는다.
- 프로필: `data/generation/config.ts`, `profiles.ts`. 학년 중심/성장 유형/전공/하위 성향/출생 개수 분포/배경·상태 근거/이름을 관리한다.
- 테스트 UI: `components/NpcGenerator.tsx`, 전용 `systems/npcGeneration.worker.ts`. 실제 게임 저장과 분리된 메모리 결과이며 화면을 벗어나면 폐기한다. Worker 취소/언마운트 정리를 제공한다. Vite의 global 별칭은 Worker에서도 유효한 globalThis를 사용한다.
- 통계: `systems/npcStatistics.ts`. 실제 반환 후보 전체를 집계한다. 실패한 최근접 후보도 포함하며 성공/유효성과 목표 달성률은 구분한다.

```ts
import {generateNpc, generateNpcs} from '../../systems/npcGeneration';
import {npcGenerationContext} from '../../systems/npcGenerationContext';

const request = {
  seed: 'academy-v1-audit', academyStudent: true,
  academyYear: 'random', specializationId: 'random',
  growthType: 'random', impactPreference: 'balanced',
} as const;
const one = generateNpc(request, npcGenerationContext);
const batch = generateNpcs({...request, count: 100}, npcGenerationContext);
// 100명 중 38번째를 독립 재생성: 나머지 NPC의 결과/시도 횟수에 의존하지 않는다.
const same = generateNpc({...request, startIndex: 37}, npcGenerationContext);
```

`GeneratedNpcResult`에는 공통 character, impact 계산 결과, success/valid/targetMet, 실제 attempts, index/하위 seed, 전공/성장/하위 성향/주숙련도, evidence와 diagnostics를 반환한다. `BatchGenerationResult`는 요청 스냅샷·루트 시드·엔진 버전·전체 결과를 가진다. 잘못된 요청이나 프로필은 구조화된 diagnostics를 가진 NpcGenerationError로 중단한다. 목표 불충족은 예외 대신 최근접 유효 후보와 warning을 반환한다.

진입: `/web-hub/games/academy-survival/?view=npc-generator`. 상단 **NPC 생성 테스트** 버튼에서도 이동한다. 수치 체계 탭에는 학년별 성장 기준을 추가했다.

## 생성 규칙

| 전공 | 주 능력치 | 주 숙련도 |
|---|---|---|
| 검술 | STR/AGI/VIT | 검술 |
| 마법 | MAG/INT/WIL | 화염/빙결/뇌전/비전 중 하나 |
| 궁술 | AGI/WIL/STR | 궁술 |
| 신성술 | WIL/MAG/CHA | 신성마법/치유 중 하나 |
| 연금술 | INT/MAG/WIL | 연금술 |
| 은신·단검 | AGI/STR/WIL | 은신/단검 중 하나 |
| 전술·지휘 | INT/CHA/WIL | 전술학/통솔술 중 하나 |

전공에는 지원 숙련도·특성 계열·기프트 관련 태그와 하위 성향이 있다. 검술은 중검/쾌검/수비검/마검, 마법은 고출력/술식 해석/안정 제어 등이다. 하위 성향은 수치 분포만 바꾸고 없는 특성을 자동 부여하지 않는다. 무관한 취미 숙련도는 0~1로 드물게 생성한다.

| 학년 | 평균 중심 | 주특기 경지 중심 |
|---|---|---|
| 1 | 30~45 | 1~2 |
| 2 | 40~55 | 2~3 |
| 3 | 50~65 | 3~4 |
| 4 | 60~75 | 4~5 |

이는 개인별 7종 평균의 분포 중심이며 모든 수치의 최소·최대가 아니다. 전공별 상관된 공통 기반 + 주/보조/비주력 편차 + 개인 오차 + 하위 성향을 사용한다. 생성용 수치 제한0~250은 설정에 있다. 영향력 계산기는 별도로0~200을 사용하며 원본을 변경하지 않는다.

성장 분포는 범재76 / 수재14 / 천재1 / 둔재7 / 이단아2의 가중치다. 평균 중심 편차는 각각0/+16/+45/−18/+4이며 주숙련도 편차는0/+1/+3/−1/0이다. 이단아는 비주력 능력치 하나에45 추가 편차를 가진다. 희귀 재능/경지 예외는 별도 낮은 확률이다. 신역은 일반 학생에게 강제하지 않는다.

특성 개수 기본98%/1.9%/0.1%, 기프트 개수87%/12.9%/0.1%는 기존 PROBABILITY를 복사해 사용한다. 기존 출생 적격성·조건·가중치·상호 배타를 통과한 후보만 사용하고 전공 적합성/성장/영향력/능력 경향/선호로 가중치를 조정한다. 출생 불가 상위 특성을 점수 때문에 풀에 넣지 않는다. 숙련도와 특성은 통계적 연관만 있으며 자동 동기화/진화는 없다.

학년 등록·입학·시민권, 무토지 귀족 신원, 학생회 선출·인준, 계약 연구원 채용, 첫 감독 실습, 유급 판정 등의 **생성 배경 근거**가 직급·칭호 부여를 허용한다. 선택한 근거와 자격 플래그를 evidence에 남기고 기존 도감 조건/소속별 충돌을 검사한다. 실제 사건 엔진이나 정치 시뮬레이션을 실행한 것이 아니다. 모든 고위 직급·칭호를 무작위 후보로 사용하지 않는다. 일반 비생도는 시민·계약 연구원 등 제한된 초기 배경만 지원한다.

신규 상태는 기본88% 없음이다. 나머지는 따뜻한 간식/격려/늦은 복습 근거와 연결된 소소한 행복·자신감·졸림 중 선택하고 실제 상태 적용/충돌 검사를 거친다. 심각한 저주·부상은 초기 프로필에 포함하지 않는다. 상태 효과를 원본 기본 능력치에 자동 합산하지 않는다.

## 시드 / 목표 영향력

FNV-1a + Mulberry32를 사용한다. 생략 시 고정 기본 시드 npc-v1-default, 빈 문자열은 별개의 유효 시드다. UI의 새 시드는 crypto로 만든 뒤 명시적으로 전달한다. 엔진에서 Math.random을 호출하지 않는다.

인물 스트림은 root/npc/index, 정체성 선택은 /identity, 수치·능력 재시도는 /attempt/n이다. 같은 요청·시드·인덱스·카탈로그·설정 버전은 같은 결과다. 학년/전공/성장/하위 성향/이름/나이/성별은 재시도 사이 유지한다. count 변경이나 다른 인물의 재시도가 해당 인물의 스트림을 소비하지 않는다. 이름은 예약 이름을 제외한600조합을 시드별 서로소 순열로 방문하여 기본 최대100명 안에서 중복되지 않는다. 카탈로그/프로필을 변경하면 같은 시드라도 결과가 바뀔 수 있으므로 장기 재현에는 해당 버전을 함께 보존해야 한다.

최대100명, 인물당16후보, 배치 예산1600후보다. maxBatchAttempts가 maxCount×maxAttempts보다 적은 설정은 오류로 중단한다. 요청을 완화하거나 학년/전공/성장 유형을 바꾸지 않는다. 후보별 기존 영향력 계산기로 평가하여 첫 충족 후보를 반환하고, 전부 실패하면 유효성을 우선한 범위까지의 거리 최소 후보를 반환한다. 같은 거리에서는 먼저 나온 후보를 유지한다. 평균 재시도는 실제 소비한 후보 수−1이다. 실패 진단은 유한 예산 안에서 못 찾았다는 뜻이며 수학적 도달 불가능 증명은 아니다.

전투/사회 성향은 관련 능력 후보·배경의 가중치를 바꿀 뿐 기존 영향력 산식을 바꾸지 않는다. 후보별 기프트 개수 확률은 유지하지만 목표 범위로 선별한 최종 표본의 기프트 비율은 조건부로 달라질 수 있다.

## 검증과 확장

- `npm run test:academy-npc`: 수량1/10/50/100·임의 인덱스,7전공/4학년/비생도, 실제 참조·배타·상태·대표·배경 근거, 전공/학년/성장 분포, 기본 기프트 비율, 동일 시드/부분 재생성, Math.random 금지, 재시도/최근접 결과, 실패 요청/프로필, 확률 설정 분리, 계산기 주입과 공통 상태창 SSR.
- `npm run test:academy-impact`: 기존 계산기와 상태창 회귀.
- `npm run test:academy-npc-browser`: Worker 실제1/100명, 시드 재현/상세 선택, 실패/잘못된 범위/비생도,390px, 성장 기준 표와 임시 결과 폐기. 같은 시드로 학년만 변경하는 재생성 시나리오는 NPC_TEST_CASE=refresh로 별도 확인한다.
- 기존 CI/테스트를 유지하고 NPC 단위 검사를 추가했다. 영향 없는 전체 게임 E2E는 생략한다. 테스트 원시 표본은 .build-projects/academy-npc-audit.json에 생성되며 빌드 임시 정리 시 없어질 수 있다. 위 표는 해당 시드의 검증 시점 기록이다.

새 전공은 profiles의 SpecializationProfile을 추가한다. 새 직업군은 현재 adult기준/BackgroundProfile을 바탕으로 별도 생성 요청·프로필 유형을 확장한다. 새로운 상태/직급/칭호는 반드시 실제 도감 ID와 배경·자격 근거를 추가한다. 새 공식은 context.calculateImpact를 교체한다. 관계·재산·평판·사건 이력·직업별 장기 성장과 실제 게임 등록은 아직 미구현이다. 현재 evidence는 생성 배경의 근거이며 실제 발생 이벤트 기록과 혼동하지 않는다.


### 최종 실행 검증 결과

NPC 단위 검사와 기존 영향력 검사는 통과했다. Academy 범위 ESLint와 TypeScript도 통과했다. 개발 서버의 변경 화면 시나리오 및 빌드 산출물 프리뷰에서 Worker 생성/학적 재생성 검사도 통과했다. 프리뷰는 같은 권한 실행 환경에서 서버와 브라우저를 함께 실행해 확인했다.

`npm run build` 통과:38프로젝트/39OG페이지/181로컬HTML·CSS참조 검증. 기존 `.animate-*` CSS 문법 경고와 큰 청크 경고는 남아 있다. Academy 청크757.48KB(gzip274.01KB), 생성 Worker673.25KB이며 Worker는 생성 버튼을 누를 때 로드한다. 번들 데이터의 추가 분할·압축은 후속 개선이다. 기존 도감 전체와 다른 게임의 장시간 E2E는 반복하지 않았다.


소속 확장으로 현재 프로필 버전은npc-generation-v1.1이다. 생성 근거의 affiliation grant와 공통 Character의 직접 가입/대표를 추가했다. 기존 능력·이름 난수는 유지한다. 학부/학생회/비생도 공동체/연구기관 연결과 가입 검증은 ../organizations/README.md를 따른다. 테스트기의 대량 표에도 대표 소속을 표시한다.


## v1.4 인간관계 결과

배치 생성은 `relationships`에 별도 희소 방향 그래프 결과를 반환한다. 단일 인물의 기존 반환 구조는 유지하고 `generateNpcWithRelationships`에서 인물과 그래프를 함께 받을 수 있다. 실제 전공 ID를 Character에도 보관하며 없는 반/거주지는 만들지 않는다. 기존 인맥은 context의 relationshipCharacters/relationshipOptions로 주입한다. [관계 생성 계약](../relationships/README.md) 참고.

## v1.5 일과표 결과

유효 NPC의 `CharacterSchedule[]`을 배치 결과 `schedules`에 반환한다. 원본 인물의 수치·위치를 바꾸지 않고 개인 계획을 별도 생성한다. 세계 등록 후 공통 일정 실행기가 자동 연결되며 명시적 계획을 주입할 수도 있다. 기본 시민 직무 미확정이나 거주지 미설정은 진단으로 유지한다. [일과표 계약](../schedules/README.md) 참고.
