# 세계관 데이터 v1 계약

- 진입점 `index.ts`: 6종족·19계통·3지리권·10정치 세력·12지역·33정착지/주요 지점·14문화권. ID 기반 참조이며 지리와 영토는 별개다.
- `seeds.ts`: 기존 장소/조직을 복제한 뒤 ID로 upsert한다. 재실행해도 중복되지 않는다. 고정 인물·위치 상태·시간·기억·관계는 수정하지 않는다.
- 마르카디아는 같은 행성의 동대륙(통칭 마계), 세피라는 군도다. 기존 정식 달력 ID `imperial`/`abyss`와 단일 세계 시계를 재사용한다.
- 장소 트리는 공간 포함 관계다. 외부 지점을 추가해도 이동 연결·거리·여행 시간·NPC를 자동 생성하지 않는다. 기존 33개 연결과 출입 규칙은 유지한다.
- `Character.worldIdentity`는 선택적 `world-lore-v1` 프로필. 종족·계통·출신·문화·국가 시민권·실제 소속/거주지는 독립적이다. 구형/고정 캐릭터는 미설정을 보존한다. 기존 도시 관할의 등록 시민 직급은 국가 시민권을 추론하는 근거가 아니다.
- 생성은 `systems/worldIdentity.ts`의 별도 시드 스트림. `WORLD_LORE_GENERATION`은 배경 빈도 설정이며 능력·선악·성향·기프트·사회적 소속의 종족 제한이 아니다.
- 수명은 일반 참고 범위다. 노화·사망·종족별 성인 연령 및 전공 제한을 실행하지 않는다. 미정 이름은 provisional, 기후/인구/좌표/언어/종교는 미설정이다.
- 초기 외교/갈등은 정적 배경이다. 실제 전쟁·국가 AI·거래·이벤트로 간주하지 않는다. 신규 국가 조직의 영향력은 미산정이다.
- 검증: `npm run test:academy-world-lore`, UI `npm run test:academy-world-lore-browser`. 정적 참조·생성·저장 변경은 관련 NPC/조직/장소 검사와 타입/빌드로 확인한다. 장기 시뮬레이션을 기본 실행하지 않는다.

구현/검증 범위 및 파일 목록: `docs/academy/WORLD_LORE_V1.md`.

문화 상세·개인 생활 연동은 `../culture/README.md`를 따른다. 기존10문화 ID는 보존하고4개 문화를 추가했다.
