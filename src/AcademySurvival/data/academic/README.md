# 학사 계약 v1

정의는 `index.ts`(86과목·공통 학사 규칙), 실제 실행은 `systems/academics.ts`, 선택적 저장은 `types/academic.ts`의 `academic-v1`이다. 실제 교수/강의실 자원을 사용하며 정의와 개설 강의를 구분한다. 학사 실행기가 없는 기존 저장은 기존 일과를 유지한다.

단일 시계·공통 이동/일과/효과·실제 교수와 학생의 수업 겹침·시드 선발·결과 멱등성·자기 성적만 공개하는 투영을 보존한다. 이벤트 정의2종은 세계 이벤트 카탈로그에서 실행한다. 신규 과목은 실제 숙련도 ID 또는 명시적 일반 능력치 과목만 사용한다.

변경 시 `test:academy-academics`, UI 변경은 `test:academy-academics-browser`; 중앙 계약 변경은 영향받는 플레이어/일과/효과/기억/세계 이벤트 검사를 추가한다. 장기 검사는 별도 목적을 명시한다.

구조·API·범위·검증·제한: [ACADEMICS_V1](../../../../docs/academy/ACADEMICS_V1.md).
