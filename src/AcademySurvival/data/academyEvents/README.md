# 공식 행사 v1 계약

- `index.ts`는6유형과9부스·16개 상태 신호·밸런스 설정이다. 학기 표창은6월/11월에 각각 열려 연간7회다. `systems/academyEvents.ts`가 연도별 실제 상태를 갖는다.
- 단일 시계의9단계에서 의도를 예약하고 기존 일과10·효과·전투23단계가 실제 실행한다. 수동 경기 중단 전에 전투 활동이 확정되므로 진행 경기 저장을 복원할 수 있다. 별도 시간/이동/승률/성장 엔진이 없다.
- NPC 등록은 학내 공지 열람과 실제 자격/숙련/성향/목표를 사용한다. 새로운 인물의 공지 대기 플래그도 저장한다. 다른 NPC 신청·비밀은 일반 조회에 공개하지 않으며 학외에 공지를 자동 배포하지 않는다.
- 참가 신청은 공식 대련에 대한 사전 동의다. `officialMatchId`는 행사 엔진이 현재 준비 중인 등록 경기/장소/양측 동의를 검증한 경우만 비살상 전투를 허용한다. 개발자 강제 전투로 우회하지 않는다.
- 대진은 최대16명, 최소2명,8강/16강과 부전승을 지원한다. 30분 슬롯과5분 체크인 유예. 시간 제한은 실제 잔여 내구 비율→가한 피해로 심판한다. 완전 동률은 양측 진출 없음이며 임의 우승자를 만들지 않는다.
- 플레이어는 경기60분 전 확인 후 실제 경로로 이동한다. 수동/자동은 기존 전투 UI와 같은 규칙이다. NPC별 전역 시간 증가나 순간이동은 없다. 수업/근무 충돌·부상·부재는 거부/기권 사유다.
- 부스는 실제 활성 동아리와 회원만 신청한다. 시설 예약과 중복 활동을 검사하고 준비/운영/방문은 실제 위치·활동의 정수 분을 집계한다. 방문자 체험은 운영자가 실제 운영하는 구간만 인정한다.
- 음악/제작/탐험 준비물이 없으면 축소/취소한다. 자작 발명품 원장이 없으므로FEST-04는 보류다. 공연 전문 평가와 연구 성과 심사도 별도 어댑터가 필요하다. 자료 설명·기초 체험의 공통 판정을 독창적인 발명/연구 성과로 부르지 않는다.
- 음식 나눔은 운영자의 실제 일반/고급 음식만 기존 선물/소유 원장으로 제안한다. 화폐 매출/제작/고등급 경품을 만들지 않는다. 기존 공동 활동·전투·기억 효과를 행사에서 중복 지급하지 않는다.
- `AcademicChanged`의 `official-*` 전이가 세계 사건과 개인 기억으로 이어진다. 결과 인지와 표현은 기존 출처·목격 정책을 유지한다. 고정15인 반응도 실제 결과를 아는 경우에만 기존 대사 선택기를 사용한다.
- 저장은선택적 `academyEvents`다. 구형 저장은 자동 삽입하지 않으며 `official_events_initialize`로 현재 이후만 연결할 수 있다. 인물 능력·성장을 바꾸지 않으며 과거 결과를 복원했다고 주장하지 않는다.
- 로그600개 상한. 연도별 공식 대진/결과 요약과 연결된 중요 전투 요약은 유지하고 전투 상세는 기존 보존 정책을 사용한다. 10년 전체 실행의 비용·저장 크기는 미검증이다.

검사: `npm run test:academy-official-events`, 관련 전투/대화/세계 사건/저장 검사. UI는 `test:academy-official-events-browser`로 실제 출전·이동·전투·대진과 격리 문화제를 확인한다. 장기 실행은 자동 기본값이 아니다. 결과와 제한은 `docs/academy/OFFICIAL_EVENTS_V1.md`를 따른다.
