# 공통 판정·전투 v1

진입: `systems/checks.ts`, `systems/combat.ts`, `types/{check,combat}.ts`. 원래 캐릭터의 능력치·특성·고정 설정은 수정하지 않는다.

- `data/checks`: 능력치 가중치/랭크 보정/±15점 상한/단일 정수 난수-10~+9/등급·난이도의 단일 출처. 등록된 숙련도와 실제 보유 랭크를 검사한다. 난수20개 전수 계산으로 확률 조회하며 세계를 변경하지 않는다. 난이도와 대항 중 하나만 허용한다.
- 기존 특성·기프트·상태의 실제 `STAT_MODIFIER`/점수형 `CHECK_MODIFIER`와 선언형 조건을 읽는다. %p와 점수, 고유 규칙 설명을 임의로 혼합하지 않는다. 아직 어댑터가 없는%p/특수 규칙은 미지원 내역에 표시한다. 상호 동의나 학점 계산을 단순 확률로 대체하지 않는다.
- 20개 기본 기술은 기존 검술/마력 제어/화염/냉기/번개/방벽/치유 숙련도로 해금한다. 장비·새 종족 마법·기프트를 임의로 생성하지 않는다. 초기 물리 공격은 공통 연습 검술을 모델링하며 모든 무기 장비를 지원한다는 뜻은 아니다.
- HP/SP/MP는 이 모듈이 최초로 추가하는 공통 자원이다. 캐릭터 정의에 두 번째 자원을 저장하지 않는다. 전투 경험이 없는 인물은 조회 시 최대 자원을 반환하지만 저장 상태를 만들지 않는다. 참여자만 기록하며 소모 후 휴식/수면의 실제 수행 구간에 따라 회복한다.
- 대련 피해는 `vitality`에만 적용하고 실제 HP는 보존한다. SP/MP는 실제로 소모한다. 실전은 실제 HP 손상과 기존 타박상 상태를 적용하며 사망·영구 장애를 만들지 않는다. HP0은 행동 불능이며 휴식/치유가 필요하다. 전투가 만든 타박상만 공통 시계의 만료 예약으로 해제한다. `status_remove.instanceId`는 다른 출처/부위의 상태를 보존한다.
- 전투1라운드는 공통 세계의1분이다. 같은 라운드에 각 참가자1주행동, 유료 방어 선언, 반격은1회, 사망 대신 전투 불능/항복/도주/최대20라운드 종료. 도주는 유효 경로와 판정 후 기존 이동 API를 사용한다. 별도 세계 시간은 없다.
- 기존 상호작용의 동의·출입·활동 예약을 유지한다. 수락된 `sparring`만 전투 드라이버로 연결하며, 실제 라운드가 끝나면 원래 상호작용의 성장·관계 보상을 실제 수행 시간으로 한 번 적용한다. 미연결 구형 세계는 공통 점수 판정으로 기존 간이 경쟁을 계속 처리한다. 실전 NPC 개시는 강한 적대/성향 또는 유효한 전투 사건 맥락을 요구한다. 개발자 강제 개시는 별도 중앙 명령으로 기록한다.
- 자동 AI는 자신의 능력/자원/성향/목표·관계와 현장에서 관찰한 기술/기억을 읽는다. 숨겨진 상대 능력으로 정밀 승률을 계산해 고르지 않는다. 자동과 직접 선택은 같은 라운드 엔진이다. 직접 행동 대기와 중요 전투는 시간 진행을 멈춘다.
- 최근 일반 전투120건, 상세 기록은 건당160행 상한이다. 중요 전투의 요약/최종 자원은 보존하고 상세 기록만 최근40건으로 제한한다. 부상 만료 참조가 있는 전투는 보존한다. 조회/상세 로그 설정은 RNG를 소비하지 않는다.
- `AiSandboxSave.combat`는 선택 필드다. 구형 저장은 자동 전투를 덧씌우지 않고 명시적으로 연결한다. 진행 중 라운드 경계/예약 행동/자원/시드와 안정 ID/원본 상호작용/부상 만료를 저장한다. 렌더링은 실제 상태를 쓰지 않는다.
