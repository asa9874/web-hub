# 콘텐츠 확장 01 — 특성 300개 / 기프트 300개 추가

기존 104개 특성과 100개 기프트를 유지하고 더했다. 총 **특성 404개, 기프트 400개**다. 레코드를 수량에 맞춰 복제하는 생성 루프를 사용하지 않았다. 아래 파일의 호출 하나하나가 이름·문학적 설명·효과·발동 또는 획득 경험을 별도로 작성한 항목이다. 헬퍼는 타입과 공통 추첨 설정을 제공할 뿐 이름이나 문장을 생성하지 않는다.

## 특성의 구성

| 파일 | 계열 | 추가 개수 | 의도 |
| --- | --- | ---: | --- |
| traitsMartial.ts | 야전 전술 / 병장기 운용 | 50 | 무기의 종류뿐 아니라 후퇴·보급·엄호·장비 안전의 역할 차이 |
| traitsMagic.ts | 물질 마법 / 의식술 | 50 | 화력 상승 대신 재료·온도·잔재·시전 중단·동의와 대가 |
| traitsBodyMind.ts | 몸의 버릇 / 내면과 감정 | 50 | 체질의 장단점, 감각 과민, 공포 대처, 자기 돌봄 |

신규 계열 12개를 포함해 전체 계열은 49개다. 독립 기술을 한 계열에 넣었다는 이유로 상호 배타 처리하지 않는다. `index.ts`에 명시한 29개 발전 경로만 이전/이후를 상호 배타로 지정한다. 예: 발표 긴장→첫 문장의 연습, 과잉 준비→짐을 줄이는 능력, 음성 시전 어려움→손짓 시전. 부정 특성도 단순 수치 손해로 끝내지 않고 보완 경로와 활용 상황을 마련했다. 의학적·심리적 특성은 진단/회복/지원이 필요한 경우를 명시하며 훈련이 모든 특성을 없앤다고 가정하지 않는다.

## 기프트의 구성

10분류에 **각 30개씩** 추가했다. 각 항목의 발동 문장은 추상적 수사가 아니라 대상·상황을 제한한다. 고유 규칙은 효과량, 횟수/쿨다운, 불가능한 일까지 별도 기록한다.

| 분야 | 서로 다른 활용 예 |
| --- | --- |
| 전투 | 깨진 방패의 얼굴 파편만 막기 / 먼지로 이동 거리 비교 / 진정한 항복 시 보고 |
| 생존 | 젖은 성냥 마지막 한 개 / 동료가 가진 바늘 방향 / 통로 공기 경고 |
| 정보 | 창 앞 통과 인원 / 신발 이동량 / 원고의 작가 이음매 |
| 관계 | 대화 거절 의사 표시 / 동의한 서약을 자유롭게 해제 / 옛 생일 축하의 녹음 |
| 운명 | 실패의 주체 구분 / 사소한 흠집 위치만 이동 / 무가치한 꼴찌 기념품 |
| 시간·공간 | 무게나 부피를 늘리지 않는 수납 편의 / 시간 대신 시계 모래만 멈춤 / 작은 거리 이동 |
| 기억 | 만료된 암호 확인 / 손에 남은 무게감 / 정답이 아닌 자기 오자 복원 |
| 저주·축복 | 해제가 아닌 저주 지연 / 대가 미고지 이의 / 마계 통행증 발급 권한 |
| 경제·사회 | 비밀 투표 내용 없이 재투표 잉크 확인 / 상자와 짐표의 분리 / 공동 취수량 |
| 일상 | 말없이 한숨 쉬는 나무 포크 / 쓸데없는 감자 표정 / 마감 제출의 색종이 |

확장 당시 구 척도(0~100)의 영향력 95 이상은 **새로 추가하지 않았다**. 이후 사회 도감 통합에서 0~1000 메타데이터로 전환했으며, 현재 등급은 data/social/README.md의 분포를 따른다. 국가·지역 규모 능력도 효과가 확인해 주는 사실과 확인 못 하는 사실을 좁게 구분했다. 초월적인 이름으로 무조건 진실을 알아내거나 법적 권한·감정·동의를 만들어내지 않는다.

## 품질 검토와 검증

- 정확히 +300/+300, 기존 ID 보존, 전체 804개 이름·문학적 설명 중복 없음.
- 발동 조건·획득 경험을 각 항목에 작성했고, 일반 효과의 모든 타깃에 한국어 표시명 추가.
- 고유 규칙의 목적은 서로 다르며, 공통 판정으로 표현 가능한 능력은 기존 CHECK/STAT/UNLOCK/가중치 효과를 활용했다. 보통 효과의 **조건을 제외한 구성**도 비교했다. 공통 시간 추정 보정을 공유하는 ‘새벽을 놓치지 않는 코’와 ‘늦었다는 정확한 말’은 각각 자연 새벽의 시각 추정과 익숙한 길의 도착 예상으로 발동·사용 목적이 다르다. 공통 엔진의 같은 보정을 사용한다는 이유만으로 불필요한 고유 엔진 코드를 만들지는 않았다.
- 2만 회 시작 추첨, 상호 배타, 가중치 합, 발전 참조/순환, 효과 단위와 중복 해석 검사 통과.
- 반대 부호를 가진 같은 능력치 효과가 서로 다른 조건에 있을 때 사라지지 않도록 STAT 효과 ID에 수치를 포함했다. 동일 소스의 같은 효과 중복 적용 방지는 유지한다.
- 기존 게임 전체 브라우저 E2E는 실행하지 않는다. 이번 변경은 콘텐츠/데이터 정의와 관련 검증 범위다.

자동 검사는 독창성과 문학성을 보증하지 않는다. 이름/설명/발동/범위/제약이 왜 다른지를 분류별로 검토했다. 실제 이벤트 실행이나 밸런스 플레이 테스트가 끝났다는 뜻은 아니다. 모든 이벤트는 여전히 예정이며 SPECIAL_RULE의 실행 어댑터는 후속 본게임 작업이다.
