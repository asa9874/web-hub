# 성장·사회적 이력 계약

`systems/lifeProgress.ts`는 기존 효과·Goal·개별 지식 위의 기록/투영이다. XP·능력치·관계·정보 전파·이동을 직접 변경하지 않는다. 카탈로그는30업적/25생활 목표다. 미지원 연구·제작·졸업 조건을 성공으로 바꾸지 않는다.

- 성장 권위: `data/actionEffects/config.ts`, `systems/actionEffects.ts`. 기존 잔여 XP·피로/환경·경지 감쇠·능력치200/경지9 규칙을 유지한다. 새100상한, 플레이어 전용 배율, 목표 보상은 없다. 기존 저난도 반복에 대한 **강제 성장 자격 구분은 추가하지 않았다**.
- 기존 `goals` 자동 생성 풀은 그대로다. 선택 생활 목표만 공통 `goalRegistry`에 추가한다. 플레이어 선택은 공통 Goal 상태/AI 의도를 사용하고 선택 시점 근거를 분리한다. 지원되지 않는 외부 조건은 미설정으로 유지한다. 기한 만료는 기존 `failed`와 이유로 표현한다.
- 성장 변경은 적용된 실제 결과를 월별 집계하고 대표 출처3개를 보존한다. 최대144개월. 완료 활동은 실제 일과 실행 이력과 대조한다. 사소한 전역 성장 사건을 추가 발행하지 않는다.
- 업적은 실제 전투/학사/행사/조직 원장을 확인한다. 최초 업적과 연도별 공식 성과를 구분한다. 동아리 정기 활동의 매 회차는 누적 근거로 집계하고 최초 업적을 무한히 쌓지 않는다. 업적을 얻어도 추가 XP/아이템/허가는 없다.
- 사건 처리 키는14일/최대180,000개이며 초과 시 오류다. 성장/증거 조회는 인덱스, 중복 업적은 집합으로 처리한다. 일·주·월 활동 보고는 최근31개 달력 날짜의 희소 집계이며 월별 성장 표시는 기간과 겹치는 월이다. 정확한 시간 범위 보고와 혼동하지 않는다.
- 평판은 현재 보유한 구조화 주장/확신도의 읽기 전용 투영이다. 기억의 분야·공식 근거 종류·정식 대련 승패가 전달 주장에도 보존된다. 같은 주제의 가장 강한 현재 근거를 사용한다. 믿음은 세계 사실/업적을 변경하지 않는다. 회상 시 효과를 재적용하지 않는다.
- 개인 평가는 관계5지표와 별개인 실력/성실성/협력/책임 평가다. 조직 평가는 승인된 조직의 실제 활동 기여와 권한자 존재만 사용한다. 조직 전체 구성원의 속마음을 합의된 평가로 만들지 않는다. 고급 조직 심사 규정은 미구현이다.
- 인지도는 지역·분야별 현재 실제 정보 보유자의 비율로 개발자 조회 시 집계한다. 외부 전파를 새로 수행하지 않는다. 일반 플레이는 공개된 본인 성과와 실제 조직 활동 기여만 보여주며, NPC별 내부 점수/정확한 전파 인원은 감춘다. 전달된 세부 평판 피드백 UI는 후속이다.
- AI 보정은 알려진 상대에 대한 기존 사회 후보에 최대±8점만 반영한다. 정보 리비전/시각별 조회 캐시로 같은 후보의 반복 검색을 줄인다. 현재 장소·동의·일정·실제 LOD가 여전히 실행 자격을 결정한다. 전용 연구/제작 제안을 새로 만들지 않는다.
- `AiSandboxSave.lifeProgress`는 선택 필드다. 새 효과 세계에는 연결하며 구형 저장에는 자동으로 과거 이력을 만들지 않는다. 공통 상태창의 명시적 연결부터 기록한다. 격리 시뮬레이터도 같은 엔진/상태창을 사용한다.

API: `getGrowth/getReport/getAchievements/getRenown/getAssessments/getOrganizationAssessments/getBias/getOpportunities/selectGoal/abandonGoal/getGoalDetail/save/diagnose`. Goal 우선순위/일시정지/실패 API는 기존 Motivation 엔진을 사용한다.
