# 아카데미 콘텐츠 작업

- 먼저 README.md를 읽는다. 본게임 이전의 데이터·도감 범위이며 이벤트/전투를 도감 안에서 흉내 내지 않는다.
- 이름을 바꿔도 ID를 유지한다. 특성 진화는 ID로 연결하며 기프트에 진화/단계를 추가하지 않는다.
- 문학적 설명과 기계적 효과 정의를 분리한다. 시스템 문구는 effectText에서 생성한다.
- 퍼센트포인트, 판정 점수, 발생 가중치를 섞지 않는다. 영향력은 확률/전투 보정에 자동 적용하지 않는다.
- SPECIAL_RULE은 고유 규칙 정의와 발동 키를 함께 등록한다. 공통 효과로 표현 가능한 것은 공통 타입을 쓴다. 실행 어댑터가 없는 규칙을 실제 게임 동작이라고 보고하지 않는다.
- 예정 이벤트는 planned 표시를 유지한다. 실제 실행 엔진이 생기기 전에는 기획 참조다.
- 능력치·숙련도 정의는 data/knowledge에서 관리한다. 공통 구간/경지 이름만 공유하고 개별 설명을 기술명 치환 템플릿으로 생성하지 않는다. 정의 변경은 test:academy-knowledge도 수행한다.
- 숙련도와 특성은 독립적이다. 자동 획득·진화·동기화를 넣지 않는다. 숙련도 경험치 임계값은 미확정(null)을 유지한다. 관련 효과 대상의 열람용 참조와 실제 수치 변환을 구분한다.
- 상태는 data/statuses/README.md 계약을 따른다. 상태 정의 수와 단계·좌우 부위를 따로 센다. 정의/인스턴스를 분리하고 상태 변경 시 test:academy-status를 수행한다. 부위 효과를 전신 판정에 자동 합산하지 않으며 상태 경로·자원 변화율·고유 규칙 정의를 실제 사건/시간 실행으로 가장하지 않는다.
- 캐릭터는 data/characters/README.md 계약과 공통 Character/CharacterStatusPanel을 사용한다. templateId나 kind로 숨겨진 수치 보정·상한·효과를 만들지 않는다. 미리보기에서 회차 슬롯을 추첨하지 않는다. 변경 시 test:academy-character와 영향받는 도감 데이터 검사만 실행한다.
- 직급·칭호/영향력은 data/social/README.md를 따른다. impact.baseImpact는 버전이 있는0~1000 요소 평가이며 효과·추첨 가중치에 합산하지 않는다. 최종 캐릭터 점수는 별도 characterImpact.ts와 버전 설정에서만 계산하며 변경 시 test:academy-impact를 실행한다. 같은 기관 ID+배타 직위 슬롯만 충돌시킨다. 칭호의 사실·인지·보존 상태와 대표 표시는 분리한다. 영향 범위 변경 시 test:academy-social을 실행한다.
- 콘텐츠/확률/효과 변경은 test:academy와 빌드로 검증한다. 시각 변경은 루트 정책대로 빌드만 수행한다. 필요한 화면/입력 확인은 새 도감 시나리오로 한정한다.
- 모든 게임의 장시간 E2E를 자동 반복하지 않는다. 검증 결과 및 생략 범위는 README/작업 보고에 기록한다.

- NPC 생성은 data/generation/README.md를 따른다. UI/엔진/프로필을 분리하고 명시적 시드만 소비한다. 출생 적격성·배타·상태·직급 조건을 우회하지 않으며 생성 배경 근거를 기록한다. 목표 미충족은 제한 시도 후 최근접 후보와 진단을 반환한다. 고정 인물·게임 저장을 변경하지 않는다. 변경 시 test:academy-npc와 영향받는 계산/상태창 검사만 실행한다.

- 소속은 data/organizations/README.md 계약을 따른다. 정식 조직과 기존 직급 관할 범위를 구별하고 임의로 타국을 제국 아래 편입하지 않는다. 직접 소속/대표/비밀, 직급의 지위, 칭호, 국적/거주는 독립적이다. 조상 중복을 저장하지 않으며 조직 영향력을 캐릭터v1에 합산하지 않는다. 변경 시 test:academy-organizations와 영향받는 캐릭터/NPC/직급/계산 검사만 실행한다.

- 성향·도덕·카르마는 data/dispositions/README.md를 따른다. 기존 personality/tendencies 소개 문장을 성향 ID로 자동 확정하지 않는다. 기존 인물은 미설정 호환, 신규 생성은 유효한1~3개를 강제한다. 도덕은 내면, 카르마는 행적이며 평판/영향력과 독립적이다. 카르마 변경은 불변 레코드와 사유/적용량을 남기며 실제 사건 판정으로 가장하지 않는다. 배타 관계의 대칭·유효 참조와 독립 시드 스트림을 유지한다. 변경 시 test:academy-morality와 영향받는 생성/상태창/영향력 검사만 수행한다.

- 시간·달력은 data/calendars/README.md를 따른다. 제국력·심연력과 월별 학사 기본 일정은 공식 설정이다. 단일 절대 분을 저장하고 날짜/JS Date/현실 타임존을 기준 상태로 사용하지 않는다. 테스트 시계를 게임 시계와 섞지 않는다. 큰 진행은 전체(from,to] 구간을 전달하고 중간 예약을 임의로 생략하지 않는다. 학년/NPC/상태를 시간 엔진이 자동 갱신하지 않는다. 변경 시 test:academy-time과 관련 조직/시계 UI만 우선 검증한다.

- 장소·이동은 data/locations/README.md 계약을 따른다. 포함 계층/이동 그래프/조직은 분리하고, 활성 캐릭터의 현재 위치는 공통 Character.location에서 관리한다. 출입 조건은 구간 출발·실제 도착에서 검사하고 모든 NPC는 단일 세계 시계를 사용한다. 강제 배치는 샌드박스 전용이다. 변경 시 test:academy-locations와 관련 NPC/시간/상태창 검사만 수행한다.

- 인간관계는 data/relationships/README.md 계약을 따른다. 희소 방향 그래프를 공통 엔진에서 관리하며 서술형 관계를 수치로 임의 변환하지 않는다. 사실 유형의 역방향만 원자적으로 유지하고 감정은 복사하지 않는다. 일반 UI는 공개 범위를 먼저 필터하고 샌드박스 기록은 실제 세계와 분리한다. 변경 시 test:academy-relationships와 관련 캐릭터/NPC/장소 검사만 수행한다.

- 일과표는 data/schedules/README.md 계약을 따른다. 계획·의도·실행을 분리하고 공통 시계 예약/실제 이동·도착 검사를 사용한다. 강제 배치는 샌드박스에 한정하며 일과표 엔진 안에서 능력치·욕구·관계를 직접 변경하지 않는다. 실제 활동에 따른 욕구 적분은 별도 욕구 엔진에 위임한다. 변경 시 test:academy-schedules와 영향받는 시간/이동/상태창 검사를 수행한다.

- 욕구·목표는 data/motivations/README.md 계약을 따른다. 구간 시작 문맥과 정밀 정수 누적을 보존하며 후보를 직접 실행하지 않는다. 진행도와 실제 달성 조건을 구분하고 미구현 조건의 NOT을 참으로 취급하지 않는다. 고정 인물의 미확정 공식 목표를 추첨하지 않는다. 저장은 시각/참조/누적값 검증과 실행 예약을 포함하며 변경 시 test:academy-motivations와 관련 시간/일과/생성/상태창 검사를 수행한다.

- 자율 행동 AI는 data/ai/README.md를 따른다. 일과·욕구·시간·이동 엔진을 복제하지 않는다. 인지 범위 밖 상대 위치를 선택에 사용하지 않으며 공동 활동은 양쪽 수락·실행 상태를 확인한다. 의무/긴급·최소 유지·실패 대기와 동일 시각 재계획 제한을 유지한다. 변경 시 test:academy-ai와 영향받는 일과/욕구/상태창 검사를 우선한다.
- 기능 노트는 data/features 레지스트리와 실제 증거를 함께 수정한다. 이름·주석만으로 완료를 표시하지 않는다. 기존 통과 기록과 이번 실행을 구분하고 새 계획은 제안으로 표시한다. 변경 시 test:academy-features를 수행한다.

- 상호작용은 data/interactions/README.md, 행동 결과는 data/actionEffects/README.md를 따른다. 공유 인스턴스·실제 동일 장소·동의·활동 완료를 검사하고 AI의 별도 사회 실행기로 중복 처리하지 않는다. 시간 기반 욕구와 완료 보상을 분리하고 결과 ID·저장 원장으로 멱등성을 유지한다. XP는 도감 null 임계값과 별개인 버전별 런타임 규칙이며 고정 인물 보정/특성 자동 진화는 없다. 변경 시 test:academy-interactions 및 관련 일과·욕구·AI 검사를 수행한다.
