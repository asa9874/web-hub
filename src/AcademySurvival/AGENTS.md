# 아카데미 콘텐츠 작업

- 먼저 README.md를 읽는다. 본게임 이전의 데이터·도감 범위이며 이벤트/전투를 도감 안에서 흉내 내지 않는다.
- 이름을 바꿔도 ID를 유지한다. 특성 진화는 ID로 연결하며 기프트에 진화/단계를 추가하지 않는다.
- 문학적 설명과 기계적 효과 정의를 분리한다. 시스템 문구는 effectText에서 생성한다.
- 퍼센트포인트, 판정 점수, 발생 가중치를 섞지 않는다. 영향력은 확률/전투 보정에 자동 적용하지 않는다.
- SPECIAL_RULE은 고유 규칙 정의와 발동 키를 함께 등록한다. 공통 효과로 표현 가능한 것은 공통 타입을 쓴다. 실행 어댑터가 없는 규칙을 실제 게임 동작이라고 보고하지 않는다.
- 예정 이벤트는 planned 표시를 유지한다. 실제 실행 엔진이 생기기 전에는 기획 참조다.
- 콘텐츠/확률/효과 변경은 test:academy와 빌드로 검증한다. 시각 변경은 루트 정책대로 빌드만 수행한다. 필요한 화면/입력 확인은 새 도감 시나리오로 한정한다.
- 모든 게임의 장시간 E2E를 자동 반복하지 않는다. 검증 결과 및 생략 범위는 README/작업 보고에 기록한다.
