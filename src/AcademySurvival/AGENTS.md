# 아카데미 작업 진입점

- 먼저 `docs/academy/PROJECT_CONTEXT.md`를 읽고 관련 경로만 조사한다. 긴 README 전체를 매번 읽지 않는다.
- 아이디어 노트의 의도와 실제 코드의 차이를 확인한다. 모순은 최신 확정 설정과 실제 구현을 확인해 판단하며, 확정 세계관·캐릭터 설정·핵심 규칙·플레이어 자유도·NPC 자율 생활과 관계·기억/정보/사건의 인과관계·중요 콘텐츠를 보존한다. `docs/academy/IMPLEMENTATION_STATUS.md`와 기능 레지스트리는 탐색 안내이며 코드·검증을 대체하지 않는다.
- `docs/academy/TASK_PROTOCOL.md`의 변경 영향 기반 검증 절차를 따른다. 기존 테스트와 CI는 보존한다. 장기 실행은 목적·수량·기간을 명시한 경우에만 수행한다.
- 자동 선택은 `npm run validate:changed`의 계획·이유를 확인한 뒤 `-- --run`으로 실행한다. 중앙 계약/분석 실패의 승격을 임의로 축소하지 않는다. 정확한 CLI·재현·결과 재사용/미실행 구분은 `docs/academy/VALIDATION_V1.md`를 따른다.
- 관련 시스템의 `data/*/README.md` 계약을 읽는다. 이전 상세 지침은 `docs/academy/SYSTEM_CONTRACTS.md`에 보존했다. 해당 시스템 항목만 읽으며 이 파일의 진입·검증 절차를 우선한다.

## 장기 플레이·성능

- 최소 제국력 10년(3,600일), NPC 100명 이상의 전체 AI가 활성화된 반자동 세계 시뮬레이션을 설계 기준으로 삼는다. 재미·자유도·사용 편의와 실제 세계 실행까지 확인하며, 데이터·UI 구현이나 테스트 통과만으로 장기 플레이 가능성을 확정하지 않는다.
- 시간 점프는 핵심 플레이 기능이다. 아래 v1.1은 대표 플레이 환경에서 NPC 100명 전체 AI가 활성화된 응답 속도 **목표**이며 현재 달성 기록이 아니다. 7일은 3초 이내를 우선하고 1초는 도전 목표다.

| 진행 | 목표 | 경고 |
| --- | --- | --- |
| 1시간 | 0.3초 이내 | 1초 초과 |
| 8시간 | 1초 이내 | 2초 초과 |
| 1일 | 1~2초 이내 | 5초 초과 |
| 7일 | 1~3초 이내 | 5초 초과 |

- 측정은 수업·교류 다수·시험/행사·세계 이벤트 시나리오별로 환경·시드·누적 기간·활성 시스템, 평균/느린 사례, 행동·사건·기억·관계 변화량과 미달 시 개선 방향을 남긴다. 미구현 행사나 짧은 구간을 실제 주간 실행으로 표시하지 않는다.
- 7일 목표는 선택 개입 없이 전체 기간을 진행한 경우다. 중요 선택 시 정확한 시점에 중단하고 실제 진행 시간·사건 수를 별도 기록한다. 엔진 단독 측정과 UI를 포함한 실제 플레이 응답을 구분한다.
- 내부 시간은 분 단위 정밀도를 유지하되 매분 전체 NPC 계산을 요구하지 않는다. 관련 사건을 보존하는 이벤트 기반 처리·LOD·캐싱·증분 계산을 검토하고, 누적 연산량·기억/사건 데이터·저장 크기와 UI 응답성을 함께 관리한다. 새 기능의 기존 시스템 비용도 판단한다.
- 성능 목표를 맞추기 위해 AI·기억·관계·세계 이벤트·중요 사건을 임의로 생략하거나 비활성화하지 않는다. UI 양보·백그라운드 실행이나 테스트 범위 축소를 실제 연산 비용 개선으로 보고하지 않는다.
- 사용자 시간 진행은 시간·일·주·다음 중요 일정 중심으로 설계하며 플레이어 선택이 필요한 사건에서는 자동 진행을 중단한다.

## 공통 불변식

- 이름과 ID를 분리한다. 공통 Character·상태창과 기존 엔진을 재사용하고 종류/템플릿별 숨은 보정이나 고정 인물의 미확정 설정을 추가하지 않는다.
- 단일 절대 분 시계, 시드 기반 결정성, 전체 시간 구간의 중간 이벤트, 저장 참조·버전·멱등성을 보존한다. 테스트 상태와 실제 세계를 격리한다.
- 능력치·기초 숙련·스킬·기프트, 소속·직급·칭호, 세계 사실·기억·믿음을 구분한다. 스킬은 실제 행동·수련·선행 숙련/경험을 확인해 습득·진화하며 플레이어의 전문 분기는 직접 선택한다. 기프트 자체의 성장·진화는 넣지 않는다. 구형 trait ID는 저장·참조 호환용으로 보존한다.
- 문학적 설명과 기계적 효과를 분리한다. 확률/퍼센트포인트/가중치를 혼용하지 않으며 영향력을 전투·확률 보정에 자동 합산하지 않는다. SPECIAL_RULE 실행 어댑터 유무를 구분한다.
- 실제 이동·출입·동의·활동 완료를 검사한다. AI가 시간·욕구·일과·사회 엔진을 복제하지 않으며 활동 효과·회상 보상을 중복 적용하지 않는다.
- 일반 UI의 비밀·개별 지식을 먼저 필터한다. 현재 위치로 과거 목격자를 만들거나 인지 범위 밖 상대 위치를 AI 판단에 사용하지 않는다.
- 계획·데이터 정의·실행·검증을 구분한다. 예정 이벤트를 실제 실행으로 보고하지 않으며 미구현 조건의 NOT을 참으로 처리하지 않는다.
- 변경 기능의 구현 현황과 검사 결과를 갱신한다. 기존 통과 기록과 이번 실행, 미실행 범위를 구분한다. 관련 없는 정리·전체 재작성은 하지 않는다.
- 세계 이벤트는 `data/worldEvents/README.md`를 따른다. 도메인 기록/정의/인스턴스를 분리하고 시간·순번 DAG, 실제 참여·출입·상호작용, 결과 멱등성·비밀·통합 저장을 보존한다. 연결된 과거 사건을 소급 삭제하지 않는다. 변경 시 `test:academy-world-events`와 관련 통합 검사부터 수행한다.
